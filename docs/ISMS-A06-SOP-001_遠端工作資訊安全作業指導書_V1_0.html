1. 作業目的

本作業指導書用於規範組織人員於公司核准場域以外執行遠端工作時之資訊安全控制要求，確保遠端工作不因人員、設備、網路、物理環境、雲端協作、資料傳輸、第三方支援或跨境存取而降低資訊之機密性、完整性、可用性、可追溯性與合規性。

本文件提供遠端工作申請、核准、設備配置、身份驗證、網路連線、雲端工具、資訊處理、視訊會議、列印與紙本、PII資料處理、AI工具使用、事件通報、監控稽核、退場與持續改善之完整作業要求，以支援ISO/IEC 27001:2022 Annex A.6.7「Remote working」及相關控制措施落地。

2. 作業原則

  • 遠端工作應基於業務必要、風險評估、授權核准、最小權限、受管設備、安全連線、可監控及可稽核原則。
  • 遠端工作不得成為規避存取控制、資訊分類、資料傳輸、雲端服務使用、AI資料使用、事件通報或文件化資訊管制要求之例外。
  • 處理機密、高機密、PII、客戶資料、源碼、金鑰、事件證據、稽核證據、合約限制資料及GHG/ESG查證資料時，應使用公司核准設備、核准通道及核准平台。
  • 遠端工作環境應避免未授權人員窺視、拍攝、旁聽、接觸、複製或取得組織資訊。
  • 組織得基於資安、法遵、稽核、事件調查、營運持續與合約要求，對遠端工作相關設備、帳號、連線、雲端活動與安全告警進行合理監控。

3. 名詞與定義

名詞 定義
遠端工作 人員於公司核准辦公場域以外，以網路、雲端服務、遠端桌面、VPN、ZTNA、行動設備或其他方式存取、處理或傳輸組織資訊之工作模式。
混合辦公 人員於公司場域與遠端場域交替工作之模式，包含固定週期、臨時核准或專案性安排。
受管設備 由組織核發或納入MDM/EDR/硬碟加密/修補管理/組態基準/資產清冊之設備。
BYOD Bring Your Own Device，人員使用自有設備執行工作。除經核准並納入受控條件外，原則上不得用於處理機密以上或受限制資料。
VPN Virtual Private Network，透過加密通道連線至組織網路或系統之技術。
ZTNA Zero Trust Network Access，依身份、設備狀態、風險、位置、應用與最小權限原則授予存取之遠端存取架構。
VDI / DaaS Virtual Desktop Infrastructure / Desktop as a Service，透過集中管理之虛擬桌面提供遠端工作環境。
公共工作環境 咖啡廳、機場、車站、飯店大廳、共享辦公空間、客戶接待區或其他可能被非授權人員接觸或觀察之場所。
肩窺風險 未授權人員透過近距離觀看螢幕、文件、鍵盤輸入或會議內容取得資訊之風險。
遠端工作Owner 對遠端工作安排、存取範圍、設備、工作地點、風險控制與合規證據負責之角色，可為主管、HR、IT或資訊安全指定角色。

4. 角色與責任

角色 主要責任
最高管理階層 核准遠端工作策略、重大例外、跨境遠端工作、高風險剩餘風險接受與必要資源。
CISO / 資訊安全負責人 制定遠端工作資訊安全要求，核准高風險遠端存取、例外使用與重大安全措施。
ISMS管理代表 維護本SOP，整合遠端工作風險、控制有效性、稽核、KPI/KRI、CAPA與管理審查輸入。
HR / 人員控制措施Owner 管理遠端工作資格、承諾書、教育訓練、異動、離職、紀律與人員合規要求。
直屬主管 確認遠端工作業務必要性、工作內容、存取需求、成果管理與人員遵循狀況。
IT營運主管 確保遠端工作設備、帳號、VPN/ZTNA、協作工具、端點防護、備份與支援流程符合要求。
Endpoint Security Owner 維護端點基準、硬碟加密、EDR、防惡意程式、修補、MDM、設備遺失處理及健康狀態檢查。
Network Security Owner 管理VPN、ZTNA、專線、網路分段、遠端存取政策、連線日誌與異常偵測。
Cloud Security Owner 審查遠端工作使用之雲端服務、協作平台、資料分享、CASB/DLP、條件式存取與雲端日誌。
SOC 監控遠端連線、端點、帳號、DLP、CASB、SIEM與異常行為告警，處理事件與通報。
DPO / PIMS負責人 審查遠端工作涉及PII、跨境存取、資料主體權利、DPIA、DPA與隱私事件之要求。
法務 / 法遵 確認遠端工作之勞務、跨境、客戶合約、保密、監控告知、資料保護與外部法規要求。
使用者 依本SOP保護設備、帳號、資料、文件、會議與工作環境，通報異常、遺失、外洩或違規事件。

5. 遠端工作核准分類

類型 適用情境 最低核准要求 資安控制基準
一般混合辦公 依組織政策固定或週期性居家辦公，處理一般內部資訊與核准業務系統。 主管核准，HR登錄，完成資訊安全承諾與訓練。 受管設備、MFA、VPN/ZTNA、硬碟加密、EDR、DLP與雲端協作平台。
臨時遠端工作 因出差、天候、交通、健康、突發事件或短期需求遠端作業。 主管核准；超過一定天數或涉及敏感資料時需IT/資安確認。 與一般混合辦公相同；必要時限制存取敏感系統。
高敏感工作遠端執行 處理高機密、PII、客戶機密、源碼、金鑰、財務、事件證據、稽核證據或受監管資料。 主管、Data Owner、CISO或DPO核准。 VDI/受控環境、禁止本機下載、加強DLP、Session Recording、限制地點與網路。
第三方遠端支援 供應商、顧問、維運人員遠端連線至組織系統。 業務Owner、IT、資安及供應商管理核准；必要時法務審查。 PAM/跳板機、MFA、時段限制、最小權限、錄影/日誌、到期撤權。
跨境遠端工作 人員於不同司法管轄區存取、處理或儲存組織資訊。 主管、HR、法務、DPO、IT與CISO核准。 跨境風險評估、資料分類限制、地區封鎖/允許清單、合法依據與日誌保存。
緊急遠端工作 災害、疫情、公共安全、機房中斷、辦公室不可用或BCP啟動期間。 BCMS/管理階層授權，事後補登核准與風險接受。 ICT備妥性控制、優先恢復清單、關鍵人員備援、強化監控與事件回報。

6. 遠端工作申請與核准流程

步驟 作業內容 責任角色 輸出/證據
1. 需求提出 申請人提出遠端工作期間、地點、工作內容、需存取系統、資料分類、設備與是否跨境。 申請人 / 直屬主管 遠端工作申請紀錄。
2. 業務必要性確認 確認遠端工作是否符合職務需求、客戶承諾、服務水準、資料處理與作業時效要求。 直屬主管 主管核准紀錄。
3. 資安風險判定 依資料分類、系統敏感度、工作地點、設備狀態、網路環境與使用者角色判定風險等級。 資訊安全 / IT / Data Owner 遠端工作風險判定紀錄。
4. 控制措施確認 確認設備、MFA、VPN/ZTNA、EDR、DLP、MDM、備份、日誌、資料分享與會議控制已就緒。 IT / Endpoint / Network / Cloud Security 設備與存取核准紀錄。
5. 法務與隱私審查 涉及PII、跨境、客戶限制、供應商、錄影監控或受監管資料時，完成法務/DPO審查。 法務 / DPO DPIA/DPA/法務審查紀錄。
6. 人員承諾與訓練 確認申請人已簽署保密與資訊安全承諾書，完成遠端工作資安訓練並了解事件通報要求。 HR / ISMS管理代表 承諾書、訓練紀錄。
7. 正式核准與開通 核准遠端工作期間、地點、系統、權限、限制事項與到期日，並開通必要存取。 主管 / IT / CISO 核准通知、權限開通紀錄。
8. 定期複核 定期確認遠端工作必要性、設備狀態、權限、異常紀錄、地點變更與合規情形。 主管 / HR / IT / 資安 複核紀錄、CAPA紀錄。
9. 結束與撤銷 遠端工作結束、職務異動或離職時撤銷不必要權限，回收設備與資料，完成檢核。 HR / IT / 主管 / 使用者 離職與異動資安檢核表。

7. 遠端工作環境安全要求

控制項目 作業要求 禁止事項 證據
工作地點 優先於居家、核准共享辦公室、客戶核准場域或其他可控制環境工作。 不得在可能被旁聽、拍攝或干擾之環境處理機密以上資訊。 遠端工作申請紀錄、地點聲明。
螢幕保護 公共或半公共環境應使用防窺片，離席時鎖定螢幕，避免肩窺。 不得將螢幕長時間暴露於未授權人員可見範圍。 訓練紀錄、抽查紀錄。
文件保管 紙本文件應收納於可上鎖空間，機密以上文件應避免攜出或列印。 不得將機密文件留置桌面、車內、飯店房間或共享空間。 文件借出/歸還紀錄。
語音與會議 視訊或電話會議應確認周邊無未授權旁聽者，必要時使用耳機。 不得在公共場所討論高機密、PII、客戶事件或安全弱點細節。 會議紀錄、資安宣導紀錄。
家庭成員與訪客 應避免家人、訪客、同住者接觸公司設備、文件、螢幕或會議內容。 不得讓非授權人員使用公司設備、帳號或網路通道。 承諾書、稽核抽查。
設備實體保護 設備應隨身保管或置於上鎖空間；外出住宿時不得留於無保護區域。 不得將設備托交未授權人員保管。 設備盤點、遺失事件紀錄。
清潔桌面與清潔螢幕 遠端工作結束時應收妥文件、登出系統、鎖定設備、清除白板與暫存資料。 不得保留未必要之本機副本、照片或截圖。 自評檢核、抽查紀錄。

8. 設備與端點安全要求

控制項目 最低要求 高敏感情境加強要求 證據
設備來源 使用公司核發或核准受管設備，設備需列入資產清冊。 高機密、PII、大量客戶資料或事件證據應使用公司核發設備或VDI。 資訊資產清冊、設備核發紀錄。
硬碟加密 筆電、行動設備與可攜式儲存設備需啟用全碟加密。 不得關閉加密；例外需CISO核准並記錄剩餘風險。 加密狀態報告。
EDR/防惡意程式 端點需安裝並啟用公司核准EDR、防惡意程式及即時防護。 事件調查、高權限帳號與管理員設備應納入強化監控。 EDR主控台報告。
修補管理 作業系統、瀏覽器、VPN、協作工具與安全軟體需依修補時限更新。 重大漏洞應依緊急變更或資安公告期限完成。 修補合規報告。
組態基準 啟用螢幕鎖定、密碼政策、防火牆、USB限制、日誌、瀏覽器安全設定與自動更新。 限制本機管理員權限、剪貼簿、截圖、列印與下載。 組態合規檢查。
MDM/MAM 行動裝置需納入MDM/MAM，支援遠端鎖定、抹除、合規檢查與公司資料容器。 處理PII或機密資料之行動裝置需禁止本機未加密儲存。 MDM合規報告。
本機資料 原則上避免將機密以上資料下載至本機；必要時需加密、限制期限並清除。 高機密或受限制資料應透過VDI/DMS處理，禁止本機副本。 DLP紀錄、清理紀錄。
設備遺失 設備遺失、遭竊、疑似被接觸或被惡意軟體感染時，應立即通報。 涉及PII、客戶資料或高機密資料時立即啟動事件回應與法務/DPO評估。 事件通報紀錄、遠端抹除紀錄。

9. 身份驗證、帳號與遠端存取控制

控制領域 作業要求 禁止事項 證據
MFA 遠端存取、雲端服務、VPN/ZTNA、管理介面、協作平台與郵件均應啟用MFA。 不得共用MFA裝置、轉傳一次性密碼或核准非本人登入請求。 身份平台MFA報告。
最小權限 遠端工作權限應依職務、期間、系統、資料分類與地點限制授予。 不得因遠端工作而授予超出職務必要之權限。 權限申請與審查紀錄。
條件式存取 依設備健康、地理位置、登入風險、IP信譽、使用者風險與應用敏感度控制存取。 不得允許不受管設備或高風險登入直接存取敏感系統。 條件式存取政策。
VPN/ZTNA 遠端連線應使用核准VPN/ZTNA，並限制可達網段、應用與服務。 不得使用私人VPN、未核准代理、Tor或規避地區限制之工具。 VPN/ZTNA日誌。
PAM與跳板機 遠端管理伺服器、網路設備、雲端管理介面或高權限系統需透過PAM/跳板機。 不得直接以個人設備連至管理介面或共用特權帳號。 PAM申請、Session Recording。
工作階段管理 閒置逾時、強制重新驗證、異常登入告警與Session終止機制應啟用。 不得長時間保持未監控之登入工作階段。 平台政策與日誌。
帳號異動 職務異動、專案結束、遠端工作結束或離職時，應依檢核表撤銷或調整權限。 不得保留過期遠端存取或第三方帳號。 權限撤銷紀錄。

10. 網路與連線安全要求

連線情境 允許條件 安全要求 限制
居家網路 可使用，但應採用受密碼保護之Wi-Fi、更新路由器韌體並避免預設密碼。 使用WPA2/WPA3、強密碼、訪客網路隔離、VPN/ZTNA與端點防護。 不得將公司設備連至未知IoT或不安全內網共享資源。
手機熱點 可用於出差或臨時替代連線。 熱點需設定強密碼，工作完成後關閉熱點。 避免在高敏感作業中使用不穩定熱點造成資料不完整。
公共Wi-Fi 僅限低敏感工作或緊急情境；需使用VPN/ZTNA並確認憑證。 禁止自動連線，避免未知Captive Portal，使用防窺與耳機。 不得處理高機密、PII大量資料、金鑰或管理作業。
共享辦公網路 需經主管核准；處理敏感資訊時需確認環境與網路保護。 VPN/ZTNA、設備防火牆、避免區域網路共享、使用安全DNS。 不得使用共享電腦、共享印表機或不受控會議設備處理敏感資料。
客戶或供應商網路 出差或專案需要時可使用。 不得關閉公司安全代理，必要時隔離客戶網路與公司通道。 不得將公司設備接入未核准維運網段或插入未知網路設備。
