1. 程序目的

本程序用於規範組織如何識別、建立、維持、評估與改善資訊安全相關能力、認知與教育訓練，確保所有在ISMS控制下工作之人員具備其職務所需能力，理解資訊安全政策、資訊安全目標、個人責任、控制要求、不符合後果及通報義務，並能有效支持資訊安全管理系統之建立、實施、維持與持續改善。

本程序為ISO/IEC 27001:2022 Clause 7.2 Competence與Clause 7.3 Awareness之核心證據，並支援Clause 7.1資源、7.4溝通、7.5文件化資訊、8.1運作控制、9.1績效評估、9.2內部稽核、9.3管理審查及10.2矯正措施要求。

3. 名詞與定義

名詞 定義
能力 人員基於教育、訓練、經驗、技能、證照或實務表現，能有效執行指定工作並達成預期結果之能力。
認知 人員對資訊安全政策、目標、責任、風險、控制措施、通報義務及不符合後果之理解與自覺。
教育訓練 透過課程、工作坊、演練、宣導、線上學習、實作、測驗或輔導，使人員取得或維持必要能力之活動。
能力矩陣 用以定義各角色所需能力、現有能力、缺口、訓練計畫與有效性結果之矩陣。
角色別訓練 依職務、權限、風險與控制責任設計之差異化訓練。
有效性評估 確認訓練或能力建置是否實際提升知識、技能、行為、控制成效或績效結果之活動。
關鍵角色 對ISMS運作、風險處理、控制有效性、事件應變、隱私、AI、復原、GHG/CO2資料治理、稽核或合規具有重大影響之角色。
訓練豁免 因人員已具備同等能力、證照或經驗，而經核准可免參加特定訓練之情形。
再訓練 因測驗不合格、事件、違規、不符合、角色變更或控制失效而需補強之訓練。
