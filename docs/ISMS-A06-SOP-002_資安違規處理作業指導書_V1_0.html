1. 作業目的

本作業指導書用於規範組織對資訊安全違規、疑似違規、未遵循控制措施、疏失、濫用授權、違反保密義務、違反資料保護要求、違反雲端與AI工具使用要求、違反遠端工作規範、未依程序通報事件及其他可能影響資訊安全管理系統有效性之行為，進行接收、分類、調查、證據保存、風險評估、處置、矯正、紀律、溝通、申訴、結案與持續改善。

本文件同時確保違規處理符合公平、一致、比例、保密、合法、可追溯、證據完整及避免報復原則，使人員控制措施可支援ISO/IEC 27001:2022 Annex A.6.4「Disciplinary process」、A.6.3「Information security awareness, education and training」、A.6.8「Information security event reporting」及A.5.24至A.5.28事件管理控制要求。

2. 作業原則

  • 所有資安違規處理應以事實、證據、風險、影響、情節、意圖、重複性、角色責任與法規合約要求為判斷基礎。
  • 違規調查不得以臆測、歧視、報復、偏見或未經授權之個人資料蒐集為依據。
  • 處置措施應符合比例原則，並依違規嚴重度、造成或可能造成之資訊安全影響、是否主動通報、是否配合調查及是否有改善可能進行決定。
  • 涉及重大事件、PII、客戶資料、營業秘密、智慧財產權、金鑰、特權帳號、AI系統、雲端環境、供應鏈、跨境資料或主管機關通報要求者，應升級至CISO、法務、DPO、最高管理階層或事件應變團隊。
  • 違規處理相關紀錄、證據、訪談內容、日誌、截圖、調查報告、紀律決議及申訴資料應視為機密或更高等級資訊，依保存期限與存取授權管理。

3. 名詞與定義

名詞 定義
資安違規 違反資訊安全政策、程序、作業指導書、承諾書、合約、法規、控制措施、授權條件或管理要求之行為，包括蓄意、重大過失、疏忽或未依規定作業。
疑似違規 尚未確認是否構成違規，但已有通報、告警、稽核發現、主管反映、系統日誌、DLP/CASB/EDR/SIEM告警或其他跡象顯示可能存在不當行為。
紀律處理 依組織人事規章、勞動契約、供應商合約、承諾書、法規及本SOP，對已確認違規行為採取提醒、教育、警告、權限限制、調職、停權、契約處置、求償、解約或移送法務等措施。
重大違規 可能或已造成重大機密性、完整性、可用性、隱私、法規、營運、客戶、聲譽、財務、驗證或監理影響之違規行為。
調查Owner 負責規劃、協調、執行或督導資安違規調查之角色，可由HR、CISO、法務、ISMS管理代表或事件應變負責人指定。
被調查人 被通報、被告警、被稽核發現或被合理懷疑涉及資安違規之人員、供應商或第三方代表。
通報人 提出資安違規或疑似違規通報之人員，可為員工、主管、稽核員、供應商、客戶、SOC、DPO或其他利害關係人。
數位證據 與違規判斷有關之日誌、郵件、檔案、截圖、系統設定、存取紀錄、端點影像、網路封包、雲端稽核紀錄、聊天紀錄、權限異動紀錄或其他電子資料。
保全措施 為避免證據滅失、風險擴大、資料外洩、權限濫用或營運中斷，於調查前或調查中採取之帳號凍結、權限限制、設備保管、連線阻斷、資料隔離或備份保存措施。
申訴 被處置人對違規事實認定、程序、處置比例或權益影響提出復核或異議之程序。

4. 角色與責任

角色 主要責任
最高管理階層 核准重大違規處置、重大剩餘風險接受、重大外部通報策略、資源配置及涉及高階主管或重大合規風險之最終決策。
CISO / 資訊安全負責人 判定違規對資訊安全之影響，核准資安保全措施、事件升級、技術調查範圍、控制改善與重大資安處置建議。
HR / 人員控制措施Owner 依人事制度主導人員違規處理、訪談安排、紀律程序、教育要求、紀錄保存、申訴受理與員工權益保護。
法務 / 法遵 審查法律風險、勞動程序、合約責任、保密義務、求償、外部通報、證據可採性與可能之民刑事或行政責任。
DPO / PIMS負責人 評估違規是否涉及PII、資料主體權利、跨境、DPIA、DPA、隱私事件與主管機關或資料主體通知。
ISMS管理代表 確保違規處理紀錄納入ISMS證據鏈，追蹤CAPA、控制有效性、稽核發現、管理審查輸入與文件更新。
SOC / 事件應變團隊 蒐集與保存技術證據，分析告警、日誌、端點、雲端、網路、DLP、IAM與SIEM資料，支援封鎖、隔離與事件處理。
IT / IAM / 系統Owner 依核准執行帳號停用、權限調整、設備回收、系統設定保存、備份、重置、修補與技術改善。
直屬主管 通報疑似違規，提供工作脈絡，確認業務影響，執行管理處置，追蹤人員改善與復職/復權條件。
內部稽核 獨立檢視違規處理程序、證據完整性、控制有效性、矯正措施與再發防止成效。
供應商管理 處理承包商或供應商人員違規之合約通知、權限限制、服務改善、求償、退場或替換要求。
全體人員 遵守政策與承諾，立即通報違規或疑似違規，保存相關資訊，不得破壞證據、串證、報復或隱匿事件。

6. 違規嚴重度分級

等級 判定條件 處理時限 最低參與角色 可能處置方向
L1 輕微違規 未造成實質影響，屬首次或低風險疏忽，例如未依規定標示一般內部文件、短時間未鎖定螢幕但未發生存取。 5個工作日內完成初步處理。 直屬主管、HR或ISMS管理代表。 提醒、補訓、書面紀錄、控制再宣導。
L2 一般違規 違反明確規範但未造成重大外洩或營運中斷，例如使用未核准工具處理內部資料、未依流程申請權限。 3個工作日內完成初判，10個工作日內完成處置建議。 主管、HR、資訊安全、IT。 書面警告、權限調整、強制訓練、改善追蹤。
L3 重大違規 涉及機密資料、PII、客戶資料、特權帳號、雲端資源、AI工具或事件延誤通報，已造成或可能造成重大影響。 24小時內升級，5個工作日內提出調查計畫。 CISO、HR、法務、DPO、SOC、系統Owner。 停權、調職、正式懲處、事件應變、外部通報、CAPA。
L4 嚴重/蓄意違規 蓄意外洩、破壞、竊取、刪除證據、規避偵測、持續違規或造成重大營運、法規、客戶或財務影響。 立即升級並採取保全措施。 最高管理階層、CISO、HR、法務、DPO、事件應變團隊。 解除契約、求償、法律行動、主管機關通報、全面控制改善。
L5 危機級違規 導致或可能導致重大系統癱瘓、重大資料外洩、監理重大事件、跨國媒體關注、重大客戶損害或刑事風險。 即時啟動危機處理與BCP/IR程序。 危機管理小組、最高管理階層、CISO、法務、DPO、BCMS、外部專家。 危機應變、外部溝通、法遵通報、重大懲處、管理審查與治理層級改善。

7. 資安違規處理流程

步驟 作業內容 責任角色 輸出/證據
1. 接收通報或告警 接收來自主管、員工、SOC、DLP、SIEM、EDR、CASB、稽核、客戶、供應商或匿名通報之疑似違規資訊。 HR / CISO / SOC / ISMS管理代表 通報紀錄、告警紀錄、初始事實摘要。
2. 初步分類 判定是否為資安違規、事件、稽核缺失、人事爭議、隱私事件、供應商違約或其他案件。 調查Owner / CISO / HR 案件分類紀錄、嚴重度初判。
3. 保全措施 必要時暫停帳號、限制權限、保存設備、封存日誌、保存雲端稽核紀錄、避免證據滅失或風險擴大。 CISO / SOC / IT / HR / 法務 保全核准紀錄、權限異動紀錄、證據保存紀錄。
4. 調查計畫 定義調查範圍、問題、證據來源、訪談對象、角色分工、時程、保密要求與法律注意事項。 調查Owner / HR / 法務 / CISO 調查計畫、證據清單、訪談安排。
5. 事實查核 蒐集日誌、郵件、檔案、存取紀錄、設備資料、雲端紀錄、會議紀錄與相關人員說明。 SOC / IT / HR / 法務 / 系統Owner 證據包、訪談紀錄、事實時間線。
6. 影響與風險評估 評估CIA影響、PII影響、客戶影響、合約影響、營運影響、法規通報、聲譽與剩餘風險。 CISO / DPO / 法務 / 風險Owner 影響評估、風險評估、通報判定。
7. 違規判定 依事實、政策、程序、承諾書、合約與法規判定是否成立違規、違規等級與責任歸屬。 HR / CISO / 法務 / 管理階層 違規判定紀錄、審查會議紀錄。
8. 處置決議 決定紀律措施、權限措施、合約措施、教育訓練、矯正措施、補救措施與外部通報。 HR / CISO / 法務 / 最高管理階層 處置決議、通知紀錄、CAPA計畫。
9. 執行與追蹤 執行處置、完成權限調整、設備回收、教育訓練、控制改善、供應商改善或法律行動。 HR / IT / CISO / 主管 / 供應商管理 執行紀錄、訓練紀錄、權限異動證據。
10. 結案與改善 確認處置完成、風險降低、矯正有效、紀錄歸檔、管理審查與稽核輸入。 ISMS管理代表 / 調查Owner / 內稽 結案報告、事件檢討報告、管理審查輸入。

外部傳輸阻斷 疑似持續外洩、惡意上傳、未授權雲端同步或大量寄送。 CISO / SOC / Network Security Owner 防火牆、DLP、CASB或郵件阻擋紀錄。
供應商連線暫停 第三方帳號異常、供應商違反合約、未授權遠端支援或第四方疑慮。 CISO / 供應商管理 / 業務Owner 連線停用紀錄、供應商通知。
文件與實體資料保管 涉及紙本機密、簽署文件、外部儲存媒體、列印資料或受控文件。 HR / 法務 / ISMS管理代表 文件交接、封存與盤點紀錄。
