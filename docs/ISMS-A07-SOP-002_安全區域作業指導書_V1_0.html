1. 作業目的

本作業指導書規範安全區域之分級、識別、設計、門禁控制、訪客管理、陪同、CCTV監控、警報、保全巡檢、環境控制、設備與文件保護、供應商進出、施工管制、清潔與維護、事件處理、例外管理、稽核與持續改善要求，確保組織資訊資產、資訊處理設施、文件化資訊、個人資料、客戶資料、系統運作與營運持續能力受到適當之實體安全保護。

安全區域控制應以風險為基礎，依區域處理之資料分類、資產重要性、業務關鍵性、可接觸人員、外部威脅、環境威脅與合規要求建立不同等級之防護措施，並與人員安全、資產管理、存取控制、訪客管理、桌面與螢幕淨空、支援設施、事件管理及營運持續流程整合。

2. 作業原則

  • 安全區域應依風險分級，採取與資訊價值、業務影響、資料敏感度與威脅程度相稱之實體安全控制。
  • 所有安全區域應有明確Owner、用途、邊界、進出規則、授權角色、監控要求、巡檢頻率與文件化紀錄。
  • 進入Restricted或Critical安全區域應採授權、識別、門禁、陪同、紀錄與必要監控，不得任意尾隨、代刷、借用門禁卡或共享存取權限。
  • 訪客、供應商、清潔人員、施工人員與臨時人員不得未經授權進入安全區域；必要時應全程陪同或採補償控制。
  • 安全區域平面圖、門禁權限、CCTV涵蓋、警報設定、機房位置與保全路線屬敏感資訊，應依文件分級控管。
  • 安全區域缺失、異常進出、門禁失效、CCTV失效、未授權人員、設備遺失、可疑物品或環境威脅應立即通報並依事件或設施程序處理。

3. 名詞與定義

名詞 定義
安全區域 依資訊安全、實體安全、營運或合規需求設置邊界、進出控制與防護措施之實體場所。
公開區域 訪客或一般人員可接觸之區域，例如接待區、公共走道或公開展示區。
內部區域 僅限員工或授權人員進入之一般辦公區域。
受限區域 保存或處理較敏感資訊、重要設備或業務流程，需門禁或授權控制之區域。
關鍵區域 若遭未授權接觸、破壞或中斷將造成重大資訊安全、營運、法規或客戶影響之區域，例如機房、資料中心、網路設備間、SOC或備份媒體庫。
區域Owner 負責安全區域用途、風險、進出授權、日常管理、巡檢、缺失改善與審查之角色。
尾隨 未經授權人員跟隨授權人員通過門禁或進入安全區域之行為。
雙人控制 特定高風險區域或作業須由兩名授權人員共同進入、執行或見證之控制。
訪客陪同 訪客或非區域授權人員進入安全區域時，由授權人員全程陪伴與監督之控制。
實體安全邊界 牆面、門、鎖、圍欄、隔間、機櫃、門禁、警報、CCTV、保全或其他界定與保護安全區域之措施。

Facility Owner 維護安全邊界、門、鎖、隔間、消防、照明、環境與支援設施。 維護紀錄、設施檢查。
Area Owner / 區域Owner 管理區域用途、授權人員、訪客、資產、資料保護、日常檢查與缺失改善。 區域清冊、授權名單。
IT Operations / Data Center Owner 管理機房、弱電間、網路設備間、伺服器與資訊處理設施進出與維護。 機房進出紀錄、設備紀錄。
HR / Line Manager 確認人員職務、離職異動撤權、教育訓練與違規處理。 人員授權與撤權紀錄。

Security Guard / 保全 執行巡邏、門禁異常處理、訪客管制、CCTV初步監看與緊急通報。 巡邏紀錄、異常紀錄。
Supplier / Contractor 遵守進出、陪同、拍照限制、工具管制與資料保護要求。 NDA、進出與作業紀錄。
Internal Auditor 抽查安全區域清冊、門禁授權、進出紀錄、CCTV、巡檢、例外與改善。 稽核底稿。

5. 安全區域分級與最低控制要求

區域等級 典型區域 最低控制要求 禁止或限制事項
Level 0 公開區域 接待區、公共走道、公開展示區。 訪客活動範圍清楚，避免可接觸內部文件、螢幕、設備或未遮蔽資訊。 禁止放置未遮蔽內部文件、客戶資料或可進入內部區域之未受控通道。
Level 1 內部區域 一般辦公區、員工座位區、一般會議室。 員工或授權人員進入，訪客需登記或陪同；落實桌面與螢幕淨空。 禁止未授權訪客自由進入或拍攝。
Level 2 受限區域 客服、HR、財務、法務、研發、列印區、文件保存室、供應商駐點區。 門禁或授權進入，進出可追溯；資料分類、螢幕防旁觀、文件保管與訪客陪同。 禁止未授權人員單獨停留、翻閱文件或使用設備。
Level 3 高安全區域 機房、弱電間、網路設備間、備份媒體庫、SOC、監控室。 具名授權、門禁紀錄、CCTV或等效監控、必要陪同、定期審查權限與巡檢。 禁止尾隨、代刷、借卡、未核准工具/媒體與未登記維護。
Level 4 關鍵安全區域 資料中心、核心機房、金鑰/密碼保管區、高敏感研發區、災備核心區。 最小授權、雙因素或雙人控制、CCTV保存、警報、訪客全程陪同、變更/維護核准、事件即時升級。 禁止未核准拍照、未核准遠端/實體作業、單人高風險維護或未記錄進出。
臨時安全區域 施工區、專案隔離區、活動設備區、臨時儲存區。 明確邊界、Owner、期限、告示、進出控制、資產清冊與退場計畫。 禁止逾期、無標示、無Owner或未清場。

6. 安全區域建立、變更與撤除流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 提出新增、變更、升級、降級、擴張、縮減或撤除安全區域需求。 Area Owner / Facility / IT 申請單。
2. 風險評估 評估資料分類、資產重要性、威脅、訪客接觸、環境、營運持續與法規要求。 Security / Facility / Area Owner 風險評估。
3. 分級決定 依安全區域分級標準決定Level與最低控制要求。 CISO / Physical Security 分級紀錄。
4. 控制設計 設計門禁、鎖具、CCTV、警報、隔間、標示、訪客動線、儲存與巡檢要求。 Facility / Physical Security 控制設計。
5. 權限設定 建立授權角色、授權名單、進出時間、例外流程與撤權規則。 IAM / Physical Security / HR 權限設定紀錄。
6. 文件更新 更新安全區域清冊、平面圖、門禁點、CCTV點位、巡檢表與作業程序。 Document Owner 文件更新紀錄。
7. 啟用驗收 測試門禁、CCTV、警報、照明、消防、環境與進出流程。 Facility / Security / Area Owner 驗收紀錄。
8. 定期審查 定期審查區域用途、授權名單、事件、巡檢缺失與風險等級。 Area Owner / Security 審查紀錄。
9. 撤除或降級 撤除前需清場、回收權限、移除資料與設備、更新清冊與圖資。 Facility / Area Owner 撤除紀錄。

7. 門禁與進出管理要求

控制項目 作業要求 驗證 / 證據
具名授權 受限以上區域應以具名人員或具名角色授權，不得以共享身份長期授權。 授權名單。
最小權限 進出權限應依職務需要、區域等級與期限授予。 權限審查紀錄。
定期審查 Level 2以上區域至少定期審查授權；Level 3/4建議每季或半年審查。 門禁權限審查。
離職異動撤權 離職、調職、專案結束或供應商退場應立即撤銷不再需要之進出權限。 撤權紀錄。
門禁紀錄 Level 2以上區域應保存進出紀錄；Level 3/4需可支援事件調查。 門禁Log。
尾隨防制 人員進出應避免尾隨，發現尾隨需制止並通報。 教育與巡檢紀錄。
訪客陪同 訪客進入Level 2以上區域原則上需授權人員陪同。 訪客紀錄。
臨時權限 臨時權限需有Owner、目的、開始/結束時間與核准。 臨時權限紀錄。
緊急權限 緊急進入需事後補記、說明原因、處置內容與核准人。 緊急進入紀錄。
門禁失效 門禁故障需採人工保全、臨時名單、巡檢與修復追蹤。 事件/維修紀錄。

8. 訪客、供應商與第三方進入要求

對象 / 情境 進入要求 限制事項 證據
一般訪客 需登記、識別、配戴訪客證，依核准區域活動。 不得進入Level 2以上區域，除非經核准與陪同。 訪客紀錄。
客戶訪問 需限定會議區或核准動線，避免接觸內部文件、螢幕或設備。 不得拍攝或自行走動。 接待紀錄。
供應商維護 需核准工單、身分確認、工具管制、陪同、作業範圍限制與離場確認。 不得接入未核准設備、拍攝敏感區域或帶走資料。 維護與訪客紀錄。
清潔人員 應限定區域、時間、作業範圍並簽署保密要求。 不得翻閱、移動、丟棄敏感文件或接觸設備。 合約/NDA、巡檢。
施工人員 需施工計畫、風險評估、陪同或監督、拍照限制、工具與材料管制。 不得進入未核准區域或破壞安全邊界。 施工紀錄。
稽核員 / 外部審查 需經授權、陪同、限制取證內容與文件帶離。 不得拍攝機房細節或導出未核准資料。 審查紀錄。
緊急維修 可依緊急程序進入，但需記錄、陪同、事後審查。 不得省略事後補件與安全檢查。 緊急進入紀錄。

9. CCTV、警報與保全巡檢要求

控制項目 作業要求 保存 / 驗證

13. 高風險情境與處置要求

情境 可能風險 立即處置 後續要求
未授權人員進入安全區域 資料外洩、設備破壞、惡意植入、竊盜。 制止、陪離、確認身份、保存門禁與CCTV紀錄。 通報Security/SOC，必要時啟動事件。
尾隨或代刷門禁 進出紀錄失真、未授權進入。 立即提醒並記錄，必要時通報主管。 再教育或違規處理。
門禁故障或門未關閉 未授權接觸、安全邊界失效。 採人工保全、限制進入、立即維修。 故障與補償控制紀錄。
CCTV或警報失效 事件偵測與調查能力下降。 啟用人工巡檢或臨時監控。 維修並評估風險接受。
安全區域內發現未知設備 惡意裝置、未授權網路、竊聽或資料外洩。 隔離設備、拍照、保全現場。 啟動事件初判與取證。
機密文件或媒體遺留 未授權揭露或資料遺失。 收回保管，確認Owner與接觸範圍。 依資料分類決定是否事件通報。
訪客或供應商未陪同 資料外洩、設備接觸或拍攝風險。 立即陪離並確認活動範圍。 檢討接待與供應商流程。
環境威脅影響安全區域 火災、漏水、電力、空調、結構損壞或營運中斷。 通知Facility，必要時啟動BCP。 RCA、CAPA與風險重評。

14. 例外管理

例外情境 最低要求 核准層級 期限與重評
臨時無法使用門禁 需採人工保全、臨時名單、訪客登記與巡檢。 Physical Security / CISO視風險 最長30日。
CCTV維修期間失效 需增加巡檢、限制進入、臨時攝影或人工監控。 Physical Security / Area Owner 修復前每日重評。
供應商需單獨作業 原則禁止；若必要需錄影、時間限制、作業範圍限制與事後檢查。 CISO / Facility / Supplier Owner 單次核准。
區域等級與現況不符 需建立改善計畫、補償控制與期限。 CISO / Area Owner 最長90日。
臨時安全區域需延期 需重新核准Owner、期限、進出控制、資產清冊與退場計畫。 Area Owner / Security 最長30日重評。
門禁權限定期審查逾期 需補審查並限制高風險權限新增。 Area Owner / HR / Security 10個工作日內。

巡檢紀錄 保全巡邏、場所安全檢查、缺失、照片、改善與驗證。 Facility / Physical Security 至少3年。
供應商與施工紀錄 進出、陪同、工具、施工、維護、退場與NDA/合約證據。 Supplier Management / Facility 合約期間及終止後至少3年。

指標 定義 目標 / 門檻 用途

門禁故障平均修復時間 門禁故障自發現至修復時間。 依SLA；Critical需立即補償控制。 復原能力。
巡檢完成率 保全/Facility完成計畫巡檢比例。 目標100%。 日常控制。

17. 稽核檢查重點

稽核項目 檢查重點 可接受證據

邊界與標示 安全區域是否有適當邊界、標示、門禁、鎖具或隔離。 現場檢查、照片。

CCTV與警報 監控、錄影保存、時間同步、告警與維護是否有效。 CCTV/警報紀錄。
巡檢與維護 保全巡檢、設施維護與缺失改善是否依計畫執行。 巡檢表、維護紀錄。
桌面與設備保護 安全區域內文件、螢幕、設備與媒體是否妥善保護。 清桌檢查、資產紀錄。
臨時區域 施工區、專案區或臨時安全區域是否有Owner、期限、控制與退場。 臨時區域紀錄。
事件處理 未授權進入、門禁故障、CCTV失效、未知設備是否依事件程序處理。 事件紀錄。
管理審查 KPI/KRI、重大事件、逾期改善與高風險例外是否納入管理審查。 管理審查紀錄。
