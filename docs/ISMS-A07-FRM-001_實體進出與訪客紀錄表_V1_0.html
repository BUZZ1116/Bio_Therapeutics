1. 表單目的

本表單用於記錄與管制人員進入、離開、停留、陪同、異常、物品攜入攜出及受控區域活動，以確保實體安全控制措施具備可稽核性、可追溯性與完整證據鏈。本表單同時支援 ISO/IEC 27001:2022 Annex A.7 實體安全控制措施、事件管理、供應商存取、個人資料保護、營運持續與內部稽核之證據需求。

本表單不得僅作為門禁簽到用途，應同時作為受控區域授權、訪客陪同、資訊資產接觸限制、攝影限制、臨時例外、緊急進出、異常通報與事後追查之正式紀錄。

2. 填表與使用原則

  • 所有外部訪客、供應商、維修人員、稽核員、查證員與臨時進入受控區域者，均應完成登錄、身份確認、受訪人確認與離場登記。
  • 進入機房、資料中心、監控室、文件保存區、備份媒體區、研發實驗室、營業秘密區或其他高敏感區域者，應取得事前核准並由指定人員陪同或依門禁授權作業辦理。
  • 涉及攝影、錄音、錄影、攜入電腦、外接儲存裝置、測試設備、維修工具或資料搬運者，應另行記錄目的、核准人、設備序號、封存狀態與離場檢查結果。
  • 若發現未授權進入、尾隨、冒用身份、門禁失效、訪客失聯、物品遺失、未核准攝影或疑似資訊安全事件，應立即通知 Physical Security Owner、SOC、CISO 或指定事件窗口。
  • 本表單所含個人資料應依資料最小化、目的限制、授權存取、保存期限與安全銷毀要求管理。

3. 名詞與定義

名詞 定義
受控區域 基於資訊安全、營運持續、法規、合約、客戶要求或資產保護需求，需限制進出、保留紀錄或加強監控之場所。
高敏感區域 包含機房、資料中心、監控室、備份媒體保存區、研發實驗室、金鑰或憑證管理區、保密文件保存區、客戶資料處理區與其他經風險評估指定之區域。
訪客 非組織正式授權常態進出人員，包括客戶、供應商、面試者、顧問、稽核員、查證員、維修人員、參訪人員與其他外部人員。
受訪人 / 接待人 對訪客進入目的、停留區域、陪同、資料接觸限制與離場確認負責之內部人員。
陪同 經指定內部人員於訪客進入、停留、移動、作業與離場期間進行現場監督，避免未授權接觸資訊、設備、文件或區域。
尾隨 未經授權人員跟隨授權人員進入受控區域之行為，屬於實體安全異常，應立即制止並通報。
臨時通行權限 因特定目的、特定期間、特定區域而授予之暫時性進出權限，目的完成後應立即回收、停用或到期失效。
