1. 登錄目的

本登錄表用於建立供應商資訊安全治理主檔，完整記錄供應商基本資料、服務範圍、資訊資產接觸情形、資料處理活動、合約與安全條款、資安能力、風險評估、隱私與AI治理、雲端與第四方依賴、營運持續能力、事件通報、退場安排、監督指標與審查結論。

本登錄表支援ISO/IEC 27001:2022 Annex A 5.19、5.20、5.21、5.22與5.23對供應商、ICT供應鏈與雲端服務之治理要求，並作為供應商准入、續約、變更、年度審查、事件後重評、稽核與管理審查之核心證據。

2. 使用原則

  • 所有中高風險供應商、可接觸組織資訊資產之供應商、處理PII或客戶資料之供應商、雲端/AI/外包開發/維運支援供應商，均應建立本登錄表。
  • 供應商登錄應於簽約前、服務啟用前或重大變更前完成，且不得以採購時程取代必要資訊安全與法務審查。
  • 供應商若涉及PII、AI、雲端、第四方、跨境資料、關鍵營運、GHG/CO2資料或客戶合約要求，應啟動專項審查。
  • 登錄資訊應定期更新，且在供應商事件、合約變更、服務變更、子處理者變更、風險等級變更或稽核發現後重新評估。
