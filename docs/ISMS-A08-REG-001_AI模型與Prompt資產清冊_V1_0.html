1. 清冊目的

本清冊用於建立組織AI模型、Prompt、AI Agent、RAG知識庫、Embedding與相關AI資產之完整登錄、分類、責任歸屬、風險分級、授權狀態、資料來源、部署環境、控制措施、監測要求與退場狀態，以支援資訊安全、AI治理、隱私保護、供應鏈安全、軟體開發安全、雲端服務安全、營運持續與管理審查。

本文件亦作為ISO/IEC 27001:2022 Annex A資產管理、資訊分類、存取控制、供應商關係、雲端服務使用、技術弱點管理、安全開發、事件管理及AI相關技術控制之稽核證據，確保AI資產可識別、可追溯、可控管、可審查與可停用。

2. 登錄原則

  • 所有AI模型、Prompt、AI Agent、RAG知識庫與AI服務在正式使用、試用、PoC、委外開發、內部開發、API整合或部署前，均應納入本清冊。
  • AI資產應有明確Owner、Custodian、使用目的、資料分類、輸入資料限制、輸出使用限制、授權條件、風險等級與審查週期。
  • 涉及PII、客戶機密、營業秘密、受合約限制資料、跨境處理、第三方模型、開源模型或自動化決策者，應完成資安、隱私、法務與AI治理審查。
  • Prompt與系統指令應視為可影響模型行為之重要資訊資產，應依敏感度與業務影響進行版本、存取、變更、審查與測試管理。
  • 清冊內容應至少每半年審查一次；重大變更、事件、供應商條款變更、模型版本變更、資料集更新或用途變更時，應即時更新。

3. 名詞與定義

名詞 定義
AI模型 使用機器學習、深度學習、規則、統計或其他AI方法，對輸入資料產生預測、分類、生成、建議、決策支援或自動化輸出之軟體元件、服務或模型權重。
基礎模型 經大量資料訓練並可適用於多種下游任務之大型模型，例如大型語言模型、多模態模型、影像生成模型或語音模型。
Prompt 提供給AI模型之指令、上下文、範例、限制條件、角色設定、工具使用規則、輸出格式要求或安全規則。
系統Prompt 由系統、平台或應用程式內部設定，用於約束模型行為、權限、角色、輸出格式與安全邊界之高優先級Prompt。
Prompt模板 可重複使用並含變數、欄位或條件邏輯之Prompt格式，用於標準化AI輸入與輸出。
RAG知識庫 Retrieval-Augmented Generation使用之文件、資料庫、索引、向量資料庫或知識來源，用於提供模型回答或生成內容時之背景資料。
Embedding 將文字、影像、聲音、程式碼或其他資料轉換為向量表示之資料或模型輸出，可能包含敏感語意與可重識別風險。
AI Agent 可依目標自主或半自主規劃、調用工具、存取系統、執行任務、讀寫資料或產生行動之AI元件。
模型卡 / 資料卡 記錄模型目的、資料來源、限制、效能、偏差、安全性、適用情境與不適用情境之治理文件。
模型Owner 對AI模型之業務目的、風險、核准、使用限制、效能與退場負責之角色。
Prompt Owner 對Prompt內容、版本、適用場景、測試、存取與變更負責之角色。

4. 角色與責任

角色 主要責任
最高管理階層 核准高風險AI應用、重大剩餘風險接受、外部揭露、跨境高風險處理與必要資源。
AI治理委員會 審查AI資產治理原則、風險分級、使用邊界、重大例外、倫理與合規議題。
CISO / 資訊安全負責人 核准AI資產之資訊安全控制、事件通報、存取限制、日誌監控與高風險使用情境。
ISMS管理代表 維護本清冊格式、整合風險登錄、SoA、稽核證據、KPI/KRI與管理審查輸入。
AI模型Owner 登錄AI模型，定義用途、輸入輸出限制、資料來源、風險、核准狀態、版本與退場計畫。
Prompt Owner 登錄Prompt、系統Prompt、Prompt模板與Prompt Chain，維護版本、測試結果、權限與安全限制。
Data Owner 確認訓練、微調、RAG、Embedding、輸入與輸出資料之分類、合法性、保護要求與保存期限。
MLOps / DevSecOps 管理模型部署、版本控制、CI/CD、測試、安全掃描、監控、回滾與技術紀錄。
DPO / PIMS負責人 審查涉及PII、資料主體權利、跨境傳輸、隱私風險、DPIA與資料處理者責任。
法務 / 採購 / 授權管理 審查模型、資料集、Prompt、外部內容、開源授權、第三方服務條款、DPA、SLA與智慧財產權。
SOC / Security Monitoring 監控AI服務存取、異常輸入輸出、資料外洩、Prompt Injection、越權工具調用與事件告警。
使用者 / 業務Owner 依核准用途使用AI資產，不得輸入未授權資料或繞過Prompt、權限與資料保護限制。
