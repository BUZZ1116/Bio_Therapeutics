1. 清冊目的與管制規則

管制目的 說明
唯一主索引 本清冊是整合管理系統受控文件的主索引，用於確認文件編號、名稱、版本、狀態、Owner、分級、保存位置與審查週期。
版本與狀態控制 文件不得只靠檔名判斷有效性；
正式使用時應以本清冊與受控文件庫狀態為準。
跨系統整合 同一份文件可同時支持 各類管理系統與永續治理要求，避免重複文件彼此衝突。
外部稽核準備 第三方驗證、供應商稽核或客戶稽核時，可先以本清冊抽樣確認文件完整性與受控狀態。

2. 欄位定義

欄位 定義 填寫要求
文件編號 依管理系統、條款或流程編碼建立。 不得重複；
如文件改為共用版，應評估由 管理系統/ISMS 前綴改為 MS 前綴。
文件類型 MAN、POL、PRO、SOP、FRM、REG、MTX、PLAN、RPT、LOG 等。 類型應符合文件分級、核准與保存要求。
適用管理系統 文件支持的標準或管理系統範圍。 可複選；
若涉及 GHG 或 CO2 聲明，應標示資料邊界。
狀態 草案、審查中、正式、暫停、作廢、封存。 正式版才可作為受控執行依據；
草案不得流入作業現場。
審查週期 文件定期審查頻率或事件觸發條件。 重大組織、法規、標準、客戶或系統變更時應啟動非例行審查。
