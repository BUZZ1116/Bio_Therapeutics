1. 作業目的

本作業指導書規範桌面淨空與螢幕淨空之日常作業、工作區離席、下班、會議、列印、掃描、遠端工作、訪客接待、共享座位、清潔與稽核檢查要求，降低因紙本文件、筆記、便利貼、白板內容、列印品、儲存媒體、可攜設備、螢幕畫面、投影內容或會議視訊畫面外露而造成未授權揭露、資料外洩、個人資料不當處理、客戶資料洩漏、商業秘密外洩或合規違反之風險。

本文件旨在將資訊分類分級、實體安全、人員安全、端點安全、遠端工作、資料保護、文件化資訊管制與資訊安全事件管理要求落實於日常工作環境，使所有人員能在辦公室、會議室、公共空間、客戶現場及遠端工作場所維持一致且可稽核之資訊保護行為。

2. 作業原則

  • 任何含有內部、機密、高機密、個人資料、客戶資料、財務資料、原始碼、密碼、金鑰、Prompt、AI輸入輸出或其他敏感內容之資訊，不得於無人看管、公共可見或未授權人員可接觸之處暴露。
  • 離席時應鎖定螢幕、收妥紙本、移除敏感媒體，並避免會議室、列印區或共用空間遺留資料。
  • 下班或長時間離開前，桌面、會議室、白板、印表機、掃描機、垃圾桶與共享座位應清空或依資料分類妥善保存/銷毀。
  • 使用投影、視訊會議或螢幕分享前，應確認分享範圍、參與者、通知視窗、桌面檔案、瀏覽器分頁、聊天紀錄與機密資訊不會外露。
  • 遠端工作或客戶現場工作應採等同或更高標準之桌面與螢幕淨空控制，尤其應避免家人、訪客、第三方、公共場所人員或攝影設備旁觀。
  • 桌面與螢幕淨空缺失應依嚴重度進行提醒、教育、改善、違規處理或資訊安全事件通報。

3. 名詞與定義

名詞 定義
桌面淨空 人員離席、下班或工作結束時，將桌面、工作區、會議室、列印區及其他可見區域之敏感文件、媒體、設備與資訊妥善收納、保護或銷毀之要求。
螢幕淨空 避免螢幕、投影、視訊會議、共享畫面、白板或電子看板顯示敏感資訊予未授權人員觀看之要求。
敏感資訊 依資訊分類分級屬內部、機密、高機密、個人資料、客戶資料、商業秘密、金鑰、密碼、帳號、系統架構、風險、弱點、事件或其他需保護之資訊。
離席 使用者短暫離開座位、會議室、櫃台、列印區或其他工作位置，而設備或資料仍可能被他人接觸或觀看之狀態。
共享座位 非固定座位、Hot Desk、臨時座位、會議室座位、訓練教室座位或供多人輪流使用之工作位置。
防旁觀 透過螢幕角度、防窺片、座位選擇、遮蔽、投影設定、視訊會議控制等方式，避免非授權人員觀看資訊。
安全銷毀 依資料分類使用碎紙機、機密文件箱、委外銷毀、資料清除或其他核准方式，使資訊不可被未授權恢復或取得。
清桌檢查 由授權人員依頻率、抽查或事件觸發，檢視桌面與螢幕淨空控制是否落實之活動。

Facility Owner 維護儲物櫃、機密文件箱、碎紙設備、列印區、會議室與清潔作業支援。 設施紀錄、清潔交接。

Cleaners / Contractors 依授權範圍執行清潔，不接觸、翻閱、移動或拍攝文件與設備，發現敏感資料遺留應通報。 保密承諾、作業紀錄。
Internal Auditor 抽查淨空控制、檢查紀錄、缺失改善、訓練與事件處理。 稽核底稿、發現。

5. 桌面淨空控制要求

控制項目 最低要求 禁止或限制事項 證據 / 驗證
紙本文件 內部以上文件離席或下班時應收納於抽屜、上鎖櫃、機密文件袋或核准位置。 不得將機密文件留在桌面、會議室、列印區或垃圾桶。 清桌檢查紀錄。
便利貼與筆記 不得記載密碼、帳號、金鑰、客戶資料、個資或高敏感內容並張貼於可見處。 禁止將密碼貼於螢幕、鍵盤、桌面、筆電或抽屜外側。 抽查紀錄。
外接媒體 USB、外接硬碟、備份媒體、記憶卡應依儲存媒體管理要求保管。 不得將未加密媒體或含資料媒體留置桌面。 媒體清冊。
識別證與Token 識別證、門禁卡、智慧卡、硬體Token應由本人保管或收妥。 不得轉借、外露、與PIN/密碼一起保存。 抽查與通報紀錄。
行動裝置 手機、平板、筆電、錄音筆與相機等設備離席時應鎖定或妥善保管。 不得無人看管置於公共區或訪客可接觸處。 巡檢紀錄。
印章/簽核工具 公司章、部門章、簽核章、憑證載具應上鎖保管。 不得置於開放桌面或交由未授權人員使用。 保管紀錄。
垃圾與回收 含敏感資訊紙張應投入機密文件箱或碎紙，不得一般回收。 禁止將含個資/機密紙張丟入一般垃圾。 銷毀紀錄。
白板與玻璃牆 會議結束後應擦除白板、玻璃牆、便利貼、流程圖與客戶資訊。 不得保留機密討論內容供下一場會議或訪客觀看。 會議室檢查。
共享座位 離開共享座位前應清空所有文件、設備、暫存紙張與私人物品。 不得將資料留給下一位使用者。 共享座位檢查。
樣品/原型/設備 含客戶、研發、專案或機密資訊之樣品與原型需妥善鎖存或遮蔽。 不得放置於訪客路徑或未管制區。 資產盤點。

6. 螢幕淨空與防旁觀控制要求

控制項目 最低要求 禁止或限制事項 證據 / 驗證
離席鎖定 離席時應立即鎖定螢幕；系統應設定自動螢幕鎖定逾時。 不得長時間讓系統保持登入且無人看管。 端點設定與抽查。
螢幕方向 螢幕應避免面向公共通道、訪客座位、窗外、接待區或未授權人員可見方向。 高敏感作業不得在公共區域開放顯示。 場所檢查。
防窺片 處理高敏感資料、客戶資料、財務資料或公共/共享環境工作時應使用防窺片或等效措施。 不得於交通工具或公共場所裸露敏感資料。 設備檢查。
投影與簡報 投影前應確認內容、桌面、通知、聊天、瀏覽器分頁與檔案名稱不含敏感資料。 不得於未授權會議顯示內部架構、客戶資料、密碼或事件資訊。 會議紀錄。
螢幕分享 視訊會議應優先分享單一視窗，關閉通知與不必要應用程式。 禁止在不確認參與者下分享整個桌面或敏感系統。 協作平台紀錄。
電子看板 公共顯示器不得顯示機密資訊、個資、客戶資料、系統狀態或安全事件細節。 不得把監控儀表板投放至訪客可見區。 看板內容檢查。
多螢幕使用 多螢幕應確認所有畫面不被旁觀，會議分享時避免外接螢幕顯示敏感內容。 不得將未分享螢幕上的敏感資料暴露給現場人員。 抽查紀錄。
通知彈窗 應設定通知隱私，避免Email、聊天、工單、資安告警於鎖定或投影時顯示內容。 不得於簡報中跳出敏感通知。 端點設定。
AI與協作工具 使用AI工具、協作文件或Prompt時，應避免顯示敏感資料或未核准內容給未授權人員。 不得在公共螢幕展示含客戶資料或Secrets之Prompt/輸出。 使用審查。

7. 工作場景作業要求

場景 桌面淨空要求 螢幕淨空要求 額外注意事項
固定座位 文件依分類收納，離席鎖櫃或收妥，外接媒體不得外露。 離席鎖定，螢幕避免朝向通道。 下班前完成清桌。
共享座位 / Hot Desk 使用後完全清空桌面、抽屜、白板與暫存資料。 登出系統、清除瀏覽紀錄與鎖定/關閉設備。 不得留下個人或公司資料。
會議室 會前確認資料最小化，會後收走文件、擦除白板、清除便利貼。 投影/分享前檢查畫面，會後關閉設備與登出。 訪客會議需更高標準。
列印/掃描區 立即取走列印品、掃描品與原稿；錯印文件需安全銷毀。 影印機面板、掃描目的地與暫存檔需檢查。 不得代領敏感文件。
接待區 / 櫃台 不得放置客戶資料、訪客資料、內部清冊或未遮蔽文件。 螢幕需避免訪客直接觀看。 訪客簽到資料需遮蔽。
客服 / 財務 / HR區 個資與薪資等敏感資料須最小顯示與上鎖保管。 應採防窺、遮蔽、分區或座位控制。 清潔與訪客需限制接觸。
機房附屬作業區 不得留置機房圖、密碼、網路配置、設備設定或維護紀錄。 監控畫面與管理介面不得被未授權人員觀看。 維修後需清場。
居家辦公 紙本與設備避免家人或訪客接觸，工作結束收納。 使用防旁觀措施，避免視訊背景或螢幕外露。 遵守遠端工作文件。
公共場所 / 交通工具 原則避免處理高敏感資料；必要時採防窺片並最小化資料。 不得顯示機密、個資、客戶資料或管理系統。 避免公共Wi-Fi與旁觀。
客戶或供應商場址 遵守客戶/供應商場域規範並保護公司資料。 分享畫面前確認參與者與授權範圍。 不得遺留文件或設備。

8. 文件、列印、掃描與銷毀要求

作業項目 控制要求 驗證方式
列印前 確認列印內容、印表機位置、資料分類與是否可使用安全列印。 列印設定與使用紀錄。
列印後 立即取回列印品；錯印、未取、重複列印或含敏感資訊之紙張需安全銷毀。 列印區巡檢。
安全列印 機密、高機密、PII、客戶資料建議使用刷卡列印、PIN列印或安全列印。 印表機設定。
掃描作業 掃描目的地需確認正確，避免寄送至錯誤Email、共享資料夾或外部帳號。 掃描紀錄。
影印作業 原稿與影本均需取回，不得留在玻璃面板、自動送稿器或出紙口。 影印區檢查。
文件暫存 會議、簽核、櫃台或專案暫存文件需放置於授權區域並限制接觸。 暫存紀錄。
文件銷毀 依資料分類使用碎紙機、機密文件箱或委外銷毀，不得一般丟棄。 銷毀紀錄。
白板清除 會議結束後應擦除白板、玻璃牆與展示板內容。 會議室檢查。
Legal Hold 涉及Legal Hold、事件證據或稽核資料不得擅自銷毀。 Legal/事件確認。

9. 清潔、保全、訪客與第三方作業要求

對象 / 情境 控制要求 證據 / 驗證
清潔人員 清潔人員不得翻閱、移動、拍攝、丟棄或帶走文件、媒體與設備。發現敏感資料遺留應通報。 NDA/契約、清潔作業規範。
保全人員 保全巡邏發現未鎖螢幕、敏感文件外露或設備異常，應依通報流程處理。 巡邏紀錄。
訪客 訪客應在授權區域活動，避免接觸桌面文件、螢幕與未遮蔽資料。 訪客紀錄與陪同。
供應商駐點 駐點人員需遵守同等淨空要求，工作區不得外露公司或客戶敏感資訊。 供應商承諾。
夜間/假日辦公 離開前需加強清桌、鎖定設備、關閉投影、收回文件並確認門禁。 巡檢紀錄。
施工/搬遷 施工區域需先移除或遮蔽敏感資料，施工人員不得接觸文件與螢幕。 施工前檢查。

11. 檢查、抽查與缺失分級

14. 例外管理

例外情境 最低要求 核准層級 期限與重評
特殊作業需暫時保留文件於桌面 需使用受控區域、標示Owner、限制進出、設定期限與下班收納。 Line Manager / Security視資料分類 最長1個工作日或作業期限。
無法使用上鎖櫃 需提供替代保管方式，例如密封文件袋、臨時櫃、機密文件箱或主管保管。 Facility / Security 最長30日重評。
螢幕無法調整方向或加裝防窺片 需調整座位、使用遮蔽、限制資料處理或採遠端/獨立空間。 Line Manager / Security 最長60日重評。
公共區域需展示資訊 僅可展示公開或核准內容，禁止顯示機密、個資、客戶資料或系統狀態。 Business Owner / Security 每次活動核准。
白板內容需保留 需標示Owner、保留期限、限制會議室使用並拍照存檔於核准位置後擦除。 Meeting Owner / Security 最長1個工作日。
遠端工作環境限制 需提出防旁觀、收納、螢幕鎖定與紙本保管替代控制。 Line Manager / Security 至少每季重評。
