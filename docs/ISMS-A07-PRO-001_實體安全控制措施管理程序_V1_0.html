1. 程序目的

本程序用於建立、實施、維持與持續改善組織實體安全控制措施，確保辦公場所、機房、資料中心、倉儲、文件保存區、備援場所、設備放置區及其他處理資訊資產之實體環境具備適當防護，降低未授權實體存取、資訊資產竊取、破壞、損壞、環境災害、電力中斷、公用設施失效、設備遺失、偷拍偷錄、社交工程與供應商實體存取所造成之資訊安全風險。

本程序同時整合 ISO/IEC 27001:2022 Annex A.7 實體控制措施要求，並將實體安全與風險管理、資產管理、人員安全、事件管理、營運持續、供應鏈安全、隱私資料保護、AI系統實體環境防護、GHG/CO2資料證據保存、內部稽核與管理審查連結，作為企業級ISMS驗證與控制有效性證據之基礎。

2. 管理原則

  • 實體安全應採風險導向、分區分級、最小權限、必要知悉、可追溯、職務區隔與縱深防禦原則。
  • 所有安全區域應依資訊資產重要性、處理資料分類、營運關鍵性、法規合約要求及威脅情境設定實體安全等級。
  • 任何人員、訪客、承包商或供應商進入受控區域，均應具明確目的、適當授權、身份確認、進出紀錄與必要陪同。
  • 機房、資料中心、網通設備區、備份媒體保存區、PII資料處理區、AI訓練/推論設備區、稽核與查證證據保存區應採較高實體防護要求。
  • 設備、媒體、文件或可攜式資訊資產離開安全區域前，應完成核准、登錄、保護、交接、追蹤與歸還或銷毀確認。
  • 實體安全控制應與資訊安全事件管理、營運持續、災害復原、設備維護、供應商管理、存取控制及文件化資訊管制流程相互銜接。
  • 實體安全控制之有效性應透過巡檢、門禁權限審查、CCTV抽查、訪客紀錄抽樣、演練、事件分析、內部稽核及管理審查進行確認。

3. 名詞與定義

名詞 定義
實體安全 透過場所、設施、設備、環境、公用設施、人員與實體存取控制，防止資訊資產遭未授權存取、損壞、干擾、竊取或破壞之管理與技術措施。
安全區域 依風險與資訊資產重要性進行劃分，並透過門禁、圍籬、牆面、保全、監控、陪同或其他控制限制進出之區域。
實體安全邊界 用於保護安全區域之牆面、門、窗、門禁、保全櫃台、閘門、圍籬、樓層、機櫃、機房、隔間或其他實體界線。
受控區域 進出需身份驗證、權限核准、紀錄保存或陪同之區域。
限制區域 僅授權特定職務、管理者、維護人員或經核准人員進入之高風險區域，例如機房、網通設備區、備份媒體庫、證據保存室。
門禁權限 授予人員以卡片、生物特徵、PIN、鑰匙、通行證、訪客證或系統設定方式進入實體區域之權限。
訪客 非組織正式授權進入特定區域之人員，包括客戶、稽核員、驗證員、查證員、面試者、承包商、維護人員及臨時來訪人員。
設備安置與保護 將資訊處理設備、網路設備、伺服器、終端、列印設備、監控設備與儲存媒體安置於適當位置，並防止環境、實體或未授權接觸風險。
公用設施 支援資訊處理與辦公營運之電力、空調、消防、供水、排水、網路、通訊、UPS、發電機及其他基礎設施。
清桌清螢幕 離席、下班或無人看管時，將敏感文件、媒體與設備妥善收存，並鎖定螢幕或登出系統之控制要求。
鏈結保管 Chain of Custody，對設備、媒體、文件或證據之取得、轉移、保存、分析與處置過程建立完整、可追溯紀錄。

Vendor Management / 採購 確保供應商、保全、清潔、維護、搬運與資料中心服務合約包含實體安全要求。 合約條款、供應商評鑑、SLA與稽核權。

BCMS / DRP負責人 確認關鍵場所、機房、公用設施、備援位置與復原流程之持續營運要求。 BIA、RTO/RPO、演練紀錄、復原計畫。
SOC / Security Monitoring 監控與分析CCTV、門禁、環境告警、異常進出與實體安全事件。 告警紀錄、事件工單、異常分析。
所有使用者 遵守門禁、陪同、清桌清螢幕、設備保護、訪客通報、可疑活動回報及資產帶出規定。 訓練紀錄、承諾書、事件通報。

7. 實體安全風險評鑑與控制選擇

評鑑項目 評估內容 控制選擇方向 應保存證據

威脅情境 竊盜、破壞、火災、水災、停電、未授權進入、尾隨、內部人員濫用、供應商風險、社交工程。 依威脅選擇保全、警報、環境監控、消防、UPS、巡檢與應變流程。 威脅弱點分析、風險評鑑紀錄。

法規與合約 客戶合約、個資法、金融/醫療/政府要求、驗證要求、資料中心合約、保全與CCTV隱私要求。 納入合約義務、保存期限、告知標示、稽核權與證據保存。 法規清冊、合約審查、DPIA/隱私審查。
營運持續 該區域失效是否影響RTO/RPO、核心流程、客戶服務、資料完整性或災害復原能力。 建立備援、環境冗餘、緊急連絡、演練與備援場地。 BIA、BCP/DRP、演練紀錄。

8. 安全區域建立、變更與廢止程序

步驟 作業要求 責任角色 核准/證據
1. 需求提出 因新辦公室、機房、專案、客戶要求、AI運算環境、PII處理、文件保存或供應商作業需求提出安全區域需求。 需求單位 / Asset Owner 區域建立/變更申請。
2. 資產與資料識別 識別區域內人員、設備、文件、媒體、資料類型、資料分類、系統、供應商與外部連線。 Physical Security Owner / IT / Data Owner 資產清冊、資料流向、區域評估表。
3. 風險評鑑 評估威脅、弱點、衝擊、可能性、既有控制與剩餘風險。 ISMS管理代表 / CISO / Facility 資訊安全風險評鑑表。
4. 區域分級 依本程序第6章決定L0至L4等級，並定義邊界、入口、權限角色與監控要求。 Physical Security Owner 實體安全區域清冊、區域配置圖。
5. 控制設計 設計門禁、CCTV、警報、保全、環境監控、機櫃、鑰匙、訪客、陪同、巡檢與紀錄保存。 Facility / IT / CISO 控制設計文件、驗收標準。
6. 實施與驗收 完成設備安裝、設定、測試、權限配置、標示、作業訓練與文件更新。 Facility / IT / 供應商 驗收紀錄、設定紀錄、訓練紀錄。
7. 上線核准 確認控制達成預期、防護證據完整、風險可接受後核准使用。 CISO / Facility主管 / 授權代表 上線核准紀錄。
8. 變更與廢止 區域用途、資產、資料、門禁、監控、外包或風險變更時，應重新評估；廢止時應撤除權限、清點資產、移除資料與保存紀錄。 Physical Security Owner / Asset Owner 變更紀錄、廢止檢核、資產清點。

9. 實體安全邊界控制

控制領域 控制要求 適用區域 證據
入口與門禁 安全區域入口應設置可控進出機制，如門禁卡、生物辨識、PIN、保全櫃台、閘門或實體鑰匙管理。 L1~L4 門禁設定、門禁日誌、鑰匙清冊。
牆面、門窗與隔間 限制區域應具足以防止未授權進入之牆面、門窗、鎖具、天花板與地板隔離；易入侵點應加固或納入監控。 L2~L4 區域配置圖、巡檢紀錄。
標示與告知 受控與限制區域應標示授權進入要求；CCTV、門禁與個資蒐集應依隱私要求提供告知。 L1~L4 現場照片、告知文件。
尾隨防範 員工不得讓未授權人員尾隨進入；高限制區域應採防尾隨設計、保全監控或雙重驗證。 L2~L4 訓練紀錄、監控告警。
緊急出口 緊急出口應符合安全法規，平時不得作為一般進出通道，並應納入警報或巡檢。 所有區域 消防檢查、警報測試紀錄。
未使用空間 閒置辦公室、空機櫃、儲藏室、天花板通道、管道間與倉儲區應定期巡檢與上鎖。 L1~L4 巡檢紀錄。

異常處理 遺失門禁卡、未授權嘗試、異常時段進出、尾隨、拒絕陪同或門禁故障應通報並記錄。 使用者 / 保全 / SOC 事件通報、告警紀錄。
