1. 作業目的

本作業指導書規範組織纜線安全之規劃、佈放、標示、保護、分離、巡檢、變更、維護、臨時線路、供應商施工、弱電間與機櫃配線管理、線路退場、事件處理、證據保存、例外管理與稽核要求，避免因纜線裸露、未授權接入、誤接、剪斷、竊聽、干擾、環境損害、施工失誤、標示不清、圖資不一致或退場不完整而造成資訊外洩、服務中斷、安全控制失效或營運持續風險。

纜線是實體安全、網路安全、支援設施、門禁監控、消防、環境監控與營運持續的重要基礎。本文件要求纜線安全作業與資產管理、變更管理、供應商管理、實體進出、支援設施檢查、網路安全、ICT備妥性及資訊安全事件管理流程整合，形成可追溯、可驗證、可稽核的企業級控制。

2. 作業原則

  • 所有資訊傳輸纜線、電力纜線、門禁/CCTV/警報線路與支援設施線路，應依用途、敏感度、區域風險與服務重要性採取適當保護。
  • 關鍵線路與機密路由不得任意公開，線路圖、配線表、Port Mapping與機櫃圖應依文件分級管制。
  • 資料纜線與電力纜線應適當分離，避免電磁干擾、熱風險、誤觸、火災、維修風險與服務中斷。
  • 所有新增、改接、搬遷、拆除、臨時接線或供應商施工，均應事前核准並保留變更與驗收紀錄。
  • 機櫃、配線架、弱電間、線槽、橋架與管道應受實體存取控制，避免未授權接入、竄改、旁路或竊聽。
  • 臨時纜線應具Owner、用途、核准單號、設置日期、到期日與移除計畫，不得長期存在而未納管。

3. 名詞與定義

名詞 定義
纜線安全 透過規劃、保護、標示、巡檢、監控與變更管制，防止纜線遭破壞、竊聽、誤接、未授權接入、干擾或造成營運中斷之控制活動。
資料纜線 承載資料通訊之纜線，例如乙太網路線、光纖、電話線、專線、控制訊號線或其他資訊傳輸線路。
電力纜線 提供設備電力、UPS、PDU、配電盤、接地或發電機連接之電源線路。
弱電間 / 電信室 放置配線架、網路設備、光纖終端、Patch Panel、弱電控制箱或通訊設備之受控區域。
Patch Panel / 配線架 集中終端與管理網路線、光纖或其他通訊線路之設備。
跳線 連接設備、配線架、Switch、Patch Panel或機櫃內端口之短距離纜線。
臨時纜線 為短期施工、測試、應急、活動或維修目的而設置之非永久性纜線。
未授權連線 未經核准接入組織網路、電力、門禁、CCTV、控制或支援設施之纜線或設備。
線路圖資 包含線路路由、起點、終點、機櫃、Port、配線架、弱電間、備援路徑與標籤之文件化資訊。
關鍵線路 若中斷或遭竄改將影響Critical/High服務、門禁、監控、消防、網路骨幹、備援或營運持續之線路。

5. 纜線分類與最低安全要求

纜線類型 安全要求 禁止或限制事項 證據
網路資料線 應使用受控線槽、配線架、機櫃鎖定、端口標示與Port Mapping。 禁止私接Switch、AP、Hub或未核准網路設備。 配線表、巡檢紀錄。
光纖骨幹 需保護路由、彎曲半徑、接頭、ODF、備援路徑與標示。 禁止任意重接、裸露或未記錄跨區跳接。 光功率測試、路由圖。
電力纜線 需符合電氣安全、負載、接地、UPS/PDU容量與消防要求。 禁止過載、串接不合格延長線或與資料線不當混放。 電力巡檢、負載紀錄。
門禁線路 控制器、讀卡機、門磁、電鎖與線路需避免外露、旁路或未授權接入。 禁止未核准調整門禁控制箱或短接電鎖。 門禁巡檢紀錄。
CCTV線路 攝影機供電、訊號、PoE、NVR連線與線槽需保護。 禁止未核准拔除、遮蔽、改接或外接錄影。 CCTV檢查紀錄。
警報/消防線路 需維持完整、測試與法規合規，不得與非核准線路混接。 禁止未核准停用、旁路或遮蔽警報功能。 消防/警報測試紀錄。
環境監控線路 溫濕度、漏水、煙霧、電力與UPS監控線路需受保護。 禁止將監控線路視為非關鍵線路而任意拆除。 環境監控紀錄。
供應商/客戶專線 需合約、路由、設備、責任界面、標示與隔離。 禁止供應商自行新增或改接專線。 專線清冊、合約證據。
臨時纜線 需申請、標示、固定、期限、Owner與移除計畫。 禁止未標示、跨走道、無期限或長期使用。 臨時線清冊。

6. 纜線佈放、變更與退場流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 提出新增、搬遷、改接、替換、維修、退場、臨時接線或供應商專線需求。 Requestor / System Owner 施工/變更申請。
2. 風險評估 評估區域敏感度、服務重要性、資料分類、電力負載、消防、環境、干擾、停機與實體安全風險。 Facility / Network / Security 風險評估紀錄。
3. 路由設計 確認路由、管槽、機櫃、配線架、Port、線材規格、備援路徑、標示與測試方法。 Network / Facility 設計圖、施工方案。
4. 核准與排程 取得Facility、Network、Security、Change、Service Owner與必要供應商核准。 Change Manager 核准紀錄。
5. 施工管制 施工人員需登記、陪同、工具管制、區域隔離、停機控制、現場安全與拍照限制。 Facility / Supplier 施工紀錄。
6. 佈線與標示 依核准路由佈放，兩端標示唯一編號、起訖點、用途、Owner或Port。 Supplier / IT 標示照片。
7. 測試驗收 完成連通、頻寬、線序、光功率、PoE、接地、負載、門禁/CCTV功能與告警測試。 Network / Facility / Owner 測試報告。
8. 文件更新 更新線路圖、機櫃圖、Port Mapping、弱電間圖、資產清冊與維護紀錄。 Document Owner 更新紀錄。
9. 退場清理 移除廢線、臨時線、未使用Port、舊標籤與施工廢棄物。 IT / Facility / Supplier 退場紀錄。
10. 結案與審查 確認無遺留風險、文件完整、缺失改善完成，保存證據。 ISMS代表 / Owner 結案紀錄。

7. 纜線標示、圖資與文件管制

項目 作業要求 管制要求 證據
雙端標示 所有Critical/High與受管纜線應於兩端標示唯一識別碼。 標籤應耐久、清楚、不暴露過多敏感資訊。 標籤照片。
Port Mapping Switch Port、Patch Panel、機櫃、資訊插座、設備端口應可追溯。 限制存取完整Port對應表。 Port表。
線路路由圖 關鍵線路需保存路由、弱電間、跨樓層、備援路徑與責任界面。 依文件分級管制，不公開張貼完整拓樸。 路由圖。
機櫃配線圖 機櫃內設備、跳線、PDU、Patch Panel與備援連線需維持更新。 機櫃圖需隨變更更新。 機櫃圖與照片。
臨時線清冊 臨時線需登錄Owner、用途、核准單號、開始日、到期日與移除日。 逾期需升級追蹤。 臨時線清冊。
供應商竣工圖 施工完成後供應商需交付竣工圖、測試報告、標籤清冊與材料清單。 未交付不得結案。 竣工文件。
版本控管 線路圖、Port表與機櫃圖需版本控管並保留修訂紀錄。 避免使用舊版圖資施工。 版本紀錄。

8. 實體保護與環境安全要求

控制領域 最低要求 檢查重點
線槽與橋架 資料線、控制線與關鍵線路應使用線槽、管道、橋架或其他保護方式。 是否破損、開放、過度擁擠或未固定。
弱電間與配線室 應限制存取、保持上鎖、清潔、無雜物，並具進出紀錄。 是否有未授權人員、未知設備或未標示線路。
機櫃與配線架 機櫃需上鎖，跳線整齊，不阻礙散熱、維護或門鎖。 是否有私接、裸露、未標示或封條破損。
電力與資料分離 電力線與資料線應依規範分離，必要時使用隔離管槽或屏蔽。 是否混放、交纏、受熱或干擾。
火災與散熱 纜線不得阻塞通風、消防設施、逃生路線或造成熱點。 是否有易燃雜物或過載。
水源與環境 纜線應遠離水源、排水、空調滴水點與潮濕區域。 是否有漏水、冷凝或腐蝕。
人員安全 纜線不得造成絆倒、跌落、割傷或維修安全風險。 臨時線是否固定與標示。
防竊聽與竄改 高敏感線路應避免外露並納入巡檢或監控。 是否有剪斷、分接、未知設備或非法Tap。

9. 臨時線路與緊急接線管理

控制項目 作業要求 到期與移除要求
申請核准 臨時線路需有申請人、Owner、用途、範圍、起訖點、風險與期限。 未核准不得施工。
標示 臨時線兩端及可見位置需標示核准單號、Owner、用途、開始日、到期日。 標示不清需立即補正。
固定與安全 跨走道、門口、維修區或人員通道之臨時線需固定、防絆倒並避免壓傷。 不符合者需立即整改。
網路隔離 臨時網路線不得接入正式網段，除非經Network與Security核准。 應限制VLAN、ACL與存取期限。
緊急接線 緊急接線可事後補核，但需記錄原因、時間、範圍、影響與核准人。 24至48小時內補件。
期限管理 臨時線需設定到期日，逾期需移除或重新核准。 逾期線路列為不符合。
移除驗收 移除後確認Port關閉、標籤清除、圖資更新與現場恢復。 保存移除紀錄。

10. 供應商與施工安全要求

控制項目 最低要求 證據
供應商資格 佈線、弱電、電力、安防、消防與網路施工供應商需經評估與核准。 供應商評估、合約。
NDA與安全條款 供應商需簽署保密與安全要求，禁止未授權拍照、複製圖資、外傳路由資訊。 NDA、合約條款。
施工前會議 施工前確認範圍、時間、停機、風險、陪同、工具、消防與驗收標準。 會議紀錄。

工具與材料 工具、測試設備、線材、標籤與材料需符合規格，不得使用來路不明設備。 材料清單。
施工期間保護 施工不得破壞既有線路、消防、門禁、CCTV、環境監控或機櫃鎖定。 施工巡檢紀錄。
竣工驗收 完成測試、標示、照片、清潔、圖資、材料、缺失改善與簽收。 測試報告、竣工圖。
供應商退場 確認工具、材料、臨時線、廢料與圖資已妥善處理，權限已撤銷。 退場紀錄。

12. 高風險情境與處置要求

情境 可能風險 立即處置 後續要求
發現未知纜線或未知設備 未授權網路接入、竊聽、旁路、防火牆繞過或惡意設備植入。 隔離Port、拍照、保全現場、通知SOC與Network Owner。 調查來源，必要時啟動資訊安全事件。
關鍵線路中斷 Critical服務、門禁、監控、消防、環境監控或網路骨幹中斷。 啟動備援路徑、緊急維修與事件通報。 RCA、CAPA與管理審查。

施工未依核准路由 干擾、消防、資料外洩、服務中斷或法規風險。 停止施工、隔離區域並重新審查。 供應商缺失改善與驗收。
電力線過載或發熱 火災、設備損壞、UPS失效或人員安全風險。 立即通報Facility並降低負載或停用。 電力檢查與整改。
安防線路異常 門禁、CCTV、警報失效或被繞過。 立即通知Physical Security，採人工保全補償。 修復、測試與事件檢討。
纜線圖資外洩 攻擊者可掌握機房、骨幹、安防與備援路由。 限制文件存取、調查外洩範圍。 依資料外洩程序處理。

15. 例外管理

例外情境 最低要求 核准層級 期限與重評
臨時纜線需延長 需說明必要性、風險、固定方式、Owner、到期日與移除計畫。 Facility / Network / Security 最長30日重評。

供應商專線無法移除 需合約確認、網路隔離、監控、到期計畫與風險接受。 Supplier Owner / CISO 續約前重評。
未能立即移除未知線路 需隔離Port、限制連線、標示、監控並追蹤來源。 Network Owner / CISO 最長7日。
