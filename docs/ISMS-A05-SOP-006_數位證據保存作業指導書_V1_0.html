1. 作業目的

本作業指導書用於規範組織在資訊安全事件、資安調查、合規審查、內部稽核、供應商事件、雲端服務事件、AI系統事件、PII事件及其他需要佐證事實之情境下，如何識別、保存、蒐集、封存、移交、分析、保管、使用、保存與銷毀數位證據，以維持證據之完整性、真實性、可用性、可追溯性、機密性與法律/稽核可接受性。

本文件同時支援ISO/IEC 27001:2022 Annex A.5.24「Information security incident management planning and preparation」、A.5.25「Assessment and decision on information security events」、A.5.26「Response to information security incidents」、A.5.27「Learning from information security incidents」、A.5.28「Collection of evidence」及A.6.8「Information security event reporting」等要求，並建立可被內部稽核、外部驗證、法務調查、客戶審查與管理審查採信之證據保存程序。

核心要求：任何可能作為證據之資料，在未完成初步保全前，不得任意刪除、覆寫、重啟、格式化、修改、轉寄、公開、下載到個人設備或交付未授權人員。所有證據處理活動均應保留時間、執行者、目的、方法、工具、Hash、保存位置及移交紀錄。

2. 作業原則

  • 完整性：證據蒐集與保存應使用可驗證方法，例如Hash、唯讀掛載、封存、簽章、時間戳、存取紀錄與證據鏈。
  • 最小干擾：蒐證活動應避免改變原始證據；若不可避免，應記錄原因、變更內容、影響與核准。
  • 授權處理：僅經授權之人員可蒐集、保管、移交、分析或銷毀證據。
  • 機密保護：證據可能含有客戶資料、PII、商業秘密、金鑰、密碼、原始碼、AI模型資料或攻擊細節，應依最高敏感等級保護。
  • 證據鏈完整：證據自取得、保管、分析、移交到銷毀之每一階段均需可追溯。
  • 合法合規：涉及個資、跨境、勞動、監理、客戶合約或司法程序時，應由法務、DPO或授權角色確認要求。
  • 時效優先：易失性證據如記憶體、網路連線、雲端暫時日誌、容器狀態、短期Token、EDR暫存資料應優先保存。
  • 職務區隔：證據保管、分析、決策與稽核宜保持適當職務區隔，降低利益衝突與證據污染。

3. 名詞與定義

名詞 定義
數位證據 以數位形式存在，可用於證明資訊安全事件、違規、存取、變更、傳輸、操作、外洩、異常或控制執行情形之資料。
原始證據 未經修改、加工或分析之第一手資料，例如磁碟映像、原始日誌、封包檔、原始郵件、雲端稽核日誌匯出檔。
衍生證據 由原始證據分析、轉換、彙整、篩選或產生之資料，例如時間線、IOC清單、關聯分析報告、截圖、摘要表。
證據鏈 記錄證據從識別、取得、封存、保管、存取、移交、分析、複製、使用到銷毀之完整歷程。
Hash 用於驗證證據完整性之雜湊值，例如SHA-256；同一資料內容應產生相同Hash值。
保全 在不破壞或盡量降低破壞原始狀態之前提下，防止證據遭刪除、覆寫、變更、洩漏或遺失。
易失性證據 系統關機、重啟、連線中斷或時間流逝後可能消失或變更之證據，例如記憶體、程序、連線、暫時Token、容器狀態。
鑑識映像 以鑑識工具建立之完整位元層級副本，通常包含Hash、工具資訊、建立時間與執行者。
證據保管人 負責證據接收、標示、封存、保存、存取授權、移交與保存期限管理之角色。
Legal Hold 因法律、合約、監理、爭議或調查需求而暫停例行刪除並保留相關資料之措施。

4. 角色與責任

角色 主要責任 禁止或限制
最高管理階層 提供重大事件蒐證所需資源，核准重大法律、監理或對外爭議之證據保存策略。 不得要求刪除、隱匿或修改證據。
CISO / 資訊安全負責人 核准證據保存策略、重大事件蒐證範圍、外部鑑識委任與高風險證據移交。 不得將未經法務審查之敏感證據任意對外提供。
Incident Manager 將證據保存納入事件回應計畫，維護事件時間線與蒐證任務追蹤。 不得以非正式方式保存唯一證據。
Digital Evidence Custodian 建立證據編號、接收證據、驗證Hash、保管證據、管理存取、執行移交與保存期限。 不得同時擔任可能有利益衝突之被調查對象。
CSIRT / Forensic Analyst 執行端點、伺服器、雲端、網路、郵件、AI與日誌蒐證及分析。 不得直接修改原始證據；分析應使用副本。
SOC 保存告警、SIEM查詢、關聯規則、封包、EDR紀錄及初步調查證據。 不得因事件關閉而刪除相關告警與查詢紀錄。
System / Cloud / Network Owner 支援日誌匯出、快照、權限凍結、備份保全與系統狀態保存。 不得未經核准重啟、重建或刪除受影響資源。
法務 / 法遵 判定法律保存、監理通報、訴訟、合約、客戶通知與對外移交要求。 不得忽略個資、跨境與保密義務。
DPO / PIMS負責人 判斷PII證據之最小化、遮罩、保存、跨境、通知與資料主體權利影響。 不得以調查為由無限制複製PII。
供應商管理 要求供應商保存、匯出與交付事件相關證據，確認合約與SLA要求。 不得接受未經完整性驗證或來源不明之供應商證據。

5. 數位證據類型與保存優先順序

優先順序 證據類型 範例 保存原因 建議行動
1 易失性證據 記憶體、程序清單、網路連線、登入Session、容器狀態、臨時Token、雲端暫時憑證。 最容易因重啟、逾期或自動輪替消失。 立即由授權人員蒐集，記錄工具、時間、命令與Hash。
2 安全告警與事件平台資料 SIEM、EDR、NDR、IDS/IPS、DLP、CASB、SOAR、WAF、IAM告警。 可建立事件起點、攻擊路徑與影響範圍。 匯出原始告警、查詢條件、事件ID、時間區間與關聯規則版本。
3 身份與存取證據 登入紀錄、MFA紀錄、SSO、OAuth同意、API Key、Token使用、PAM Session。 可證明誰在何時以何種權限操作。 保存來源IP、User Agent、地區、設備、權限變更與Session紀錄。
4 主機與端點證據 磁碟映像、檔案系統、Registry、EDR Telemetry、惡意檔案、排程任務、服務。 支援惡意程式、入侵路徑與資料外洩分析。 隔離主機、建立映像、計算Hash、保存EDR資料。
5 網路與流量證據 封包、NetFlow、防火牆、Proxy、DNS、VPN、ZTNA、Load Balancer紀錄。 支援攻擊來源、C2、資料外傳與橫向移動分析。 匯出相關時間區間資料並保存查詢條件。
6 雲端與SaaS證據 CloudTrail、Activity Log、Audit Log、Storage Access、IAM、KMS、VPC Flow、SaaS稽核日誌。 雲端事件常依平台日誌重建事實。 啟用Legal Hold或日誌保留，匯出至受控證據庫。
7 資料與文件證據 資料庫日誌、資料表快照、DMS版本、檔案Hash、分享紀錄、下載紀錄。 支援資料被存取、修改、刪除或外洩之判定。 保存版本、權限、存取紀錄、筆數與完整性驗證。
8 AI與自動化證據 Prompt、AI輸入/輸出、RAG查詢、模型版本、Agent Actions、MLOps Pipeline、訓練資料版本。 支援AI事件、資料外洩、錯誤輸出、越權工具調用與責任歸屬。 保存模型/服務版本、輸入輸出、審核紀錄與使用者上下文。

6. 證據保存作業流程

階段 作業活動 責任角色 輸出紀錄
識別 依事件類型、時間範圍、受影響資產、資料分類與法遵需求識別需保存證據。 Incident Manager / CSIRT / 法務 / DPO 證據保存範圍清單。
保全 採取隔離、快照、Legal Hold、權限凍結、日誌匯出、備份保留、防刪除等措施。 System Owner / Cloud Owner / Evidence Custodian 保全操作紀錄。
蒐集 使用核准工具與方法蒐集原始證據，記錄時間、工具、版本、參數與操作者。 Forensic Analyst / SOC / IT 蒐集紀錄、Hash、原始檔。
標示 為每項證據建立唯一編號、分類、來源、敏感等級、案件編號與保存期限。 Evidence Custodian 證據標籤、證據清冊。
驗證 計算Hash、確認檔案大小、筆數、時間區間、來源完整性與可讀性。 Evidence Custodian / Analyst Hash驗證紀錄。
封存 將證據存放於受控位置，啟用加密、存取控制、備份與防竄改。 Evidence Custodian 封存紀錄、存放位置。
移交 內外部移交需取得授權，記錄移交人、接收人、目的、時間、方式與Hash。 Evidence Custodian / 法務 證據移交紀錄。
分析 使用工作副本分析，不直接操作原始證據，分析結果應可追溯至原始證據。 Forensic Analyst 分析紀錄、時間線、報告。
保存/銷毀 依保存期限、Legal Hold、合約與法規要求保存；期滿經核准銷毀。 Evidence Custodian / 法務 保存期限紀錄、銷毀證明。

欄位 格式/要求 說明

欄位 必填內容 控制目的

14. PII、客戶資料與敏感證據保護要求

控制項目 要求 證據
資料最小化 蒐集證據時應僅蒐集調查必要範圍；若需完整資料集，應有明確核准。 蒐證範圍核准。
遮罩與去識別 分析副本應優先遮罩PII、客戶資料、憑證與商業秘密；原始證據加密封存。 遮罩規則、分析副本Hash。
存取限制 PII與高機密證據僅限授權調查、法務、DPO與必要技術人員存取。 存取授權與日誌。
跨境限制 證據若需跨境移交或由境外供應商分析，需完成法務/DPO審查。 跨境審查紀錄。
資料主體權利 處理資料主體請求時，若證據受Legal Hold保護，應由DPO與法務判定回應方式。 資料主體請求處理紀錄。
通知義務 證據分析確認外洩或高風險PII事件時，應依事件管理程序啟動通知判定。 通報判定紀錄。

15. Hash與完整性驗證要求

項目 最低要求 補充要求
演算法 SHA-256為最低要求。 重大事件可加做SHA-512；不建議單獨使用MD5或SHA-1作為完整性證明。
計算時點 證據取得後立即計算Hash；每次複製、移交、分析前後應驗證。 若Hash不一致，立即停止使用並啟動異常調查。
記錄內容 檔名、路徑、大小、Hash值、工具、工具版本、執行者、時間、系統時區。 可附命令輸出或工具報告。
截圖證據 截圖本身亦應計算Hash，並記錄截圖來源、時間、畫面URL或系統位置。 關鍵截圖應同時保存原始系統日誌。
壓縮封存 證據壓縮檔需加密並保存壓縮前與壓縮後Hash。 密碼或金鑰不得與證據同通道傳輸。
Hash異常 Hash不一致、檔案大小不一致或讀取失敗時應建立異常紀錄。 由Evidence Custodian與CISO判定是否可採用備份副本。

16. 證據保存位置與存取控制

保存位置 適用證據 控制要求 禁止事項
受控證據庫 大多數數位證據、日誌、匯出檔、分析副本。 MFA、RBAC、加密、存取日誌、不可變更設定、備份。 不得允許全員或專案群組任意存取。
WORM/不可變更儲存 重大事件、法律保存、客戶/監理要求證據。 Object Lock、Retention、Legal Hold、管理權限區隔。 不得任意縮短Retention。
實體保險櫃 硬碟、USB、手機、紙本簽收、封存媒體。 封條、盤點、雙人控管、環境保護。 不得放置於個人抽屜或未上鎖區域。
加密離線媒體 需離線保存之大量映像或長期證據。 全碟加密、金鑰分離、媒體標籤、定期可讀性驗證。 不得使用未核准個人媒體。
法務保存區 Legal Hold、訴訟、監理、重大爭議證據。 法務核准存取、保留期限鎖定、移交紀錄。 不得未經法務核准銷毀。

17. 證據移交與對外提供要求

移交情境 核准要求 移交方式 保存紀錄
內部分析移交 Incident Manager或Evidence Custodian核准。 受控證據庫權限或加密副本。 移交人、接收人、目的、時間、Hash。
外部鑑識廠商 CISO、法務與採購/供應商管理核准；確認NDA、DPA、SOW與保密義務。 加密MFT、專用通道或實體加密媒體。 合約、移交單、Hash、收件確認。
主管機關/執法機關 法務主導，依正式函文、法令或授權流程辦理。 依法務指定方式，必要時保留副本。 函文、交付清單、簽收、保留副本Hash。
客戶或合作夥伴 依合約、NDA、DPA與CISO/法務核准提供最小必要證據。 經審查之摘要、遮罩版本或受控副本。 提供範圍、核准、交付紀錄。
跨境移交 法務、DPO、資料Owner核准；完成跨境與資料保護判定。 加密傳輸、存取期限、地區限制。 跨境審查、傳輸紀錄。

18. 證據分析作業要求

分析活動 要求 輸出
建立工作副本 所有分析應在工作副本進行，原始證據維持唯讀與封存。 工作副本Hash與建立紀錄。
建立事件時間線 依日誌、告警、使用者行為、系統變更、網路流量與雲端活動建立時間線。 事件時間線表。

重現與驗證 重大結論需可由證據支持，必要時由第二分析者覆核。 覆核紀錄、分析報告。

19. 日誌保存與時間同步要求

控制項目 要求 證據

時區標示 所有證據記錄應標示時區，重大事件建議同時使用UTC與本地時間。 事件時間線。

短期日誌 雲端、SaaS、端點與網路設備若日誌保留短，事件後應立即匯出。 緊急匯出紀錄。

20. 保存期限、Legal Hold與銷毀要求

情境 保存期限原則 銷毀條件 核准
一般資安事件 依紀錄保存期限清冊與事件嚴重度保存。 結案且保存期限屆滿，且無Legal Hold。 Evidence Custodian / CISO。
重大事件 至少保存至管理階層核准結案、CAPA完成、驗證或客戶審查完成後依期限保存。 CISO、法務確認無持續爭議。 CISO / 法務。
PII事件 依個資法規、DPO判定、通知義務與合約要求保存。 DPO確認保存目的消失且無法務保留。 DPO / 法務 / CISO。
訴訟/監理/合約爭議 啟用Legal Hold，不得依一般期限銷毀。 法務書面解除Legal Hold。 法務主管。
供應商證據 依合約、SLA、DPA與事件需求保存。 供應商義務完成且內部保存期限屆滿。 供應商管理 / 法務。
分析副本 事件結案後應清理不必要副本，避免敏感資料擴散。 確認原始證據仍受控保存。 Evidence Custodian。
