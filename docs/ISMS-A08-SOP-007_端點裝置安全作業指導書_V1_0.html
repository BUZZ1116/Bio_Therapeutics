1. 作業目的

本作業指導書規範端點裝置於取得、登錄、配置、交付、使用、遠端工作、維護、監控、修補、資料保護、事件處理、遺失通報、退還、抹除與報廢之安全要求，確保端點裝置能有效保護組織資訊資產、客戶資料、PII、機密資料、AI服務憑證、雲端存取權限與業務系統存取，降低惡意軟體、未授權存取、資料外洩、端點淪陷、橫向移動、憑證竊取與供應鏈風險。

本文件同時支援遠端工作、安全開發、AI工具使用、MLOps、供應商維運與事件應變需求，要求所有端點裝置具備可識別、可控管、可監控、可修補、可加密、可撤銷及可稽核之安全管理能力。

2. 作業原則

  • 所有連接組織網路、系統、雲端、SaaS或資料之端點裝置，應於使用前完成資產登錄、安全組態、使用者指派與管理工具納管。
  • 端點裝置應依用途、資料分類、使用者角色、遠端工作情境與風險等級設定適當控制，不得以便利性取代必要安全控制。
  • 正式端點應啟用全碟加密、EDR/防惡意程式、修補管理、防火牆、螢幕鎖定、強驗證、遠端抹除或等效控制。
  • 未納管、不合規、疑似淪陷、遺失、遭竊或超過修補期限之端點，應限制或阻斷其存取組織資源。
  • 端點不得保存不必要之PII、客戶資料、高機密資料、Secrets、AI API Key、模型權重或GHG/ESG底稿；必要保存時應加密、最小化、備份與限制存取。
  • BYOD、供應商端點或外部裝置不得直接存取高風險系統或機密資料，除非完成核准、風險評估與技術隔離控制。

3. 名詞與定義

名詞 定義
端點裝置 使用者或系統用於存取組織資源之裝置，包括筆電、桌機、工作站、行動裝置、平板、VDI、Thin Client、共享設備與供應商維運端點。
受管端點 已納入組織MDM/UEM/EDR/資產管理/修補管理或等效工具，並符合基準組態與監控要求之端點。
未受管端點 未納入組織管理工具，或無法確認安全狀態、Owner、組態、修補、加密與監控狀態之端點。
EDR Endpoint Detection and Response，用於偵測、阻擋、調查與回應端點威脅之安全工具。
MDM/UEM Mobile Device Management / Unified Endpoint Management，用於管理端點設定、合規、加密、App、憑證、遠端鎖定與抹除之工具。
全碟加密 對端點儲存媒體進行完整加密，避免裝置遺失或遭竊時資料外洩。
裝置合規性 端點符合組織設定之安全基準，包括加密、EDR、修補、螢幕鎖、OS版本、防火牆、未Root/Jailbreak等條件。
BYOD Bring Your Own Device，個人自有裝置用於存取組織資源之情境。
CYOD Choose Your Own Device，使用者在組織核准清單內選擇之企業裝置或受控裝置。
遠端抹除 端點遺失、遭竊、退場或離職時，由管理平台移除企業資料或清除整機資料之措施。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
CISO / 資訊安全負責人 核准端點安全策略、重大例外、端點事件處置與高風險端點存取限制。 政策核准、例外核准、事件決策。
Endpoint Security Owner 維護端點安全基準、EDR/MDM/UEM控制、合規規則、偵測規則與端點風險監控。 端點安全基準、合規報告、EDR報告。
IT Operations / Helpdesk 執行端點採購、配置、交付、支援、修補、故障處理、退還、抹除與資產更新。 資產紀錄、交付紀錄、抹除紀錄。
Asset Management Owner 維護端點資產清冊、Owner、使用者、狀態、位置、序號、生命週期與退場紀錄。 資訊及相關資產清冊、盤點報告。
IAM Owner 管理端點登入、SSO、MFA、裝置憑證、條件式存取、特權帳號與離職撤權。 IAM設定、條件式存取紀錄。
SOC / Monitoring Owner 監控端點告警、惡意軟體、資料外洩、異常登入、憑證竊取與橫向移動跡象。 SIEM告警、事件工單。
Application / System Owner 確認其系統對端點合規性、瀏覽器、憑證、VPN、設備信任與資料保護要求。 存取條件、應用端控制。
Data Owner / DPO 確認端點可處理之資料分類、PII、客戶資料、保存期限、加密與外洩通報要求。 資料分類、隱私審查。
HR / 主管 支援人員到職、異動、離職、遠端工作、裝置歸還、違規處理與教育訓練。 人員異動通知、歸還確認。
使用者 依規定使用與保護端點，不私自停用安全控制、安裝未核准軟體、共享裝置或延誤通報遺失/異常。 使用承諾、事件通報。
供應商 / 外包人員 依合約與存取規則使用受控端點或受控連線，不保存未授權資料並配合撤權與稽核。 供應商存取紀錄、NDA。

5. 端點裝置分類與最低控制

端點類型 範圍 最低控制要求 備註
一般企業筆電 / 桌機 一般員工、辦公、行政、教育訓練與一般業務使用。 資產登錄、MDM/UEM、EDR、防火牆、全碟加密、自動修補、螢幕鎖、MFA、資料備份或雲端同步。 不得停用安全代理程式。
高權限管理端點 系統管理、雲端管理、網路管理、PAM、SOC、資料庫管理、特權作業使用。 一般控制加上PAM/JIT、管理網段限制、USB限制、強化稽核、禁止日常瀏覽與Email、獨立管理帳號。 建議使用PAW或隔離管理工作站。
開發與工程端點 開發、DevSecOps、MLOps、AI工程、CI/CD、原始碼與模型開發使用。 一般控制加上Secrets掃描、原始碼保護、容器/套件安全、SCA/SAST工具、Repo權限與本機資料加密。 不得保存未核准Secrets或客戶資料。
行動裝置 公司或核准個人手機、平板，用於Email、MFA、SaaS或業務App。 MDM/MAM、螢幕鎖、生物辨識或PIN、加密、遠端抹除、Jailbreak/Root偵測、App控制。 BYOD應限制資料與App範圍。
遠端工作端點 於家庭、旅途中或非公司場域使用之端點。 VPN/ZTNA、MFA、端點合規性檢查、螢幕防窺、Wi-Fi安全、禁止家人共用。 應遵守遠端工作SOP。
共享端點 / 會議室設備 會議室、教育訓練、借用或多人共用設備。 自動清除使用者資料、限制本機登入、鎖定設定、定期重置、禁存機密資料。 不得保存個人或客戶資料。
供應商維運端點 供應商用於遠端維運、支援、開發或監控之端點。 需合約要求、NDA、端點安全證明、VPN/ZTNA、MFA、Session Recording、存取時間限制。 高風險作業優先使用組織提供之受管端點或跳板。
BYOD裝置 個人自有裝置存取組織資源。 限低風險用途；需MAM/容器化、MFA、裝置合規、遠端移除企業資料。 不得存取高機密、特權系統或大量PII。

6. 端點生命週期管理流程

階段 作業要求 責任角色 輸出證據
1. 需求與核准 確認端點用途、使用者、資料分類、風險等級、特殊軟體與遠端工作需求。 主管 / IT / Data Owner 端點申請或核准紀錄。
2. 採購與入庫 採購核准型號，記錄序號、資產編號、供應商、保固、位置與Owner。 IT / Asset Management 端點資產清冊。
3. 安全基準配置 安裝標準映像、MDM/UEM、EDR、防火牆、加密、修補、瀏覽器安全與安全設定。 Endpoint Security / IT 基準設定紀錄。
4. 使用者交付 交付前確認合規、資產標籤、使用者承諾、密碼/MFA、資料同步與使用指引。 Helpdesk / HR 交付簽收紀錄。
5. 日常使用與監控 持續監控端點合規、EDR告警、修補狀態、DLP、USB、軟體與異常行為。 SOC / Endpoint Owner 合規報告、告警紀錄。
6. 維護與修補 依修補SLA更新OS、應用、瀏覽器、驅動、韌體與安全代理。 IT / Endpoint Owner 修補報告。
7. 異動與借用 人員異動、端點借用、角色變更、地點變更或用途變更時重新確認權限與控制。 IT / HR / 主管 異動紀錄。
8. 遺失、遭竊或事件 立即通報、遠端鎖定/抹除、撤銷憑證、調查日誌與評估資料外洩。 使用者 / SOC / IT 事件紀錄。
9. 退還與抹除 離職、汰換或退場時回收端點、備份必要資料、抹除、撤銷權限並更新清冊。 IT / HR / Asset Owner 抹除與退場紀錄。

7. 端點安全基準要求

控制項目 最低要求 高風險端點加強要求 證據
資產登錄 端點須有資產編號、序號、Owner、使用者、位置、狀態與風險分類。 每月核對高權限端點與管理端點。 資產清冊。
MDM/UEM納管 端點需納入管理平台，推送安全基準、設定與遠端處置。 禁止未納管端點存取高風險系統。 MDM/UEM報表。
EDR/防惡意程式 端點應安裝、啟用並定期更新EDR或防惡意程式。 EDR Tamper Protection、隔離與即時回應能力。 EDR覆蓋率報表。
全碟加密 筆電、行動裝置與保存資料之端點應啟用全碟加密。 高機密端點需加強金鑰託管與復原金鑰保護。 加密合規報告。
防火牆 端點本機防火牆應啟用，限制不必要入站連線。 管理端點採更嚴格白名單規則。 組態報表。
螢幕鎖定 端點應設定自動螢幕鎖定與重新認證。 高風險端點縮短閒置鎖定時間。 MDM設定。
OS與應用修補 依修補SLA更新作業系統、應用、瀏覽器、Office、VPN與安全代理。 Critical弱點需緊急修補或隔離。 修補報表。
本機管理員限制 一般使用者不得具本機管理員權限；需臨時授權時應核准與記錄。 採用EPM、JIT Local Admin或PAM。 權限審查紀錄。
裝置合規檢查 不符合加密、EDR、修補、OS版本或安全設定者應限制存取。 條件式存取阻擋高風險資源。 合規政策與報表。
安全代理保護 不得停用、移除或繞過EDR、DLP、MDM、VPN、憑證、Proxy或監控代理。 Tamper Protection與異常告警。 告警紀錄。

8. 端點資料保護要求

資料類型 端點保存規則 保護要求 備註
公開資料 可依工作需要保存。 維持正確性與版本管理。 避免混入未公開草稿。
內部使用資料 可短期保存於受管端點。 端點加密、使用者帳號保護、雲端同步或備份。 離職或退場時清除。
機密資料 原則應保存於受控系統或雲端平台，端點僅限必要暫存。 全碟加密、最小保存、DLP、禁止未核准外傳。 必要時設定自動清理。
高機密資料 原則不得長期保存於端點；必要時需Data Owner與CISO核准。 加密容器、嚴格存取、禁止USB、DLP、存取日誌。 高風險端點才可處理。
PII / 客戶資料 僅依合法目的與最小資料保存，避免本機大量保存。 加密、DLP、遮罩、保存期限、遺失通報。 需遵守PIMS與合約要求。
Secrets / Token / 私鑰 不得明文保存於端點檔案、桌面、下載資料夾、聊天或瀏覽器記錄。 使用Secrets Manager、密碼管理器、硬體金鑰或安全金鑰庫。 外洩即事件處理。
AI資料 / Prompt / 模型權重 需依AI工具與資料使用政策管理，不得保存未核准模型資料或Prompt。 權限控管、加密、版本管理、資料刪除。 MLOps端點加強控管。
事件證據 僅由授權事件人員保存與處理。 保管鏈、加密、不可竄改、限制複製。 不得放置一般端點。

9. 軟體、應用程式與瀏覽器安全

控制項目 作業要求 證據
核准軟體清單 端點應使用核准軟體來源與版本，禁止安裝盜版、未授權或高風險工具。 軟體清冊、MDM報表。
應用程式控制 高風險端點應採Allowlist、阻擋未知執行檔、限制腳本與巨集。 應用控制設定。
瀏覽器安全 瀏覽器應受管理，限制高風險外掛、阻擋惡意網站、啟用安全更新與下載防護。 瀏覽器政策。
AI外掛與工具 未核准AI瀏覽器外掛、桌面AI工具或資料讀取外掛不得安裝或啟用。 端點軟體掃描、CASB/DLP報告。
巨集與腳本 預設停用不可信巨集，PowerShell、Shell Script與自動化工具應受控與記錄。 組態設定、EDR告警。
套件與開發工具 開發端點之套件管理器、IDE外掛、容器與SDK應依安全開發要求控管。 SCA報告、端點基準。
移除不必要軟體 停用或移除不必要服務、舊版軟體、試用工具與高風險遠端控制工具。 盤點與移除紀錄。
授權合規 端點軟體應符合授權條款，避免侵權、盜版與不合規使用。 授權紀錄、稽核報告。

10. 網路連線與遠端存取要求

連線情境 最低要求 禁止或限制事項
公司網路連線 端點需通過裝置合規檢查、EDR健康狀態與身份驗證。 未納管或不合規端點不得接入內部網路。
遠端工作 使用核准VPN/ZTNA、MFA、端點合規檢查與受控DNS/Proxy。 不得使用公共電腦或家庭共用帳號存取組織資料。
公共Wi-Fi 應使用VPN/ZTNA及端點防火牆，避免敏感作業。 不得在無保護公共網路處理高機密資料。
管理介面存取 需由受控端點、特權帳號、PAM/JIT及指定網段或跳板存取。 不得由一般端點直接登入雲端Root、PAM、網路設備或資料庫管理介面。
供應商遠端支援 需事前核准、MFA、Session Recording、時間限制與活動紀錄。 不得開放永久遠端控制或共享固定帳密。
個人熱點與行動網路 可依遠端工作要求使用，需符合端點合規與加密連線。 不得繞過公司Proxy/DLP或監控要求。
藍牙、NFC、近端連線 僅限業務必要，應停用不必要配對與自動連線。 不得連接未知設備或未核准周邊。

11. USB、外接裝置與周邊管理

裝置類型 管理要求 例外核准
USB儲存裝置 預設限制或唯讀；若需使用應加密、登錄、掃描惡意程式並限制資料分類。 Data Owner、IT、CISO依資料等級核准。
外接硬碟 / 隨身碟 機密以上資料不得存於未加密可攜媒體。 依儲存媒體管理SOP。
手機連接端點 不得未核准傳輸公司資料至個人手機；充電或資料傳輸應受控。 主管與IT核准。
印表機與掃描器 列印或掃描機密資料需遵守資料分類與實體安全要求。 Data Owner核准。
外接螢幕與投影 公開場域使用時應防止旁觀、誤投影或敏感資訊曝光。 使用者自主管理，高風險會議需主管提醒。
硬體安全金鑰 應由IT登錄、發放、回收與撤銷，遺失需立即通報。 IAM Owner核准。
未知周邊 禁止連接來源不明或未核准周邊設備。 IT安全檢查後方可使用。

12. 行動裝置與BYOD管理

管理項目 公司裝置要求 BYOD要求
納管 必須納入MDM/UEM並套用完整裝置政策。 至少納入MAM或受控容器；高風險資料需MDM。
螢幕鎖 強制PIN、生物辨識或密碼，設定自動鎖定。 同公司最低要求。
加密 裝置儲存加密必須啟用。 需啟用或由平台確認。
Jailbreak/Root偵測 偵測到Root/Jailbreak即限制存取。 同公司裝置。
App管理 僅允許核准業務App與受控資料分享。 企業資料應限制於受控App或容器。
遠端抹除 離職、遺失或事件時可遠端抹除企業資料；公司裝置可整機抹除。 僅抹除企業資料，除非使用者另行同意或合約約定。
資料外洩防護 限制複製貼上、螢幕截圖、個人雲端備份與未核准分享。 依MAM能力限制。
高風險存取 特權系統、高機密資料與大量PII不應由BYOD存取。 原則禁止。

13. EDR、惡意軟體與端點偵測回應

控制項目 作業要求 處置要求
EDR覆蓋 所有正式端點應安裝EDR並保持上線、更新與健康狀態。 未上線超過門檻應調查或限制存取。
Tamper Protection EDR、防毒、DLP與安全代理應啟用防竄改保護。 遭停用或移除即產生高優先告警。
惡意軟體防護 即時掃描、行為分析、隔離與雲端威脅情報應啟用。 偵測惡意程式應隔離端點並調查。
威脅獵捕 SOC應定期針對憑證竊取、橫向移動、惡意腳本、未知工具進行查詢。 建立獵捕紀錄與改善建議。
隔離能力 EDR應支援網路隔離、程序終止、檔案隔離、IOC搜尋或遠端回應。 事件時由SOC或授權人員執行。
告警分級 EDR告警應依嚴重度、受影響資料與端點角色分級處理。 Critical/High告警依事件程序升級。
例外排除 EDR排除規則需核准、最小化、到期並定期審查。 不得以效能為由永久排除高風險路徑。

15. 遠端工作與外出使用要求

情境 安全要求 使用者責任
居家工作 端點應置於可控環境，避免家人或訪客接觸螢幕與裝置。 不共享帳號與裝置，離席鎖定。
旅途中使用 應避免於公共場所處理高機密資料，必要時使用防窺措施。 注意肩窺、遺失與公共網路風險。
跨境攜帶 攜帶端點跨境應遵守資料所在地、出口管制、客戶合約與加密管制要求。 必要時申請空白或臨時端點。
飯店與公共場所 不得將端點留置無人看管；使用保險箱或隨身攜帶。 遺失立即通報。
公共充電與外接設備 避免使用未知USB充電或外接設備；使用電源轉接器或資料阻斷器。 不得連接未知USB。
遠端維運 高權限操作應使用PAM、跳板、受控端點與Session Recording。 不得在不安全環境進行高風險管理作業。

16. 端點遺失、遭竊與資料外洩處理

處理階段 作業要求 責任角色 證據
1. 立即通報 使用者發現端點遺失、遭竊、被搶、遭未授權接觸或疑似資料外洩時，應立即通報Helpdesk、主管與SOC。 使用者 / 主管 通報紀錄。
2. 鎖定與抹除 IT應立即遠端鎖定、定位、抹除企業資料或整機抹除，必要時撤銷裝置憑證與Session。 IT / Endpoint Owner MDM處置紀錄。
3. 權限撤銷 撤銷相關SSO Session、VPN、裝置憑證、Token、API Key、MFA信任裝置與本機憑證。 IAM / Cloud / System Owner 撤權紀錄。
4. 影響評估 確認裝置加密狀態、資料分類、最近同步、DLP告警、使用者權限、是否含PII或客戶資料。 Incident Manager / Data Owner / DPO 影響評估。
5. 事件分級 依資料敏感度、加密狀態、外洩可能性、法規與合約要求判定事件等級。 CISO / Incident Manager 事件分級紀錄。
6. 後續通知 若可能涉及PII、客戶資料、合約或法規，依事件程序通知DPO、法務、客戶或主管機關。 Legal / DPO / CISO 通知紀錄。
7. 補發與改善 補發端點前確認使用者教育、控制缺口與必要改善措施。 IT / 主管 / ISMS管理代表 補發與CAPA紀錄。

17. 端點退還、抹除與報廢

退場情境 作業要求 證據

18. 端點例外管理

例外情境 最低要求 核准層級 期限與重評

供應商未受管端點 需使用跳板、VDI、Session Recording、限制資料下載與時間限制。 CISO / Supplier Management 每次或短期核准。
特殊測試設備 需隔離、限制資料、專案到期、端點標示與責任人。 CISO / Project Owner 專案期間，定期重評。
