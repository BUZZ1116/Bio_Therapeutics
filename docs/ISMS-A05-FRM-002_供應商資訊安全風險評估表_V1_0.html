1. 表單目的

本表用於在供應商導入、續約、重大變更、事件後或定期重評時，系統化評估供應商資訊安全、隱私、雲端、AI、ICT供應鏈、營運持續、法規、合約、服務可用性、資料處理與退場風險，作為供應商核准、合約條款、補償控制、風險接受、持續監督與退場決策之依據。

本表評估結果應連動供應商資訊安全登錄表、資訊資產清冊、雲端服務與AI服務清冊、風險登錄表、風險處理計畫、供應商合約、DPA、SLA、事件通報要求、內部稽核及管理審查。

2. 評估與判定原則

  • 供應商風險評估應於採購、簽約、導入、資料傳輸、帳號開通或服務上線前完成，不得先使用後補評估。
  • 高風險或重大供應商應完成強化盡職調查，包含資安證明、DPA、合約安全條款、事件通報、稽核權、BCP/DR、資料刪除及退場能力。
  • 供應商提供之自評或聲明不得作為唯一證據；應依風險要求取得第三方稽核報告、證書、合約承諾、技術設定、測試報告或其他可查證證據。
  • 涉及PII、客戶資料、高機密資料、雲端控制平面、AI服務、外包開發、外包維運、MSSP/SOC或關鍵流程者，應由CISO及必要角色共同審查。
  • 未達最低安全要求者，不得導入或續約；如因業務必要需使用，應完成風險處理、補償控制、例外核准與有效期限管理。
