1. 作業目的

本作業指導書用於規範組織資訊之分類、標示、處理、傳輸、儲存、共享、列印、攜出、歸檔、保存、刪除、銷毀與例外管理方式，確保資訊在整個生命週期中依其價值、敏感度、法規合約要求及風險等級受到適當保護。

本文件同時提供使用者可操作之標示方式、處理規則、控制要求、檢核表與稽核證據基準，以支援ISO/IEC 27001:2022 Annex A.5.12資訊分類、A.5.13資訊標示、A.5.14資訊傳輸及相關控制之落實。

2. 作業原則

  • 所有資訊均應依業務價值、機密性、完整性、可用性、法規合約、PII、AI、供應鏈、營運持續與GHG/CO2揭露影響進行分類。
  • 資訊標示應清楚、可見、可追溯，且不得因格式、媒介或系統限制而免除保護責任。
  • 資訊處理應遵循最小權限、最小揭露、最小保存、必要知悉、加密保護、完整性保護與可稽核性原則。
  • 高機密、PII、客戶資料、AI輸入輸出、源碼、金鑰、稽核證據與GHG/CO2查證底稿應依專項規則加強保護。
  • 資訊分類、標示或處理方式發生疑義時，應依較高保護等級處理，並由Data Owner、資訊資產Owner或ISMS管理代表確認。

3. 名詞與定義

名詞 定義
資訊分類 依資訊敏感度、價值、法規要求、業務影響與風險等級，對資訊指定保護等級之活動。
資訊標示 以文字、標籤、浮水印、metadata、系統欄位、檔名、頁首頁尾或其他方式標示資訊分類與處理限制。
資訊處理 資訊之建立、收集、存取、使用、修改、複製、傳輸、共享、列印、儲存、備份、歸檔、刪除與銷毀。
Data Owner 對資料之分類、用途、授權、保護、保存、刪除及風險承擔負責之角色。
Information Custodian 受託保管或維運資訊之角色，例如IT、雲端管理員、系統管理員或外包服務提供者。
必要知悉 僅允許因職務或核准目的確有需要者存取資訊。
PII 可識別自然人或與自然人相關之個人資料，包括一般PII與敏感PII。
高機密資訊 若未授權揭露、修改或遺失，可能造成重大法規、財務、營運、聲譽、客戶或個人權益損害之資訊。
受控傳輸 依資訊分類使用核准通道、加密、收件人確認、傳輸紀錄與必要核准之資訊傳輸活動。
安全銷毀 使資訊無法被合理還原或復原之刪除、覆寫、消磁、粉碎、熔毀或供應商銷毀程序。

角色 主要責任
最高管理階層 支持資訊分類與標示制度，核准重大例外、資源與風險接受。
CISO / 資訊安全負責人 制定與監督資訊標示與處理安全要求，核准高風險例外與重大違規處置。
ISMS管理代表 維護本作業指導書，整合風險、稽核、CAPA、教育訓練與管理審查。
Data Owner 指定資料分類、使用限制、保留期限、共享條件與刪除要求。
資訊資產Owner 確保資訊資產清冊、分類、標示、授權與保護措施維持正確。
Information Custodian 依Owner要求實施存取控制、備份、加密、日誌、保存、刪除與技術保護。
文件管制負責人 確保文件版次、發行、回收、保存、封存與銷毀符合文件化資訊要求。
DPO / PIMS負責人 審查PII分類、標示、跨境傳輸、DPIA、DPA與隱私處理要求。
AI治理負責人 審查AI輸入、AI輸出、模型資料、提示內容與AI服務資料處理限制。
BCMS / DRP負責人 確認關鍵資訊之備份、復原、保存與中斷期間保護要求。
GHG資料治理負責人 確認碳資料、排放係數、查證底稿與對外揭露資訊之標示與處理要求。
使用者 依分類與標示要求處理資訊，保護資訊，避免未授權揭露，並即時通報異常。

5. 資訊分類等級

等級 定義 範例 基本處理要求
公開（Public） 經正式核准可對外公開，揭露不會造成不利影響之資訊。 公開網站內容、公開新聞稿、已發布型錄。 需經對外發布程序核准，避免誤導或過期資訊。
內部（Internal） 僅供組織內部使用，未授權外流可能造成輕微影響之資訊。 一般內部公告、部門流程、內部會議資料。 限內部授權使用，不得公開或輸入未核准外部平台。
機密（Confidential） 未授權揭露可能造成中度至重大影響之業務、客戶、技術、合約或營運資訊。 客戶資料、合約、內部稽核、系統設計、財務草案。 需限制授權、加密傳輸、受控共享、保存紀錄。
高機密（Highly Confidential） 未授權揭露、竄改或遺失可能造成重大法規、財務、營運、聲譽或個人權益損害之資訊。 大量PII、敏感PII、金鑰、核心源碼、併購、重大漏洞、資安事件證據。 最小權限、強加密、強監控、DLP、雙人覆核、嚴格傳輸與銷毀。
受法規/合約限制（Restricted） 受法律、合約、DPA、NDA、客戶要求、監管或查證要求限制之資訊，可與上述等級疊加。 PII、客戶受託資料、支付資料、醫療資料、GHG查證底稿。 依最嚴格適用要求處理，保留法規與合約證據。

6. 分類判定準則

判定面向 判定問題 提高分類等級條件
機密性 未授權揭露是否造成業務、客戶、合約或法規損害？ 涉及客戶資料、商業秘密、未公開財務、資安事件、金鑰或源碼。
完整性 資訊錯誤、竄改或未授權修改是否造成決策、營運或揭露錯誤？ 涉及財務、GHG/CO2、查證、合規報告、系統設定或AI訓練/評估資料。
可用性 資訊不可用是否影響關鍵流程、客戶SLA或RTO/RPO？ 涉及關鍵系統設定、復原文件、備份索引、事件應變與DRP資料。
隱私 是否可識別自然人或涉及敏感PII？ 涉及大量PII、敏感PII、資料主體權利或跨境處理。
AI風險 資訊是否會作為AI輸入、訓練、評估或自動化決策依據？ 涉及高影響AI用途、模型資料、提示資料、標註資料或AI輸出決策。
供應鏈 資訊是否提供給供應商、第四方或雲端服務處理？ 涉及外包、子處理者、雲端、AI API或供應商遠端支援。
法規合約 是否受法規、合約、NDA、DPA、SLA或客戶承諾限制？ 違反可能導致罰則、違約、通報、客戶損害或驗證不符合。

7. 資訊分類決策流程

步驟 作業內容 責任角色 輸出
1. 識別資訊 確認資訊名稱、來源、用途、Owner、資料類型、使用者與生命週期。 資訊產生者 / Data Owner 資訊識別紀錄。
2. 判定敏感度 依機密性、完整性、可用性、PII、AI、供應鏈、法規合約與營運影響判定。 Data Owner / ISMS代表 分類判定結果。
3. 指定分類 選擇公開、內部、機密、高機密及受限制標籤，必要時加上專項標籤。 Data Owner 分類與標示設定。
4. 定義處理規則 定義存取、傳輸、共享、列印、保存、刪除、備份、AI使用與第三方處理限制。 Data Owner / Custodian 處理規則。
5. 設定技術控制 於DMS、雲端、DLP、權限、標籤、加密或系統欄位實作控制。 IT / Custodian 控制實施證據。
6. 定期檢討 依年度、事件、法規、合約、用途或Owner變更重新檢討。 Data Owner / ISMS代表 重評紀錄。

8. 標示要求總則

標示原則 要求
可見性 紙本、電子文件、郵件、簡報、報表與匯出資料應有清楚可見之分類標示。
一致性 檔名、頁首/頁尾、浮水印、metadata、DMS標籤與系統欄位應盡量一致。
可機器讀取 可行時應使用DLP、Microsoft Purview、Google Workspace Labels、DMS欄位或等效標籤支援自動控制。
最嚴格標示 混合多種分類資訊時，應以最高分類等級標示整體文件或清楚標示區段差異。
不可移除 除非資料重新分類或由Owner核准，使用者不得移除、降低或規避分類標示。
外部接收 接收外部資訊時，應保留原標示；若無標示，應依組織分類準則重新判定。

11. 電子文件處理規則

分類等級 存取 傳輸 儲存 共享 處理限制
公開 依對外發布流程授權後可公開。 可使用一般通道。 可存於核准公開平台。 可公開分享。 需避免過期、錯誤或未核准聲明。
內部 限內部授權人員。 可使用公司郵件、內部協作平台。 公司核准儲存位置。 限組織內部。 不得放置公開平台或個人帳號。
機密 限必要知悉者。 需使用公司核准加密或受控通道。 核准DMS、雲端或加密儲存。 需Owner核准或受控分享。 不得使用個人雲端或未核准AI工具。
高機密 限最小授權、強驗證與監控。 需加密、收件人確認、必要時雙人覆核。 高安全區域、加密儲存、DLP監控。 原則上不得外部分享，必要時高層核准。 禁止輸入未核准AI、禁止公開連結、需嚴格銷毀。
受限制 依法規、合約、DPA、NDA或客戶要求。 依最嚴格要求加密、核准與留痕。 需符合法規地區、保存與刪除要求。 限合約或法定目的。 需保留處理依據、授權與稽核證據。

12. 紙本文件處理規則

分類等級 列印 保存 攜出 銷毀 特殊要求
公開 依需求列印。 一般保存。 可攜出。 一般回收或銷毀。 需確認為核准公開版。
內部 限業務需要列印。 內部辦公區域保存。 避免不必要攜出。 碎紙或受控回收。 不得遺留於公共區域。
機密 需業務必要，建議列印登錄。 上鎖櫃或受控區域。 攜出需主管或Owner核准。 碎紙、機密文件銷毀或委外銷毀證明。 列印後即時取件。
高機密 原則上避免列印，必要時核准並登錄。 保險櫃或高安全區域。 原則上不得攜出，例外需CISO或授權核准。 交叉碎紙、熔毀或受控銷毀證明。 需編號、收發、回收與盤點。
受限制 依法規、合約或客戶要求。 依保存與存取限制。 依授權與傳輸要求。 依法規或合約銷毀要求。 需保留銷毀紀錄。

13. 電子郵件與附件處理規則

情境 處理要求 控制措施
寄送內部資訊 確認收件人與業務目的，可使用公司郵件。 內部標示、避免轉寄外部。
寄送機密資訊 確認收件人、附件、分類、授權與必要加密。 加密附件、權限連結、DLP提示。
寄送高機密資訊 需Owner核准，使用受控傳輸，避免附件外寄。 加密、到期權限、下載限制、雙人覆核。
寄送PII 需確認合法目的、最小資料、收件人與DPO/流程要求。 加密、DLP、收件人確認、傳輸紀錄。
誤寄處理 立即通報SOC/DPO/主管，不得自行隱匿。 事件通報、收件人回收要求、證據保全。
外部郵件附件 對可疑附件或連結不得開啟，應通報。 郵件安全閘道、釣魚通報。

14. 即時通訊與協作平台處理規則

情境 允許要求 禁止或限制
一般內部討論 可使用核准通訊工具與授權群組。 不得加入未授權外部人員。
機密資訊分享 需確認群組成員、權限、保存與下載限制。 不得使用個人通訊軟體或公開群組。
高機密資訊分享 原則上避免於即時通訊中傳送，必要時使用受控文件連結。 不得貼上完整高機密內容、金鑰或大量PII。
PII討論 僅分享最小必要內容，必要時遮罩。 不得於非核准通道傳送敏感PII。
AI輸出分享 需標示AI Output與覆核狀態。 不得將未覆核AI輸出作為正式決策。
群組退場 人員離職、轉調或專案結束時移除群組。 不得保留無業務必要之存取。

15. 雲端儲存與共享處理規則

項目 作業要求 禁止事項
核准平台 僅得使用核准雲端儲存、DMS或協作平台保存組織資訊。 禁止使用個人雲端、私人帳號或未核准SaaS。
共享權限 共享應採最小權限、指定對象、到期日與必要下載限制。 禁止公開連結分享內部以上資訊。
外部分享 外部分享機密資訊需Owner核准並記錄目的與期限。 不得將高機密資料外部分享，除非正式核准。
下載與同步 大量下載、離線同步或跨裝置同步需符合分類與設備安全要求。 禁止同步至未受管設備。
雲端標籤 雲端資料夾、文件或資料集應套用分類標籤與DLP規則。 不得移除標籤或規避DLP。
到期清理 專案結束或用途消失時，應檢討權限、封存或刪除。 不得無限期保留共享權限。

16. 可攜式媒體與外部儲存處理規則

分類等級 使用要求 控制措施
公開 可依業務需求使用。 避免混入內部或機密資料。
內部 需使用公司核准媒體，避免不必要複製。 標示、盤點、基本加密。
