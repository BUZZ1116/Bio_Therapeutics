1. 填寫說明與維護原則

本表單為企業級設備維護紀錄。填寫時應依設備重要性、資料分類、維護類型、是否涉及供應商、是否涉及遠端存取、是否需停機、是否涉及資料或設定變更，完整記錄維護前檢查、維護過程、維護後驗收與異常改善。若維護活動涉及Critical/High設備、機房支援設施、個人資料、客戶資料、特權帳號、加密金鑰、遠端維護或供應商攜出設備，應提高審查與簽核層級。

  • 維護活動不得未經授權即停機、拆機、替換零件、調整組態、接入外部工具或變更安全控制。
  • 涉及設定變更、韌體更新、停機、備援切換或安全控制調整者，應依變更管理、備份還原與安全組態要求執行。
  • 供應商進場維護應完成訪客登記、身分確認、陪同、工具管制、拍照/錄影限制、資料保護與離場確認。
  • 遠端維護應採核准時段、具名帳號、MFA、最小權限、Session紀錄、日誌保存與事後撤權。
  • 維護後應確認設備功能、安全組態、日誌、監控、告警、門禁、攝影、封條、纜線、備份或環境參數恢復正常。
