1. 作業目的

本作業指導書規範組織網路與網路安全控制之設計、建置、分段、連線、存取、監控、變更、審查、事件處理與持續改善要求，確保網路基礎設施、雲端網路、遠端存取、供應商連線、AI/MLOps/RAG連線、API與對外服務具備適當保護，降低未授權存取、橫向移動、資料外洩、服務中斷、DDoS、惡意流量、弱協定、錯誤設定與供應鏈連線風險。

本文件支援ISO/IEC 27001:2022 Annex A.8.20網路安全、A.8.21網路服務安全、A.8.22網路分隔、A.8.23網頁過濾、A.8.24密碼學使用及相關存取控制、日誌監控、弱點管理、供應商管理、雲端服務與營運持續要求。

2. 作業原則

  • 網路安全應採最小連線、預設拒絕、分區分段、零信任、深度防禦、可監控、可追溯、變更受控與風險導向原則。
  • 任何網路連線、開放埠、外部暴露、供應商連線、跨區連線、雲端安全群組、VPN/ZTNA或防火牆規則均應具明確Owner、業務目的、資料分類、風險評估、核准紀錄與定期審查。
  • 管理介面、特權系統、資料庫、備份平台、KMS、PAM、SIEM、MLOps、AI模型服務與關鍵系統不得直接暴露於網際網路，除非經CISO核准並具補償控制。
  • 網路架構、規則與設定應與資產清冊、資料分類、業務流程、ICT備妥性、雲端服務清冊、供應商登錄及風險登錄保持一致。
  • 網路安全控制不得因效能、成本或便利性而任意關閉；若須例外，應執行風險評估、補償控制、核准、期限與重評。

3. 名詞與定義

名詞 定義
網路區域 依業務功能、資料分類、風險等級、信任邊界或技術用途劃分之網路範圍，例如DMZ、內部區、管理區、資料庫區、備份區、AI/MLOps區。
網路分段 透過VLAN、子網、防火牆、安全群組、ACL、微分段或SDN策略限制不同區域間通訊之控制。
DMZ Demilitarized Zone，介於網際網路與內部網路間之隔離區域，用於放置對外服務並限制其對內部資源存取。
防火牆規則 定義來源、目的、埠、協定、動作、時間、應用、使用者與記錄要求之網路存取控制設定。
ZTNA Zero Trust Network Access，基於身份、裝置狀態、風險與應用層授權提供遠端或內部應用存取之方式。
NAC Network Access Control，用於檢查裝置身份、合規狀態與授權，並控制其網路接入之機制。
IDS/IPS 入侵偵測/防禦系統，用於偵測或阻擋可疑網路流量與攻擊行為。
WAF Web Application Firewall，用於保護Web應用與API免受常見應用層攻擊之控制。
安全群組 / NSG 雲端環境中控制資源入站與出站流量之邏輯防火牆或網路安全規則。
微分段 以工作負載、應用、身份或標籤為單位進行細粒度網路隔離與通訊控制。
網路服務 由內部或外部供應商提供之網路連線、防護、DNS、VPN、DDoS、CDN、專線、SD-WAN、Proxy或網路管理服務。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
CISO / 資訊安全負責人 核准網路安全策略、高風險連線、重大例外、事件升級與風險接受。 核准紀錄、風險接受、事件決策。
Network Security Owner 制定網路安全基準、分區分段要求、防火牆規則標準與網路安全監控要求。 網路安全基準、規則審查紀錄。
Network Operations Owner 負責網路設備、線路、VPN、DNS、DHCP、NTP、SD-WAN、防火牆與網路可用性維運。 網路組態、維運紀錄、服務報告。
Cloud Security / Cloud Network Owner 管理雲端VPC/VNet、安全群組、路由、Private Link、跨區連線、雲端防火牆與CSPM。 雲端網路設定、CSPM報告。
SOC / Monitoring Owner 監控網路流量、IDS/IPS、WAF、DNS、Proxy、DDoS、VPN、異常連線與威脅告警。 SIEM告警、事件工單、監控報告。
System / Application Owner 提出網路需求，確認來源、目的、埠、資料分類、業務必要性、服務依賴與測試驗證。 連線申請、驗收紀錄。
Data Owner 確認涉及資料之網路傳輸、加密、跨境、供應商連線與資料外洩風險。 資料分類、傳輸核准。
IAM Owner 確保VPN/ZTNA、管理介面與網路設備存取符合身份驗證、MFA、特權管理與離職撤權。 IAM設定、權限審查。
Supplier Management Owner 管理電信、雲端、MSSP、DDoS、CDN、專線與外包維運之網路服務供應商安全要求。 供應商評估、合約SLA。
BCMS / ICT Readiness Owner 評估網路服務之RTO/RPO、冗餘、備援、故障切換、專線與DDoS復原能力。 ICT備妥性評估、演練報告。
Internal Auditor 抽查網路規則、連線、組態、變更、日誌、例外、事件與供應商管理證據。 稽核底稿、稽核發現。

5. 網路區域與分段架構

網路區域 用途 最低安全要求 典型限制
Internet / 外部區 公共網際網路、外部使用者與未信任來源。 預設不信任，所有入口需經邊界保護、WAF、DDoS或CDN等控制。 不得直接連至內部關鍵系統。
DMZ / 對外服務區 對外網站、API Gateway、反向代理、WAF後端與公開服務。 最小必要連線、強化主機、WAF/IPS、日誌監控與漏洞修補。 僅允許必要流量進入內部服務。
內部使用者區 一般辦公端點、內部應用存取與使用者網段。 NAC/端點合規、網路分段、Proxy/DNS過濾、EDR與最小通訊。 不得直接存取資料庫或管理介面。
伺服器區 內部應用、服務、檔案、資料處理與中介服務。 防火牆分段、最小連線、日誌、弱點管理與備份。 僅允許核准應用流量。
資料庫區 資料庫、資料倉儲、資料湖、敏感資料儲存。 嚴格分段、僅應用服務存取、加密、資料庫審計。 禁止使用者端點直接連線，除核准管理通道。
管理區 網路設備、伺服器、PAM、KMS、備份、虛擬化、雲端管理入口。 MFA/PAM、跳板、管理端點、Session Recording、來源限制。 不得公開網際網路。
安全監控區 SIEM、EDR、IDS/IPS、Log Collector、DLP、SOAR。 高完整性保護、限制存取、時間同步、備份。 不得讓一般使用者存取。
備份與復原區 備份平台、備份儲存、不可變備份、DR系統。 隔離網段、最小管理、不可變、離線或獨立權限域。 不得由一般端點直接存取。
開發測試區 開發、測試、CI/CD、測試資料與測試服務。 與正式環境隔離、測試資料限制、Secrets隔離。 不得使用正式資料或正式Secrets，除非核准。
AI/MLOps/RAG區 AI模型服務、MLOps、向量資料庫、RAG資料源、推論API。 資料分類、API限制、RAG權限、Secrets管理、模型與資料監控。 不得未核准連接高機密資料源或外部AI服務。
供應商連線區 供應商VPN、專線、遠端支援、B2B整合。 單獨分段、MFA、時間限制、Session Recording、最小權限。 不得橫向存取其他網段。
Guest / 訪客區 訪客與非受管裝置上網。 完全隔離內部網路，限上網，使用者告知與頻寬/時間限制。 不得存取內部資源。

6. 網路安全管理流程

階段 作業要求 責任角色 輸出證據
1. 網路需求提出 提出來源、目的、埠、協定、用途、資料分類、系統Owner、有效期限與業務必要性。 Application / System Owner 網路連線申請。
2. 風險與架構審查 評估信任邊界、資料敏感度、暴露面、供應商、AI/雲端、營運持續與合規風險。 Network Security / CISO 架構審查紀錄。
3. 規則設計 採最小連線、預設拒絕、分段、日誌、到期日、命名與Owner標籤。 Network Owner / Cloud Owner 規則設計紀錄。
4. 變更核准 依變更管理流程核准網路、防火牆、VPN、雲端安全群組與路由變更。 Change Manager / CISO 變更單。
5. 實作與驗證 部署後驗證連線、阻斷非預期流量、日誌產生與告警可用。 Network Operations / SOC 實作與測試紀錄。
6. 持續監控 監控流量、規則命中、異常、掃描、DDoS、WAF、IDS/IPS、DNS與Proxy事件。 SOC / Network Owner 監控報告。
7. 定期審查 定期審查規則必要性、Owner、有效期限、寬鬆規則、未命中規則與過期連線。 Network Security Owner 規則審查紀錄。
8. 偏差與例外處理 不符合基準之規則、公開暴露或弱協定需修正或例外核准。 CISO / Risk Owner 偏差或例外紀錄。

7. 防火牆、ACL與安全群組管理

控制項目 最低要求 證據
規則命名與Owner 每條規則應具用途、Owner、申請單、有效期限、環境與風險標籤。 防火牆規則清單、變更單。
最小權限 來源、目的、埠、協定應最小化，不得使用any-any或過寬CIDR，除非例外核准。 規則審查報告。
預設拒絕 邊界、防火牆、重要區域與雲端安全群組應預設拒絕。 組態基準。
臨時規則 臨時規則需設定到期日，到期自動停用或審查。 到期規則報告。
日誌記錄 對外入口、跨區、高風險、管理與拒絕流量應記錄日誌。 防火牆Log、SIEM。
規則審查 至少每季審查高風險與對外規則，至少每年全面審查。 規則審查紀錄。
未命中規則 長期未命中規則應停用或刪除，降低攻擊面。 命中率報告。
高風險服務 管理服務、資料庫、RDP、SSH、SMB、Kubernetes API、雲端Metadata等需嚴格限制。 掃描報告、規則檢查。
雲端安全群組 Security Group/NSG應受IaC與CSPM管理，避免手動漂移。 CSPM/IaC報告。

8. 遠端存取、VPN與ZTNA管理

控制項目 最低要求 高風險加強要求
身份驗證 遠端存取必須使用具名帳號、MFA與核准身份來源。 高權限遠端存取需PAM/JIT或管理端點。
裝置合規 遠端端點需符合EDR、加密、修補、MDM/UEM與風險狀態要求。 不合規端點自動阻斷或限制。
最小存取 VPN/ZTNA應以應用或網段最小授權，避免全網段通行。 高風險系統採ZTNA或跳板。
Session控制 高風險遠端作業應記錄Session、來源、時間、命令或操作活動。 供應商與特權作業需Session Recording。
地理與風險限制 可依地區、IP、時間、使用者風險、裝置風險設定限制。 異常地區登入需升級驗證或阻斷。
供應商遠端支援 供應商存取需事前核准、時段限制、最小權限、活動記錄與使用後撤權。 不得使用共享固定VPN帳密。
Split Tunneling 如開啟Split Tunneling，應評估資料外洩與監控缺口。 高風險端點或管理作業原則停用。
憑證與密鑰 VPN憑證、裝置憑證與金鑰需受控、輪替與撤銷。 離職或事件後立即撤銷。

9. 無線網路與訪客網路管理

控制項目 企業無線網路要求 訪客網路要求
身份驗證 使用企業身份、憑證或強驗證，不得共享靜態密碼。 可使用訪客帳號、Portal或短期憑證。
加密 使用核准無線加密協定，禁用弱協定與預設密碼。 同樣需使用安全加密與隔離。
網路隔離 企業無線依使用者與裝置分類分段。 完全隔離內部網路，僅允許上網。
裝置合規 受管裝置優先，必要時NAC檢查。 不得授予內部系統存取。
訪客管理 訪客存取需有期限、用途、責任人或訪客政策告知。 到期自動失效。
日誌 記錄連線時間、裝置、來源、帳號或訪客識別。 依隱私與法規要求保存。
異常偵測 偵測Rogue AP、Evil Twin、異常連線或暴力破解。 重大異常通報SOC。

10. DNS、Proxy、Web過濾與外部連線管理

控制項目 作業要求 證據
DNS安全 使用核准DNS解析器，啟用惡意網域阻擋、查詢日誌與DNS異常偵測。 DNS日誌、阻擋報告。
Web過濾 依風險分類阻擋惡意網站、釣魚、C2、匿名代理、未核准檔案分享與高風險AI工具。 Proxy/CASB報告。
TLS檢查 依法規、隱私與風險啟用TLS檢查或替代偵測，排除需核准。 Proxy設定、例外清單。
外傳控制 外部上傳、雲端儲存、AI服務、檔案分享與API外連應受DLP/CASB監控。 DLP/CASB告警。
C2偵測 監控可疑DNS、Beaconing、異常User-Agent、長連線與未知目的地。 SIEM告警、SOC調查。
Proxy例外 Proxy繞過、直連Internet或白名單需風險評估與期限。 例外核准紀錄。
遠端瀏覽隔離 高風險瀏覽或未知網站可採用瀏覽器隔離或沙箱。 工具報告。

11. IDS/IPS、WAF、DDoS與邊界防護

控制項目 最低要求 事件處置
IDS/IPS 重要邊界、DMZ、資料中心與雲端關鍵流量應納入入侵偵測或等效監控。 Critical/High告警依事件程序處理。
WAF 對外Web與API服務應依風險啟用WAF，使用基準規則與自訂防護。 阻擋與誤判需記錄與調整。
API Gateway 對外API需具認證、授權、Rate Limit、Schema驗證、日誌與濫用防護。 異常流量與濫用需告警。
DDoS防護 對外關鍵服務應具DDoS偵測、緩解、CDN或流量清洗能力。 DDoS事件需通知BCMS與業務Owner。
邊界設備強化 防火牆、WAF、VPN、Proxy、DNS與DDoS設備應依安全基準強化。 弱點或設定缺失需修正。
規則更新 IDS/IPS/WAF規則需定期更新並進行誤判管理。 規則重大變更需測試。
日誌接入 WAF、IDS/IPS、DDoS、API Gateway與邊界防火牆日誌應接入SIEM或集中保存。 日誌中斷需告警。

12. 雲端與混合網路安全

控制項目 作業要求 證據
VPC/VNet設計 依環境、資料分類、服務與信任邊界設計子網與路由。 雲端架構圖、IaC。
Security Group/NSG 採最小開放、禁止高風險公開管理服務、規則需Owner與有效期限。 CSPM報告、規則清單。
Private Connectivity 關鍵服務優先使用Private Link、Private Endpoint、專線或私有連線。 雲端設定。
跨區與跨雲連線 需加密、路由明確、最小存取、監控與故障切換計畫。 連線設計、測試紀錄。
雲端流量日誌 VPC Flow Log、Firewall Log、Load Balancer Log、DNS Log應依風險啟用。 日誌接入紀錄。
CSPM監控 雲端網路錯誤組態、公開暴露、過寬規則與未加密流量應持續偵測。 CSPM報告。
雲端NAT與Egress 外連流量應可監控、可限制、可追蹤，避免未受控Egress。 Egress Policy、Proxy設定。
雲端管理介面 雲端管理API與Console需MFA、條件式存取、日誌與PAM。 IAM與Audit Log。

2 保存防火牆、VPN、DNS、Proxy、WAF、IDS/IPS、Flow Log與端點/伺服器相關日誌。 □ 完成
3 依事件類型阻斷來源、停用規則、隔離網段、啟用DDoS防護或限制API。 □ 完成
4 確認是否涉及資料外洩、PII、客戶資料、供應商連線或AI/MLOps資料源。 □ 完成
5 通知CISO、System Owner、Data Owner、BCMS與必要供應商。 □ 完成
6 分析根因，包括錯誤規則、弱協定、暴露服務、憑證外洩、弱點或攻擊活動。 □ 完成
7 修正網路規則、組態、監控、弱點或供應商連線控制。 □ 完成
8 完成事件檢討、CAPA、風險登錄與管理審查輸入。 □ 完成
