1. 文件目的

本文件用於正式任命ISMS、PIMS、AI治理及GHG/CO2資料治理相關角色，明確定義受任人之責任、權限、報告線、代理人、能力要求、利益衝突聲明、職責區隔、證據保存義務及任命異動管理要求。

本任命書可作為ISO/IEC 27001:2022 Clause 5.3「組織角色、責任與權限」、Clause 7.2「能力」、Clause 7.3「認知」、Clause 7.5「文件化資訊」及Annex A控制措施Owner分派之驗證證據。

1.1 管理活動與輸出摘要

文件章節 / 管理主題 如何使用 輸出 / 證據
1. 文件目的 用於將資訊安全政策與領導治理程序中對角色、責任、權限及資源承諾的要求，轉化為可簽署、可保存、可稽核之任命證據。 任命目的、管理階層授權與責任分派證據。
2. 適用範圍 用於判定哪些ISMS/PIMS/AI/GHG範圍、資產、系統、資料集、AI服務、碳資料與供應商活動需有正式Owner或責任角色。 任命範圍、資產Owner、AI/GHG資料Owner。
3. 名詞與定義 用於統一任命、Owner、Control Owner、代理人、利益衝突、風險擁有者等術語，避免不同文件使用不同責任定義。 一致化術語與責任定義。
4. 組織架構參考 用於將最高管理階層、治理委員會、ISMS管理代表、PIMS、AI、GHG、內稽與CAPA組織化呈現，支援管理審查與稽核訪談。 組織架構、報告線、治理委員會紀錄。
5. 資訊安全責任任命書表單 用於填寫每位受任人之角色、責任、權限、任期、代理人、能力、證據、利益衝突及簽署承諾，並納入文件化資訊管制。 簽署版任命書、能力證據、接受聲明。
6. 任命角色責任矩陣 用於確認CISO、風險、SoA、Asset Owner、Data Owner、System Owner、DPO、AI、GHG、內稽、CAPA等角色之責任與最低證據。 角色責任矩陣、SoA Owner、風險Owner、資產Owner。
7. Annex A控制群組任命責任對照 用於將Annex A.5、A.6、A.7、A.8控制群組分派給組織、人員、實體及技術控制Owner，並確認能力與證據。 控制群組Owner、控制證據、控制有效性證據。
8. 任命作業流程 用於說明任命需求識別、角色確認、能力確認、核准、簽署、文件更新及定期審查的操作流程。 任命需求、任命草案、核准紀錄、異動紀錄。
9. 任命作業RACI Matrix 用於將任命流程的Responsible、Accountable、Consulted、Informed分配給最高管理階層、CISO、HR、法務、部門主管、受任人及內部稽核。 任命作業RACI、溝通矩陣。
10. 能力、訓練與認知要求 用於確認受任人是否具備履行角色之能力，並將能力缺口納入訓練計畫、認知溝通、績效監督及稽核。 能力確認、訓練紀錄、測驗、資格證據。
11. 任命審查、異動與撤銷 用於在組織變更、重大事件、稽核發現、CAPA、職務異動或年度審查時重新確認任命有效性。 任命審查、異動、撤銷、CAPA與改善追蹤。
12. 利益衝突與職責區隔要求 用於確認核准、執行、審查、稽核及權限管理是否適當區隔，並要求受任人揭露利益衝突。 利益衝突聲明、稽核員獨立性、權限審查。
13. 任命接受與承諾聲明 用於確保受任人已理解資訊安全、AI、PII、GHG資料、保密及事件通報義務。 受任人簽署承諾、認知紀錄。
14. 文件化資訊與保存要求 用於保存任命書、能力訓練、RACI更新、權限設定、任命異動與利益衝突聲明。 保存證據、文件清冊、權限紀錄。
15. 驗證稽核對照表 用於對應Clause 5.3、7.2、7.3、7.5及Annex A.5.2、5.3、6.3、5.35等查核重點。 稽核工作底稿、稽核發現、管理審查輸入。

2. 適用範圍

  • 適用於被任命為最高管理階層授權代表、CISO、ISMS管理代表、風險管理負責人、風險Owner、Asset Owner、Data Owner、System Owner、Control Owner、DPO/PIMS負責人、AI治理負責人、Model Owner、Prompt/RAG Owner、GHG資料治理負責人、Carbon Data Owner、內部稽核員、CAPA負責人、文件管制負責人、教育訓練負責人及其他ISMS/PIMS/AI/GHG責任角色之人員。
  • 適用於新任、異動、續任、代理、撤銷或因組織變更、重大風險、重大事件、稽核發現、管理審查決議所需之責任重新指派。
  • 適用於內部人員、外包人員、專案成員、供應商代表及其他經組織授權承擔管理系統責任之角色。
  • 適用於控制措施Owner、資產Owner、流程Owner、資料Owner、AI系統Owner、GHG/CO2資料Owner及關鍵供應鏈/雲端服務管理Owner之正式責任確認。

3. 名詞與定義

名詞 定義
任命 由最高管理階層或授權主管正式指定特定人員擔任ISMS/PIMS/AI/GHG相關責任角色，並賦予其責任、權限、報告線及資源需求。
受任人 接受資訊安全、隱私、AI、GHG資料治理、控制措施或稽核責任指派之人員。
委任主管 具備正式授權，可指派、核准或調整資訊安全責任任命之主管或管理階層代表。
Owner 對特定資產、資料、系統、模型、流程或控制措施負有保護、授權、風險判定與證據維護責任之角色。
Control Owner 負責控制措施設計、執行、證據保存、有效性測試與改善追蹤之角色。
Risk Owner 對特定資訊安全、隱私、AI或GHG資料風險之評估、處理、接受、監測與改善負有責任之角色。
代理人 受任人無法履行職責時，依本任命書或授權程序暫時代理其職責之人員。
利益衝突 受任人因職務、稽核、供應商、採購、開發、營運或個人關係，可能影響其客觀執行資訊安全責任之情形。
職責區隔 將核准、執行、審查、稽核及權限管理責任適當分離，以降低錯誤、舞弊、利益衝突及控制失效風險。
