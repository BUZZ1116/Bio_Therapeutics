1. 作業目的

本作業指導書規範安全編碼之原則、要求、程式碼審查、安全測試、弱點修復、開源元件管理、Secrets保護、API安全、資料保護、雲端與容器安全、AI應用安全、CI/CD閘門與稽核證據要求，確保所有由組織自行開發、委外開發、共同開發、低程式碼/無程式碼建置或整合開源/第三方元件之系統，均於程式碼層級降低安全缺陷與供應鏈風險。

本文件旨在將安全要求落實至每日開發活動，使開發人員能以一致、可驗證、可追蹤之方式避免常見弱點，例如注入攻擊、越權、身份驗證缺陷、敏感資料外洩、跨站攻擊、不安全反序列化、錯誤加密、錯誤設定、硬編碼Secrets、AI Prompt Injection、RAG越權檢索及不安全API使用。

2. 作業原則

  • 安全編碼應於需求、設計、實作、測試、部署、維護及退場各階段落實，不得僅依賴上線前掃描或滲透測試。
  • 所有程式碼應遵循安全預設、最小權限、輸入不信任、輸出需編碼、資料最小化、錯誤訊息最小揭露、Secrets不進Repo、日誌可追溯及失敗安全原則。
  • 任何處理PII、客戶資料、機密/高機密資料、支付資料、身份驗證、授權、加密、AI模型、RAG資料源、API或外部整合之程式碼，應執行強化安全編碼與審查。
  • 程式碼提交前應執行必要之自動化檢查；高風險缺陷不得以未經核准之方式帶入正式環境。
  • 使用開源、第三方套件、AI產生程式碼、範例程式或外包交付程式碼時，仍需依本文件進行安全審查、授權確認、弱點掃描與品質驗證。

3. 名詞與定義

名詞 定義
安全編碼 於程式設計與實作階段採取安全控制、檢查與設計模式，以降低程式碼缺陷、弱點與濫用風險。
SAST Static Application Security Testing，靜態應用程式安全測試，於程式碼或編譯階段檢查安全缺陷。
DAST Dynamic Application Security Testing，動態應用程式安全測試，於執行環境對應用程式進行黑箱或灰箱安全測試。
SCA Software Composition Analysis，軟體組成分析，用於識別開源元件、授權、版本與已知弱點。
Secrets掃描 檢查程式碼、Repo、CI/CD、日誌、容器映像與設定檔是否含有API Key、Token、密碼、私鑰或憑證。
SBOM Software Bill of Materials，軟體物料清單，用於記錄軟體元件、版本、授權、來源與供應鏈資訊。
安全閘門 CI/CD或發布流程中必須通過之安全檢查，例如SAST、SCA、Secrets掃描、IaC掃描、弱點門檻與人工審查。
AI產生程式碼 由生成式AI工具產生或輔助撰寫之程式碼、設定、測試或文件。
RAG Retrieval-Augmented Generation，透過檢索資料源或向量資料庫增強AI輸出之架構。
Prompt Injection 攻擊者透過輸入、文件、資料源或提示操作，使AI系統忽略原指令、外洩資料、執行未授權動作或產生不安全輸出。

5. 安全編碼基本要求

控制領域 安全編碼要求 驗證方式
輸入驗證 所有外部輸入、API參數、檔案、Header、Cookie、Webhook、AI輸入與RAG資料均視為不可信，需白名單驗證、長度限制、格式檢查與型別檢查。 Code Review、SAST、測試案例。
輸出編碼 依輸出情境進行HTML、JavaScript、URL、SQL、XML、JSON或Shell編碼，防止XSS與注入。 SAST、DAST、人工審查。
身份驗證 不得自行實作不安全認證；應使用核准身份服務、OAuth/OIDC、SSO、MFA與安全Session。 架構審查、測試。
授權控制 每個敏感操作、API、資料查詢與管理功能應於伺服器端驗證授權，不得僅依賴前端控制。 Code Review、權限測試。
錯誤處理 錯誤訊息不得洩漏Stack Trace、SQL、路徑、金鑰、內部架構或敏感資料。 DAST、日誌抽查。
日誌記錄 記錄必要安全事件，但不得記錄密碼、Token、PII全文、信用卡、私鑰或敏感Prompt。 日誌檢查、SIEM驗證。
資料保護 依資料分類進行加密、遮罩、最小化、保留、刪除與DLP控制。 Data Owner審查、測試。
Secrets管理 不得硬編碼Secrets，應使用Secrets Manager、KMS、環境隔離、短期憑證與輪替。 Secrets掃描、Vault紀錄。
安全預設 新功能預設應採安全設定，例如預設不公開、預設拒絕、預設最小權限。 架構審查、設定檢查。
防止濫用 對登入、API、搜尋、檔案上傳、AI呼叫與敏感操作設定Rate Limit、Captcha或風險控制。 API測試、WAF/API Gateway。

6. 常見弱點與禁止事項

弱點類型 禁止或避免事項 安全做法
注入攻擊 禁止將未驗證輸入直接拼接至SQL、NoSQL、LDAP、OS Command、Template、GraphQL或Prompt。 使用參數化查詢、ORM安全模式、命令白名單、模板隔離與Prompt防護。
XSS 禁止將未編碼資料輸出至HTML、JS或DOM。 使用情境化編碼、CSP、安全模板與輸入限制。
越權存取 禁止僅於前端隱藏按鈕或依URL猜測控制權限。 伺服器端每次檢查身份、角色、資料Owner與資源層授權。
不安全直接物件參照 禁止以可猜測ID直接存取他人資料。 資源存取需授權檢查、不可預測ID與資料範圍限制。
敏感資料外洩 禁止在URL、Log、Error、Analytics、AI Prompt、測試資料或前端程式保存敏感資料。 遮罩、加密、最小化、DLP與資料分類控管。
硬編碼Secrets 禁止在程式碼、設定、Repo、Notebook、容器映像或CI/CD檔案中保存Secrets。 使用Secrets Manager與掃描工具。
不安全反序列化 禁止反序列化不可信資料或啟用危險反序列化功能。 使用安全格式、簽章、白名單與完整性驗證。
不安全檔案上傳 禁止未檢查副檔名、MIME、內容、大小、惡意程式與儲存位置。 檔案白名單、AV掃描、隔離儲存、重新命名與權限限制。
不安全加密 禁止自創加密演算法、弱Hash、固定IV、明文金鑰或可逆密碼保存。 使用核准加密函式庫、KMS、Salted Hash與安全隨機數。
AI Prompt Injection 禁止讓外部輸入、RAG文件或使用者Prompt直接覆蓋系統指令或觸發高風險工具。 指令隔離、工具白名單、輸入分類、輸出驗證與人工確認。

7. 身份驗證、授權與Session安全編碼

項目 安全要求 測試要求
登入流程 使用核准身份服務，支援MFA、風險登入偵測、帳號鎖定或速率限制。 暴力破解、帳號枚舉、MFA繞過測試。
密碼處理 不得明文保存密碼；使用核准雜湊、Salt與參數，重設流程需一次性、短效。 密碼儲存與重設測試。
Session Cookie Cookie需設Secure、HttpOnly、SameSite，Session需具Timeout與撤銷能力。 DAST與手動檢查。
授權檢查 每個API與資料操作需伺服器端授權，依角色、屬性、租戶與資料Owner控管。 水平/垂直越權測試。
管理功能 管理功能需PAM或強驗證、操作日誌、雙人核准或敏感操作再驗證。 管理功能測試。
服務帳號 服務帳號需最小權限、用途明確、不可互動登入、Secrets受控與定期審查。 IAM與API權限審查。
權杖管理 JWT、OAuth Token、API Token需限制Scope、Audience、Issuer、期限與撤銷策略。 Token安全測試。

8. API與微服務安全編碼

項目 安全要求 測試要求
API認證 所有非公開API需認證；內部API亦不得預設信任網路位置。 未授權呼叫測試。
API授權 每支API需驗證使用者、服務、租戶、資源與動作授權。 BOLA/BFLA測試。
Rate Limit 登入、搜尋、匯出、AI呼叫、檔案上傳與敏感API需限制速率與配額。 濫用與壓力測試。
輸入Schema API需定義Schema、型別、長度、格式與必填欄位。 Fuzzing與負面測試。
錯誤回應 API錯誤不得洩漏Stack Trace、SQL、內部URL、Token或雲端資源識別。 DAST、錯誤測試。
CORS CORS需白名單來源，不得任意允許所有來源搭配憑證。 CORS組態測試。
Webhook Webhook需簽章驗證、Replay Protection、時間戳與來源限制。 Webhook攻擊測試。
版本管理 API版本退場、棄用、相容與安全修復需明確管理。 API清冊與版本紀錄。

9. 資料保護與隱私安全編碼

項目 安全要求 證據
資料最小化 程式僅收集、儲存、傳輸完成目的所必要之資料。 需求與資料欄位審查。
敏感資料標示 資料模型、欄位、DTO、Log與API回應應識別敏感欄位。 資料分類紀錄。
加密 敏感資料傳輸與儲存需加密；金鑰不得與資料保存在同一風險域。 加密設計與KMS設定。
遮罩 UI、API、報表、Log、測試環境與客服工具應對敏感資料遮罩。 測試截圖或驗證紀錄。
資料保留 程式需支援保留期限、封存、刪除與資料主體請求。 保留與刪除測試。
測試資料 禁止使用未遮罩正式PII或客戶資料於開發測試。 測試資料來源審查。
跨境與第三方 資料傳送外部API、SaaS、AI服務或供應商前需確認核准與合約限制。 DPA/供應商核准。
AI資料輸入 不得將Secrets、PII、高機密或客戶受限資料輸入未核准AI服務。 AI使用審查、DLP紀錄。

10. 檔案、內容與媒體處理安全編碼

項目 安全要求 測試要求
檔案類型限制 檔案上傳應採白名單副檔名、MIME與內容檢查。 上傳測試。
檔案大小與數量 限制檔案大小、數量、速率與總容量。 濫用測試。
惡意檔案掃描 上傳檔案應進行惡意程式掃描或沙箱分析。 AV/沙箱紀錄。
儲存位置 上傳檔應存於非Web Root或隔離儲存，並重新命名。 組態檢查。
下載授權 每次下載均需驗證使用者、租戶、資料Owner與授權範圍。 越權下載測試。
內容解析 處理PDF、Office、影像、壓縮檔、XML或模型檔時需防止解析器弱點與Zip Slip。 SCA、Fuzzing。
Metadata清理 對外提供檔案前應評估是否清除作者、路徑、地理位置或內部資訊。 資料外洩檢查。

11. 加密、金鑰與Secrets安全編碼

項目 安全要求 禁止事項
加密函式庫 使用核准且維護中之密碼學函式庫，不自行實作加密演算法。 禁止自創演算法或使用過時函式。
隨機數 Token、Nonce、IV、Session ID需使用密碼學安全隨機數。 禁止使用一般Random產生安全值。
密碼保存 密碼應以適當雜湊、Salt與參數保存。 禁止明文、Base64、可逆加密保存密碼。
金鑰管理 金鑰應由KMS、HSM或Secrets Manager管理，具權限、輪替與審計。 禁止硬編碼金鑰或提交至Repo。
API Key API Key需限制Scope、到期、用量與來源；外洩後可快速撤銷。 禁止前端暴露高權限Key。
Secrets掃描 提交、PR、Pipeline、容器映像與Artifact需執行Secrets掃描。 禁止忽略Critical Secret命中。
Token設計 Token需最小權限、短效、Audience限制、簽章驗證與撤銷策略。 禁止長效萬用Token。

12. 前端、Mobile與用戶端安全編碼

項目 安全要求 測試要求
前端授權 前端僅可作為使用體驗控制，不得作為唯一授權依據。 API越權測試。
敏感資料 前端、LocalStorage、SessionStorage、Mobile本地儲存不得保存高敏感Secrets或未加密敏感資料。 用戶端檢查。
XSS防護 使用安全框架、模板編碼、CSP、避免dangerous HTML或不可信DOM操作。 XSS測試。
CSRF防護 狀態改變操作需具CSRF防護或SameSite與Token策略。 CSRF測試。
Mobile安全 Mobile App需安全儲存、憑證固定視風險採用、Root/Jailbreak偵測與反逆向評估。 Mobile安全測試。
第三方SDK 前端與Mobile SDK需審查來源、權限、資料蒐集、授權與弱點。 SCA與隱私審查。
錯誤與Debug 正式版本不得開啟Debug、測試端點、Verbose Log或內部設定。 Release檢查。

13. 雲端、容器、IaC與CI/CD安全編碼

項目 安全要求 證據
IaC安全 Terraform、CloudFormation、Kubernetes YAML、Helm、Ansible等需掃描錯誤組態。 IaC掃描報告。
容器映像 使用最小基礎映像、非Root、唯讀檔案系統、移除不必要工具並掃描弱點。 容器掃描報告。
Kubernetes設定 限制特權容器、Capabilities、Host Network、ServiceAccount與Network Policy。 Policy as Code報告。
CI/CD權限 Pipeline Runner、Deploy Token、Artifact與環境變數需最小權限與環境隔離。 Pipeline設定。
分支保護 主分支需PR審查、狀態檢查、簽章或保護規則。 Repo設定。
Artifact完整性 Build Artifact需版本、雜湊、來源、SBOM與簽章或等效完整性保護。 Artifact紀錄。
部署防呆 正式部署需通過安全閘門，不得手動繞過Critical掃描結果。 Release Gate紀錄。

14. 開源、第三方元件與供應鏈安全

項目 安全要求 證據

15. AI輔助開發與AI應用安全編碼

項目 安全要求 證據
AI產生程式碼審查 AI產生或輔助撰寫之程式碼須視同人工程式碼審查，不得未檢查直接上線。 Code Review紀錄。
禁止輸入敏感資訊 不得將Secrets、內部漏洞、客戶資料、PII、高機密程式碼或未核准資料輸入外部AI工具。 DLP/AI使用紀錄。
Prompt安全 Prompt模板需版本管理、權限控管、輸入分類、防Prompt Injection與輸出驗證。 Prompt清冊、測試紀錄。
RAG安全 RAG檢索需權限繼承、資料分類、索引刪除同步與越權測試。 RAG測試報告。
AI Agent工具 Agent工具需白名單、最小權限、人工確認、操作日誌與高風險動作阻斷。 Agent權限矩陣。
模型API安全 AI模型API需認證、授權、Rate Limit、用量監控、成本告警與資料外傳監控。 API Gateway與監控報告。
AI輸出處理 AI輸出不得直接作為高風險動作依據，需驗證、過濾、人工覆核或業務規則限制。 測試案例、覆核紀錄。
AI安全測試 測試Prompt Injection、資料外洩、越權、敏感輸出、工具濫用與模型供應鏈風險。 AI安全測試報告。

16. 程式碼審查與Pull Request要求

審查項目 最低要求 高風險加強要求
審查人員 所有正式程式碼需至少一名具權限審查人員審核。 高風險功能需AppSec或資深工程師審查。
審查範圍 審查安全、品質、測試、資料保護、授權邏輯、錯誤處理、Secrets與依賴套件。 需使用安全檢核表。
自動檢查 PR需通過單元測試、SAST、SCA、Secrets掃描及格式/品質檢查。 Critical/High安全結果需阻擋合併。
敏感變更 身份、授權、加密、資料匯出、AI、RAG、Secrets、IAM、網路、CI/CD變更需標記。 需安全架構或AppSec審查。
測試證據 修復或新增功能需包含安全測試、負面測試或驗證紀錄。 高風險需滲透或專項測試。
例外處理 未通過安全檢查不得直接合併；例外需CISO或授權角色核准。 需風險接受與期限。

17. 安全測試與CI/CD安全閘門

安全閘門 觸發時點 阻擋條件 證據
Secrets掃描 Commit、PR、Pipeline、Artifact、Container Build。 任何有效Secret或高可信Secret命中。 掃描報告、撤銷紀錄。
SAST PR、每日Build、Release前。 Critical/High未修正或未接受。 SAST報告。
SCA PR、Build、Release、定期排程。 Critical可利用弱點、禁止授權或惡意套件。 SCA/SBOM報告。
DAST 測試環境、Release前、重大變更後。 Critical/High應用弱點未修正。 DAST報告。
IaC掃描 PR、部署前。 公開高風險資源、過寬權限、未加密、未記錄日誌。 IaC掃描報告。
容器掃描 映像建立、部署前、定期。 Critical/High未修正或無補償控制。 容器掃描報告。

AI安全測試 AI/RAG/Agent變更、模型版本變更、Release前。 Prompt Injection、資料外洩或高風險工具濫用未處理。 AI測試報告。

18. 弱點修復與風險接受

弱點等級 判定條件 修復期限 處理要求
Critical 可被遠端利用、造成特權取得、資料外洩、重大服務中斷、Secrets外洩或高風險AI濫用。 立即處理，原則24至72小時內修正或隔離。 不得上線；若例外需CISO核准與補償控制。
High 可能造成越權、敏感資料暴露、重大功能濫用、供應鏈風險或重要控制失效。 7至14日內修正，依風險設定。 上線前應修正或風險接受。
Medium 需特定條件利用，可能導致局部資料暴露、功能濫用或安全控制降低。 30至60日內修正。 納入修復計畫。
Low 低風險缺陷、最佳實務差異或資訊揭露有限。 90日內或依版本規劃修正。 定期追蹤。
Accepted Risk 因技術、業務或供應商限制暫不修正。 依核准期限重評。 需風險接受、補償控制、Owner與到期日。
