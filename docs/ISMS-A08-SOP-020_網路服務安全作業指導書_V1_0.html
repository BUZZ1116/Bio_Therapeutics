1. 作業目的

本作業指導書規範組織網路服務之規劃、建置、組態、存取、監控、變更、維護、備援、事件處理、供應商管理及稽核要求，確保支援業務、雲端、SaaS、AI、資料交換及遠端工作之網路服務具備機密性、完整性、可用性、可追溯性及合規性。

本文件旨在避免因網路服務錯誤設定、未授權連線、弱協定、開放管理介面、網段混用、DNS/DHCP濫用、供應商線路風險、雲端網路暴露、遠端存取失控、日誌不足或變更未控而導致資料外洩、服務中斷、攻擊橫向移動、惡意流量外連及法規/合約違反。

2. 作業原則

  • 網路服務應採最小連線、預設拒絕、分層防禦、網段分離、零信任、身份導向存取及持續監控原則設計。
  • 所有網路服務應具備Owner、用途、範圍、資料分類、風險等級、組態基準、變更紀錄、日誌監控及退場要求。
  • 正式環境、測試環境、開發環境、DR環境、管理網路、使用者網路、訪客網路、供應商連線及AI/MLOps網段應依風險進行邏輯或實體區隔。
  • 網路管理介面不得直接暴露於Internet，應透過VPN/ZTNA/PAM/MFA/跳板主機或等效安全通道進行受控存取。
  • 網路服務變更應經風險評估、核准、測試、備份、回復計畫、監控及事後驗證，不得以臨時規則長期存在。
  • 網路服務日誌應足以支援事件調查、稽核、異常偵測、流量分析及合規要求，並依分類分級保護。

3. 名詞與定義

名詞 定義
網路服務 支援資訊傳輸、連線、解析、路由、存取、防護、負載、遠端連線或監控之網路功能或平台。
管理網路 用於管理伺服器、網路設備、雲端資源、資料庫、Kubernetes、CI/CD或安全設備之受控網路區域。
網段區隔 以VLAN、Subnet、VPC/VNet、ACL、防火牆、安全群組、微分段或Zero Trust政策限制不同網路區域間連線。
Egress控制 限制內部系統或端點對外連線目的地、協定、埠號、API或網域之出站流量控制。
Ingress控制 限制外部來源進入組織網路、雲端環境、應用或服務之入站流量控制。
ZTNA Zero Trust Network Access，基於身份、裝置、風險與應用情境之零信任網路存取。
SASE/SSE 整合安全網路存取、SWG、CASB、ZTNA、DLP與DNS安全等能力之雲端安全架構。
Network ACL / Security Group 雲端或網路層用於限制來源、目的、協定與埠號之存取控制。
NDR Network Detection and Response，透過網路流量偵測異常、威脅與攻擊行為之機制。
DNS Security 透過DNS解析與威脅情報阻擋惡意網域、C2、釣魚、DGA或資料外傳之控制。
服務曝光面 可被內部或外部存取之IP、網域、埠號、API、管理介面或網路服務集合。

Internal Auditor 抽查網路清冊、規則審查、日誌、變更、例外、事件與控制有效性。 稽核底稿、稽核發現。

5. 網路服務分類與最低安全要求

服務類型 範例 最低安全要求 證據
內部使用者網路 辦公室LAN、Wi-Fi、端點網段。 使用者與伺服器網段分離，套用NAC/EDR/網頁過濾，禁止直接管理正式系統。 網路圖、NAC報告。
伺服器與資料中心網路 應用伺服器、資料庫、檔案服務、虛擬化平台。 分層區隔、最小連線、管理網路隔離、東西向流量監控。 防火牆規則、NDR報告。
雲端網路 VPC/VNet、Subnet、Security Group、Private Link。 預設拒絕、最小暴露、日誌、CSPM、跨帳號/跨區連線核准。 雲端網路設定。
外部公開服務 Web、API、VPN、客戶入口、SaaS Gateway。 WAF/API Gateway/DDoS保護、TLS、弱點掃描、暴露面監控。 掃描報告、WAF設定。
遠端存取服務 VPN、ZTNA、VDI、SASE、跳板主機。 MFA、裝置健康、最小權限、Session紀錄、地理/風險限制。 VPN/ZTNA紀錄。
管理網路 設備管理、伺服器管理、雲端管理、PAM。 不得公開暴露，需PAM/MFA/JIT、跳板、日誌與Session Recording。 PAM紀錄。
訪客網路 訪客Wi-Fi、臨時連線。 與內部網路隔離，限制頻寬與存取，套用DNS/網頁安全。 Wi-Fi設定。
供應商/客戶連線 Site-to-Site VPN、專線、B2B API、維護通道。 合約、存取範圍、MFA、日誌、到期日、定期審查。 連線申請與合約。
AI/MLOps網路 模型API、GPU工作負載、RAG、向量資料庫、Notebook。 資料分類、Egress控制、AI API Key保護、RAG權限、用量監控。 AI網路設計。

6. 網路服務生命週期流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 提出網路服務目的、系統、資料分類、來源/目的、協定、埠號、使用者與期限。 System Owner / Network Service Owner 網路需求申請。
2. 風險評估 評估暴露面、資料敏感度、供應商、雲端、遠端、AI、合規與營運影響。 Network Security / CISO 風險評估紀錄。
3. 架構設計 設計網段、路由、DNS、防火牆、ACL、WAF、負載、監控、備援與回復。 Network Architect / Cloud Network Owner 網路設計文件。
4. 安全審查 審查最小連線、預設拒絕、管理介面、日誌、弱點、加密與例外。 Network Security / CISO 安全審查紀錄。
5. 建置與設定 依核准設計與安全基準建置，保存設定與版本。 IT Operations / Cloud Owner 組態與變更紀錄。
6. 測試與驗收 測試連線、封鎖、日誌、告警、備援、回復、弱點與安全需求。 Network Security / SOC / QA 測試報告。
7. 上線與監控 上線後監控流量、異常、效能、錯誤、告警與服務可用性。 SOC / IT Operations 監控報告。
8. 定期審查 定期審查規則、例外、未使用連線、暴露面、權限與服務必要性。 Network Service Owner 審查紀錄。
9. 退場與清理 服務停用時移除規則、DNS、憑證、帳號、日誌設定與文件更新。 Network Service Owner 退場紀錄。

7. 網段區隔與連線控制要求

控制項目 最低要求 高風險加強要求
預設拒絕 新網段、新服務與跨區連線應預設拒絕，僅允許核准連線。 正式、高機密與管理網路需白名單化。
網段分層 使用者、伺服器、資料庫、管理、備份、訪客、供應商與AI/MLOps網段應分離。 採微分段或身份導向政策。
東西向流量 資料中心與雲端內部橫向流量應依應用需求限制。 高風險系統導入NDR/微分段。
南北向流量 對外服務需透過WAF/API Gateway/Load Balancer/Reverse Proxy或等效控制。 重要服務需DDoS防護與暴露面管理。
跨環境連線 Dev/Test/UAT/Prod/DR間連線需核准、限定來源目的與期限。 正式至非正式連線需CISO核准。

Egress控制 正式系統對外連線應限制目的地、埠號、協定與網域。 高敏感系統採Proxy或FQDN允許清單。

8. 防火牆、ACL與安全群組規則管理

管理項目 作業要求 證據
規則申請 每項規則需記錄來源、目的、協定、埠號、用途、Owner、資料分類、期限與風險。 規則申請單。
最小範圍 避免Any-to-Any、0.0.0.0/0、高風險埠或過寬CIDR。 規則審查紀錄。
期限控制 臨時規則需設定到期日；到期未續核應移除。 到期報告。

異常規則 發現未核准、過期、過寬、重複或未命中規則需修正或移除。 改善紀錄。
變更管制 規則新增、修改、刪除需經變更流程與回復計畫。 變更單。

服務 安全要求 證據

14. 網路服務變更管理

變更類型 管理要求 核准層級 驗證

15. 網路服務弱點與組態管理

控制項目 作業要求 證據
資產登錄 所有網路設備、雲端網路元件、遠端存取平台與安全設備需登錄清冊。 資產清冊。
安全基準 網路設備與雲端網路服務應依核准基準設定。 基準檢查報告。
韌體與修補 網路設備、VPN、Firewall、WAF、Proxy、DNS服務需定期更新與緊急修補。 修補紀錄。
弱點掃描 對外服務、管理介面、VPN與網路設備需定期掃描或評估。 弱點掃描報告。
組態備份 重要網路設備與服務設定需備份、加密保存並可回復。 組態備份紀錄。
預設帳號 移除預設帳號、預設密碼與不必要服務。 組態審查。
不安全協定 停用Telnet、FTP、SNMPv1/v2未保護、HTTP管理、弱TLS與不必要協定。 設定證據。
組態漂移 偵測組態偏離基準、未核准變更或雲端規則漂移。 漂移報告。

16. DDoS、防護與可用性要求

項目 最低要求 證據
DDoS防護 對外關鍵服務應評估並啟用DDoS防護、CDN、WAF或雲端防護。 DDoS設定。
容量管理 關鍵網路服務應監控容量、頻寬、連線數、CPU、Memory與錯誤率。 容量報表。
負載平衡 重要服務應具備負載平衡、健康檢查、故障切換與回復策略。 LB設定。
DNS可用性 關鍵網域需具備高可用DNS、合理TTL與備援。 DNS架構。
遠端存取可用性 遠端工作與緊急維運需有替代連線或降級方案。 BCP/DR文件。
網路備援 關鍵線路、雲端連線、設備與供應商服務需評估單點失效。 網路備援設計。
演練 重要網路服務需依風險執行故障切換、DDoS或連線中斷演練。 演練紀錄。

17. 供應商、客戶與外部連線管理

控制項目 最低要求 證據
連線申請 外部連線需記錄對方、目的、資料、協定、埠號、加密、期限、Owner與合約依據。 連線申請單。
合約與責任 合約需明確安全責任、事件通報、變更通知、稽核權、SLA與退場。 合約/SOW。
最小連線 僅允許必要來源、目的、埠號與資料流，禁止全網互通。 防火牆規則。
加密與認證 外部連線應使用VPN、TLS、mTLS、IPSec或等效強認證與加密。 連線設定。
監控與日誌 外部連線流量、失敗、異常與變更需監控。 SIEM/Flow Log。
定期審查 外部連線至少每半年審查，確認必要性與安全狀態。 審查紀錄。
退場清理 合約終止或需求消失時，移除路由、規則、憑證、帳號與DNS。 退場紀錄。
