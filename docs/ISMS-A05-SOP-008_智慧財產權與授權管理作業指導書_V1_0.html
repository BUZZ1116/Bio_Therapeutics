1. 作業目的

本作業指導書用於規範組織於取得、使用、開發、整合、散布、部署、轉授權、委外、採購、退役及稽核智慧財產權與授權資產時之控制要求，確保組織遵循法規、合約、授權條款、客戶要求、供應商義務及資訊安全管理制度要求，避免未授權使用、侵權、授權超用、開源軟體不合規、營業秘密外洩、資料集來源不明、AI模型與輸出權利不明、第三方交付物權利歸屬不清、雲端與SaaS授權濫用及未經核准之再散布風險。

本文件同時建立可稽核之登錄、核准、證據、例外、監控、定期盤點、事件處理與改善機制，以支援 ISO/IEC 27001:2022 Annex A.5.32「Intellectual property rights」及相關組織控制、技術控制、供應商控制、雲端服務控制、AI治理與資料治理要求。

2. 作業原則

  • 智慧財產與授權資產之取得、使用及散布，應基於合法來源、明確授權、業務必要、最小使用、可追溯、可驗證及權責明確原則。
  • 任何軟體、SaaS、雲端服務、開源套件、第三方元件、資料集、AI模型、圖片、音訊、影片、教材、文件範本、設計素材或外部交付物，使用前應確認授權條款、使用範圍、限制、地區、期間、使用者數量、再散布條件、資料處理條件與安全要求。
  • 禁止使用未經核准、來源不明、盜版、破解、共享帳號、超出授權範圍、違反開源義務、違反雲端服務條款或未通過資安審查之智慧財產與授權資產。
  • 受限授權、高風險開源授權、copyleft授權、商業再散布、客戶交付、AI訓練、AI輸出商用、個資資料集、跨境處理與供應商成果移轉，應由法務、資訊安全、資料Owner及相關Owner完成審查。
  • 授權證據、採購紀錄、合約、EULA、DPA、SLA、開源清單、SBOM、模型卡、資料來源聲明、著作權聲明、第三方通知、盤點紀錄及例外核准應依文件化資訊管制程序保存。

3. 名詞與定義

名詞 定義
智慧財產權（IPR） 著作權、專利權、商標權、營業秘密、資料庫權、設計權、積體電路布局權、專有技術、文件、教材、程式碼、模型、資料集、流程、演算法、品牌識別及其他依法規、合約或組織政策保護之權利。
授權（License） 權利人允許組織於特定範圍、期間、地區、用途、使用者數量、設備、環境、再散布或修改條件下使用資產之法律或合約許可。
EULA / Terms of Service 軟體、SaaS、雲端服務或平台提供者所訂定之終端使用者授權協議或服務條款。
開源軟體（OSS） 依開源授權條款提供原始碼或可再利用元件之軟體，包含 permissive、weak copyleft、strong copyleft、network copyleft 等授權類型。
SBOM Software Bill of Materials，軟體材料清單，記錄軟體元件、版本、供應商、授權、雜湊、相依性與安全資訊。
第三方元件 由外部供應商、開源社群、雲端平台、SaaS、SDK、API、套件管理器、模型市集或顧問提供並納入組織產品、服務、流程或交付物之元件。
營業秘密 具有秘密性、經濟價值並已採取合理保密措施之技術、商業、營運、客戶、定價、模型、資料、演算法、流程或策略資訊。
權利歸屬 成果、程式碼、文件、資料集、模型、設計、發明、商標或其他智慧財產由何方擁有、可否使用、可否修改、可否再授權及可否對外散布之判定。
授權超用 實際使用人數、設備數、部署數、地區、功能、資料量、API用量、環境或用途超過授權條款或合約約定。
未授權使用 未經核准、無合法授權、超出授權範圍、違反條款、使用破解或盜版、以個人帳號處理公司業務、共享帳號或將第三方資產導入未核准用途。
AI模型與AI輸出 由組織或第三方AI系統產生、微調、訓練、推論或提供之模型、權重、Embedding、Prompt、RAG知識庫、輸入資料、輸出內容及相關文件。
授權證據 採購單、發票、合約、訂閱紀錄、授權金鑰、License portal截圖、EULA、服務條款版本、供應商證明、開源授權文本、SBOM、第三方通知檔及法務審查紀錄。

4. 角色與責任

角色 主要責任
最高管理階層 核准重大授權策略、重大侵權或合規風險接受、重大軟體資產投資、訴訟或對外聲明，以及支援必要資源。
CISO / 資訊安全負責人 確保智慧財產與授權管理納入ISMS控制、風險評鑑、事件管理、供應鏈管理、雲端服務管理與稽核證據。
法務主管 / Legal Owner 審查授權條款、權利歸屬、第三方交付物、開源授權風險、商業再散布、侵權疑慮、合約義務及對外聲明。
Software Asset Manager 維護軟體、SaaS、開源、授權、使用者與部署清冊；執行盤點、授權符合性檢查與超用改善追蹤。
IT Asset Owner 管理安裝、部署、移除、授權配置、帳號、設備、雲端訂閱與技術盤點工具。
System / Application Owner 確保系統、應用、API、第三方元件與授權使用符合核准範圍，維護SBOM與元件清單。
DevSecOps / 研發主管 導入開源掃描、SCA、授權檢查、SBOM產出、版本控管、程式碼來源審查與CI/CD阻擋機制。
Cloud / SaaS Owner 確認雲端服務、SaaS、Marketplace元件、API、模型服務與資料處理條款符合授權、安全與合約要求。
AI Governance Owner / Model Owner 審查AI訓練資料、模型、Prompt、RAG、輸出商用、第三方模型授權、資料保留與再訓練條款。
Data Owner 確認資料集、資料庫、客戶資料、PII、GHG/CO2資料及內部資料之使用、授權、限制、共享與保存要求。
採購 / 供應商管理 確保採購流程取得合法授權、合約條款、供應商聲明、授權證據、退場條款與稽核權。
DPO / PIMS負責人 審查涉及PII資料集、AI訓練資料、跨境處理、資料主體權利與隱私授權之合規要求。
使用者 僅使用核准資產與授權，遵守授權限制，不安裝未核准軟體，不使用盜版或破解工具，發現異常立即通報。

15. 違規、疑似侵權與事件處理

情境 立即處置 升級與後續作業
發現未授權軟體、盜版、破解或共享帳號 立即停止使用、隔離或移除，保存端點、安裝、使用者與來源證據。 通報IT、CISO、法務與單位主管，評估是否需採購補正、紀律處理或事件通報。
疑似開源授權違反 暫停發版或對外交付，鎖定受影響版本、元件、授權與散布範圍。 法務與研發評估替換、揭露、補正、源碼提供、客戶通知或風險接受。
第三方侵權通知或律師函 立即轉法務，不得自行回覆或承認責任，保存所有相關文件與溝通紀錄。 啟動事件管理、數位證據保存、對外溝通核准與管理階層通報。

供應商交付物權利不明 暫停驗收或部署，要求供應商提供授權、SBOM、權利歸屬與不侵權聲明。 採購、法務與Owner評估合約救濟、替換、退貨或終止。
營業秘密或受限資料外洩 依資訊安全事件管理程序啟動通報、圍堵、證據保存與影響評估。 評估法規、合約、客戶、供應商與保險通報義務。

客戶指定工具或素材 客戶合約明確要求或提供，且責任與授權範圍清楚。 法務、客戶Owner、CISO確認。 專案結束依合約退場或刪除。
