1. 表單目的

本表用於正式登錄、評估與核准資訊安全資源需求，確保ISMS所需人力、能力、預算、技術工具、基礎設施、外部服務、雲端服務、資料資源、事件應變能力、稽核驗證資源與管理支持能被系統化識別、風險導向排序、合理核准、有效配置並持續追蹤。

本表支援ISO/IEC 27001:2022 Clause 7.1 Resources之符合性證據，並連結資訊安全目標、風險處理計畫、SoA控制措施、事件應變、變更管理、隱私、AI、GHG/CO2資料治理、供應鏈治理、管理審查與CAPA持續改善。

2. 適用時機

  • 年度ISMS資源規劃、預算編列或資源重新配置時。
  • 風險評估、風險處理、SoA控制實施或控制有效性不足需新增資源時。
  • 發生資訊安全事件、隱私事件、AI事故、營運中斷或重大弱點，需緊急或補強資源時。
  • 重大變更、雲端導入、供應商變更、AI系統上線、PII處理活動變更、備份/備援/復原改善、GHG/CO2資料治理或碳證據管理改善時。
  • 內部稽核、外部驗證、客戶稽核、管理審查或CAPA發現資源不足時。

成本效益 資源投入相對於風險降低、合規符合、控制有效、效率提升或營運韌性改善之合理性。
