1. 目的

本程序旨在建立資訊及相關資產之識別、登錄、分類、分級、標示、責任指派、可接受使用、保管、移轉、存取、盤點、風險連結、變更、歸還、刪除、汰除、證據保存與持續改善要求，使組織能完整掌握資訊安全管理系統範圍內之資訊資產及其關聯資產，並確保資產於全生命週期中受到適當保護。

本程序特別納入PII、AI模型與服務、Prompt、RAG知識庫、AI訓練/測試資料、GHG/CO2資料、碳證據、產品碳足跡資料、雲端資源、供應商服務與外部來源文件等新型資產類型，以支援ISMS、PIMS、AI治理與GHG資料治理之整合管理。

2. 適用範圍

本程序適用於所有由組織擁有、保管、使用、處理、委外處理、雲端代管、供應商提供、客戶提供或可影響資訊安全之資訊及相關資產。

資產範圍 內容範例 管理要求
資訊與資料資產 業務資料、客戶資料、PII、財務資料、合約、報告、紀錄、日誌、備份資料、外部來源文件。 應建立Owner、分類分級、保存期限、存取權限、保護措施與刪除/歸還要求。
AI相關資產 AI模型、AI服務、Prompt、RAG知識庫、向量資料庫、訓練資料、測試資料、AI輸出、AI服務憑證、AI供應商資料。 應納入AI服務與碳足跡資料資產清冊，並連結AI風險評估與AI使用政策。
GHG/CO2與碳證據資產 能源用量、排放係數、活動數據、雲端碳資料、產品碳足跡、碳中和聲明證據、查證資料、供應商碳資料。 應納入GHG/CO2資料與碳證據清冊，並管理完整性、可追溯性、版本與保存期限。
系統與技術資產 應用系統、資料庫、伺服器、雲端服務、端點裝置、網路設備、儲存設備、API、原始碼、CI/CD平台。 應與技術控制措施、組態、弱點、備份、備援、監控與存取控制連結。
實體與支援資產 機房、辦公室、支援設施、電力、空調、消防、纜線、門禁、監控設備、儲存媒體。 應連結實體安全控制措施與場域風險。
供應商與外部服務資產 ICT服務、雲端服務、AI服務、資料處理服務、外包開發、GHG查證服務、碳資料供應商。 應納入供應商風險評估、合約安全要求與服務監督。

3. 名詞與定義

名詞 定義
資訊及相關資產 任何對組織具有業務、法規、合約、隱私、AI、GHG/CO2、營運或資訊安全價值之資訊、資料、系統、服務、設備、文件、場所、人員能力或供應鏈依賴。
資產Owner 對資產之用途、分類、風險、存取、保存、處理與保護要求負最終責任之角色。
Custodian / 保管者 依Owner要求維護資產、保存資產、執行技術或行政控制之角色。
User / 使用者 依授權使用資產之內部人員、外部人員、系統帳號、AI服務或供應商。
資訊分類分級 依資訊敏感度、價值、法律合約要求、PII、AI、GHG/CO2資料及業務影響進行分類與保護分級。
可接受使用 使用者對資訊及相關資產可執行與禁止執行之行為規則。
資產生命週期 資產自需求、建立/取得、登錄、分類、使用、變更、移轉、保存、盤點、歸還、刪除、汰除至銷毀之完整過程。
碳證據 支援GHG/CO2量化、產品碳足跡、碳中和聲明、客戶ESG回覆或查證之文件、資料、計算、紀錄與外部來源證據。

4. 權責

角色 主要責任
最高管理階層 核准重大資產治理策略、資源需求、重大風險接受及管理審查決議。
ISMS管理代表 維護本程序，確保資產管理與ISMS範圍、風險管理、SoA、監督量測、稽核及管理審查一致。
Asset Management Owner 統籌資訊及相關資產清冊、分類分級、盤點、Owner指定、異動、歸還、刪除、汰除與證據保存。
Asset Owner 定義資產用途、分類、存取權限、保存期限、保護要求、風險與可接受使用規則。
Custodian / IT Owner 依Owner要求執行資產保管、技術控制、備份、監控、加密、刪除、組態與變更。
DPO / Privacy Owner 確認PII資產、處理目的、合法性、資料主體權利、保存期限與隱私風險。
AI Governance Owner 確認AI模型、資料集、Prompt、RAG、AI服務、AI輸出與AI供應商資產之治理要求。
GHG Data Owner 確認GHG/CO2資料、雲端碳資料、產品碳足跡、碳證據、查證資料與供應商碳資料之完整性與保存要求。
Supplier Owner 確認供應商提供或處理之資產、雲端服務、AI服務、外包服務、碳資料與第四方依賴。
使用者 依授權與可接受使用規則使用資產，保護資料，不得未授權複製、外傳、輸入AI工具或刪除。
內部稽核負責人 依風險與資產重要性抽查資產清冊、分類、Owner、保護措施、盤點與證據。

5. 管理活動與輸出摘要

程序階段 如何使用 輸出
治理與範圍確認 確認資產管理應涵蓋之組織、地點、流程、系統、PII、AI服務、GHG/CO2資料及供應商邊界。 資產管理範圍、資產清冊邊界、範圍聲明輸入。
法規、合約與關注方需求 確認資產是否受到法規、客戶合約、DPA、SLA、個資、AI監管、GHG查證或碳資料揭露要求約束。 合規義務、保存期限、分類分級與保護要求。
資產識別與登錄 建立資訊及相關資產清冊、資訊分類分級表、AI服務與碳足跡資料資產清冊及GHG/CO2資料與碳證據清冊。 完整資產清冊、分類分級、AI/GHG專項清冊。
資產風險評鑑 依資產價值、威脅、弱點、既有控制、AI/PII/氣候/GHG專項風險進行評估並登錄風險。 資產、威脅與弱點識別表、風險評鑑、風險登錄。
控制措施與SoA連結 將資產分類與風險結果連結至SoA、控制措施與運作控制矩陣。 SoA適用性、控制措施風險對應、運作控制。
供應商與雲端資產 對外部代管、雲端、AI供應商、ICT服務與碳資料供應商之資產進行責任界定與風險評估。 供應商風險評估、AI/雲端供應商GHG與資訊安全評估。
技術與實體保護 依資產分類與風險指定加密、密碼、端點、組態、刪除、遮罩、DLP、備份、備援、實體安全等保護措施。 控制設定、備份還原測試、加密金鑰紀錄、DLP/遮罩紀錄。
變更、歸還、刪除與汰除 資產新增、異動、移轉、用途改變、離職歸還、資料刪除、設備汰除或文件廢止時使用。 變更影響評估、刪除證明、歸還紀錄、廢止/保存紀錄。
監督、稽核、管理審查與改善 用於監測資產清冊完整性、盤點準確率、控制有效性、稽核缺失、管理審查及CAPA。 KPI/KRI、稽核發現、管理審查輸入、矯正措施。
文件化資訊與保存 管理資產清冊、分類表、外部來源文件、碳證據、風險紀錄與控制證據之版本、存取與保存期限。 受控文件、紀錄保存、外部來源文件登錄。

6. 管理原則

原則 要求 落地方式
完整性 所有對資訊安全、隱私、AI、GHG/CO2、營運或合規有影響之資產均應納入管理。 建立主資產清冊及AI/GHG專項清冊，定期盤點與更新。
Owner明確 每項資產應指定Owner與Custodian，不得存在無Owner資產。 清冊中必填Owner、Custodian、使用者、供應商與審查日期。
分類分級 資產應依敏感度、法律合約要求、PII、AI、GHG/CO2、營運重要性與CIA影響分類分級。 使用資訊分類分級表並連結保護措施。
風險導向 高價值、高敏感、高依賴或高合規資產應優先執行風險評鑑與控制措施。 連結資產、威脅與弱點識別表及風險登錄表。
最小權限 資產存取應基於業務需要、分類分級與授權流程。 透過存取權限、加密、DLP、日誌與監控控制。
生命週期管理 資產應於新增、使用、變更、移轉、保存、歸還、刪除與汰除各階段受控。 建立異動流程、刪除證據、歸還紀錄與汰除紀錄。
可追溯性 資產、Owner、分類、風險、控制、證據、變更與保存期限應可追溯。 清冊與控制證據需與SoA、風險登錄、文件化資訊管理連結。

7. 作業程序

7.1 資產識別與來源確認

資產來源 識別方法 需登錄欄位
業務流程 依流程、輸入、輸出、客戶資料、報告、文件與系統盤點。 資產名稱、流程、Owner、用途、分類、保存期限。
資訊系統與雲端服務 依系統清單、雲端帳戶、資源群組、API、資料庫、備份、日誌與管理帳號盤點。 系統名稱、環境、資料類型、雲端區域、Custodian、SLA。
PII處理活動 依PIMS範圍、資料流程、資料主體、處理目的與委外處理盤點。 PII類型、處理目的、合法基礎、Owner、保存期限、接收方。
AI服務與資料 依AI工具、AI模型、Prompt、RAG、資料集、AI供應商、AI輸出與服務憑證盤點。 AI角色、模型/服務、資料來源、Prompt/RAG、供應商、碳足跡資料。
GHG/CO2資料與碳證據 依能源資料、活動數據、排放係數、產品碳足跡、碳中和聲明與查證資料盤點。 資料來源、版本、計算依據、Owner、分類、保存期限、查證用途。
實體與支援設施 依辦公室、機房、設備、媒體、支援設施、門禁與環境控制盤點。 地點、設備、資產標籤、保管者、維護頻率、環境風險。
供應商與外包服務 依合約、SLA、供應商服務、資料處理、雲端、AI與GHG資料供應商盤點。 供應商名稱、服務內容、資料類型、責任邊界、第四方、退出方式。

7.3 資訊分類分級

分類等級 判定條件 保護要求
公開 經核准可公開揭露，外洩不會造成重大影響。 仍需確保正確性、版本與授權使用。
內部 僅供內部使用，未授權揭露可能造成輕微營運或聲譽影響。 需限制內部存取並依保存期限管理。
機密 包含客戶資料、合約、PII、系統設定、內部財務、風險、稽核、供應商安全或未公開營運資訊。 需存取控制、加密、日誌、DLP或備份保護。
高度機密 包含敏感PII、特權憑證、金鑰、AI模型核心資料、營業秘密、未公開重大合約、查證敏感資料或高影響資產。 需最小權限、MFA/PAM、加密、嚴格日誌、定期審查與管理階層核准。
特殊分類：PII 可直接或間接識別自然人之資料。 需合法性、目的限制、最小化、權限、刪除、委外與資料主體權利控制。
特殊分類：AI資產 AI模型、資料集、Prompt、RAG、AI輸出、AI服務憑證、AI供應商資料。 需AI風險評估、輸入限制、輸出驗證、供應商管理與使用政策控制。
特殊分類：GHG/CO2資料 能源、排放、產品碳足跡、碳中和聲明、查證、供應商碳資料。 需完整性、來源、版本、保存期限、查證證據與存取控制。

7.4 資產Owner指定與責任確認

作業要求 說明 輸出
Owner指定 每項資產均需指定Owner；不得存在未指定Owner或僅指定部門之資產。 資產清冊Owner欄位。
責任確認 Owner應確認資產用途、分類、存取、保存期限、風險、控制措施與盤點頻率。 Owner確認紀錄。
多Owner處理 跨流程、跨系統、AI/PII/GHG複合資產應指定主Owner及共同Owner。 責任界定紀錄。
RACI對應 重大資產Owner、Custodian、Approver、Reviewer應對應RACI。 ISMS/PIMS/AI RACI權責矩陣。
變更移交 Owner離職、職務變更或組織調整時，應完成資產責任移交。 資產移交紀錄。

7.5 可接受使用與限制

使用場景 允許要求 禁止或限制事項
一般資訊資產使用 依授權、業務目的與分類分級使用。 不得未授權複製、外傳、公開、轉存個人帳號或使用未核准工具。
PII使用 依合法目的、最小化、授權與保存期限使用。 不得將PII輸入未核准AI工具、測試環境或外部服務。
AI工具使用 依核准AI工具、資料輸入限制、輸出驗證與人工覆核要求使用。 不得輸入機密、PII、金鑰、原始碼、客戶合約或GHG敏感資料至未核准AI服務。
GHG/CO2資料使用 依查證、客戶回覆、碳揭露或內部分析目的使用。 不得未授權修改來源、版本、計算依據或查證證據。
雲端與供應商服務使用 依核准服務、合約、SLA、資料所在地與責任共擔要求使用。 不得將資料移轉至未核准區域、帳戶或未評估供應商。
端點與媒體使用 依端點安全、加密、惡意軟體防護與可移動媒體限制使用。 不得使用未核准USB、未加密媒體或未管理端點處理機密資料。

7.6 資產異動與變更管理

異動類型 處理要求
新增資產 應於正式使用前完成登錄、Owner指定、分類分級、保存期限、風險初評與控制要求。
資產用途變更 若用途、使用者、資料類型、存放位置、供應商或處理目的改變，應重新評估分類、風險與控制。
AI或PII用途變更 若資產開始用於AI、模型訓練、RAG、PII處理、跨境或委外，應啟動專項風險評估。
GHG/CO2用途變更 若資產用於GHG量化、碳足跡、碳中和聲明或查證，應更新碳證據清冊與氣候風險評估。
資產移轉 跨部門、跨系統、跨雲端區域、供應商移轉或資料交付前，應確認授權、加密、傳輸、接收與紀錄。
封存與停用 資產不再日常使用但需保存時，應設定封存狀態、存取限制、保存期限與銷毀日期。
