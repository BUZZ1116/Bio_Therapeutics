1. 紀錄目的

本紀錄用於保存教育訓練活動之實際執行、出席、完成、測驗、補訓、豁免、教材版本、講師、有效性初步結果及後續改善事項，確保組織可證明人員已依其角色、責任、風險與控制要求取得必要能力與認知。

本紀錄支援ISO/IEC 27001:2022 Clause 7.2與7.3，作為能力與認知之文件化證據，亦可支援內部稽核、外部驗證、客戶稽核、管理審查、CAPA有效性驗證與隱私、AI、復原、GHG/CO2資料治理等專項治理查核。

1.1 管理活動與輸出摘要

紀錄章節 / 管理主題 如何使用 輸出 / 證據
0. 文件基本資料與審查核准 確認紀錄來源、課程計畫、課程設計、文件管制、核准與保存要求。 受控教育訓練紀錄、核准紀錄與保存依據。

6~15. 教材、課程內容、名單、出席、測驗、補訓、例外、回饋與有效性 保存教材版本、出席完成、測驗作業、補訓、豁免、課程回饋與有效性初判，並支援後續有效性評估。 教材紀錄、出席紀錄、測驗結果、補訓追蹤、有效性初判。

2. 適用時機

  • 完成任一ISMS教育訓練課程、認知宣導、角色別訓練、桌上演練、技術訓練、事件後補訓或專項治理訓練後。
  • 需要保存訓練出席、完成率、測驗結果、補訓狀態、豁免/延期及有效性初步評估時。
  • 內部稽核、外部驗證、客戶稽核、管理審查或CAPA需查證人員能力與認知證據時。

3. 名詞與定義

名詞 定義
教育訓練紀錄 記錄訓練活動之課程、對象、出席、完成、測驗、補訓、教材、講師與證據之正式紀錄。
完成狀態 受訓人員是否完成指定課程、測驗、作業、演練或確認事項之狀態。

補訓 對未完成、測驗未通過、逾期、事件後或稽核發現相關人員進行之再訓練。
豁免 因具備同等能力、證照、外部訓練或管理核准，而免除特定訓練之情形。
訓練證據 包含LMS紀錄、簽到表、測驗、作業、教材版本、錄影、證書、演練紀錄、截圖與核准紀錄。
