1. 文件目的

本報告用於彙整、分析與證明組織資訊安全目標之達成情形，包含年度目標、KPI、KRI、風險改善、控制有效性、合規義務、PIMS、AI治理、GHG/CO2資料治理、雲端與ICT供應鏈及外包流程等相關目標之績效結果、證據、偏差、原因、CAPA及管理審查輸入。

本報告應呈現目標結果與資訊安全政策、組織全景、關注方需求、風險登錄表、風險處理計畫、SoA、Annex A控制措施、管理審查決議及持續改善活動之追溯關係。

1.1 管理活動與輸出摘要

報告章節 / 管理主題 如何使用 輸出 / 證據
1. 文件目的 用於定義本報告作為目標達成、監督量測、管理審查、CAPA及持續改善之核心紀錄。 報告目的與管理閉環。
2. 適用範圍 用於確認目標達成報告涵蓋ISMS/PIMS/AI/GHG範圍、資訊資產、AI服務、碳資料、供應商及外包流程。 報告範圍與範圍充分性結論。
4. 報告管理摘要 用於彙整年度目標總數、KPI達標、KRI超標、重大風險改善、控制有效性及CAPA狀態。 管理摘要與管理審查輸入。
5~8. 目標/KPI/KRI/趨勢分析 用於承接目標規劃表之目標值、KPI/KRI資料來源及實績資料，形成達成率與趨勢判定。 年度目標達成總表、KPI分析、KRI升級分析、趨勢分析。
9~11. 風險、SoA及Annex A影響 用於判定目標結果是否降低風險、影響剩餘風險、支援SoA及證明Annex A控制有效性。 風險改善分析、SoA控制有效性分析、Annex A摘要。
12~16. PIMS/AI/GHG/供應鏈/韌性專項分析 用於彙整隱私、AI、碳資料、供應鏈、雲端、備份與復原目標之達成結果、偏差與證據。 專項治理目標達成分析與改善建議。
17~19. 事件、稽核、CAPA、偏差與改善 用於將事件、稽核發現、未達標、KRI紅燈及控制失效連結至CAPA與改善計畫。 偏差分析、CAPA追蹤、改善計畫與有效性驗證。
20~21. 管理審查與儀表板 用於將目標達成結論、重大偏差、資源需求、風險/SoA影響及專項治理議題輸入管理審查。 管理審查輸入、治理儀表板與管理階層決策事項。
22~24. RACI、ISO條文與Annex A對應 用於證明本報告責任分工、ISO條文符合性及Annex A控制結果追溯。 RACI矩陣、條文對應、控制對應矩陣。

2. 適用範圍

  • 適用於ISMS範圍內所有年度資訊安全目標、專案型資訊安全目標、重大風險改善目標、控制有效性目標、合規目標、隱私目標、AI治理目標、GHG/CO2資料治理目標及ICT供應鏈目標。
  • 適用於內部稽核、外部驗證、客戶稽核、管理審查、CAPA、持續改善及治理委員會會議。
  • 適用於資訊安全目標結果對風險登錄、風險處理計畫、SoA、Annex A控制措施、PIMS/AI/GHG專項治理及資源規劃之回饋。

3. 名詞與定義

名詞 定義
資訊安全目標達成報告 用於彙整、分析與證明資訊安全目標、KPI、KRI、風險改善、控制有效性及整合治理目標之達成情形的正式紀錄。
達成率 目標實際結果相對於目標值之完成程度，可依百分比、件數、等級或完成狀態呈現。
KPI 績效指標，用於衡量目標或流程是否達成預期結果。
KRI 關鍵風險指標，用於監測風險升高、控制失效、事件趨勢或目標偏離。
偏差分析 針對目標未達成、KRI超標、實績與目標值差異進行原因、影響及改善需求分析。
證據包 支持目標達成狀態之文件、紀錄、系統報表、工單、稽核工作底稿、測試結果、會議紀錄或截圖集合。
管理審查輸入 提交最高管理階層審查ISMS適切性、充分性及有效性之目標績效資料。
CAPA 不符合與矯正措施，用於處理未達標、KRI超標、稽核發現或控制失效。
