1. 作業目的

本作業指導書旨在建立組織存取控制與身分管理之完整作業要求，確保使用者、系統、服務、API、雲端資源、AI服務、資料平台及第三方連線之存取權限，皆依業務必要、最小權限、職務區隔、可追溯、可審查及及時撤銷原則進行管理。

本文件支援 ISO/IEC 27001:2022 Annex A.5.15「Access control」、A.5.16「Identity management」、A.5.17「Authentication information」、A.5.18「Access rights」以及 A.8.2「Privileged access rights」、A.8.3「Information access restriction」、A.8.4「Access to source code」、A.8.5「Secure authentication」等控制措施落地，並提供驗證、內部稽核、供應商管理、雲端安全、AI治理、隱私保護與事件調查所需之證據鏈。

2. 作業原則

  • 所有存取權限應基於明確業務目的、經授權角色、最小權限、必要期間及可追溯性。
  • 所有身份應具唯一性，禁止多人共用一般使用者帳號；例外共用帳號需核准、補償控制與完整日誌。
  • 特權帳號、雲端管理者、資料庫管理者、程式碼庫管理者、AI模型管理者及安全工具管理者應採更高強度控管。
  • 新進、異動、離職、外包啟用、供應商退場、專案結束及重大系統變更時，應同步更新或撤銷權限。
  • 存取控制應整合人員、流程、技術與監控，包括HR事件、ITSM流程、IAM/SSO/MFA、PAM、SIEM、CASB、EDR、DLP與雲端日誌。
  • 任何未授權存取、越權、權限未撤銷、帳號共用、憑證外洩或異常登入，均應依事件管理程序通報與處理。

3. 名詞與定義

名詞 定義
身份（Identity） 代表自然人、系統、服務、裝置、應用程式、API、機器人、AI代理或第三方實體之可識別主體。
存取控制 依政策、角色、屬性、風險、地點、裝置狀態、資料分類或其他條件，限制主體對資訊資產之讀取、建立、修改、刪除、執行、管理、匯出或分享。
最小權限 僅授予完成授權業務目的所需之最低權限、最小資料範圍與最短有效期間。
職務區隔（SoD） 透過角色與權限設計避免單一人員可完成不相容或高風險交易、部署、核准與審查。
特權帳號 具系統管理、資料庫管理、雲端管理、網路管理、安全工具管理、IAM管理、PAM管理、程式碼庫管理或高敏感資料存取能力之帳號。
服務帳號 供系統、應用程式、批次作業、API、CI/CD、監控工具、RPA或AI代理執行自動化作業之非人員帳號。
驗證資訊 密碼、Passphrase、MFA因素、Token、API Key、SSH Key、憑證、私鑰、生物特徵模板、恢復碼或其他用於身份驗證之資訊。
PAM Privileged Access Management，特權存取管理機制，用於特權帳號保管、核准、取用、輪替、Session Recording與命令稽核。
JML流程 Joiner-Mover-Leaver流程，指人員到職、職務異動與離職時之帳號與權限生命週期管理。
零信任存取 以身份、裝置、風險、地點、行為與資源敏感度進行持續驗證與動態授權之存取方式。

4. 角色與責任

IAM Owner 管理身份生命週期、SSO、MFA、帳號申請流程、權限模型、定期審查與身份治理工具。
System Owner 定義系統角色、權限、資料存取範圍、授權準則、日誌與定期權限審查要求。
Data Owner 核准資料存取目的、資料分類、敏感資料權限、匯出限制與資料使用條件。
HR / 人資單位 提供到職、異動、離職、停職、外包結束及組織異動資訊，觸發JML流程。
IT Operations 執行帳號建立、變更、停用、刪除、MFA設定、端點與基礎設施存取控制。
Cloud Security Owner 管理雲端IAM、租戶管理者、角色、Policy、Service Principal、Key、跨帳戶存取及雲端日誌。
SOC 監控登入、異常存取、特權操作、資料匯出、暴力破解、可疑地點、Impossible Travel與權限濫用。
PAM Administrator 維護特權帳號保管、授權工作流、Session Recording、密碼輪替及Break-glass控管。
DPO / PIMS負責人 審查PII存取權限、資料主體要求、跨境存取與隱私高風險存取。
AI Governance Owner 審查AI服務、模型、Prompt、資料集、RAG知識庫與AI代理之存取權限與監控要求。
使用者 / 管理者 依授權使用資源，保護驗證資訊，不共用帳號，定期確認權限必要性並通報異常。

身份/帳號類型 適用範圍 最低控制要求 審查頻率

特權帳號 系統、雲端、資料庫、網路、安全工具、IAM/PAM、備份與程式碼庫管理帳號。 PAM保管、MFA、Just-in-Time、核准取用、Session Recording、命令稽核、定期輪替。 至少每季，高風險每月。
服務帳號 應用程式、批次、API、CI/CD、監控、RPA、AI代理或資料同步帳號。 Owner、用途、最小權限、禁止互動登入、Secret保護、輪替、日誌、到期或年度重認證。 至少每半年，高風險每季。
第三方帳號 供應商、外包、客戶、稽核員、維護商、遠端支援人員。 合約/NDA、到期日、限定範圍、MFA、遠端支援申請、活動監控與退場撤銷。 至少每季或專案結束。
緊急帳號 / Break-glass 緊急災難復原、IAM故障、資安事件或重大營運中斷時使用。 高階核准、離線保管、雙人取用、完整記錄、使用後立即審查與輪替。 每次使用後及至少每季測試。
雲端身份 / Service Principal 雲端租戶、訂閱、專案、資源群組、Kubernetes、Serverless、API服務。 最小IAM Role、條件式存取、Key Vault/KMS、Policy as Code、CloudTrail/Activity Log監控。 至少每季。
AI與資料平台帳號 AI模型、Prompt資產、RAG知識庫、向量資料庫、資料集、MLOps、Feature Store。 資料分類、模型角色、輸入輸出控制、API Key保護、Prompt與資料集存取審查、AI使用日誌。 至少每季，高風險每月。

6. 存取權限生命週期作業

審查 審查業務必要性、最小權限、職務區隔、資料分類、風險等級、合規要求與是否需例外核准。 主管 / System Owner / Data Owner / CISO 審查與核准紀錄。

啟用 使用者完成身份驗證、MFA註冊、資安承諾與必要訓練後始得啟用。 IAM Owner / 使用者 / HR MFA註冊紀錄、訓練紀錄、承諾書。

暫停 停職、留職停薪、長期休假、調查中、合約暫停或異常風險時，應限制或暫停權限。 HR / 主管 / CISO 暫停核准與執行紀錄。
離職/退場 離職、合約結束、專案結束或供應商退場時，於規定時限內停用或刪除帳號並回收設備與資料。 HR / IT / 主管 / 供應商管理 離職與異動資安檢核表、帳號停用紀錄。

8. 身份驗證與MFA要求

控制項目 最低要求 高風險/特權要求 證據
密碼政策 長度、複雜度、黑名單、歷史紀錄、嘗試次數限制與安全重設流程。 特權帳號不得共用密碼，應由PAM保管與輪替。 IAM設定、密碼政策截圖。
MFA 遠端存取、雲端、管理者、外部存取與高敏感系統需啟用MFA。 特權帳號需使用強MFA或硬體金鑰；禁止僅依SMS作為唯一高風險因素。 MFA註冊與政策紀錄。
SSO 優先整合企業SSO，以集中身份、條件式存取與帳號撤銷。 關鍵系統應避免孤島帳號，若無法整合需補償控制。 SSO整合清單。
條件式存取 依地點、裝置、風險、登入行為、IP信譽、資料敏感度及使用者狀態限制存取。 高風險登入需阻擋、Step-up MFA或管理者確認。 條件式存取政策。
帳號鎖定 偵測暴力破解、密碼噴灑、異常登入與Impossible Travel。 特權帳號異常需即時告警SOC。 SIEM/IAM告警紀錄。
憑證與金鑰 SSH Key、憑證、API Key、Token應有Owner、用途、到期與輪替。 Secret需存放於Vault/KMS，禁止硬編碼或明文傳輸。 Secret管理紀錄。
密碼重設 需確認身份，重設後強制變更，避免透過未受控通道傳送。 特權帳號重設需雙人覆核或PAM流程。 重設紀錄與核准紀錄。

10. 服務帳號、API Key與Secrets管理

控制領域 作業要求 禁止事項 證據
服務帳號建立 需申請Owner、用途、系統、資料範圍、權限、到期或重認證週期。 不得以個人帳號作為永久服務帳號。 服務帳號申請紀錄。
互動登入限制 服務帳號原則禁止互動登入、郵件收發與一般使用者登入。 不得將服務帳號供人員日常登入。 帳號設定紀錄。
Secret保存 API Key、Token、私鑰、憑證應存放於Vault、KMS、Secret Manager或等效工具。 不得硬編碼於程式碼、文件、Chat、Email或工單。 Secret Manager紀錄。
權限最小化 服務帳號僅授予必要API、資料表、Topic、Bucket、Queue或模型端點權限。 不得授予Wildcard或Owner權限，除非核准例外。 IAM Policy / ACL。
輪替與撤銷 Secret應定期輪替，外洩、離職、供應商退場或事件後立即撤銷與重新簽發。 不得使用無到期、無Owner或未知用途Key。 輪替紀錄。
日誌監控 記錄呼叫來源、時間、端點、資料量、錯誤、異常頻率與高風險操作。 不得關閉或繞過API日誌。 API Gateway / SIEM日誌。
年度重認證 所有服務帳號與Key至少年度重認證，高風險至少每季審查。 不得保留閒置或未知用途帳號。 重認證紀錄。

11. 資料、應用、雲端與AI存取控制

領域 控制要求 監控與證據
資料存取 依資料分類、Data Owner核准、最小資料欄位、遮罩、去識別、匯出限制與DLP控制管理。 資料權限清冊、DLP紀錄、資料庫稽核日誌。
應用系統 採角色式權限、功能分離、敏感功能二次確認、Session逾時與管理操作日誌。 角色矩陣、應用日誌。
作業系統 管理者權限需PAM，禁止不必要Local Admin，端點與伺服器需集中管理。 端點管理報表、PAM紀錄。
資料庫 高敏感資料庫需DBA與查詢權限分離，啟用審計、加密、遮罩與高風險查詢監控。 DB Audit、權限審查紀錄。
網路設備 管理介面限制來源IP、MFA或金鑰、跳板機、配置備份與命令日誌。 網路設備AAA與Syslog。
雲端IAM 使用角色與Policy最小化、禁止長期Root/Owner使用、啟用MFA、Cloud Logging與Policy Guardrail。 雲端IAM審查、CSPM報告。
SaaS平台 整合SSO/MFA、限制外部分享、管理員審查、資料匯出控制與租戶安全設定。 SaaS管理報表、CASB紀錄。
程式碼庫 Repo權限依專案與角色，保護分支、強制Code Review、限制Secrets、記錄Commit與Pull Request。 Repo權限清單、Code Review紀錄。
AI模型與Prompt資產 模型、Prompt、資料集、RAG知識庫與向量資料庫存取需依資料分類、AI風險與用途核准。 AI資產清冊、模型存取日誌。
備份與復原資料 備份庫與復原權限需高度限制、不可任意下載，復原需核准與完整性驗證。 備份系統權限、復原紀錄。

12. 權限審查與重認證要求

審查類型 審查範圍 頻率 處置要求
一般帳號審查 使用者帳號、群組、角色、部門權限、外部使用者。 至少每半年。 移除不必要權限，更新Owner，保存審查紀錄。
特權帳號審查 Admin、Root、DBA、Cloud Owner、PAM Admin、Security Admin。 至少每季，高風險每月。 移除閒置、過大、未知或未核准特權。
第三方帳號審查 供應商、外包、遠端支援、稽核員、臨時專案帳號。 至少每季或合約/專案結束。 到期停用、退場撤銷、確認合約仍有效。
服務帳號審查 服務帳號、API Key、Token、Service Principal、CI/CD Key。 至少每半年，高風險每季。 確認Owner、用途、權限、最後使用、Secret輪替。
資料權限審查 機密、高機密、PII、客戶資料、財務資料、GHG/CO2與AI資料集。 至少每季或依法規/合約。 不必要存取立即撤銷，重大異常通報事件。
職務區隔審查 不相容角色、開發/上線、核准/執行、付款/審核、資料建立/覆核。 至少每半年及重大組織變更時。 衝突需移除、補償控制或高階核准。
閒置帳號審查 超過規定期間未登入、無Owner或無業務用途帳號。 至少每月。 停用、刪除或重新確認。

14. 離職、異動與緊急撤權作業

情境 處置時限 作業要求 證據
一般離職 依HR通知或最後工作日前完成；高風險角色應即時撤權。 停用SSO、Email、VPN、SaaS、系統、雲端、資料庫、程式碼庫、PAM與實體門禁。 離職與異動資安檢核表、帳號停用紀錄。
非自願離職或高風險離職 HR/CISO通知後立即執行。 同步撤銷遠端存取、MFA、特權、資料匯出能力與設備存取。 緊急撤權紀錄。
職務異動 異動生效日前後依流程完成。 新增新職務必要權限，移除舊職務不再必要權限。 異動申請與權限審查紀錄。
專案結束 專案結束或目的消失後即時撤銷。 移除專案群組、Repo、雲端資源、資料集、AI資產與外部分享權限。 專案退場紀錄。
供應商退場 合約終止、支援結束或合作暫停時。 停用第三方帳號、VPN、SaaS、API Key、遠端工具與共享資料。 供應商退場與刪除證明。
事件處理撤權 偵測帳號外洩、越權、惡意行為或異常存取時立即執行。 暫停帳號、撤銷Token、輪替Secret、保全證據並啟動事件管理程序。 事件紀錄、撤權紀錄。

21. 附錄C：常見違規與處置參考

違規或異常情境 風險說明 立即處置 後續改善
帳號共用 無法追溯責任，可能造成未授權存取。 停用共用方式或納入例外控管。 建立個人帳號或PAM流程。
離職帳號未停用 可能遭前員工或攻擊者濫用。 立即停用並檢查近期活動。 檢討HR-IT串接與撤權SLA。
特權帳號未納管 高權限操作缺乏控制與稽核。 限制權限並納入PAM。 完成特權盤點與重認證。
MFA未啟用 帳密外洩後易被登入。 立即要求註冊MFA或暫停遠端存取。 強制條件式存取政策。
API Key外洩 可造成資料存取、服務濫用或供應鏈攻擊。 立即撤銷Key、輪替Secret並查核日誌。 導入Secret掃描與Vault。
服務帳號無Owner 無法確認用途與權限必要性。 暫停或限制權限直到確認Owner。 建立服務帳號重認證機制。
權限過大 可能造成越權、資料外洩或破壞。 移除不必要權限。 優化角色模型與最小權限。
未核准第三方遠端支援 可能造成供應商越權或未監控操作。 中止連線並保全證據。 納入供應商存取流程與Session Recording。
