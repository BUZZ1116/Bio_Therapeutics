1. 表單目的

本評估表用於識別、分析、評價與記錄雲端服務導入、使用、變更、續約及退場之資訊安全風險，確保雲端服務在資料分類、存取控制、加密、共享責任、供應商、第四方、PII、AI、跨境、營運持續、日誌監控、事件應變與合約要求等面向受到適當評估與處理。

本表單可作為雲端服務准入、上線、續約、年度重評、事件後重評、管理審查、內部稽核與外部驗證之正式證據。

2. 使用原則

  • 所有中高風險雲端服務、處理機密以上資訊、PII、客戶資料、AI資料、GHG/CO2資料或支援關鍵營運之雲端服務，均應完成本風險評估表。
  • 雲端風險評估應以實際用途、資料流、供應商條款、共享責任、技術控制與營運影響為基礎，不得僅依供應商品牌或市場聲譽判定。
  • 評估結果若存在不可接受風險，應建立風險處理計畫、補償控制、剩餘風險接受或限制使用條件。
  • 雲端服務用途、資料類型、使用者範圍、區域、供應商、第四方、AI功能或核心組態發生重大變更時，應重新評估。
