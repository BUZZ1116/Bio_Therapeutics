1. 表單目的

本清冊用於識別、登錄、分級、管理與定期審查組織實體安全區域，確保承載資訊資產、ICT設備、紙本文件、備份媒體、關鍵營運活動、PII、AI資料、客戶資料、供應鏈資料、稽核證據及GHG/ESG資料之場所，均具備符合風險、業務重要性、資訊分類、法規合約與營運持續要求之實體安全控制。

本清冊不僅作為場所盤點文件，也作為實體安全風險評鑑、門禁權限設定、訪客管理、環境監控、設備保護、資產配置、供應商進出管制、內部稽核、管理審查及ISO/IEC 27001驗證之核心證據。

2. 使用原則

  • 所有處理、儲存、傳輸或支援組織資訊資產之實體場所，均應納入清冊管理。
  • 實體安全區域應依區域用途、資訊資產敏感性、營運關鍵性、外部人員可接近程度、環境風險、法規合約要求及風險評鑑結果進行分級。
  • 安全區域分級應連結門禁權限、訪客陪同、監控錄影、巡檢頻率、環境偵測、設備保護、清潔桌面、列印控管、媒體保存與事件通報要求。
  • 新增、搬遷、改裝、租用、外包或退場任何安全區域時，應更新本清冊並完成風險影響評估。
  • 涉及高機密資料、PII、客戶資料、AI模型資料、金鑰、備份媒體、資安事件證據或營運關鍵系統之區域，應採用較高等級管制與可稽核證據保存。

3. 名詞與定義

名詞 定義
實體安全區域 組織基於資訊安全、營運持續、資產保護、法規合約或管理需求而需進行實體邊界、存取、監控與環境控制之場所或空間。
安全邊界 用以區分公開區、內部區、受控區、限制區或高限制區之實體界線，例如牆面、門禁、櫃位、警戒線、櫃鎖、機房門、保全管制點或監控範圍。
受控區域 需經授權方可進入，並應保留進出紀錄、訪客紀錄或門禁紀錄之區域。
限制區域 承載機密資訊、關鍵系統、網路設備、備份媒體、PII或重要營運活動之區域，需強化門禁、監控與陪同要求。
高限制區域 承載高機密資訊、核心基礎設施、資安事件證據、密鑰管理、資料中心、重要備援設施或重大營運關鍵活動之區域。
區域Owner 對特定實體安全區域之用途、控制措施、權限核准、風險管理、盤點與審查負責之角色。
環境控制 對溫濕度、電力、消防、防水、防塵、震動、門禁異常、監控盲區、清潔與維護等條件之控制。
區域退場 安全區域停止使用、搬遷、租約終止、轉作他用或外包服務結束時，進行資產移除、權限取消、資料清理、證據保存與風險確認。

4. 實體安全區域分級準則

區域等級 典型區域 最低控制要求 進出與審查要求
L0 公開區 公共接待區、公開展示區、對外活動區、一般大廳。 明確標示公開範圍，不得放置內部以上資訊、未受保護設備或未鎖定螢幕。 一般訪客可進入；需防止未授權越界至內部區。
L1 內部區 一般辦公區、開放式工作區、內部會議室、茶水間。 員工或授權人員進入；基本門禁、員工識別、清潔桌面與列印文件控管。 訪客需登記並依規定陪同；至少年度審查。
L2 受控區 IT工作區、文件保存區、專案作戰室、受控列印區、倉儲辦公區。 門禁或鑰匙管理、進出紀錄、訪客陪同、區域Owner核准、敏感文件與設備妥善保護。 權限至少每半年審查；異動或事件後重評。
L3 限制區 機房、網路機櫃區、弱電間、備份媒體櫃、資安監控區、PII處理區、客戶資料作業區。 MFA或雙因素門禁、CCTV、環境監測、進出紀錄、陪同、定期巡檢、設備與媒體盤點。 權限至少每季審查；進出紀錄至少每月抽查。
L4 高限制區 資料中心、核心機房、金鑰或密碼保管區、事件證據保存區、DR備援中心、重大營運關鍵控制區。 雙人或強化授權、完整CCTV、門禁告警、不可共用權限、環境冗餘、進出理由記錄、嚴格訪客與維護控制。 權限至少每月或每季審查；重大變更、事件、稽核發現後立即重評。
