1. 文件目的

本文件用於記錄資訊安全治理委員會之正式會議內容，包含會議基本資料、出席人員、議程、治理輸入、討論重點、風險與控制審查、決議、行動事項、責任人、期限、附件證據及後續追蹤要求。

本紀錄作為最高管理階層與治理委員會履行資訊安全領導、監督、資源配置、風險治理、績效監督、管理審查準備與持續改善之重要文件化資訊。

1.1 管理活動與輸出摘要

紀錄章節 / 會議活動 如何使用 輸出 / 證據
0. 文件基本資料與管制基準 確認會議紀錄編號、文件名稱、會議性質、文件分級、Owner、核准者、保存期限與文件總清冊一致。 受控會議紀錄基本資料。
4. 會議基本資料 確認會議類型、召集依據、治理目的、主席、紀錄、發佈對象及是否作為管理審查前輸入。 會議基本資料與會議結論摘要。
5. 出席人員與列席人員 確認出席角色與治理責任、代理關係、能力要求及其認知責任。 出席紀錄、代理紀錄、治理責任確認。
6. 會議議程 作為治理會議各項輸入資料之來源，包括組織情境、關注方、風險、績效、稽核、CAPA與管理審查準備。 正式議程與應備資料清單。
7. 前次會議決議與行動事項追蹤 追蹤前次決議、CAPA、持續改善及須提報管理審查之未結事項。 行動事項追蹤表。
8. 各議題討論與決議紀錄 將治理輸入轉化為討論內容、風險/影響、正式決議、責任人與期限。 議題討論與決議紀錄。
9. 資訊安全風險與機會決議表 審查風險等級、處理選項、剩餘風險接受、責任人、期限及是否升級管理階層。 風險決議、風險接受或處理要求。
10. KPI/KRI與績效審查 審查資訊安全目標、KPI/KRI、趨勢、未達標事項及是否啟動改善或CAPA。 KPI/KRI治理審查紀錄。
11. SoA與Annex A控制措施有效性審查 審查Annex A控制適用性、控制證據、控制有效性與補強決議。 SoA與控制有效性審查紀錄。
12. 事件、弱點與技術控制審查 審查事件、弱點、日誌監控、備份、備援、加密與技術控制缺口，必要時轉入風險重評或CAPA。 事件弱點審查與技術控制決議。
13. 供應商、雲端與ICT供應鏈審查 審查供應商風險、雲端服務、AI供應商、GHG資料供應商及改善追蹤。 供應商風險與改善決議。
14. PIMS / AI / GHG延伸治理議題審查 審查隱私、AI、氣候變遷、GHG/CO2資料與AI模型能源效率相關風險及治理決議。 專項治理審查紀錄。
15. 內部稽核、外部驗證、CAPA與持續改善審查 審查稽核發現、外部驗證缺失、CAPA、有效性驗證與持續改善優先順序。 稽核與CAPA審查紀錄。
16. 本次會議正式決議事項 將治理委員會決議正式化，明確決議內容、依據、責任人、期限、預期證據及追蹤狀態。 正式決議事項表。
18. 管理審查輸入彙整 彙整需提報管理審查之風險、績效、稽核、資源、能力、PIMS、AI、GHG及改善資料。 管理審查輸入彙整。
19. 附件與證據索引 將會議簡報、KPI/KRI、風險、SoA、事件、供應商、PIMS/AI/GHG、CAPA及碳證據建立附件索引與保存位置。 附件與證據索引。
22. 文件化資訊保存要求 定義會議紀錄、簡報、附件、行動事項、風險接受、CAPA及碳證據之保存責任與期限。 保存要求與證據保護要求。

2. 適用範圍

  • 適用於定期或臨時資訊安全治理委員會會議。
  • 適用於ISMS、PIMS、AI治理、GHG/CO2資料治理、雲端與ICT供應鏈、資訊及相關資產、資料中心、AI系統、安全開發、內部稽核、管理審查、CAPA與持續改善相關議題。
  • 適用於管理階層決策、重大風險審查、重大事件後檢討、控制有效性審查、外部驗證準備及管理審查輸入彙整。

3. 名詞與定義

名詞 定義
資訊安全治理委員會 由最高管理階層授權，負責監督ISMS治理、風險、控制措施、績效、稽核、事件、CAPA、資源與持續改善之跨部門治理機制。
會議紀錄 記載會議議程、出席人員、審查輸入、討論內容、決議、責任人、期限、證據與追蹤狀態之正式紀錄。
行動事項 由會議決議產生之待辦改善、風險處理、資源配置、文件修訂、控制補強或後續追蹤任務。
KPI/KRI KPI為績效指標，KRI為風險指標，用於監督ISMS控制有效性、風險趨勢與管理系統績效。
CAPA 不符合與矯正措施管理活動，包含不符合反應、根本原因分析、矯正措施、有效性驗證與結案。
重大風險 超過組織風險接受準則、需提報治理委員會或最高管理階層審查、決策或接受之資訊安全風險。
重大事件 可能造成重大資訊安全、營運、法規、客戶、隱私、AI、GHG資料或聲譽影響之事件。
管理審查輸入 需由治理委員會彙整後提交最高管理階層管理審查之績效、風險、資源、稽核、CAPA與改善資料。
