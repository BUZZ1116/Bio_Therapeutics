1. 作業目的

本作業指導書規範組織於營運中斷、ICT服務中斷、災害復原、資安事件、供應商中斷、場所不可用、網路中斷、雲端服務異常、勒索軟體、資料毀損或其他緊急事件期間，如何維持最低必要資訊安全控制，避免組織為了快速恢復服務而犧牲機密性、完整性、可用性、隱私、法規合規、客戶承諾與證據保全。

本文件的核心目標是在中斷期間確保「不中斷資安治理、不降低必要控制、不失去可追溯性、不破壞證據、不擴大資料外洩、不產生未授權存取、不讓臨時措施永久化」，並確保復原後能回到正常控制狀態且完成事後檢討與改善。

2. 作業原則

  • 中斷期間仍應維持風險導向之資訊安全控制；任何控制暫停、降低或繞過，均需核准、記錄、期限、補償控制與事後復原。
  • 恢復服務不得以未授權存取、共享帳號、未加密資料移轉、未驗證備份、未掃描系統、未保全證據或未受控變更作為代價。
  • 中斷期間應優先保護人員安全、關鍵業務、客戶資料、個人資料、身份服務、特權帳號、備份、金鑰、日誌、證據與核心資產。
  • 替代作業、手工作業、臨時帳號、臨時系統、臨時網路、臨時供應商或臨時雲端資源，均需納入資安控制與追蹤清冊。
  • 若中斷事件同時涉及資安事件，應以事件管理、證據保全、通報、調查與復原完整性為優先，不得任意重建或清除證據。
  • 中斷結束後應完成控制復原、臨時權限撤銷、資料同步驗證、日誌保存、風險重評、CAPA與管理審查輸入。

3. 名詞與定義

名詞 定義
中斷期間 因災害、故障、資安事件、供應商異常、網路中斷、場所不可用或其他原因造成正常業務或ICT服務無法按既定水準運作之期間。
資安維持 於中斷期間持續維持最低必要資訊安全控制，包括身份驗證、存取控制、日誌、監控、加密、備份、資料保護、證據保存與變更控制。
替代作業 當正常系統、流程、場所或供應商不可用時，採用手工作業、備援系統、雲端替代、紙本流程、臨時流程或外部服務維持業務運作。
臨時控制 為因應中斷期間特殊情況而暫時採用之安全控制或替代控制，需有明確期限、Owner、核准與復原計畫。
控制繞過 暫停、降低或避開既有安全控制之行為，例如停用MFA、共用帳號、開放防火牆、跳過審批或停止日誌。
補償控制 在原控制不可用或需暫停時，用於降低風險之替代安全措施。
最低可接受控制 即使在中斷期間也不得省略或需替代維持之核心安全控制。
復原完整性 確認復原後系統、資料、設定、權限、日誌、金鑰與業務資料一致、可信、未遭竄改或遺漏之狀態。
保管鏈 證據、影像、日誌、備份、磁碟、文件或調查資料從取得到保存、移交、分析、歸檔過程之完整紀錄。
危機通訊 中斷期間對內部、客戶、供應商、監管機關、媒體或其他利害關係人之授權溝通。

6. 中斷期間最低可接受資安控制

控制領域 最低要求 不得省略事項 補償控制範例
身分驗證 維持MFA、具名帳號、最小權限與特權帳號管制。 不得長期共用帳號或停用MFA且無核准。 臨時帳號限時、PAM、人工審批、登入監控。
特權存取 緊急權限需核准、限時、記錄、事後審查與撤銷。 不得無紀錄使用Root/Admin。 Break-glass帳號封存、雙人控制、Session錄影。
日誌與監控 維持核心系統、身份、網路、備援、雲端與安全設備日誌收集。 不得為恢復效能而停止關鍵日誌。 本地暫存日誌、手動匯出、增加SOC巡檢。
網路安全 臨時開放防火牆、VPN、ACL或遠端連線需核准、期限與監控。 不得永久開放Any-to-Any或未限制管理介面。 白名單、限時規則、跳板機、連線審查。
資料保護 維持加密、資料最小化、傳輸保護與敏感資料處理限制。 不得將敏感資料傳至未核准平台。 加密容器、受控SFTP、臨時DLP監控。
備份與還原 還原前確認備份完整、未感染、符合RPO並保留原始證據。 不得使用未驗證或疑似被污染備份。 隔離還原環境、Hash驗證、惡意程式掃描。
變更控制 緊急變更可簡化但不可無紀錄；事後需補審查。 不得無Owner、無時間、無回復計畫。 緊急CAB、變更日誌、事後回顧。
供應商控制 供應商臨時支援需授權、NDA、連線限制與作業紀錄。 不得讓供應商無監控遠端存取。 限時VPN、Session紀錄、陪同操作。
實體安全 替代場所、災備站點、臨時工作區需最低門禁、訪客與資產管制。 不得將設備與資料置於未受控場所。 人工保全、臨時清冊、場外資產控管。
溝通安全 危機通訊需使用授權內容與核准渠道，避免揭露弱點或敏感資訊。 不得未經核准對外透露攻擊細節或客戶影響。 通訊模板、發言人機制、Legal審查。

7. 中斷期間資安維持作業流程

階段 作業要求 責任角色 輸出證據
1. 啟動與分類 確認中斷類型、影響範圍、是否涉及資安事件、資料影響與服務優先序。 BCMS Owner / Incident Manager / CISO 啟動紀錄、事件分類。
2. 指揮與授權 建立指揮架構、聯絡窗口、決策權限、會議節奏與記錄方式。 Management Team / CISO 指揮紀錄。
3. 風險快速評估 評估可用性、機密性、完整性、隱私、法規、供應商與客戶影響。 Security / Business / Legal 快速風險評估。
4. 控制維持清單 確認不可降低控制、可暫時替代控制、需核准繞過控制與補償控制。 CISO / Control Owners 資安維持清單。
5. 遏止與保全 若涉及資安事件，先隔離、保存證據、保全日誌與避免破壞調查。 Incident Manager / SOC 證據保全紀錄。
6. 替代作業啟用 啟用手工作業、備援系統、災備站點、遠端工作、臨時供應商或雲端替代。 BCMS / Service Owner 替代作業紀錄。
7. 緊急存取管理 核准臨時帳號、特權、VPN、防火牆、供應商連線與到期撤銷。 IAM / PAM / CISO 緊急權限紀錄。
8. 復原與驗證 還原系統、資料、設定、連線、監控與安全基準，驗證完整性。 IT / Application Owner / Data Owner 復原驗收紀錄。
9. 對內外通報 依授權內容與時限向內部、客戶、供應商、監管或其他利害關係人溝通。 Communications / Legal / DPO 通報紀錄。
10. 控制回復 撤銷臨時權限、關閉臨時連線、移除例外、恢復正常監控與變更流程。 Control Owners 控制回復清單。
11. 事後檢討 完成RCA、CAPA、風險重評、管理審查輸入、演練更新與文件修訂。 CISO / BCMS Owner 事後檢討報告。

8. 臨時措施、控制繞過與風險接受

臨時措施類型 核准要求 必要補償控制 結束要求
臨時管理員權限 需CISO/IAM/PAM或Incident Manager核准，明確期限與用途。 Session紀錄、命令紀錄、雙人見證或事後審查。 期限到期立即撤銷並審查活動。

臨時雲端/替代平台 需Cloud Owner、Security、Legal/DPO視情況核准。 IAM、加密、地區、日誌、資料最小化、合約確認。 資料移回、刪除、權限撤銷。
日誌暫停或降低 原則禁止；如技術限制需CISO核准。 本地保留、手動匯出、縮短間隔、提高人工監控。 恢復日誌並補收可取得紀錄。
