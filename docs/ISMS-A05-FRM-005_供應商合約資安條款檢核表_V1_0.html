1. 表單目的

本檢核表用於確認供應商合約、採購條款、服務條款、SOW、DPA、NDA、SLA、安全附件、雲端服務條款、AI服務條款與子處理者條款，是否已納入充分之資訊安全、隱私、AI治理、供應鏈、雲端、事件通報、營運持續、資料保護、稽核權、退場與合規要求。

本檢核表之目的在於降低因供應商合約條款不足所造成之資料外洩、未授權再委外、事件通報延誤、服務中斷、跨境資料風險、AI資料誤用、第四方不可視、SLA無法落實、查證資料失控及驗證不符合等風險。

2. 使用原則

  • 所有中高風險供應商、新供應商、續約、重大合約變更、服務範圍變更、子處理者變更或事件後重評，均應完成本檢核表。
  • 若合約涉及PII、AI服務、雲端服務、客戶資料、關鍵營運、外包開發、跨境傳輸、第四方、GHG/CO2資料或法規合約要求，應啟動專項檢核。
  • 檢核結果若有「不符合」或「部分符合」，應記錄補救條款、補償控制、風險接受或CAPA，不得以口頭承諾取代合約條款或正式證據。
  • 供應商合約資安條款之最終接受，應依風險等級由採購、法務、CISO、DPO、AI治理或最高管理階層授權代表核准。
