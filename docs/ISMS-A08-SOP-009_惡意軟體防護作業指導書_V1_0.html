1. 作業目的

本作業指導書規範組織惡意軟體防護之防禦架構、端點與伺服器保護、Email與Web防護、雲端工作負載防護、行動裝置防護、容器與CI/CD防護、AI/MLOps防護、偵測規則、掃描、隔離、通報、事件處理、惡意樣本管理、威脅情報、例外管理、供應商管理、教育訓練、稽核與持續改善要求，降低病毒、蠕蟲、木馬、勒索軟體、間諜軟體、後門、Rootkit、惡意Script、惡意巨集、檔案型/無檔案攻擊、供應鏈惡意套件、惡意容器、惡意瀏覽器外掛、惡意AI模型或其他惡意程式造成之資訊安全風險。

本文件旨在建立可預防、可偵測、可隔離、可回復、可追溯之企業級惡意軟體防護能力，並與端點安全、弱點修補、軟體白名單、網頁過濾、Email安全、備份還原、日誌監控、事件回應、數位證據保存、供應鏈安全與AI治理流程整合。

2. 作業原則

  • 惡意軟體防護應採多層防禦，包括使用者教育、端點防護、EDR/XDR、Email/Web過濾、DLP、網路偵測、應用程式控制、弱點修補、備份與事件回應。
  • 所有受管理端點、伺服器與雲端工作負載應部署核准之防惡意軟體或等效EDR/XDR控制，並維持啟用、更新、監控與不可被一般使用者停用。
  • 惡意軟體偵測、隔離、清除與復原作業應以證據保存、業務影響、資料保護、復原可信度與再感染防止為核心。
  • 惡意樣本、IOC、分析報告與事件證據屬高敏感資訊，應採限制存取、加密保存與安全傳輸。
  • 勒索軟體、資料竊取、供應鏈惡意套件、無檔案攻擊、特權帳號異常、EDR停用或多端點感染應視為高風險事件並立即升級。
  • 任何防護停用、掃描排除、白名單、隔離解除或誤判例外均應具備核准、期限、補償控制與定期重評。

3. 名詞與定義

名詞 定義
惡意軟體 任何未經授權且意圖破壞、竊取、加密、監控、控制、滲透或濫用系統與資料之程式碼、Script、巨集、檔案、套件、容器、模型或工具。
EDR Endpoint Detection and Response，端點偵測與回應，提供端點行為監控、威脅偵測、隔離、調查與回應能力。
XDR Extended Detection and Response，整合端點、網路、Email、雲端、身份與應用日誌之擴展偵測回應能力。
IOC Indicator of Compromise，入侵指標，例如Hash、IP、Domain、URL、檔名、Registry Key、Mutex、行為特徵或憑證痕跡。
IOA Indicator of Attack，攻擊行為指標，例如權限提升、橫向移動、持久化、憑證傾倒或資料外傳行為。
勒索軟體 透過加密、竊取、破壞或威脅公開資料以勒索金錢或利益之惡意軟體或攻擊活動。
無檔案攻擊 不依賴傳統惡意檔案，透過記憶體、合法工具、PowerShell、WMI、Script或系統功能執行之攻擊。
惡意樣本 疑似或確認惡意之檔案、Script、Macro、記憶體Dump、封包、URL、容器映像、套件或模型檔案。
隔離 將受感染或疑似受感染之端點、伺服器、檔案、帳號、網路連線或工作負載限制於安全狀態，以防止擴散。
清除 移除惡意軟體、持久化機制、惡意帳號、排程、Registry、服務、後門、IOC與相關殘留之活動。
重新佈署 / 重建 對高風險或無法保證清除之系統，以可信映像、備份或IaC重建，取代單純清除。
威脅情報 來自內部事件、供應商、社群、政府、ISAC或商業來源之惡意活動、IOC、TTP與防護建議。

Email / Collaboration Owner 管理Email防護、附件沙箱、URL重寫、釣魚防護、協作平台惡意檔案掃描。 Email安全報告。

AI Governance / MLOps Owner 管理惡意模型、惡意Notebook、AI工具外掛、模型供應鏈與AI Agent濫用風險。 AI安全審查紀錄。

All Users 遵守安全使用規範，不開啟可疑附件、連結、巨集、外掛或未核准軟體，及時通報異常。 教育訓練與通報紀錄。
Internal Auditor 抽查防護覆蓋、更新、告警、例外、事件、復原與控制有效性。 稽核底稿、稽核發現。

防護層級 控制要求 主要證據

端點層 部署EDR/AV、行為偵測、裝置控制、應用程式控制、USB限制、惡意Script控制。 EDR健康報告、政策設定。
伺服器層 伺服器EDR、防護策略、弱點修補、最小服務、特權控制、完整性監控。 伺服器防護清冊。
Email層 防惡意附件、沙箱、URL重寫、DMARC/SPF/DKIM、釣魚偵測與隔離。 Email安全報告。
Web層 SWG/Proxy、DNS安全、惡意URL封鎖、下載檔案掃描、分類控制。 Proxy/DNS報告。
網路層 NDR、IDS/IPS、惡意C2連線偵測、DNS Sinkhole、Egress控制。 NDR/SIEM告警。

AI/MLOps層 模型檔案掃描、Notebook與套件控制、RAG資料保護、AI Agent工具限制。 AI安全審查。

6. 防護部署與覆蓋要求

資產類型 最低防護要求 例外條件
使用者端點 必須部署EDR/AV、即時防護、行為偵測、惡意URL/檔案防護與集中管理。 僅因相容性例外，需CISO核准與補償控制。
伺服器 必須部署伺服器防護或等效工作負載防護，啟用掃描、行為監控與告警。 高效能或專用系統需風險評估。
雲端主機 需納入雲端EDR/CWPP、弱點管理、日誌與隔離能力。 短期主機需以映像基準與雲端控制補償。
容器映像 需於Registry與CI/CD進行惡意軟體、弱點與Secrets掃描。 禁止未掃描高風險映像進入正式環境。
行動裝置 受管理行動裝置需MDM/MTD或等效惡意應用與惡意URL防護。 BYOD需隔離企業資料與條件式存取。
檔案伺服器 需啟用即時掃描、定期掃描、勒索行為偵測與異常大量修改告警。 需避免掃描造成服務中斷並設測試窗口。
Email與協作平台 需附件掃描、沙箱、URL防護、惡意檔案隔離與釣魚回報機制。 不得停用高風險附件檢查。
SaaS與雲端儲存 需CASB/雲端DLP/惡意檔案掃描與外部分享監控。 例外需SaaS Owner與CISO核准。
AI/MLOps環境 Notebook、模型檔、資料集、套件、容器與外部模型來源需掃描與來源驗證。 研究隔離環境需限制外連與資料存取。
供應商維運設備 供應商遠端維運設備需具惡意軟體防護與事件通報證明。 不可證明者不得直接連入高風險環境。

7. 惡意軟體防護作業流程

階段 作業要求 責任角色 輸出證據
1. 資產識別 識別需納入防護之端點、伺服器、雲端、SaaS、容器、AI/MLOps與供應商設備。 Endpoint Security / Asset Owner 防護覆蓋清冊。
2. 風險分級 依資料分類、暴露面、系統重要性、使用者角色、威脅情境與業務影響分級。 CISO / Risk Owner 風險分級紀錄。
3. 防護策略設定 設定EDR/AV、掃描、行為偵測、隔離、封鎖、排除、更新與告警策略。 Malware Protection Owner 防護政策設定。
4. 部署與啟用 透過MDM、GPO、EDR平台、雲端Agent或映像基準部署防護。 IT Operations / Endpoint Security 部署紀錄。
5. 健康監控 監控Agent離線、功能停用、特徵碼過期、隔離失敗與政策不符。 SOC / Endpoint Security 健康報告。
6. 掃描與偵測 執行即時掃描、定期掃描、行為偵測、IOC搜尋與威脅獵捕。 SOC / EDR Owner 掃描與偵測紀錄。
7. 告警分級 依感染範圍、資料影響、惡意類型、端點重要性與攻擊階段分級。 SOC 告警分級紀錄。
8. 隔離與處置 隔離端點、檔案、帳號或網路連線，清除惡意程式與持久化機制。 Incident Response / IT 隔離與處置紀錄。
9. 復原與驗證 確認系統乾淨、修補弱點、重設憑證、復原資料與加強監控。 IT / Security / Data Owner 復原驗證紀錄。
10. 檢討改善 分析根因、更新規則、教育、修補、白名單、網路封鎖與風險登錄。 IR Owner / ISMS代表 事件檢討與CAPA。

8. 掃描與偵測要求

掃描 / 偵測類型 最低要求 頻率 / 觸發
即時防護 檔案建立、執行、下載、Email附件、外接媒體與Script執行時即時檢查。 持續啟用。
定期全機掃描 端點與伺服器定期執行完整掃描或等效風險掃描。 至少每月或依風險。
快速掃描 針對高風險區域、啟動項、記憶體、系統目錄與使用者下載資料夾掃描。 至少每週或依平台能力。
外接媒體掃描 USB、外接硬碟、光碟、記憶卡接入時掃描。 每次接入。
Email附件沙箱 高風險附件、壓縮檔、Office文件、可執行檔與未知檔案需沙箱分析。 每次接收或政策觸發。
Web下載掃描 瀏覽器下載、Proxy下載與雲端檔案下載需檢查。 每次下載或政策觸發。
IOC搜尋 針對威脅情報、事件或供應商通報之IOC進行企業範圍搜尋。 威脅情報更新或事件觸發。
行為偵測 偵測勒索加密、大量檔案修改、憑證傾倒、橫向移動、持久化與EDR停用。 持續啟用。
雲端儲存掃描 對上傳至Bucket、檔案共享、Artifact或資料交換區之檔案掃描。 上傳時或定期。
Container/Image掃描 掃描映像、Layer、套件、惡意檔案、Secrets與弱點。 Build、Push、Deploy前。
AI/MLOps掃描 掃描模型檔、Notebook、資料集、外部套件、容器與工具。 匯入、訓練、部署前。

9. 告警分級與處置SLA

等級 判定條件 初步處置 處理時限
Critical 勒索軟體、資料竊取、特權帳號感染、EDR大範圍停用、多端點感染、C2連線、橫向移動、Domain Controller/關鍵伺服器感染。 立即隔離、啟動事件回應、通知CISO與管理層，保存證據。 立即至4小時內初判與控制。
High 確認惡意軟體感染、惡意PowerShell/Script、木馬、後門、惡意套件、伺服器感染或高敏感端點感染。 隔離設備或檔案，執行取證與清除。 1個工作日內初判。
Medium 可疑檔案、PUA/PUP、單一端點低影響感染、未知檔案或使用者誤點但未執行。 隔離檔案，通知使用者與IT處理。 3個工作日內初判。
Low 已阻擋之低風險威脅、廣告軟體、可解釋測試活動或誤判疑似。 記錄、調校規則或教育提醒。 依SOC流程處理。
False Positive 經確認為合法軟體、測試工具或業務行為。 依例外流程調整規則或白名單。 納入定期調校。
Policy Violation 使用者安裝未核准工具、破解軟體、惡意外掛或規避防護。 依違規程序與事件風險處理。 依嚴重性處理。

10. 隔離、清除與復原要求

處置項目 作業要求 驗證要求
端點隔離 EDR或網路層隔離受感染端點，保留管理連線與取證能力。 確認無C2、外連與橫向移動。
檔案隔離 隔離惡意或可疑檔案，避免刪除前破壞證據。 保存Hash、路徑、時間與偵測名稱。
帳號控制 停用或重設受影響帳號、Token、API Key、Session與憑證。 確認無異常登入與持久化。
網路封鎖 封鎖惡意Domain、IP、URL、Hash、DNS與C2流量。 確認封鎖命中與無繞過。
清除惡意程式 移除檔案、服務、排程、Registry、啟動項、後門與持久化。 EDR重新掃描與人工確認。
系統修補 修補被利用弱點，移除不必要服務與高風險設定。 弱點掃描與組態檢查通過。
資料復原 由乾淨且驗證之備份復原必要資料，避免復原惡意檔案。 備份掃描與還原驗證。
重建系統 高風險感染或Rootkit/勒索感染應優先重建。 使用可信映像、IaC或黃金映像。
解除隔離 需確認清除、修補、憑證輪替、監控正常與Owner驗收。 解除隔離核准與紀錄。
強化監控 復原後進入強化監控期，觀察再感染或異常外連。 監控期紀錄。

11. 勒索軟體專項防護與應變要求

控制項目 預防要求 事件中要求
不可變備份 關鍵資料需具不可變、離線或邏輯隔離備份，並定期還原測試。 禁止立即覆蓋備份；確認最後乾淨備份點。
權限最小化 限制共享資料夾寫入權、管理員權限、服務帳號與橫向移動。 暫停可疑帳號與高風險共享權限。
行為偵測 偵測大量加密、快速改名、影子複製刪除、備份刪除與安全服務停用。 立即隔離相關端點、伺服器與帳號。
網路區隔 關鍵系統、備份網路、管理網路與使用者網路應分離。 依情況封鎖東西向流量與高風險連線。
憑證保護 強化MFA、PAM、LSASS保護、Credential Guard或等效控制。 輪替受影響帳號與Secrets。
資料外洩評估 勒索事件需評估是否有資料竊取與DLP/外連證據。 通知DPO、Legal與管理層。
復原決策 復原前需確認攻擊入口、持久化與乾淨復原點。 不得在未清除攻擊者存取前貿然復原。
通報與溝通 依法規、合約、保險、客戶與管理要求通報。 由Incident Manager統一對外溝通。

12. 惡意樣本與證據管理

項目 管理要求 保存要求
惡意樣本收集 僅由授權SOC/Forensics人員收集，使用隔離工具與安全容器。 記錄來源、時間、Hash、操作者與保管鏈。

銷毀與退場 樣本保存期限屆滿或目的消失時，依資料清除程序銷毀。 保留銷毀紀錄。

1. 接收告警 確認告警來源、資產、使用者、時間、偵測名稱、Hash與處置狀態。 SOC 告警截圖與日誌。
2. 初步分級 依惡意類型、資產重要性、感染範圍、資料影響與攻擊階段分級。 SOC / IR 分級紀錄。
3. 隔離控制 對確認或高信心感染資產執行端點或網路隔離。 IR / Endpoint Security 隔離紀錄。
4. 證據保存 保存檔案Hash、路徑、程序、網路連線、使用者、記憶體或磁碟證據。 Forensics 保管鏈。
5. 範圍分析 搜尋IOC、相同Hash、相同使用者、相同郵件、C2或橫向移動跡象。 SOC IOC搜尋紀錄。
6. 清除或重建 移除惡意程式、修補入口、輪替憑證，必要時重建系統。 IT / Security 修復紀錄。
7. 復原驗證 重新掃描、確認無C2、無持久化、無弱點與業務功能正常。 IT / SOC 驗證報告。
8. 通報與檢討 依事件等級通報並完成根因分析與CAPA。 IR / CISO 事件檢討報告。
