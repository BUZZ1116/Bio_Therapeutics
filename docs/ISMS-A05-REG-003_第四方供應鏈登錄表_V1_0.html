1. 登錄目的

本登錄表用於識別、記錄、分類、監督及管理直接供應商所依賴之第四方、第五方及其他下游供應鏈關係，確保組織對關鍵供應鏈、雲端服務、資料處理、外包支援、AI供應商、軟體供應鏈、資料中心、通訊服務、GHG/CO2資料來源及查證服務具有足夠之可視性、風險評估與治理控制。

本登錄表支援ISO/IEC 27001:2022 Annex A 5.19、5.20、5.21、5.22、5.23供應商與雲端服務相關控制，以及5.8專案管理、5.34隱私與PII保護、5.30 ICT就緒度、8.30外包開發及8.32變更管理等要求。

2. 使用原則

  • 凡直接供應商使用或依賴會影響組織資訊安全、服務可用性、PII處理、AI服務、雲端服務、客戶承諾、法規合約或GHG/CO2揭露之第四方，均應登錄。
  • 高風險或關鍵第四方應完成風險評估、合約條款檢查、事件通報要求、可替代性分析及退場策略。
  • 第四方資訊應由直接供應商定期更新，並由供應商管理、資訊安全、法務、DPO、AI治理及BCMS等角色依適用性審查。
  • 第四方變更、重大事件、法規變更或服務範圍異動時，應觸發重新評估。
