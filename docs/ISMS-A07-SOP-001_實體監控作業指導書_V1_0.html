1. 作業目的

本作業指導書規範實體監控之規劃、設置、操作、監看、告警、巡檢、錄影保存、調閱、證據保全、維護、權限控管、隱私保護、供應商管理、例外管理、稽核與持續改善要求，確保組織能即時或事後偵測未授權進入、尾隨、可疑行為、設備破壞、資料或資產遺失、環境異常、門禁失效、監控設備故障與其他實體安全事件，並提供可追溯、完整且合規之調查證據。

實體監控應以風險為基礎，與安全區域、門禁、訪客管理、保全巡檢、CCTV、警報、環境監控、支援設施、資訊安全事件管理與數位證據保存流程整合，確保監控控制不僅具備技術設備，也具備明確責任、授權、保存、調閱、維護與管理審查機制。

2. 作業原則

  • 實體監控應依安全區域等級、資產重要性、資料敏感度、威脅情境與營運持續要求配置CCTV、門禁、警報、環境告警、巡檢或其他等效控制。
  • 監控點位、錄影角度、警報設定、保全路線、門禁權限與事件紀錄屬敏感資訊，應依文件化資訊管制要求限制存取。
  • 監控作業應兼顧資訊安全與隱私保護，不得超出核准目的使用監控紀錄，不得未授權複製、散布、截圖、下載或公開監控畫面。
  • 監控系統應具備適當存取控制、日誌紀錄、時間同步、備援、保存期限、完整性保護與調閱授權。
  • 任何監控異常、設備失效、錄影中斷、門禁異常、未授權進入、可疑行為或重要區域盲點，應即時通報並建立改善措施。
  • 監控紀錄若涉及事件、爭議、法務、個資或調查用途，應依證據保全要求保存，不得任意刪除或覆寫。

3. 名詞與定義

名詞 定義
實體監控 透過CCTV、門禁、警報、環境感測、保全巡檢、訪客紀錄或其他方式監測實體場所、資產、設施與人員活動之控制。
CCTV 閉路電視或網路攝影監控系統，用於錄影、即時監看、事件調查或實體安全證據保存。
門禁紀錄 人員使用門禁卡、生物辨識、PIN、鑰匙、訪客證或人工登記進出安全區域之紀錄。
警報事件 門禁強開、門未關閉、入侵偵測、CCTV遮蔽、環境告警、設備離線或其他安全設備觸發之事件。
監控室 集中監看、管理或保存CCTV、門禁、警報與支援設施告警之場所。
調閱 因事件調查、稽核、法務、管理或安全目的，經授權存取、檢視、擷取或輸出監控紀錄之行為。
證據保全 為確保監控紀錄於事件調查、法律程序、稽核或管理審查中可被信賴，對其完整性、保管鏈、存取與保存進行控制。
監控盲點 應被監控但因角度、遮蔽、故障、設計不足或環境改變導致無法有效監看之區域。
保全巡檢 由保全或授權人員依路線、頻率與檢查項目巡視安全區域、設備、門窗、警報與環境狀態之活動。
影像保存期限 監控影像依風險、法規、合約或內部要求保存之最短或最長期間。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
CISO / Security Owner 核准監控政策、高風險調閱、例外、重大事件處理與管理審查輸入。 核准紀錄、風險接受。
Physical Security Owner 規劃實體監控點位、門禁、警報、巡檢與監控事件處理流程。 監控設計、巡檢紀錄。
Facility Owner 維護監控設備供電、安裝位置、線路、環境、固定與設施支援。 維護紀錄。
Monitoring System Owner 管理CCTV、門禁、警報平台之帳號、權限、備份、日誌、時間同步與系統健康。 系統設定與稽核日誌。
Security Guard / 保全 執行即時監看、巡檢、異常通報、現場初步處置與紀錄。 巡邏紀錄、異常紀錄。
SOC / Incident Response Team 接收重大實體安全告警，進行事件初判、調查、證據保全與協調應變。 事件紀錄、調查報告。
Area Owner 確認區域監控需求、盲點、訪客風險、設備保護與缺失改善。 區域審查紀錄。
DPO / Legal 審查監控涉及個資、員工隱私、法務調閱、保存期限與外部揭露要求。 隱私/法務審查。
Supplier / Maintenance Vendor 依合約維護CCTV、門禁、警報、感測器與相關系統，不得未授權存取或保留資料。 維護報告、NDA。
Internal Auditor 抽查監控設計、權限、調閱、保存、事件、維護、例外與改善有效性。 稽核底稿。

5. 實體監控範圍與控制要求

監控對象 / 區域 監控目的 最低控制要求 注意事項
主要出入口 偵測未授權進入、尾隨、異常出入與訪客活動。 CCTV、門禁紀錄、訪客登記、保全巡檢。 避免直接拍攝不必要之敏感個資區域。
接待區與訪客動線 掌握訪客活動與防止進入內部區域。 訪客證、陪同、CCTV或人工監控。 訪客資料需遮蔽與保護。
機房 / 資料中心 保護關鍵資訊處理設施與偵測未授權接觸。 門禁、CCTV、警報、進出紀錄、必要雙人控制。 影像與門禁Log需可支援事件調查。
弱電間 / 網路設備間 防止未授權接線、設備破壞、竊聽或植入。 上鎖、門禁或鑰匙紀錄、巡檢、必要CCTV。 重點檢查未知設備與線路。
備份媒體 / 文件保存區 保護備份媒體、紙本文件、合約與高敏感資料。 門禁、上鎖櫃、進出紀錄、CCTV或等效控制。 調閱紀錄與媒體清冊需一致。
監控室 / 保全室 保護監控平台、畫面、調閱能力與事件紀錄。 授權進入、螢幕防旁觀、操作日誌、CCTV畫面保護。 監控畫面不得被訪客觀看。
列印/掃描區 降低敏感文件遺留、誤取與未授權接觸。 巡檢、安全列印、必要CCTV或位置管制。 不可過度監控個人行為，應以資料保護目的為限。
倉儲 / 裝卸區 保護設備、媒體、退役資產、物流與供應商交接。 出入紀錄、CCTV、交接簽收、巡檢。 高敏感設備需雙人或封條。
停車 / 外部周界 偵測未授權靠近、破壞、裝卸風險。 依風險設置CCTV、照明、巡檢或保全。 遵循當地隱私與法規。
臨時施工區 防止施工人員接觸未授權區域與資產。 臨時邊界、訪客/施工紀錄、陪同、巡檢。 施工結束需清場與復原。

6. 監控系統安全與存取控制

控制項目 作業要求 證據 / 驗證
具名帳號 CCTV、門禁、警報與監控平台應使用具名帳號，不得共用管理帳號。 帳號清冊。
最小權限 監看、調閱、匯出、設定、刪除、管理權限應分離並依職務授權。 權限矩陣。
MFA與強驗證 管理者、遠端登入與高權限調閱應採MFA或等效強驗證。 登入設定。
權限審查 至少定期審查監控平台、門禁平台與錄影系統權限。 權限審查紀錄。
時間同步 CCTV、門禁、警報、監控伺服器與事件系統應同步標準時間。 NTP設定與測試。
操作日誌 登入、調閱、匯出、刪除、設定變更與權限調整需留存日誌。 系統Audit Log。
資料完整性 重要錄影或事件證據應防止未授權修改、覆寫、刪除或外洩。 保全與證據保存紀錄。
網路隔離 監控設備網路應與一般使用者網路適當隔離，限制管理介面存取。 網路架構與ACL。
弱點與修補 監控系統、攝影機、NVR、門禁控制器應定期修補與弱點管理。 維護與修補紀錄。
備援與容量 重要監控系統應考量儲存容量、錄影保存、UPS與故障備援。 容量與健康檢查。

7. 監控紀錄保存與調閱管理

項目 作業要求 管制重點
保存期限 依區域風險、法規、合約與事件需求設定影像、門禁與警報紀錄保存期限。 保存期限應文件化並定期審查。
覆寫控制 錄影系統自動覆寫前應確保未涉及事件、法務、稽核或調查保存需求。 事件相關影像需先保全。
調閱申請 調閱監控紀錄需有目的、範圍、時間、區域、申請人、核准人與使用限制。 禁止無目的瀏覽。
調閱核准 涉及員工、訪客、個資、法務或高敏感區域之調閱需提高核准層級。 CISO/DPO/Legal視情況核准。
匯出與複製 影像或紀錄匯出需加密、標示、保存保管鏈並限制接收者。 禁止未授權截圖與轉傳。
調閱日誌 所有調閱、匯出、複製、刪除或交付外部之行為應留存紀錄。 保留Audit Trail。
外部提供 提供執法機關、客戶、保險、法院或第三方需經Legal/CISO核准。 保存交付紀錄。
到期刪除 超過保存目的與期限之監控資料應依規定刪除或覆寫。 避免過度保留。
證據保全 涉及事件之影像需鎖定保存，記錄Hash、保管人、移交與存取。 確保證據完整性。

8. 實體監控作業流程

階段 作業要求 責任角色 輸出證據
1. 監控需求識別 依安全區域、資產重要性、事件歷史、環境風險與合規要求識別監控需求。 Area Owner / Physical Security 監控需求紀錄。
2. 風險評估 評估監控目的、隱私影響、盲點、保存期限、系統安全與維護需求。 Security / DPO / Facility 風險與隱私評估。
3. 設計與核准 確認點位、角度、保存、門禁/警報整合、權限、告示與監控室要求。 Physical Security / CISO 設計核准。
4. 安裝與設定 依核准配置安裝CCTV、門禁、警報、環境感測與平台設定。 Facility / Supplier 安裝紀錄。
5. 測試與驗收 測試畫面、錄影、門禁、警報、時間同步、日誌、權限與告警通知。 System Owner / Security 驗收報告。
6. 日常監看與巡檢 依區域等級執行即時監看、告警回應、保全巡檢與異常紀錄。 Security Guard / Facility 巡檢與告警紀錄。
7. 事件處理 異常進出、可疑行為、設備破壞、盲點或系統失效依事件程序處理。 Incident Response / Physical Security 事件紀錄。
8. 紀錄調閱 依調閱申請、核准、匯出、保管鏈與使用限制進行。 Authorized Reviewer 調閱紀錄。
9. 定期審查 定期審查監控有效性、點位、權限、保存、盲點、事件與改善。 CISO / Physical Security 審查紀錄。
10. 退場與刪除 監控點位停用或搬遷時，清除帳號、回收設備、更新圖資與刪除不必要紀錄。 Facility / System Owner 退場紀錄。

9. 即時監看、告警與巡檢要求

監控活動 最低要求 升級條件 紀錄
即時監看 依風險與營運需求對Level 3/4區域、主要入口或事件高風險區域進行監看。 未授權進入、尾隨、可疑停留、設備破壞。 監看紀錄或事件紀錄。
門禁告警 門未關閉、強行開門、拒絕進入、多次失敗、異常時間進出需追蹤。 Level 3/4或非上班時間異常。 門禁告警紀錄。
CCTV異常 攝影機離線、遮蔽、角度偏移、錄影中斷、畫面模糊需處理。 關鍵區域CCTV失效。 維護/事件紀錄。
環境告警 漏水、煙霧、溫濕度、UPS、空調、電力告警需通報Facility/IT。 影響Critical服務或安全區域。 環境告警紀錄。
保全巡檢 依巡檢路線、頻率與檢查項目確認門窗、機櫃、設備、訪客與環境狀態。 發現未上鎖、未知設備、異常人員。 巡檢表。
交接班 保全或監控人員交接應記錄未結事件、故障、特殊訪客、施工與注意事項。 重大未結事件。 交接紀錄。

13. 高風險情境與處置要求

情境 可能風險 立即處置 後續要求
CCTV關鍵點位離線或遮蔽 未能偵測未授權進入、證據缺失。 通知Facility/維護供應商，啟用人工巡檢或臨時監控。 修復後驗收，評估是否需事件紀錄。
門禁強開或門未關閉 未授權進入、安全邊界失效。 保全現場確認，檢查CCTV與門禁Log。 通報Physical Security與CISO視風險。
多次門禁拒絕或異常時間進入 可能為嘗試進入或帳號濫用。 確認人員身份、原因與授權。 必要時啟動事件初判。
監控影像遭未授權調閱或匯出 隱私外洩、證據污染、合規違反。 停用相關帳號、保存日誌、通知CISO/DPO。 調查、CAPA與違規處理。
錄影保存容量不足或覆寫異常 事件證據缺失、合規風險。 立即擴充容量或調整保存策略，保全重要影像。 容量管理與管理審查。
監控系統遭入侵或異常登入 攻擊者可能刪除影像或掌握實體安全資訊。 隔離系統、保存日誌、啟動資安事件。 重建、修補、憑證輪替。
保全巡檢發現未知設備或可疑人員 惡意裝置、竊盜、未授權進入風險。 隔離現場、通知SOC/Physical Security。 事件調查與證據保全。
警報未能通知指定人員 事件延遲回應、控制失效。 改用人工通報並修復通知鏈。 測試與改善通報機制。

14. 例外管理

例外情境 最低要求 核准層級 期限與重評
CCTV因維修暫停 需建立臨時巡檢、臨時攝影、門禁加強或區域限制。 Physical Security / CISO視風險 每日重評至修復。
監控點位存在盲點 需評估風險，採調整角度、增設設備或補償控制。 Area Owner / Physical Security 最長60日。
保存期限低於標準 需說明容量、法規或技術限制，採風險接受與改善計畫。 CISO / DPO / Legal視情況 最長90日。
需緊急調閱但無法事前核准 可先由授權主管口頭核准，事後補單與審查。 CISO / Incident Manager 24至48小時內補件。
供應商需遠端維護監控系統 需限時、MFA、Session紀錄、陪同監看與事後撤權。 Monitoring System Owner / CISO 單次核准。
監控畫面需外部提供 需Legal/CISO/DPO核准，限定範圍、加密交付與接收者。 Legal / CISO / DPO 單次核准。
