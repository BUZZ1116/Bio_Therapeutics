1. 管理意圖

本程序依 ISO 31000 風險管理流程，建立 【公司名稱】 可共用於 QMS、ISMS、PIMS、AIMS、BCMS 與 GHG/CO2資料治理之風險管理方法。本程序作為整合型管理系統的共通第二階程序，適用於 ISO/IEC 27001 條款6.1，並保留 ISO 9001、ISO/IEC 27701、ISO/IEC 42001、ISO 22301、ISO 14064/14067 與 GHG Protocol 的專項介面，也支援條款 4 全景分析、5 領導與承諾、8 產品與服務生命週期、9 績效評估與10 改善。

本程序不是只列出風險清單，而是要求流程Owner以可比較、可重現、可稽核的方法，將不確定性轉換為可管理的決策、控制措施、資源需求、處理計畫、剩餘風險接受與管理審查輸入。

依 ISO 31000 5.4.3，最高管理階層與督導機構（如適用）應確保風險管理相關角色、職權、責任及當責被分派與溝通；
每一項風險自識別階段起即應指派風險當責者 (Risk owner)。

12.2 共通風險分類與母子風險關係

同一事件可能同時產生多領域風險。主責單位應建立一筆母風險，並以子風險連結各專項評估；不得因分屬不同管理系統而重複計算、遺漏控制或出現不同處理狀態。跨系統彙整使用 ISMS-061-REG-007 管理系統風險與機會總登錄表。

12.3 機會管理

機會應記錄預期效益、受益對象、投入資源、實施Owner、衡量指標、可能引入的新風險與停止條件。追求機會不得繞過法規、合約、資訊安全、隱私、AI倫理、營運持續、品質或碳聲明控制。

12.4 整合邊界

本程序統一治理原則、流程、共同尺度、升級、紀錄與管理審查；專項SOP可增加但不得降低法規或標準要求。尺度差異應透過轉換規則映射至共同等級，並保留原始專項評分。
