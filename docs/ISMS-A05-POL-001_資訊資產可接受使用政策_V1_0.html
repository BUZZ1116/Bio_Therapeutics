1. 政策目的

本政策旨在規範組織資訊資產之可接受使用原則，確保所有資訊資產在授權、合法、合規、符合業務目的與資訊安全要求之前提下被使用，並降低未授權存取、資料外洩、惡意軟體感染、帳號濫用、PII不當處理、AI工具不當輸入、雲端服務誤用、供應商存取濫用及營運中斷等風險。

本政策同時建立使用者對資訊資產使用之責任、禁止行為、例外管理、監督與違規處置要求，以支持ISMS、PIMS、AIMS、BCMS與組織治理之持續有效運作。

2. 政策聲明

所有資訊資產僅得用於經授權之業務目的、合約目的、法規要求或經核准之工作活動。使用者應依資訊分類、存取權限、最小權限、資料保護、保密義務、可追溯性與可稽核性原則使用資訊資產，並不得以任何方式危害組織、客戶、供應商、員工、資料主體、AI系統、營運持續能力或外部利害關係人之權益。

4. 名詞與定義

名詞 定義
資訊資產 對組織有價值且需保護之資料、系統、服務、設備、文件、軟體、帳號、憑證、流程、知識與外部服務。
可接受使用 符合授權、業務目的、法規合約、資訊安全政策與本政策規範之資訊資產使用方式。
不可接受使用 未授權、非法、違反政策、危害安全、破壞營運、侵犯隱私或造成組織風險之使用方式。
使用者 任何被授權存取或使用組織資訊資產之自然人或服務帳號操作責任人。
資訊資產Owner 對資訊資產之分類、授權、使用、保存、保護與風險承擔負有責任者。
機密資訊 依資訊分類政策被標示為內部、機密、高機密或受法規、合約、DPA、NDA保護之資訊。
PII 可識別自然人或與自然人相關之個人資料。
AI工具 可產生、分析、分類、預測、建議或自動化處理資訊之AI系統、模型、平台或外部服務。

5. 角色與責任

角色 主要責任
最高管理階層 核准政策方向，提供必要資源，支持資訊安全與可接受使用治理。
CISO / 資訊安全負責人 制定政策要求，監督政策遵循，審查重大例外、事件與違規處置。
ISMS管理代表 維護本政策，整合風險、控制、稽核、CAPA與管理審查輸入。
資訊資產Owner 定義資產用途、分類、授權、保護要求、使用限制與例外核准。
IT / SOC 提供技術控制、監控、日誌、告警、終端管理、網路與雲端安全支援。
HR 將政策納入到職、訓練、保密承諾、紀律處分與離職流程。
DPO / PIMS負責人 審查PII使用、資料主體權利、隱私事件與委外處理要求。
AI治理負責人 審查AI工具使用、資料輸入限制、AI輸出使用、人類監督與AI風險。
供應商管理負責人 確保供應商、外包人員及第三方使用資訊資產符合合約與安全要求。
使用者 遵守本政策、保護資訊資產、立即通報異常、不得規避或破壞安全控制。

6. 資訊資產可接受使用總則

原則 要求
授權使用 使用者僅得存取與使用其職務、合約或核准工作所需之資訊資產。
最小權限 資訊資產使用應限於完成業務目的所需之最低權限、最低資料量與最低期間。
業務目的 資訊資產不得用於私人商業活動、非法活動、政治宣傳、騷擾、賭博、侵犯智慧財產權或與工作無關之高風險活動。
保密義務 使用者應保護機密資訊、PII、客戶資料、商業秘密、AI輸入/輸出及GHG/CO2底稿資料。
可追溯性 重要資訊資產使用應保留日誌、紀錄或可追溯證據，不得規避監控或偽造紀錄。
合規使用 使用者應遵守法律、合約、客戶要求、DPA、NDA、軟體授權與組織政策。
安全優先 任何便利性、效率或個人偏好不得凌駕資訊安全、隱私、AI治理或營運持續要求。

7. 禁止使用行為

禁止行為類別 禁止內容 可能處置
未授權存取 嘗試存取未被授權之系統、資料、帳號、資料夾、雲端空間或管理介面。 撤銷權限、事件調查、紀律處分、法律追訴。
帳號共用 共用密碼、借用帳號、代打卡、代登入、轉讓Token或允許他人使用個人帳號。 立即停權、強制換密碼、紀律處分。
安全控制規避 停用防毒、EDR、MFA、日誌、加密、DLP、VPN或規避安全監控。 停用設備、事件調查、CAPA。
資料外洩風險 未授權複製、下載、上傳、轉寄、公開或外洩機密資訊、PII或客戶資料。 事件通報、法務審查、紀律處分。
惡意或非法行為 散布惡意軟體、掃描攻擊、破解、盜版、詐騙、騷擾、歧視、侵犯智慧財產權。 立即停權、法律追訴。
不當AI使用 將機密資訊、PII、客戶資料、未核准資料或受保護程式碼輸入未核准AI工具。 停用工具、事件調查、教育訓練。
不當雲端使用 使用未核准雲端儲存、個人信箱、個人SaaS或公開分享連結處理公司資料。 刪除分享、停權、CAPA。

8. 資訊分類與標示使用要求

資訊等級 可接受使用要求 限制
公開資訊 可依核准溝通程序對外發布。 未經授權不得代表公司發言或發布未核准內容。
內部資訊 限組織內部業務使用。 不得外傳、公開分享或輸入未核准外部服務。
機密資訊 限授權人員與核准用途使用。 需加密傳輸、限制下載、禁止個人設備保存。
高機密資訊 限最小授權、必要知悉與高層核准用途。 需強化存取控制、日誌監控、DLP與嚴格保存要求。
PII/敏感PII 限合法目的、最小化、明確授權與保存期限。 不得未授權轉移、輸入AI、外部分享或跨境傳輸。
GHG/CO2底稿資料 限盤查、查證、揭露與內部治理目的。 不得竄改、刪除、未核准揭露或使用未受控係數。

9. 帳號、密碼與憑證使用規範

項目 政策要求
個人帳號 使用者應使用個人專屬帳號，不得共用、轉讓或借用。
密碼保護 密碼應符合複雜度與變更要求，不得寫於明顯處、傳送於未加密通道或重複使用於私人服務。
MFA 所有高風險系統、遠端存取、雲端管理、特權帳號及PII/AI相關系統應啟用MFA。
憑證與Token API Key、憑證、Token、SSH Key、雲端Access Key應受控保存，不得硬編碼、公開上傳或分享。
特權帳號 特權帳號僅得用於授權管理活動，須保留日誌，必要時使用PAM或等效控制。
服務帳號 服務帳號應指定Owner、用途、權限、輪替週期與監控機制。

10. 終端設備與行動裝置使用規範

項目 政策要求
公司設備 僅得由授權使用者使用，需安裝公司核准之安全軟體、EDR、防毒、MDM或等效控制。
行動裝置 處理公司資料之行動裝置應啟用螢幕鎖、加密、遠端清除與MDM控制。
BYOD BYOD使用需事前核准，並符合隔離、加密、MDM、資料刪除與監控要求。
可攜式媒體 USB、外接硬碟、記憶卡等使用需核准，敏感資料應加密並保留移轉紀錄。
遺失或遭竊 設備遺失、遭竊或可能被未授權存取時，應立即通報IT/SOC與主管。
軟體安裝 不得自行安裝未授權軟體、破解軟體、P2P工具、遠控工具或高風險瀏覽器外掛。

11. 網路、網際網路與遠端存取使用規範

項目 政策要求
公司網路 公司網路僅供授權業務使用，禁止未授權設備接入、私設AP、私接交換器或規避網路控管。
遠端存取 遠端存取應使用核准VPN、MFA與受控設備，不得使用未核准遠端桌面或穿透工具。
公共網路 於公共Wi-Fi、旅館、機場或客戶場域連線時，應使用VPN並避免處理高機密資訊。
網際網路使用 不得瀏覽、下載或傳播非法、惡意、侵犯著作權、色情、仇恨、騷擾、賭博或高風險內容。
網路監控 組織得依合法合規及政策目的監控網路流量、連線紀錄、惡意活動與資料外洩風險。
DNS與代理 不得繞過公司DNS、Proxy、Secure Web Gateway、CASB或其他網路安全控制。

12. 電子郵件與即時通訊使用規範

項目 政策要求
公司信箱 公司信箱主要供業務目的使用，不得用於私人商業活動或高風險註冊用途。
外部寄送 寄送機密資訊、PII、客戶資料或合約資料至外部收件人前，應確認收件人、目的、授權與加密需求。
附件與連結 不得開啟可疑附件或連結；疑似釣魚郵件應立即通報。
自動轉寄 不得將公司郵件自動轉寄至個人信箱或未核准外部信箱。
即時通訊 僅得使用核准通訊工具處理業務資訊；機密資料分享應遵守分類與存取限制。
群組管理 通訊群組應定期檢查成員，離職、轉調或第三方結束合作時應移除。

13. 雲端服務與SaaS使用規範

項目 政策要求
核准使用 僅得使用經IT、資安、法務或資料Owner核准之雲端服務處理公司資料。
資料分類 上傳雲端前應確認資料分類、分享權限、地區、加密與保存要求。
分享連結 禁止使用公開連結分享內部、機密、PII、客戶資料或高機密資訊。
權限管理 雲端資料夾、專案空間與SaaS權限應採最小權限與定期審查。
雲端下載 下載大量資料、敏感資料或客戶資料應具業務必要性並受監督。
第三方整合 外掛、API、OAuth授權、Marketplace應用需事前審查，不得任意授權存取公司資料。

14. AI工具與生成式AI使用規範

項目 政策要求
核准工具 僅得使用經核准之AI工具、模型或平台處理公司資訊。
禁止輸入 不得將PII、敏感PII、客戶機密、商業秘密、源碼、金鑰、未公開財務、合約或高機密資料輸入未核准AI工具。
輸出驗證 AI輸出不得未經人工覆核即作為正式決策、對外承諾、法務意見、醫療/金融/人資重大決策或客戶交付物。
著作權與授權 使用AI產出內容時，應評估智慧財產權、資料來源、授權限制與抄襲風險。
AI紀錄 高風險AI使用應保留用途、輸入類型、輸出審查、人員覆核與決策紀錄。
AI事件 發現AI輸出錯誤、偏差、資料外洩、違反政策或不當使用時，應立即通報AI治理負責人與資安單位。

15. PII與個人資料使用規範

項目 政策要求
合法目的 PII僅得於合法、明確、必要之目的下處理，並符合資料最小化原則。
授權存取 PII存取須基於職務必要性、核准權限與可追溯紀錄。
傳輸與共享 PII對外傳輸、跨境傳輸、委外處理或第三方共享需經DPO/法務審查。
保存與刪除 PII應依保存期限保存，到期應安全刪除、匿名化或封存。
資料主體權利 使用者接獲資料主體請求時，應依程序轉交DPO，不得私自回覆或處理。
隱私事件 PII外洩、誤寄、未授權存取或錯誤揭露應立即通報。

16. 機密資訊、客戶資料與智慧財產使用規範

項目 政策要求
機密資訊 使用者應依NDA、合約、資訊分類與最小揭露原則處理機密資訊。
客戶資料 客戶資料僅得依合約、SOW、DPA、授權目的與服務範圍使用。
源碼與技術文件 源碼、架構圖、金鑰、漏洞資訊、部署文件不得未授權外傳或上傳公開平台。
智慧財產 不得未授權使用、複製、散布或修改第三方受保護軟體、內容、模型或資料集。
對外發布 白皮書、簡報、社群文章、程式碼、研究成果或媒體回應需依對外溝通與審查程序核准。

17. 軟體、開發工具與開源元件使用規範

項目 政策要求
軟體授權 所有軟體、工具、套件與服務應符合授權條款，不得使用盜版或破解軟體。
開源元件 開源元件使用應符合授權、弱點、維護狀態與供應鏈安全要求。
開發環境 開發、測試、正式環境應分離，不得使用正式機密資料於未核准測試環境。
程式碼保護 程式碼倉庫應採權限控管、分支保護、Code Review、Secret Scanning與日誌追蹤。
外部平台 不得將公司源碼、金鑰、客戶資料或未公開內容上傳公開平台、個人GitHub或未核准雲端。

18. 實體資訊資產與辦公環境使用規範

項目 政策要求
清桌清屏 離開座位時應鎖定螢幕，機密文件不得留置於未受控區域。
列印與掃描 列印機密資料應即時取件，掃描或影印應確認收件位置與保存安全。
會議室 會議結束後應清除白板、文件、投影資料與共享畫面。
訪客區域 訪客不得未經陪同接觸內部資訊、設備、文件或網路。
設備搬移 公司設備、文件或媒體攜出辦公區域需依資產管理與授權流程。
報廢與銷毀 設備、媒體、紙本文件報廢應依安全抹除與銷毀程序。

19. GHG/CO2資料與ESG資訊使用規範

項目 政策要求
資料來源 GHG/CO2活動數據、排放係數、盤查底稿與查證資料應使用受控來源。
資料完整性 不得未授權修改、刪除、重算或替換碳資料與查證證據。
對外揭露 對外揭露ESG、碳排、減碳、碳中和或查證資訊前應經核准。
供應鏈資料 供應商碳資料應依約定目的使用，並保護供應商商業資訊。
AI/工具使用 使用AI或工具分析GHG資料時，應避免輸入機密、未核准或不可外流資料。
