1. 清冊目的與證據鏈要求

目的 要求
建立碳證據鏈 確保GHG活動數據、排放係數、方法學、計算、查證與公開聲明能互相追溯。
支援標準要求 支援 ISO 14064、ISO 14065、ISO 14067、ISO 14068-1 與客戶、供應商、主管機關或揭露要求。
保護資料品質 標示資料來源、期間、邊界、方法、係數版本、資料品質等級與查證狀態。
連結管理系統 將碳資料要求連結到 管理系統 產品生命週期、供應商管理、文件保存、管理審查與改善。

2. 碳資料與證據類別

類別 例子 控制重點
Scope 1 燃料、冷媒、製程排放、車隊燃料。 保留原始活動數據、單位換算、設備或地點資訊。
Scope 2 外購電力、蒸汽、熱能或冷能。 確認帳單期間、地點、電力憑證、市場基準或地區基準。
Scope 3 採購商品、運輸、商務旅行、雲端服務、產品使用或報廢。 確認供應商資料品質、估算方法與邊界限制。
產品碳足跡 產品生命週期資料、BOM、製程、能源、運輸與報廢資料。 連結設計與開發、變更、供應商資料與產品版本。
碳中和聲明 減量方案、殘餘排放、抵換或移除證據、聲明文本。 確認聲明邊界、期間、證據充分性與避免誤導。

4. 資料品質等級

等級 判定準則 允收與改善要求
A 原始證據完整、來源可靠、期間與邊界清楚、單位一致、可直接追溯。 可作為主要查證證據；
仍需抽樣確認。
B 證據大致完整，但需補充換算、對帳、供應商聲明或方法說明。 可使用，但應列入改善清單。
C 資料來自估算、供應商平均值、外部報告或假設，直接證據不足。 可暫用於估算；
若支援公開聲明，應提升資料品質。
D 來源不明、期間不清、單位不一致或無法追溯。 不得作為查證或公開聲明主要證據；
應補件或排除。

5. 變更與查證控制

控制點 要求
資料變更 任何活動數據、係數、方法、邊界或計算公式變更，應保留變更原因、版本與影響分析。
查證準備 查證前應凍結證據包版本，並確保證據編號、計算工作簿與報告相互一致。
聲明審查 對外揭露或碳中和聲明前，應確認證據、範圍、期間、限制、核准權責與避免誤導聲明。
供應商資料 供應商提供之碳資料應評估方法、邊界、期間、證據層級與是否經第三方查證。

6. 不符合事項發現與改善追蹤

不符合事項發現類型 例子 改善方向
原始資料缺失 缺少帳單、發票、里程、重量或供應商活動數據。 建立資料提交流程與截止日。
係數版本不一致 不同工作簿使用不同公告係數或單位。 建立係數版本清單與鎖定機制。
邊界不清 組織邊界、產品邊界、雲端服務邊界未定義。 補充邊界判定與管理審查核准。
聲明證據不足 碳中和、減碳或產品碳足跡聲明缺少支持證據。 暫緩發布並完成確證或查證。
