1. 政策目的

本政策旨在建立組織使用雲端服務之資訊安全治理、風險管理、合規、採購、導入、組態、存取、資料保護、監控、事件通報、營運持續、退出與稽核要求，確保雲端服務於完整生命週期內維持機密性、完整性、可用性、可追溯性、隱私保護、法規遵循與營運韌性。

本政策特別支援 ISO/IEC 27001:2022 Annex A.5.23「Information security for use of cloud services」之落地，並與供應商安全、ICT供應鏈安全、資訊分類、存取控制、資訊傳輸、隱私保護、AI治理、備份復原、日誌監控、事件管理、合約管理、法遵、稽核與持續改善形成完整證據鏈。

2. 政策聲明

  • 所有雲端服務導入、續約、重大變更、資料遷移、跨境處理、AI功能啟用及退場，均應依本政策及相關程序完成審查、核准、風險評估與紀錄保存。
  • 任何人不得使用未核准雲端服務、個人雲端帳號、個人訂閱、未列入清冊之SaaS、未審查之外掛、未核准AI雲端服務或公開分享連結處理組織資訊。
  • 雲端服務應採責任共擔模式管理，明確界定雲端服務供應商、組織、系統Owner、資料Owner、使用者與供應鏈角色之責任。
  • 雲端資料處理應遵循資料分類、最小權限、最小揭露、資料最小化、加密、日誌監控、備份復原、跨境合規、保存期限與資料刪除要求。
  • 雲端服務安全控制應可驗證、可追溯、可監控、可稽核，並應納入ISMS風險評鑑、SoA、控制有效性監測、管理審查與持續改善。

3. 名詞與定義

名詞 定義
雲端服務 透過網路提供之運算、儲存、資料庫、網路、應用、平台、AI、資安、協作、備份或分析服務，包括SaaS、PaaS、IaaS、CaaS、FaaS及託管服務。
SaaS Software as a Service，由供應商提供應用程式與平台營運，組織通常負責使用者、資料、組態、存取、整合與合規。
PaaS Platform as a Service，由供應商提供平台、資料庫、中介軟體或開發環境，組織負責應用、資料、設定、身份、整合與安全開發。
IaaS Infrastructure as a Service，由供應商提供運算、儲存、網路等基礎設施，組織負責作業系統、應用、資料、網路規則、身份、弱點與組態安全。
責任共擔模型 雲端安全責任由雲端服務供應商與組織共同承擔，依服務模式、部署模式、合約與實際組態分配控制責任。
雲端服務Owner 對特定雲端服務之業務目的、資料類型、風險、預算、供應商、合約、存取、使用者及持續監督負責之角色。
Cloud Security Owner 負責雲端安全架構、基準、組態審查、監控、例外、雲端風險評估與技術控制落地之角色。
Cloud Tenant 組織於雲端供應商中租用或配置之帳戶、租戶、訂閱、專案、資源群組或管理邊界。
CASB/CSPM/CWPP/CNAPP 用於雲端存取代理、雲端安全態勢管理、雲端工作負載保護與雲端原生應用防護之技術或平台。
雲端Marketplace服務 透過雲端平台市集取得之第三方映像、外掛、資料服務、AI服務、安全服務或應用元件。
影子IT 未經組織核准、登錄、風險評估、合約審查或安全設定即使用之雲端服務或工具。
雲端退出 終止雲端服務或供應商關係時，進行資料匯出、刪除、帳號停用、金鑰撤銷、合約終止、證據保存與服務替代之活動。

4. 角色與責任

角色 主要責任
最高管理階層 核准雲端策略、重大雲端風險接受、關鍵雲端服務資源、重大委外與營運持續要求，確保本政策落實。
CISO / 資訊安全負責人 核准雲端安全政策、風險準則、高風險雲端服務、重大例外、雲端事件通報與控制有效性改善。
ISMS管理代表 維護本政策，整合雲端服務風險、SoA、控制矩陣、稽核、KPI/KRI、CAPA與管理審查輸入。
Cloud Security Owner 建立雲端安全基準、審查雲端組態、監控雲端安全態勢、處理雲端安全例外與支援雲端事件應變。
Cloud Service Owner 定義雲端服務業務目的、資料範圍、服務等級、使用者、供應商要求、風險接受與持續監督。
Data Owner 決定雲端處理資料之分類、授權、保存、加密、共享、跨境、刪除、備份與資料主體權利要求。
System Owner / Application Owner 確保雲端應用、介接、API、帳號、日誌、備份、弱點、變更與復原符合本政策。
IT營運 / DevOps / DevSecOps 執行雲端資源配置、基準套用、IaC、CI/CD安全、補丁、監控、備份、變更與復原作業。
SOC / Security Operations 監控雲端日誌、CASB、SIEM、DLP、CSPM、EDR、NDR及事件告警，執行事件分級、通報與處置。
採購 / 供應商管理 確保雲端供應商審查、合約條款、SLA、DPA、稽核權、第四方、退出與續約要求完成。
法務 / 法遵 審查雲端服務條款、資料處理、跨境傳輸、監理要求、合約責任、智慧財產權與爭議處理。
DPO / PIMS負責人 審查PII雲端處理、跨境、DPIA/DPA、資料主體權利、刪除、事件通報與隱私法遵。
AI治理負責人 審查雲端AI功能、AI供應商、模型資料、Prompt、RAG、訓練資料、人工覆核與AI輸出風險。
使用者 僅使用核准雲端服務，遵循分類、存取、分享、下載、AI輸入、事件通報與禁止事項。

5. 雲端服務使用原則

原則 政策要求 最低證據
事前核准 任何雲端服務於正式使用前應完成需求、供應商、風險、法務、隱私、架構與安全審查。 雲端服務申請、風險評估、核准紀錄。
清冊管理 所有雲端服務、租戶、訂閱、第三方外掛、AI功能及Marketplace服務應納入清冊。 雲端服務與AI服務清冊。
責任共擔 應依服務模式、合約及實際組態確認組織與供應商安全責任。 責任共擔矩陣、合約條款、設定基準。
分類與最小化 雲端資料應完成分類，僅處理達成業務目的所需資料。 資訊分類紀錄、資料流向、Data Owner核准。
安全預設 新租戶、新資源、新服務與新功能應採安全預設與基準組態，不得以便利性降低安全控制。 CIS Benchmark/CSPM結果、組態審查紀錄。
持續監控 關鍵雲端服務應啟用日誌、告警、異常偵測、資產盤點與控制有效性監測。 SIEM/CASB/CSPM/CNAPP報表。
變更受控 雲端服務、區域、資料類型、身份、權限、網路、加密、AI功能或供應商條款變更應受控。 變更申請、影響評估、CAB紀錄。
退出可行 導入前應確認資料可攜性、刪除證明、替代方案、服務終止與供應商退場方式。 退出計畫、合約退出條款、測試紀錄。

6. 雲端服務分類與允許使用基準

雲端服務類型 允許使用條件 主要限制 核准層級
一般SaaS協作平台 已列入核准清冊、完成SSO/MFA、DLP/分享控制、合約與資料地區確認。 不得使用公開連結處理內部以上資料，不得繞過公司帳號使用個人帳號。 Cloud Service Owner / CISO授權。
客戶資料或PII處理SaaS 完成DPA/DPIA或隱私風險評估，具加密、存取、刪除、資料主體權利與事件通報條款。 不得使用未確認跨境地區、未承諾刪除或會將資料用於非核准目的之服務。 DPO / 法務 / CISO。
IaaS/PaaS生產環境 採受控租戶、網路區隔、IaC、CSPM、日誌、備份、KMS、弱點管理與變更控制。 不得建立未受控公開IP、預設帳號、未加密儲存、過寬IAM或未監控工作負載。 Cloud Security Owner / IT主管 / CISO。
開發測試雲端環境 使用隔離環境、測試資料管理、權限與預算限制，禁止真實PII除非已核准並保護。 不得使用生產資料、Secrets硬編碼或公開儲存桶。 System Owner / DevSecOps / Cloud Security。
雲端AI/ML服務 列入AI與雲端清冊，確認資料是否留存、訓練、人工審查、跨境與第三方分享。 不得輸入未核准PII、客戶機密、金鑰、源碼、法律受限資料或高機密資料。 AI治理負責人 / DPO / CISO。
雲端備份與DR服務 具加密、不可變備份、存取分離、復原測試、跨區合規、RTO/RPO與刪除控制。 不得將備份置於與生產完全相同權限邊界或未測試復原能力。 BCMS/DRP / IT主管 / CISO。
Marketplace第三方服務 完成來源可信、弱點、權限、資料存取、授權、支援、第四方與更新機制審查。 不得安裝未審查外掛、未驗證映像或要求過高權限之服務。 Cloud Security / 採購 / CISO。
個人雲端或未核准服務 禁止處理組織資訊。 不得上傳、同步、備份、分享或分析組織資料。 不適用；例外需CISO書面核准。

7. 雲端服務導入前審查要求

審查領域 審查內容 責任角色 證據
業務必要性 確認服務目的、預期效益、使用部門、使用者範圍、資料類型、處理活動與替代方案。 Cloud Service Owner 需求申請、效益評估。
資訊分類 確認是否處理公開、內部、機密、高機密、PII、客戶資料、源碼、Secrets、AI資料或GHG資料。 Data Owner 分類紀錄、資料流向。
供應商安全 審查供應商安全能力、認證、控制報告、漏洞管理、事件通報、BC/DR及子處理者。 供應商管理 / CISO 供應商風險評估表、SOC報告摘要。
合約與SLA 確認SLA、支援、資料所有權、使用限制、稽核權、保密、通知、賠償與終止條款。 法務 / 採購 合約條款檢核表。
隱私與跨境 確認PII處理目的、合法依據、DPA、子處理者、處理地、儲存地與跨境機制。 DPO / 法務 DPIA/DPA/跨境評估。
技術架構 確認身份、網路、加密、金鑰、日誌、備份、API、整合與安全基準。 Cloud Security / Architect 架構審查紀錄。
營運持續 確認RTO/RPO、備援、復原、資料匯出、替代服務與供應商中斷因應。 BCMS / IT營運 BC/DR審查紀錄。
退出可行性 確認資料匯出格式、刪除證明、帳號停用、合約終止、移轉成本與時間。 Cloud Service Owner / 法務 退出計畫。

8. 雲端資料分類與處理要求

資料類型 雲端處理條件 保護要求 禁止事項
公開資料 已正式核准對外發布或無限制揭露資料。 確認版本、發布權限與來源。 不得將草稿誤標為公開。
內部資料 限核准雲端服務與公司帳號處理。 SSO/MFA、權限控管、分享限制。 不得使用個人雲端或公開連結。
機密資料 需Data Owner核准，使用加密、限制分享、日誌、DLP與下載控制。 加密、MFA、最小權限、到期權限、外部分享審查。 不得同步至未受管設備或未核准第三方外掛。
高機密資料 原則限制於高安全等級雲端環境，需CISO核准與強監控。 KMS/HSM、PAM、零信任、強DLP、不可公開、雙人覆核。 不得輸入一般SaaS或未核准AI服務。
PII / 敏感個資 需合法目的、DPA/DPIA、最小化、跨境審查與刪除機制。 加密、去識別、資料主體權利、事件通報、保存期限。 不得提供給未列明子處理者或用於供應商訓練模型。
源碼與Secrets 源碼需受控儲存；Secrets需使用Secret Manager，不得明文存放。 儲存庫權限、掃描、簽章、金鑰輪替。 不得放在公開Repo、共享文件或聊天工具。
AI資料與Prompt 需依AI政策與雲端AI服務審查結果處理。 輸入限制、輸出覆核、留存設定、訓練退出。 不得輸入高機密或未遮罩PII至未核准AI。
GHG/CO2與ESG資料 需維持來源、版本、完整性、可追溯與查證證據。 權限、版本控管、審計軌跡、加密、保存期限。 不得覆蓋原始活動數據或刪除查證證據。

9. 雲端責任共擔矩陣

控制領域 雲端供應商責任 組織責任 共同責任/確認事項
實體與基礎設施 資料中心實體安全、硬體、基礎環境與部分底層網路。 確認供應商認證、地區、稽核報告與合約承諾。 定期取得或審查第三方保證報告。
身份與存取 提供IAM、SSO、MFA、角色、日誌與API能力。 設計角色、最小權限、PAM、權限審查、帳號生命週期。 整合企業身份、禁用共享帳號、保留審查證據。
資料保護 提供加密、KMS、備份、資料刪除與區域選項能力。 選擇加密、管理金鑰、分類資料、設定保存與刪除。 確認資料所有權、留存、復原與刪除證明。
網路安全 提供安全群組、防火牆、私有連線、WAF、DDoS與網路日誌能力。 設定網路區隔、限制公開暴露、配置路由、WAF與流量監控。 測試暴露面與網路存取規則。
應用安全 提供平台安全功能與部分託管服務修補。 負責應用程式安全、API安全、SDLC、弱點修補與測試。 確認託管責任邊界與補丁責任。
日誌與監控 提供日誌來源、告警、API與安全服務。 啟用日誌、集中至SIEM、定義告警、保留與事件應變。 測試告警與事件通報流程。
營運持續 提供區域、可用區、備份與復原功能選項。 設計備援、備份、復原、演練、RTO/RPO與退出計畫。 驗證服務等級與復原能力。

10. 雲端身份與存取控制政策

控制項目 政策要求 證據
集中身份 雲端服務應優先整合企業IdP、SSO、條件式存取與MFA。 SSO設定、MFA政策、登入日誌。
最小權限 角色與權限應基於工作職責、業務必要與期間限制配置。 IAM角色矩陣、核准紀錄。
特權存取 管理員與高權限帳號應使用PAM、JIT/JEA、MFA與Session記錄。 PAM紀錄、管理員審查。
服務帳號 服務帳號需有Owner、用途、最小權限、金鑰保存、輪替與停用機制。 服務帳號清冊、金鑰輪替紀錄。
外部使用者 外部帳號需有業務Owner、有效期限、資料範圍與定期審查。 外部帳號審查紀錄。

42. 附錄A：雲端服務核准判定規則

雲端服務若符合下列任一條件，應完成正式雲端服務申請、風險評估、供應商審查與核准：處理內部以上資訊、處理PII或客戶資料、支援關鍵流程、與內部系統介接、具外部分享功能、提供AI或自動化決策、儲存或處理GHG/CO2資料、涉及跨境處理、需長期保存紀錄、或由供應商/第四方管理組織資料。

若服務僅用於公開資料、短期展示或低風險用途，仍應由Cloud Service Owner確認不涉及組織敏感資訊，並遵循未核准雲端不得處理內部以上資料之原則。

43. 附錄B：最低雲端安全基準聲明

任何正式雲端服務至少應滿足以下最低基準：企業帳號或受控租戶、SSO/MFA、清楚Owner、資料分類、最小權限、日誌啟用、靜態與傳輸加密、外部分享限制、備份或資料匯出可行性、事件通報窗口、合約與DPA審查、退出與刪除方式、供應商服務監督及定期審查。若無法滿足任一基準，應提出例外、風險評估、補償控制、期限及CISO或授權角色核准。
