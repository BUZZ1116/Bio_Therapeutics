1. 文件目的

本文件用於定義組織在ISMS、PIMS、AI治理與GHG/CO2資料治理範圍內之組織架構、治理層級、角色責任、權限、報告線、代理機制、控制措施Owner、RACI責任分派、委員會章程、稽核獨立性與驗證證據對照。

本文件亦用於證明ISO/IEC 27001:2022 Clause 5.3所要求之組織角色、責任與權限已被分派、溝通與維持，並可追溯至RACI矩陣、任命書、SoA、風險登錄表、資產清冊、內部稽核與管理審查。

1.1 管理活動與輸出摘要

文件章節 / 管理主題 如何使用 輸出 / 證據
1. 文件目的 用於將管理階層承諾、政策要求、RACI權責分派及正式任命轉化為可視化組織架構與治理證據。 組織架構目的、角色分派與任命依據。
2. 適用範圍 用於確認本組織架構涵蓋的ISMS/PIMS/AI/GHG範圍、資訊資產、AI服務、碳足跡資料、系統、供應商與流程。 架構適用範圍、範圍聲明、資產與資料Owner。
3. 名詞與定義 用於統一治理角色、Owner、RACI、三道防線、代理人、控制Owner、Risk Owner等術語。 一致化名詞與角色定義。
4. 整合治理架構總覽 用於建立策略治理層、監督治理層、專責管理層、執行層與獨立保證層，並與管理審查及治理委員會運作連結。 治理架構、會議紀錄、管理審查輸入。
5. 組織架構圖 用於將正式角色、報告線、管理小組、控制Owner及文件Owner可視化，並供稽核訪談與驗證查閱。 組織圖、角色清單、任命書、文件清冊。
6. 三道防線模型 用於區分第一道控制執行、第二道治理監督與第三道獨立稽核責任，避免稽核不獨立或責任混淆。 三道防線矩陣、稽核獨立性證據、CAPA。
7. ISO/IEC 27001條文責任對照矩陣 用於將Clause 4~10各條文責任對應至主要負責角色、協辦角色及驗證證據。 條文責任矩陣、驗證證據地圖。
8. Annex A 93項控制措施逐項責任矩陣 用於逐項指定93項控制措施Owner、協辦角色與驗證證據，並與SoA及控制措施與風險對應矩陣一致。 控制Owner矩陣、SoA證據、控制有效性證據。
9. Asset / Data / System / AI / GHG Owner清冊架構 用於建立資產、資料、系統、AI模型、AI風險、Prompt/RAG、Carbon Data與碳證據Owner責任。 Owner清冊、資產清冊、碳證據清冊。
10. ISO/IEC 27701 PII Controller / Processor責任矩陣 用於分派PII controller、processor、DPO、PII Owner、法務與供應商管理責任。 PIMS責任矩陣、PII處理與隱私風險證據。
11. ISO/IEC 42001 AI生命週期治理矩陣 用於分派AI生命週期各階段Owner，包括需求、資料、模型、風險、部署、人類監督、監控與退役。 AI生命週期責任、AI風險評估、模型治理證據。
12. GHG Scope 1/2/3與碳證據治理矩陣 用於建立Scope 1/2/3、碳證據、揭露前審查及查證準備之資料Owner與治理責任。 GHG資料責任矩陣、碳證據清冊、查證準備證據。
13. 全面RACI Matrix 用於將組織架構圖角色轉化為RACI權責分派，支援溝通、績效監督與稽核查核。 RACI矩陣、溝通矩陣、KPI/KRI。
14. 管理委員會章程 用於定義資訊安全、PIMS、AI及GHG治理委員會之目的、成員、頻率、輸入、輸出與紀錄要求。 委員會章程、會議紀錄、管理審查輸入。
15. 報告線、代理人與職務代理矩陣 用於指定關鍵角色代理人、代理限制、代理觸發條件及權限調整要求。 代理人矩陣、任命書、權限異動證據。
16. 稽核獨立性與報告線要求 用於確保內部稽核不稽核自身工作，重大發現可直接報告最高管理階層，並追蹤CAPA。 稽核獨立性聲明、稽核發現追蹤、CAPA。
17. 稽核訪談對照表 用於Stage 1/Stage 2或內部稽核時，依角色安排訪談主題、典型問題與應提供證據。 稽核訪談表、訪談紀錄、證據索引。
18. Stage 1 / Stage 2驗證證據地圖 用於外部驗證前確認Stage 1文件準備與Stage 2執行證據責任。 驗證證據地圖、Stage準備清單。

6. 三道防線模型

防線 組織角色 核心責任 不得替代之責任 主要證據
第一道防線 業務單位、IT、SOC、開發、供應鏈、資料/系統/AI/GHG Owner 依政策與SOP執行控制措施、保護資產、維護證據、回報事件與風險。 不得將日常控制責任完全轉移給ISMS或稽核單位。 操作紀錄、控制執行證據、事件紀錄、供應商證據、資料品質紀錄。
第二道防線 CISO、ISMS管理代表、風險管理、DPO、AI治理、GHG治理、法遵 制定治理要求、監督風險與控制、提供方法、審查證據、追蹤改善。 不得取代第一道防線實際執行控制。 風險登錄表、SoA、KPI/KRI、治理會議紀錄、審查紀錄。
第三道防線 內部稽核 獨立評估管理系統符合性與有效性，提出稽核發現與改善建議。 不得設計或執行受稽流程之日常控制。 稽核方案、稽核計畫、稽核工作底稿、內部稽核報告、追蹤紀錄。
