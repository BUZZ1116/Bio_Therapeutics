1. 作業目的

本作業指導書規範資訊及相關資產於公司受控場所之外使用、攜出、運送、暫存、出差、遠端工作、居家辦公、客戶現場、供應商場址、展覽展示、教育訓練、測試驗證、維修、租借、借用或臨時保管時之安全控制，確保資產、資料、系統存取、使用者身分、機密資訊及公司權益不因場外環境之實體風險、網路風險、人員風險、遺失、竊盜、未授權存取、拍攝、旁觀、跨境、供應商保管或不可控環境而受損。

場外資產安全是實體安全、端點安全、遠端工作、資產管理、供應商安全與資訊安全事件管理之交會控制。本文件要求場外資產於整個生命週期中維持可識別、可授權、可保護、可監控、可回收、可追蹤與可稽核狀態。

2. 作業原則

  • 公司資產離開受控場所前，應依資產類型、資料分類、使用目的、場外環境、使用者角色與風險等級取得必要授權。
  • 場外使用資產應啟用加密、端點防護、MDM/EDR、螢幕鎖定、遠端鎖定/抹除、MFA、VPN或條件式存取等必要控制。
  • 不得將未經授權之機密資料、客戶資料、個人資料、Secrets、金鑰、原始碼或高敏感紙本文件攜出或存放於未受控場所。
  • 資產於場外使用期間，使用者應負保管與即時通報責任，避免遺失、竊盜、未授權使用、旁觀、偷拍、公共網路攻擊或資料外洩。
  • 場外資產使用期限屆滿、任務結束、專案結束、離職、異動、供應商退場或設備更換時，應依規定回收、清點、檢查、清除或重新登錄。
  • 涉及跨境攜帶、客戶現場、供應商保管或高風險國家/地區之場外資產，應進行額外風險評估與核准。

3. 名詞與定義

名詞 定義
場外資產 任何離開公司受控場所、機房、辦公區或指定保管區域之資訊及相關資產。
受控場所 由公司或授權供應商管理，具備門禁、訪客管理、實體安全與環境控制之場所。
攜出 將資產自公司受控場所帶出、運送、郵寄、交付或移至場外之行為。
遠端工作資產 員工或承包商於居家、共享辦公、客戶現場或其他非公司受控場所工作時使用之公司資訊資產。
高敏感資產 保存或可存取高機密資料、PII、客戶資料、原始碼、金鑰、Secrets、財務資料、管理權限或關鍵系統之資產。
借用資產 臨時提供給員工、承包商、供應商、專案、教育訓練或活動使用之公司資產。
資產保管人 實際持有、使用或管理場外資產之人員，對資產安全與通報負直接責任。
遠端抹除 透過MDM、EDR、端點管理或雲端服務對遺失或高風險資產執行資料刪除或鎖定之控制。
場外環境 居家、旅館、交通工具、共享辦公室、客戶場址、供應商場址、展場、訓練教室、公共場所或其他非公司受控區域。
跨境攜帶 資產被帶離原營運國家/司法管轄區，可能涉及資料保護、出口管制、海關、加密或客戶合約要求。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
Asset Owner 核准資產場外使用目的、期限、保管人、資料範圍與回收要求。 攜出/借用核准。
Asset Manager 維護場外資產清冊、序號、保管人、位置、狀態、期限、回收與盤點紀錄。 場外資產清冊。
Asset Custodian / 使用者 妥善保管場外資產，遵守安全要求，避免未授權使用並即時通報遺失、竊盜或異常。 承諾、領用、歸還紀錄。
IT Operations / Helpdesk 執行設備交付、加密、EDR/MDM、遠端抹除、技術支援、回收檢查與重新部署。 端點管理紀錄。
Endpoint Security Owner 確認場外端點安全狀態、合規設定、遠端鎖定/抹除、告警與不合規處置。 EDR/MDM報告。
CISO / Security Owner 核准高風險場外使用、例外、跨境、高敏感資產、遺失事件與風險接受。 安全核准、風險接受。
Physical Security / Facility 協助資產出場、交接、物流、暫存、保管與實體安全事件調查。 出場與交接紀錄。
HR / Line Manager 確認人員資格、離職異動回收、違規處理與教育訓練。 人員異動與回收紀錄。
DPO / Legal 審查涉及個資、客戶資料、跨境、合約、Legal Hold或法規要求之場外使用。 隱私/法務審查。
Supplier Management 管理供應商借用、代管、場外維護與退場回收。 供應商清冊與證明。
Incident Response Team 處理場外資產遺失、竊盜、疑似外洩、未授權存取與證據保存。 事件紀錄、RCA/CAPA。
Internal Auditor 抽查場外資產授權、清冊、技術控制、盤點、回收、事件與例外。 稽核底稿。

5. 場外資產分類與最低控制要求

資產類型 場外使用最低要求 禁止或限制事項 必要證據
筆記型電腦 全碟加密、EDR/MDM、螢幕鎖、MFA、VPN/條件式存取、資產標籤、遠端抹除。 禁止停用安全軟體、借予他人或無保護放置於公共場所。 領用紀錄、MDM/EDR狀態。
行動電話 / 平板 MDM、裝置加密、螢幕鎖、生物辨識或PIN、遠端鎖定/抹除、應用程式管控。 禁止Root/Jailbreak、安裝未核准高風險App或共享解鎖碼。 MDM紀錄。
外接媒體 核准、加密、標示、用途期限、最小資料、歸還與清除。 原則禁止未加密USB或私人物媒體儲存公司資料。 媒體借用與清除紀錄。
紙本機密文件 核准攜出、封袋、最小份數、不得無人看管、使用後回收或碎毀。 禁止於公共場所展示、拍攝或任意丟棄。 文件攜出/回收紀錄。
備份媒體 高等級核准、加密、封條、雙人交接、可追蹤物流與安全暫存。 禁止一般郵寄、無加密或無交接紀錄。 交接與保管紀錄。
展示 / 訓練設備 資料清除或使用展示資料、限制網路、活動後回收與檢查。 禁止使用真實客戶資料作Demo。 活動借用紀錄。
網路 / 測試設備 核准用途、設定清除、管理帳號重設、連線限制與回收驗收。 禁止接入未授權網路或客戶環境。 設備借用與設定紀錄。
門禁卡 / Token / 智慧卡 具名發放、期限、遺失即時停用、MFA或PIN保護。 禁止轉借、共享或與密碼一同保存。 領用與停用紀錄。
供應商代管資產 合約/NDA、清冊、位置、保管責任、保護要求、盤點與退場證明。 禁止供應商未核准轉移、再委外或保留資料。 供應商證明。
雲端/虛擬場外資產 標籤、Owner、IAM、加密、監控、位置/區域、生命週期與退場。 禁止建立未納管Shadow IT資源。 雲端資產清冊。

6. 場外資產申請、核准與交付流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 說明資產類型、用途、使用期間、場外地點、資料分類、使用者、是否跨境與是否供應商使用。 申請人 / Line Manager 場外資產申請單。
2. 風險分級 依資產敏感度、資料分類、場外環境、使用期限、跨境、供應商與業務重要性判定風險。 Asset Owner / Security 風險分級紀錄。
3. 核准 依風險取得主管、Asset Owner、CISO、DPO、Legal或Supplier Owner核准。 核准角色 核准紀錄。
4. 技術準備 安裝安全基準、EDR/MDM、加密、VPN、MFA、DLP、遠端抹除與必要應用程式。 IT / Endpoint Security 設備準備紀錄。
5. 資產交付 記錄資產編號、序號、配件、使用者、期限、責任聲明與歸還日期。 Asset Manager / 使用者 領用紀錄。
6. 使用期間監控 監控設備合規、登入異常、遺失通報、EDR/MDM狀態、DLP與地理異常。 Endpoint Security / SOC 監控紀錄。
7. 到期提醒 使用期限屆滿前通知保管人歸還、延長核准或重新評估。 Asset Manager 提醒紀錄。
8. 歸還與檢查 清點資產、配件、資料、設定、損壞、告警、異常與是否需資料清除。 IT / Asset Manager 歸還檢查紀錄。
9. 清除/再部署 依設備狀態執行資料清除、重建、維修、再使用或汰除。 IT Operations 清除或再部署紀錄。
10. 清冊更新 更新資產位置、狀態、使用者、期限、回收結果與證據位置。 Asset Manager 資產清冊。

7. 場外使用安全要求

控制領域 最低要求 使用者注意事項
實體保管 設備不得無人看管；於交通工具、旅館、會議場地、客戶場址應置於可控範圍。 不得將設備留在車內可見處或無保護區域。
螢幕與旁觀防護 公共場所使用時應避免旁觀，可使用防窺片並調整座位。 不得顯示機密或客戶資料於可被旁觀位置。
網路連線 使用核准VPN、MFA與條件式存取；避免不可信公共Wi-Fi。 不得關閉VPN或安全代理以繞過限制。
資料儲存 場外設備僅保存最小必要資料，敏感資料應加密或存於核准平台。 不得將資料存至個人雲端或未核准媒體。
列印與紙本 場外列印需核准並妥善保管或銷毀紙本。 不得將機密文件遺留於共享印表機或公共場所。
會議與展示 展示資料應去識別或使用測試資料；投影前檢查桌面、通知與資料夾。 不得展示未核准客戶資料、內部架構或Secrets。
外部設備接入 不得連接未知USB、外部硬碟、公共充電資料線或未核准周邊。 需充電時優先使用公司充電器或資料阻隔器。
共享設備限制 公司設備不得借予家人、朋友、供應商或未授權人員使用。 使用者對設備與資料安全負責。
拍照與錄音 不得拍攝、錄音或分享含機密資訊之螢幕、文件、會議或設備。 客戶現場需遵守對方規定。
跨境使用 跨境攜帶設備或資料前需確認合約、法規、加密、海關與資料主權要求。 高敏感資料跨境需額外核准。

8. 居家辦公與遠端工作資產要求

檢查項目 控制要求 證據 / 驗證
工作環境 居家或遠端工作位置應可避免未授權旁觀、竊聽、拍攝或接觸設備。 遠端工作承諾或自評。
設備使用 優先使用公司核准設備，不得以個人設備處理高敏感資料，除非BYOD已納管。 MDM/EDR或BYOD合規狀態。
家庭網路 應使用安全Wi-Fi設定、強密碼、WPA2/WPA3與更新路由器韌體。 自評或安全指引確認。
資料保管 紙本、外接媒體與設備應妥善存放，避免家人或訪客接觸。 使用者承諾。
遠端連線 使用MFA、VPN、條件式存取與公司核准協作工具。 登入與存取紀錄。
通話會議 遠端會議應確認參與者、避免機密內容被第三方聽見或錄製。 會議平台設定。
設備回收 遠端工作結束、離職或異動時，設備應依規定寄回、交回或安全清除。 回收紀錄。

9. 出差、客戶現場與跨境攜帶控制

場景 控制要求 額外注意事項
國內出差 攜出資產需最小化、加密、貼標、隨身保管並避免公共場所暴露。 旅館內可使用保險箱，但高敏感設備仍應隨身或受控。
國外出差 跨境前確認資料分類、當地法規、客戶合約、加密限制與風險國家要求。 必要時使用乾淨設備或臨時設備。
客戶現場 遵守客戶場域安全規定；不得擅自接入客戶網路或複製客戶資料。 任何資料交換需有正式授權。
展覽 / Demo 使用展示資料、測試帳號與受限網路；避免真實資料與管理權限。 活動後需檢查設備與清除展示資料。
教育訓練 訓練設備需使用訓練資料，活動後清除學員資料與暫存檔。 不得將正式資料作為教材展示。
高風險地區 需CISO核准，使用最小資料、臨時帳號、限制同步與返國後重建設備。 可能需禁止攜帶高敏感資料。
海關/執法檢查 如被要求解鎖或交出設備，應依法律要求並立即通報公司窗口。 返還後需安全檢查與憑證輪替。

10. 供應商、承包商與第三方場外資產管理

控制項目 最低要求 證據
借用核准 供應商借用或保管公司資產需合約、NDA、使用目的、期限、保管責任與退場要求。 借用申請、合約/NDA。
資產清冊 供應商持有之公司資產需列入清冊，含序號、位置、保管人、用途與期限。 供應商資產清冊。
安全基準 供應商使用公司設備時不得停用EDR、MDM、加密或安全設定。 端點合規報告。
資料保護 供應商不得將公司資料複製至未核准設備、個人雲端或其他第三方。 合約條款、檢查紀錄。
轉包限制 供應商不得未經核准將公司資產交予次承包商或轉移場址。 供應商承諾。
定期盤點 長期代管或專案設備需定期盤點並回報狀態。 盤點紀錄。
退場回收 合約終止、專案結束或人員異動時，資產需回收、清除、銷毀或提供證明。 退場紀錄。
事件通報 資產遺失、竊盜、未授權存取、資料外洩或設備感染需立即通報。 事件通報紀錄。

11. 場外資產盤點與回收要求

控制項目 作業要求 頻率 / 觸發
場外資產清冊 維護資產編號、序號、保管人、位置、用途、期限、狀態與技術控制狀態。 持續維護。
定期盤點 依風險對場外資產進行抽查或全量盤點。 至少每半年或每年；高風險每季。
到期回收 使用期限屆滿、專案結束、活動結束、離職異動時回收資產。 事件觸發。
離職異動 HR離職異動流程應觸發場外資產回收與權限撤銷。 每次離職/異動。
供應商退場 供應商退場前需清點所有公司資產、資料與憑證。 合約/專案結束。
不合規處理 設備離線、EDR/MDM失效、加密關閉或長期未回報需追蹤。 監控觸發。

15. 遺失、竊盜與異常事件處理

情境 立即處置 升級對象 後續要求
設備遺失或遭竊 立即通報Helpdesk/SOC/主管；執行遠端鎖定、抹除、帳號停用與Token撤銷。 SOC / CISO / DPO視資料分類 評估資料外洩、保險、報案與事件檢討。
外接媒體遺失 確認媒體是否加密、資料內容、最近使用與可能影響範圍。 CISO / Data Owner / DPO 必要時啟動資料外洩通報評估。
紙本機密文件遺失 通報主管與Security，確認文件內容、份數、地點與可能接觸者。 CISO / Legal / DPO 採取補救、通知與改善措施。
設備遭未授權使用 隔離設備、重設密碼、檢查日誌、EDR掃描與保存證據。 SOC / Incident Response 依事件管理程序處理。
公共網路或釣魚疑似入侵 停用連線、保存告警、執行EDR掃描與憑證輪替。 SOC 完成RCA與使用者教育。
跨境被檢查或設備被扣留 立即通知Legal、CISO與主管；記錄事件細節。 Legal / CISO / Management 返還後進行取證、重建與憑證輪替。
供應商未歸還資產 依合約升級，停用帳號、遠端鎖定、追蹤物流與法律處理。 Supplier Owner / Legal / CISO 更新供應商風險評估。
