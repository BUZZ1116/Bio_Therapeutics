1. 文件目的

本表單用於記錄資訊安全政策及其延伸政策之審查活動，確保政策持續符合組織目的、ISMS範圍、內外部議題、關注方要求、法規合約、風險與機會、控制措施、PIMS、AI治理、GHG/CO2資料治理要求及持續改善需求。

本紀錄可作為ISO/IEC 27001:2022 Clause 5.2「政策」、Clause 7.5「文件化資訊」、Clause 9.1「監督、量測、分析與評估」、Clause 9.3「管理審查」及Annex A.5.1「資訊安全政策」之驗證證據。

1.1 管理活動與輸出摘要

表單章節 / 審查活動 如何使用 輸出 / 證據
4. 政策審查基本資料 確認被審查政策、版本、Owner、審查類型、審查範圍、審查結論及是否需提報治理委員會或管理審查。 政策審查基本資料與審查結論。
5. 審查小組與參與人員 確認政策審查之核准、審查、風險、法規、HR、IT、DPO、AI、GHG及內部稽核角色與責任。 審查小組、角色責任與簽名確認。
6. 政策審查準則 用於判定政策之適切性、充分性、有效性、一致性、法規符合性、風險導向、可執行性、可稽核性、溝通認知與持續改善。 政策審查準則判定紀錄。
7. ISO/IEC 27001條文政策審查對照 依Clause 4至10逐項檢查政策是否支援組織情境、領導承諾、風險目標、資源、能力、文件化資訊、運作、監督、稽核、管理審查與改善。 條文對照審查結果。
8. Annex A與延伸政策審查對照 檢查政策是否支援Annex A控制群組、資產、資料分類、供應商、事件、營運持續、法遵、隱私、獨立審查、技術控制及AI系統安全。 Annex A與延伸政策審查結果。
9. 政策審查觸發來源與影響確認 確認政策審查是否因組織、法規、事件、弱點、稽核、供應商、AI、GHG、治理委員會或管理審查決議觸發。 觸發來源與政策影響紀錄。
10. 政策修訂建議與差異紀錄 記錄政策章節、現行內容、建議修訂、原因、影響文件/流程、責任人與期限，並啟動文件修訂管制。 政策修訂差異紀錄與文件修訂申請。
11. 政策修訂風險與影響評估 評估政策維持或修訂對資訊安全、隱私、AI、GHG、營運、稽核、SoA及控制證據之影響。 政策修訂風險與影響評估。
12. 審查結論與核准決議 將政策維持、修訂、廢止、公告、訓練、SoA/風險/KPI更新與是否提報管理審查形成核准決議。 審查結論與核准意見。
13. 政策審查後行動事項追蹤表 追蹤修訂、公告、訓練、風險更新、SoA更新、KPI更新、CAPA與管理審查輸入。 政策審查後行動追蹤。
14. 政策發布、溝通與訓練計畫 規劃政策公告、主管說明、教育訓練、供應商通知與外部關注方通知。 發布、溝通、訓練與認知證據。
15. 附件與證據索引 將政策現行版、草案對照、法規合約、風險、稽核、KPI/KRI、治理委員會、管理審查與訓練證據建立索引。 附件與證據索引。
16. 政策審查RACI Matrix 依RACI確認政策審查各活動之最高管理階層、CISO、ISMS管理代表、政策Owner、風險、法務、HR、DPO/AI/GHG、文件管制與內部稽核責任。 政策審查RACI。
17. 文件化資訊與保存要求 定義政策審查紀錄、修訂草案、法規合約、風險、公告、訓練、CAPA與碳證據之保存責任與期限。 保存要求與證據保護要求。
18. 內部稽核與外部驗證查核提示 提供內外部稽核對政策適切性、充分性、有效性、法規一致性、風險導向、文件化資訊與持續改善之查核提示。 查核提示與應備證據。

2. 適用範圍

  • 適用於資訊安全政策、AI資訊安全與治理政策、隱私與PII保護政策、氣候變遷、GHG資料與AI永續治理政策、AI工具與資料使用政策，以及其他由ISMS管理之政策文件。
  • 適用於年度定期審查、臨時審查、重大事件後審查、內外部稽核後審查、法規合約變更審查、管理審查前審查及重大組織/技術/供應鏈變更審查。
  • 適用於政策修訂、維持、廢止、合併、重新公告、教育訓練及相關文件同步更新作業。

3. 名詞與定義

名詞 定義
政策審查 針對政策之適切性、充分性、有效性、一致性、可執行性及符合性進行系統性檢查與確認。
定期審查 依文件管制要求或管理系統要求，至少每年或依組織規定週期執行之政策審查。
臨時審查 因重大組織變更、法規合約變更、重大事件、稽核發現、風險變化、技術或供應鏈變更而啟動之政策審查。
政策Owner 對政策內容、審查、修訂、溝通、維持與證據保存負有主要責任之角色。
關注方要求 客戶、主管機關、員工、供應商、合作夥伴、驗證機構、股東或其他相關方對資訊安全、隱私、AI、GHG資料治理之要求。
適切性 政策是否符合組織目的、策略方向、ISMS範圍、風險環境及關注方要求。
充分性 政策內容是否足以涵蓋必要要求、責任、原則、控制方向與適用範圍。
有效性 政策是否已被溝通、理解、落實，並能支持目標達成、風險降低與持續改善。
政策差異紀錄 用於記錄現行政策內容與建議修訂內容之差異、修訂原因及影響文件/流程。
