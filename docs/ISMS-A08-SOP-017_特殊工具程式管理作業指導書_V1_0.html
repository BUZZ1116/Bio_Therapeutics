1. 作業目的

本作業指導書規範特殊工具程式之識別、分類、申請、核准、安裝、白名單、執行、監控、日誌、資料保護、授權、維護、例外、退場與稽核要求，確保具備高權限、高影響、高敏感或可被攻擊者濫用之工具在受控環境下合法、必要、可追溯且安全地使用。

特殊工具程式可能具有掃描、封包擷取、資料抽取、權限提升、遠端控制、弱點驗證、取證、逆向工程、雲端管理、AI模型分析或安全控制繞測能力。若缺乏適當管理，可能導致資料外洩、未授權存取、服務中斷、攻擊技術濫用、證據污染、供應鏈風險及法規/合約違反。因此，本文件要求特殊工具程式必須依風險分級與最小必要原則進行嚴格治理。

2. 作業原則

  • 特殊工具程式不得任意下載、安裝、攜入、執行或分享；所有使用均應具備明確業務或安全目的、核准、範圍、期限、責任人與日誌。
  • 特殊工具程式應優先使用受管理設備、隔離環境、跳板主機、PAM/JIT或專用安全測試環境執行，不得於一般使用者設備或正式環境任意執行。
  • 特殊工具程式之使用應遵循最小權限、最小範圍、最小資料、最短期限、可追溯與事後審查原則。
  • 可造成服務影響、掃描、攻擊模擬、弱點利用、封包擷取、資料抽取、密碼分析或AI模型繞測之工具，應事前定義停止條件與事件升級方式。
  • 特殊工具程式不得用於未授權測試、個人用途、繞過監控、破解授權、取得他人資料、規避資安控制、攻擊第三方或違反法律/合約之活動。
  • 特殊工具程式產生之報告、封包、記憶體映像、日誌、掃描結果、弱點細節、模型輸入輸出與取證證據，應依資訊分類分級與證據保全要求管理。

3. 名詞與定義

名詞 定義
特殊工具程式 具有系統管理、特權操作、掃描、取證、分析、測試、控制繞測、資料抽取、遠端控制或高影響能力之工具程式、腳本、套件或平台。
特權工具 需管理員、Root、sudo、PAM、雲端高權限、資料庫管理權限或特權API才可執行之工具。
安全測試工具 用於弱點掃描、滲透測試、API測試、配置檢查、紅隊演練或攻擊模擬之工具。
取證工具 用於收集、保存、分析或驗證事件證據、磁碟、記憶體、日誌、封包或雲端證據之工具。
封包分析工具 用於擷取、解析或分析網路封包、連線與流量行為之工具。
遠端管理工具 可遠端控制、監控、維護、部署、執行命令或修改系統設定之工具。
雙用途工具 可用於合法管理或安全測試，也可能被攻擊者濫用之工具。
工具白名單 經核准可於特定設備、角色、環境、期間與目的下安裝或執行之特殊工具清單。
受控執行環境 隔離、受監控、具日誌、有限權限且明確授權之工具執行環境。
工具使用證據 特殊工具程式之申請、核准、執行時間、操作者、目標、輸出、日誌、結果與關閉紀錄。

Data Owner / DPO 審查工具是否存取PII、客戶資料、封包、日誌、資料庫、AI資料或跨境資料。 資料審查、DPIA紀錄。
AI Governance / MLOps Owner 審查AI模型工具、Prompt工具、RAG工具、模型測試、資料集工具與AI安全測試工具。 AI工具核准、模型測試紀錄。
Tool User / Operator 依核准範圍使用工具，保護輸出資料，記錄操作並於完成後清理。 工具執行紀錄、結果報告。
Supplier Management 確保供應商使用特殊工具符合合約、NDA、資料保護、授權與監控要求。 供應商工具申請、合約證據。
Internal Auditor 抽查特殊工具清冊、核准、白名單、日誌、例外、退場及控制有效性。 稽核底稿、稽核發現。

資料庫與資料抽取工具 DB Admin、ETL、Dump、Migration、Query Client。 High 需Data Owner核准、最小資料與日誌。
雲端/容器/K8s管理工具 Cloud CLI、Terraform、kubectl、Helm、Container Runtime工具。 High 需身份、環境限制、Secrets保護與變更紀錄。
AI/MLOps特殊工具 模型檢測、Prompt Injection測試、RAG測試、向量庫管理、模型轉換工具。 High/Critical 需AI Governance、Data Owner與CISO視風險核准。
禁止工具 破解、Keygen、未授權攻擊工具、規避監控工具、惡意程式產生器。 Prohibited 禁止安裝與執行，發現即依事件或違規程序處理。

6. 特殊工具程式管理流程

階段 作業要求 責任角色 輸出證據
1. 工具需求提出 說明工具名稱、版本、來源、用途、目標系統、使用者、環境、資料類型、期間與預期輸出。 申請人 / Tool Owner 特殊工具申請單。
2. 分類與風險評估 依工具能力、資料存取、特權需求、網路影響、AI/供應鏈風險進行分級。 Privileged Tool Management Owner / Security 風險評估紀錄。
3. 授權與合規審查 確認授權條款、商用限制、開源授權、供應商合約與法律合規。 Procurement / Legal 授權審查紀錄。
4. 安全與隱私審查 評估PII、客戶資料、封包、日誌、資料庫、模型資料、跨境與輸出保護。 CISO / DPO / Data Owner 安全與隱私審查。
5. 測試與驗證 於隔離或受控環境測試安裝、行為、EDR告警、網路流量與移除方式。 Endpoint Security / SOC 工具測試紀錄。
6. 核准與白名單 依風險等級核准，設定可使用角色、設備、環境、期限與監控規則。 CISO / Tool Owner 核准與白名單紀錄。
7. 受控部署 透過MDM、軟體庫、跳板主機、受控容器或專用安全工作站部署。 IT / Endpoint Security 部署紀錄。
8. 使用與監控 依授權範圍執行，記錄操作者、時間、目標、參數、輸出與異常。 Tool User / SOC 工具執行紀錄。
9. 結果保護與清理 保護工具輸出、報告、封包、Dump、模型輸出，完成後清理暫存。 Tool User / Data Owner 清理與保存紀錄。
10. 定期審查與退場 定期審查必要性、版本、弱點、授權、使用紀錄與移除退場。 Tool Owner / ISMS代表 審查與退場紀錄。

8. 安全評估與核准矩陣

風險等級 判定條件 最低核准 加強要求
Low 低影響維運輔助工具，不存取敏感資料、不需特權、不對外連線。 IT Owner / Tool Owner 登錄清冊與授權確認。
Medium 一般管理工具、開發工具或資料檢視工具，需特定角色使用。 Tool Owner / Endpoint Security 白名單、版本控管、日誌。
High 需特權、可存取大量資料、可遠端控制、可掃描、可擷取封包或可修改系統。 CISO授權角色 / System Owner / Data Owner視情況 PAM/JIT、SOC通知、使用紀錄、期限。
Critical 可執行弱點利用、攻擊模擬、密碼分析、取證、正式環境高影響操作或AI安全繞測。 CISO / 管理階層授權代表視情況 隔離環境、停止條件、事件準備、事後審查。
Prohibited 破解、盜版、Keygen、惡意程式、未授權攻擊工具、規避控制工具。 不得核准 發現即移除並依事件或違規程序處理。
AI High Risk 可測試模型繞過、資料外洩、RAG越權、Agent工具濫用或大量AI資料抽取。 AI Governance / CISO / Data Owner / DPO AI風險評估、資料最小化、輸出保護。

9. 安裝、白名單與執行控制要求

控制項目 最低要求 高風險加強要求
安裝來源 工具應來自官方、企業軟體庫、核准Registry或受信任供應商。 保存Hash、簽章、SBOM或供應商完整性證據。
白名單條件 白名單應限制工具名稱、版本、Hash、簽章、路徑、使用者與設備群組。 高風險工具採Hash或簽章精準控制。
執行環境 應於受管理端點、跳板主機、安全工作站或隔離環境執行。 Critical工具不得於一般辦公端點執行。
特權控制 特權執行需PAM/JIT、MFA、工單、Session Recording或等效控制。 需雙人核准或事後審查。
網路限制 限制工具連線目的地、協定、埠號與Egress。 掃描/攻擊工具需限定目標與測試窗口。
資料限制 不得取得超出核准目的之資料、封包、Dump、Log或模型輸出。 需資料最小化與DPO/Data Owner審查。
日誌監控 工具安裝、執行、封鎖、特權、網路與輸出操作需記錄。 接入SIEM並建立告警。
禁止攜出 特殊工具與其輸出不得任意複製至個人設備、未核准雲端或外部AI工具。 使用DLP與媒體控管。

資料庫工具 需查詢目的、Data Owner核准、最小權限與查詢日誌。 不得匯出完整資料庫或未核准PII。
遠端管理 需具名帳號、MFA、PAM/JIT、Session Recording與工單。 不得使用共享帳號或個人遠端工具。
取證工具 需事件授權、保管鏈、不可竄改保存與取證程序。 不得污染證據或未授權查看私人資料。

輸出類型 保護要求 保存 / 刪除

封包檔案 可能含PII、憑證、Token與敏感資料，需加密與最小化。 調查完成後刪除不必要封包。

系統Dump / 記憶體 可能含Secrets與敏感資料，需高機密管理。 僅保存必要期間。
資料庫查詢輸出 需Data Owner核准，遮罩PII與客戶資料。 依資料保存要求處理。
滲透測試證據 攻擊路徑、Exploit、截圖、憑證證據需嚴格限制。 修復驗證後依規定保存。

工具日誌 操作人、時間、目標、命令、參數與結果需完整保護。 至少1至3年，依風險。

使用環境 優先使用組織提供之受控環境或跳板，不得使用未受控個人設備。 環境與存取紀錄。

資料限制 供應商不得擷取、匯出或保留未核准資料、封包、日誌或取證證據。 資料使用核准。

事件通報 工具誤用、外洩、越權、服務影響或弱點利用失控需立即通報。 事件通報紀錄。
