1. 表單目的

本表用於對資訊、資料、文件、紀錄、系統資料、AI資料、雲端資料、供應商資料及其他相關資訊資產進行分類與分級，明確定義其機密性、完整性、可用性、隱私、法規、合約、營運與AI治理影響，並據以決定標示、存取、儲存、傳輸、分享、遮罩、加密、備份、保存、刪除、外包與事件通報等保護要求。

本表之結果應回饋至資訊及相關資產清冊、風險評估、適用性聲明書、控制措施與風險對應矩陣、DLP規則、存取權限矩陣、雲端服務風險評估、AI模型與Prompt資產清冊、紀錄保存期限清冊及相關作業程序。

2. 填表與使用原則

  • 資訊分類分級應由資料Owner或資訊Owner負責確認，必要時由CISO、DPO、法務、合規、AI治理或業務Owner共同審查。
  • 當同一資料集合包含不同分類等級資料時，原則上應以最高保護需求之分類等級控管，或採分割、遮罩、去識別、加密、存取限制等方式分別管理。
  • 資訊分類應於資訊建立、取得、導入、系統上線、資料匯入、資料共享、供應商處理、AI使用或對外揭露前完成。
  • 分類分級結果應定期審查；資料用途、保存地點、供應商、跨境、法規、合約、AI用途、資料敏感度或風險改變時，應重新分級。
  • 分類標示與處理方式不得僅依檔名或主觀判斷決定，應依資料內容、影響、法規、合約及風險準則綜合判斷。

5. 資訊分類等級判定

分類等級 定義 典型範例 最低處理要求
公開（Public） 經核准可對外公開，揭露不會對組織、客戶、供應商、員工、法規或營運造成不利影響之資訊。 已發布新聞稿、公開網站內容、公開課程資訊、已核准對外簡介。 發布前核准；維持版本正確性；避免將未核准草稿誤標為公開。
內部使用（Internal Use） 僅供組織內部或授權合作方使用，未授權揭露可能造成輕微營運、聲譽或管理影響。 內部流程文件、一般會議紀錄、內部通告、非敏感營運報表。 限授權人員存取；外部分享需核准；傳輸應使用核准通道。
機密（Confidential） 未授權揭露可能造成重大營運、合約、客戶、法規、財務、資安或聲譽影響之資訊。 客戶資料、合約、報價、系統架構、弱點報告、供應商審查、AI Prompt模板、內部財務資料。 最小權限、加密傳輸與儲存、DLP監控、外部分享核准、保存與刪除受控。
高機密（Highly Confidential） 未授權揭露、竄改或遺失可能造成重大法規違反、重大財務損失、重大事件、客戶重大影響、核心競爭力損害或不可逆後果之資訊。 大量PII、特權憑證、私鑰、重大事件證據、核心原始碼、模型權重、未公開併購資料、GHG查證底稿、高風險AI訓練資料。 嚴格最小權限、強制加密、特權控管、存取日誌、DLP、外部分享高階核准、必要時不可變保存或保管鏈。
受限 / 法規或合約限制（Restricted） 受特定法規、合約、客戶、供應商、DPA、NDA、跨境或資料所在地限制之資訊；可與其他分類等級併用。 客戶合約限制資料、受DPA保護PII、供應商未公開SOC報告、雲端碳係數、授權模型資料。 依限制條件執行使用、傳輸、保存、刪除、跨境、再委外及揭露控管。

6. CIA與影響分級判定

等級 機密性 C 完整性 I 可用性 A 典型控制強度
1 低 揭露影響有限或已公開。 錯誤易修正，對流程影響低。 短暫不可用影響低。 基本存取控制與版本管理。
2 中低 未授權揭露造成部門層級影響或輕微聲譽影響。 錯誤可能造成部門作業延誤。 中斷造成短期不便但可手動替代。 授權存取、基本備份與變更控制。
3 中 揭露可能造成營運、客戶、合約或資安影響。 錯誤可能影響主要流程、報表或客戶服務。 中斷可能影響重要服務或SLA。 最小權限、加密、備份、日誌監控、定期審查。
4 高 揭露可能造成重大營運、法規、財務、客戶或聲譽影響。 錯誤可能造成重大決策、合約、法規或客戶影響。 中斷可能造成關鍵流程停止或重大SLA違反。 強化存取、MFA、DLP、加密、監控、復原測試與事件通報。
5 重大 揭露可能造成重大法規違反、重大資料外洩、核心機密外洩或不可逆損害。 錯誤可能造成重大事件、法規申報錯誤、財務重大損失或不可逆後果。 中斷可能造成危機、重大服務中斷或營運停擺。 最高等級控管、特權審查、保管鏈、不可變紀錄、管理階層核准。
