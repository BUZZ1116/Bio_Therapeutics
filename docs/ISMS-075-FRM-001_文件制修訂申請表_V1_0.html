1. 表單目的與使用時機

使用情境 觸發事件 最低要求
新增文件 新增政策、手冊、程序、作業指導書、表單、清冊、矩陣或外部文件登錄。 確認文件編號、Owner、適用管理系統、相關條款、審查核准權責與生效方式。
修訂文件 標準、法規、客戶要求、流程、組織、系統、風險或控制措施變更。 說明修訂原因、影響範圍、訓練需求、舊版處置與相關文件同步更新。
作廢 / 合併 文件已不再適用，或內容已納入其他受控文件。 確認替代文件、紀錄保存、舊版封存、外部發布撤回與使用者通知。
緊急變更 重大不符合、資安事件、客訴、法規期限、營運中斷或碳揭露錯誤需立即修正。 可先臨時發布，但應於指定期限內完成正式審查、核准與文件庫更新。

5. 影響分析

影響面 應確認事項 處置 / 證據

資訊安全與個資 是否涉及機密資料、個人資料、跨境傳輸、供應商或系統權限。 完成權限檢查、DPIA或安全審查紀錄。
