1. 作業目的

本作業指導書規範組織密碼與秘密資訊之建立、核發、保存、使用、傳輸、存取、輪替、撤銷、監控、掃描、事件處理、備援、退場與稽核要求，確保任何可用於認證、授權、加密、簽章或系統整合之秘密資訊均受適當保護，降低帳號盜用、憑證外洩、API濫用、供應鏈攻擊、資料外洩、服務中斷及未授權存取風險。

本文件同時將一般使用者密碼、特權密碼、服務帳號、API Key、雲端Access Key、加密金鑰、TLS憑證、CI/CD Secrets、AI服務Token、RAG資料源憑證及供應商維運Secrets納入統一生命週期管理，支援存取控制、弱點管理、日誌監控、安全開發、AI治理、事件應變、供應商管理及內部稽核。

2. 作業原則

  • 所有密碼與秘密資訊應依最小權限、最小揭露、職務分離、可追溯、加密保存、定期輪替與事件即時撤銷原則管理。
  • 秘密資訊不得以明文儲存於原始碼、文件、聊天紀錄、Email、工單、Wiki、截圖、測試資料、AI Prompt、日誌、映像檔、容器環境變數或未核准儲存位置。
  • 所有高風險Secrets應使用核准之Secrets Manager、PAM、KMS、HSM、Vault或等效受控工具保存及發放。
  • 人員不得共用個人密碼；特權或共享類Secrets應以PAM、Just-in-Time、Break-glass、Session Recording或具名授權方式控管。
  • 密碼與秘密資訊之建立、輪替、撤銷、例外與事件應留下足以稽核之紀錄；實際密碼或秘密值不得出現在稽核紀錄中。
  • 發現秘密資訊外洩、疑似外洩、誤提交、誤輸入AI工具、出現在公開Repo、日誌、工單、截圖或外部平台時，應立即視為資安事件或重大違規處理。

3. 名詞與定義

名詞 定義
密碼 用於驗證使用者、系統、服務或設備身分之秘密字串、片語或憑證資訊。
秘密資訊 / Secret 任何可用於認證、授權、加密、簽章、資料解密、服務呼叫、系統整合或安全控制之敏感資訊，包括API Key、Token、私鑰、憑證、密碼、Webhook Secret等。
特權密碼 可用於管理系統、網路、資料庫、雲端、SaaS、安全設備、PAM、KMS、CI/CD或其他高權限功能之密碼或Secret。
服務帳號 供系統、應用、批次作業、整合、API、MLOps、RAG、容器或自動化流程使用之非個人帳號。
API Key / Token 用於存取API、AI服務、雲端服務、Webhook、資料平台或第三方服務之認證資訊。
加密金鑰 用於資料加密、解密、簽章、驗章或金鑰包裝之金鑰，包括KMS、HSM、資料庫、備份及應用層金鑰。
私鑰 公私鑰架構中需嚴格保護之私密金鑰，例如SSH私鑰、TLS私鑰、簽章私鑰。
Secrets Manager 集中保存、加密、授權、輪替、審計及發放Secrets之工具或平台。
PAM Privileged Access Management，用於管理特權帳號、特權密碼、Session、核准、錄影及存取稽核之系統。
Break-glass帳號 緊急情況下使用之高權限帳號，應嚴格保管、啟用警示、事後審查並定期測試。
Secrets掃描 透過工具或流程檢查原始碼、Repo、CI/CD、容器映像、日誌、文件或雲端儲存是否含有Secrets。

使用者 依規定建立及保護密碼，不共用密碼，不將Secrets輸入未核准工具或AI服務，發現外洩立即通報。 教育訓練、事件通報。

5. 密碼與秘密資訊分類

類別 範圍 保護等級 主要控制
一般使用者密碼 員工、外包人員、一般業務系統與SaaS登入密碼。 機密 SSO/MFA、密碼雜湊、禁止共用、密碼管理器。
特權密碼 管理員、root、domain admin、DBA、防火牆、雲端管理、PAM與安全設備密碼。 高機密 PAM、MFA、JIT/JEA、Session Recording、定期審查與輪替。
服務帳號密碼 系統整合、批次、排程、應用、資料庫、API、自動化流程之非人員帳號密碼。 機密或高機密 Secrets Manager、最小權限、無互動登入、輪替、Owner指定。
API Key / Token 內外部API、雲端、AI服務、Webhook、SaaS、資料平台Token。 機密或高機密 Key Vault、範圍限制、到期、輪替、使用量監控。
雲端Access Key Cloud Access Key、Service Principal、IAM Access Key、Workload Identity。 高機密 優先使用Role/短期憑證、Key輪替、CSPM監控、最小權限。
加密金鑰 資料加密、備份、資料庫、KMS、HSM、簽章與金鑰包裝。 高機密 KMS/HSM、分權管理、輪替、存取日誌、Key生命周期。
私鑰與憑證 SSH私鑰、TLS私鑰、Code Signing Key、憑證私鑰。 高機密 加密保存、Passphrase、到期管理、吊銷、憑證透明度監控。
CI/CD與DevOps Secrets Pipeline Secret、Registry憑證、Deployment Token、Repo Deploy Key。 高機密 Secret Masking、Protected Variables、分環境隔離、掃描、輪替。
AI與MLOps Secrets AI API Key、模型供應商Token、Embedding Key、RAG資料源憑證、MLOps平台Token。 機密或高機密 AI服務清冊、資料不訓練條款、Secrets Manager、使用量監控。
Break-glass Secrets 緊急帳號密碼、災難復原解密金鑰、緊急管理憑證。 高機密 封存、雙人控管、啟用告警、定期測試、使用後輪替。

6. 密碼政策要求

控制項目 最低要求 適用範圍 證據
密碼長度 一般使用者密碼或Passphrase應符合組織密碼政策之最低長度；高權限帳號應採更高強度或改採無密碼/MFA/PAM。 使用者帳號、特權帳號。 IAM密碼政策設定。
密碼複雜度 應避免可預測、常見、洩漏、重複或與個人資訊相關之密碼；系統應阻擋已知洩漏密碼。 所有密碼型認證。 密碼政策、洩漏密碼檢查設定。
MFA 所有遠端存取、管理介面、雲端、SaaS、AI服務、特權與高風險系統應啟用MFA或等效強驗證。 高風險與外部存取。 MFA覆蓋率報表。
密碼重用限制 不得跨系統重用企業密碼；系統應禁止或降低密碼重用風險。 使用者與管理員。 政策宣導、技術設定。
臨時密碼 臨時密碼應一次性、短效、首次登入強制變更，不得透過不安全通道傳送。 新帳號、重設密碼。 重設紀錄、首次登入紀錄。
密碼儲存 系統不得以明文或可逆方式保存密碼；應使用核准雜湊演算法、Salt及適當參數。 應用系統、資料庫。 安全設計、程式碼審查、測試報告。
密碼傳輸 密碼不得透過明文通道傳輸；登入及密碼重設流程應使用TLS及防暴力破解控制。 所有登入服務。 TLS設定、WAF/API Gateway設定。
密碼管理器 使用者應使用核准密碼管理器保存非SSO密碼，不得以紙本、明文檔、聊天或Email保存。 使用者與團隊。 工具核准、教育訓練。

7. Secrets生命週期管理流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 提出Secret用途、系統、Owner、資料分類、權限範圍、到期日、輪替頻率與風險等級。 System Owner / Developer / Cloud Owner Secret申請紀錄。
2. 風險與分類 依Secret用途、權限、資料影響、外部存取、雲端/AI/供應商情境判定保護等級。 Secrets Owner / CISO Secret分類紀錄。
3. 建立與核發 使用核准工具生成或核發Secret，避免人工可見，必要時雙人覆核。 IAM / PAM / Secrets Owner 建立紀錄、核發紀錄。
4. 安全保存 Secret應保存於Secrets Manager、PAM、KMS、HSM或核准等效平台，不得明文保存。 Secrets Owner / System Owner 保存位置與權限紀錄。
5. 使用與存取 應透過安全API、短期憑證、Role、OIDC、Workload Identity或受控注入方式使用。 Application Owner / DevOps 存取日誌、系統設定。
6. 監控與掃描 監控Secret使用、異常、過期、外洩、Repo提交、日誌暴露與API濫用。 SOC / DevSecOps / Cloud Security SIEM、掃描報告。
7. 輪替與更新 依風險、期限、事件、角色變更、供應商變更或系統變更執行輪替。 Secrets Owner / System Owner 輪替紀錄、驗證紀錄。
8. 撤銷與退場 Secret不再使用、系統退場、人員離職、供應商終止或事件後應立即撤銷。 IAM / Cloud / System Owner 撤銷紀錄、退場證據。

8. Secrets儲存與使用位置限制

位置 / 情境 是否允許 控制要求
核准Secrets Manager / Vault 允許 應啟用加密、RBAC、MFA、審計日誌、輪替、備份與高可用性。
PAM系統 允許 適用特權密碼、Break-glass與共享管理帳號；需Session Recording與審查。
KMS / HSM 允許 適用加密金鑰、簽章金鑰、敏感私鑰；需分權、輪替與審計。
CI/CD Protected Secret Variables 有條件允許 需遮罩、環境隔離、保護分支、最小權限、禁止輸出至Log。
容器環境變數 有條件允許 不得保存高機密Secrets；應優先使用Secrets掛載或Workload Identity，避免出現在Dump或Log。
原始碼Repo 禁止 不得硬編碼Secret；發現即撤銷、輪替並進行歷史清理。
文件、Wiki、工單、聊天、Email 禁止 不得保存明文Secrets；如需交接應使用核准秘密分享工具。
日誌、監控、錯誤訊息 禁止 應遮罩或過濾Secrets，避免輸出Token、密碼、Authorization Header。
本機明文檔案 禁止 不得以txt、xlsx、csv、截圖或未加密檔案保存Secrets。
AI工具或外部AI服務Prompt 禁止 不得將Secrets輸入任何生成式AI工具；誤輸入即通報事件。
供應商平台 有條件允許 需合約、DPA、存取控制、加密、日誌、刪除與退場要求。

9. 服務帳號與非人員帳號管理

控制項目 作業要求 證據
Owner指定 每個服務帳號應指定Business/System Owner與Technical Owner，不得無Owner。 服務帳號清冊。
用途描述 服務帳號應明確記錄用途、系統、資料範圍、權限、使用位置與依賴關係。 帳號登錄紀錄。
最小權限 服務帳號權限應限於必要API、資料、資源與時間，不得使用高權限通用帳號。 權限矩陣、IAM Role。
禁止互動登入 除經核准外，服務帳號不得允許互動式登入、VPN登入或人員直接登入。 IAM設定、登入紀錄。
認證方式 優先使用短期憑證、Role、Managed Identity、Workload Identity、OAuth Client Credentials或mTLS。 技術設定。
輪替頻率 長效Secret應依風險定期輪替；外洩、權限變更或系統變更時立即輪替。 輪替紀錄。
監控 服務帳號應納入異常使用、來源IP、API頻率、時間、地區、權限擴張與失敗登入監控。 SIEM告警、API報表。
退場 系統停用、整合取消或供應商終止時，應撤銷服務帳號及相關Secrets。 撤銷紀錄。

10. API Key、Token與Webhook Secret管理

控制項目 最低要求 高風險加強措施
Key核發 API Key應由核准系統或Secrets Manager核發，禁止個人私下建立共用Key。 CISO或Service Owner核准，設定有效期限。
範圍限制 Key應限制API Scope、資源、租戶、IP、來源、環境、速率與用途。 採用分環境、分服務、分客戶Key。
到期與輪替 Key應設定到期日或輪替週期，長效Key需例外核准。 使用短期Token或OIDC Federation取代長效Key。
儲存 Key不得硬編碼於前端、Repo、Mobile App、容器映像或文件。 使用Vault、Secret Injection或KMS。
傳輸 Webhook Secret與Token不得出現在URL Query String；應使用Header或簽章驗證。 採mTLS、Request Signing、Replay Protection。
監控 監控Key使用量、異常來源、異常時間、失敗率、API濫用與地理異常。 SIEM、API Gateway、Rate Limit與自動停用。
撤銷 Key疑似外洩、離職、供應商終止或服務退場時立即撤銷。 建立緊急撤銷Runbook。

11. 加密金鑰與憑證管理

管理項目 作業要求 證據
金鑰分類 加密金鑰應依用途、資料分類、系統重要性與法規要求分類管理。 金鑰清冊、分類紀錄。
金鑰建立 高敏感金鑰應由KMS/HSM或核准安全工具產生，不得使用不明來源或弱演算法。 KMS/HSM建立紀錄。
金鑰保存 私鑰、KMS主金鑰、備份解密金鑰應加密保存，限制存取並納入審計。 KMS存取日誌、權限紀錄。
金鑰使用 金鑰用途應受限制，不得同一金鑰跨用途、跨環境或跨客戶濫用。 Key Policy、用途標籤。
金鑰輪替 依風險、演算法壽命、法規、事件或供應商要求定期輪替。 輪替紀錄、變更單。
金鑰撤銷 金鑰外洩、疑似外洩、用途終止或系統退場時應撤銷、停用或銷毀。 撤銷/銷毀紀錄。
憑證到期 TLS/SSL、Code Signing、Client Certificate應監控到期，避免服務中斷。 憑證清冊、到期告警。
演算法管理 不得使用已禁用或弱密碼學演算法；演算法淘汰應納入風險處理。 密碼學標準、掃描報告。

12. DevSecOps與原始碼Secrets防護

控制項目 作業要求 證據
Pre-commit掃描 開發端應使用Secrets掃描工具或Hook避免Secrets提交。 工具設定、掃描紀錄。
Repo掃描 所有內部、外部、歷史Repo應定期掃描Secrets，特別是公開Repo與開源專案。 掃描報告、修復紀錄。
CI/CD掃描 Pipeline應檢查Secrets、憑證、Token、私鑰及敏感環境變數外洩。 Pipeline結果。
Secret Masking CI/CD與Log系統應遮罩Secrets，避免在Build Log、Error Log、Artifact中顯示。 CI/CD設定、抽樣驗證。
分環境隔離 開發、測試、預備、正式環境Secrets應分離，不得共用正式Secrets進行測試。 Secrets清冊、環境設定。
Artifact與映像掃描 容器映像、建置產物、IaC、Helm Chart、Terraform State應掃描Secrets。 掃描報告。
外洩修復 一旦Secret進入Repo，即使刪除檔案也視為外洩，需撤銷輪替並清理歷史。 事件紀錄、輪替證據。
第三方整合 GitHub/GitLab/Cloud/Package Registry等應啟用Secret Protection或等效掃描。 平台設定截圖或報表。

13. 雲端Secrets與工作負載身分管理

控制項目 作業要求 證據
避免長效Access Key 雲端工作負載應優先使用IAM Role、Managed Identity、Workload Identity或短期憑證。 雲端IAM報表。
Key使用監控 雲端Access Key應監控最後使用時間、來源、權限、異常地區與未使用Key。 CSPM/IAM報表。
Root/主帳號保護 雲端Root或最高權限帳號不得日常使用，需MFA、Break-glass、告警與存取審查。 Root帳號檢查紀錄。
KMS管理 雲端KMS應定義Key Owner、用途、輪替、Key Policy、刪除保護與審計。 KMS設定、CloudTrail/Audit Log。
Secret注入 容器、Serverless、VM、Pipeline應透過安全方式取得Secrets，不得寫入映像或User Data明文。 部署設定。
雲端組態掃描 CSPM應檢查明文Secrets、公開儲存桶、過寬IAM、未輪替Key與不安全憑證。 CSPM報告、修復追蹤。
跨帳戶與第三方 跨帳戶Role、供應商Access、SaaS整合Key應有到期、最小權限與撤銷流程。 第三方存取清冊。

14. AI與MLOps Secrets管理

控制項目 作業要求 證據
AI API Key管理 AI API Key應登錄Owner、用途、服務、環境、限制、到期、輪替與費用/用量監控。 AI服務清冊、API Key清冊。
禁止輸入Secrets至AI 不得將密碼、Token、API Key、私鑰、連線字串、憑證或內部安全規則輸入AI工具。 AI政策宣導、DLP告警。
Prompt與日誌遮罩 AI Prompt、輸入輸出、錯誤訊息、RAG日誌及MLOps日誌不得保留Secrets明文。 日誌遮罩規則、抽樣檢查。
RAG資料源憑證 RAG連接資料庫、文件庫、向量庫與知識庫之憑證應最小權限且可撤銷。 RAG設定、權限測試。
模型供應商Token 外部模型供應商Token應保存於Secrets Manager，不得嵌入前端或Notebook。 Vault紀錄、Notebook掃描。
MLOps平台Secrets 訓練任務、Notebook、Pipeline、Feature Store、Model Registry之Secrets應分環境管理。 MLOps設定、Secrets掃描。

15. 密碼與Secrets輪替要求

Secret類型 一般輪替週期 立即輪替觸發條件 備註
使用者密碼 依密碼政策與風險；若啟用MFA與洩漏密碼防護，可依風險調整。 疑似外洩、離職交接、違規共用、系統入侵。 不得要求使用者定期改成弱密碼；應阻擋洩漏密碼。
特權密碼 至少每90日或依PAM政策；高風險可更短。 人員離職、權限異動、疑似外洩、緊急使用後。 優先PAM自動輪替。
服務帳號密碼 至少每90至180日，或依系統風險設定。 系統變更、供應商終止、外洩、Owner變更。 需驗證輪替不影響服務。
API Key / Token 至少每90至180日；高風險或外部Key更短。 疑似外洩、濫用、供應商事件、Repo曝光。 優先使用短期Token。
雲端Access Key 至少每90日；未使用Key應停用。 外洩、權限過大、異常使用、Role替代完成。 優先改用Role/Workload Identity。
TLS/SSL憑證 依有效期，到期前完成更新；建議自動化更新。 私鑰外洩、CA事件、域名或服務變更。 需監控到期。
加密金鑰 依KMS政策、資料分類與法規；高風險定期輪替。 金鑰外洩、演算法淘汰、管理員異動、事件後。 須評估資料重加密影響。
Break-glass密碼 每次使用後立即輪替；定期驗證可用性。 任何啟用、疑似接觸、保管鏈異常。 需雙人控管與告警。
AI API Key 至少每90日；依供應商與風險調整。 用量異常、Prompt誤輸入、供應商事件、Notebook/Repo曝光。 需監控成本與Token使用量。

16. Secrets外洩偵測與監控

偵測來源 偵測內容 告警條件 處置要求
Repo與CI/CD 硬編碼密碼、API Key、Token、私鑰、憑證、連線字串。 任何疑似Secret命中。 立即撤銷輪替，建立事件或修復工單。
日誌與SIEM Authorization Header、Token、密碼、私鑰片段、連線字串、Secrets錯誤輸出。 出現明文Secret或高風險模式。 遮罩、刪除或限制日誌，撤銷Secret。
DLP/CASB/Proxy Secrets外寄、上傳未核准雲端、輸入AI工具、貼到聊天平台。 命中Secrets規則或大量外傳。 阻擋或隔離，通報CISO。
雲端監控 Access Key異常地區、異常API、權限擴張、未使用Key、Root使用。 異常使用或高權限Key活動。 停用Key、調查來源、輪替。
API Gateway API Key暴增、Rate Limit觸發、未知來源、錯誤率增加。 疑似濫用、爬蟲或外洩。 限流、撤銷Key、事件處理。
Dark Web / Public Leak 組織Domain密碼、Token、憑證或Repo外洩。 確認或疑似外洩。 強制重設、撤銷、通報事件。
Endpoint/EDR 憑證Dump、Key檔案被讀取、Secret工具異常操作。 可疑程序或特權存取。 隔離端點、調查、輪替Secrets。
AI工具監控 Prompt含Key、Token、密碼、連線字串或Secrets片段。 任何命中禁止資料。 通報AI違規或資安事件，撤銷Secret。

17. Secrets外洩事件處理

處理階段 作業要求 責任角色 證據
1. 通報與分級 任何疑似Secrets外洩應立即通報，依Secret權限、資料影響、暴露範圍與濫用跡象分級。 發現者 / SOC / Incident Manager 事件通報、初步分級。
2. 遏止 立即停用、撤銷、輪替受影響Secrets，必要時停用相關帳號、API、服務或供應商存取。 IAM / Cloud / System Owner 撤銷與輪替紀錄。
3. 影響分析 確認Secret暴露位置、時間、存取紀錄、濫用痕跡、受影響資料、供應商與客戶影響。 Incident Manager / SOC / Data Owner 調查紀錄、日誌。
4. 根因分析 判定是否因硬編碼、權限過大、日誌洩漏、AI誤輸入、CI/CD設定或人員違規造成。 CISO / DevSecOps / Owner 根因分析報告。
5. 清理與修復 清除Repo歷史、日誌、文件、工單、AI輸入紀錄或外部平台殘留；修正流程與控制。 System Owner / DevSecOps 修復紀錄、PR/變更單。
6. 通知與合規 若影響PII、客戶資料、合約或法規，依事件程序通知DPO、法務、客戶或主管機關。 CISO / DPO / Legal 通知紀錄。
7. 事後檢討 檢討控制缺口、改善Secrets掃描、輪替、教育訓練與技術控制。 Incident Manager / ISMS管理代表 事件檢討、CAPA。

18. 例外管理

例外情境 最低要求 核准層級 期限與重評
無法使用Secrets Manager 說明技術限制、替代保護措施、加密保存、權限限制、輪替與導入改善計畫。 CISO / Secrets Owner / System Owner 最長90日，期滿重評。
長效API Key 說明必要性、Scope限制、IP限制、Rate Limit、監控、到期與輪替計畫。 CISO / Service Owner 依風險設定，最長180日。
共享帳號或共享Secret 說明不可使用具名帳號原因，採PAM、Session Recording、使用者核准與使用後輪替。 CISO / PAM Owner 最長90日或每次使用後檢討。
無法定期輪替 說明系統限制、影響評估、補償控制、替代架構與改善時程。 CISO / System Owner 高風險每30日追蹤。
Secret需人工交接 使用核准一次性秘密分享工具，限制時效、接收人、下載次數與紀錄。 Secrets Owner / Manager 單次有效，不得長期例外。
供應商Secrets限制 合約或服務不支援輪替、Scope限制、日誌或撤銷時，需風險接受與替代控制。 Supplier Management / CISO / Legal 續約或供應商變更時重評。
