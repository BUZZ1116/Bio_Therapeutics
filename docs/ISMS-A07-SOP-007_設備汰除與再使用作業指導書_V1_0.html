1. 作業目的

本作業指導書規範資訊處理設備於汰除、報廢、退租、轉售、捐贈、再使用、移轉、維修、更換、返修、盤點調整或雲端資源退場時之資訊安全、資料清除、實體保護、資產管理、供應商管理、證據保存與稽核要求，確保設備中保存之資料、系統設定、帳號、金鑰、憑證、Token、日誌、授權、網路組態及其他敏感資訊不會因設備生命週期結束或轉換而遭未授權存取、外洩、竄改、遺失或濫用。

本文件旨在將設備汰除與再使用流程與資產清冊、資料分類、資訊刪除、儲存媒體管理、備份還原、事件管理、供應商安全、實體安全、環境法規與營運持續要求整合，建立可追溯、可驗證、可稽核且可持續改善之企業級設備退場與再部署控制。

2. 作業原則

  • 任何設備於離開受控區域、交付供應商、轉售、捐贈、報廢、退租或再使用前，均應完成資產盤點、資料分類、保存限制檢查、資料清除、設定重置與驗證。
  • 含儲存媒體、快取、設定檔、憑證、網路組態、通訊錄、列印紀錄、掃描目的地、金鑰或Token之設備，不得未經清除或重置即移交他人。
  • 設備汰除應同時考量資訊安全、個人資料保護、客戶合約、軟體授權、環境保護、保固/租賃條款、出口管制與供應商合規。
  • 高機密資料、客戶資料、PII、金鑰或Secrets相關設備，應採更嚴格之安全清除、加密抹除、實體銷毀、雙人見證或CISO核准。
  • 設備再使用應重新建立可信狀態，包括核准映像、修補、加密、EDR/MDM、最小權限、安全組態、資產標籤與監控。
  • 所有清除、銷毀、移轉、供應商交接、退租與再使用紀錄應保存完整證據，並可與資產清冊及工單相互追溯。

3. 名詞與定義

名詞 定義
設備汰除 設備因年限、故障、租約到期、技術淘汰、專案結束、風險不可接受或業務需求消失而退出使用之活動。
設備再使用 已使用設備經資料清除、重置、檢查、重新組態與安全驗收後，重新分配給其他使用者、環境、系統或用途。
報廢 設備不再具使用價值或不適合再使用，經核准後進行資產除帳、資料清除與環保銷毀之過程。
退租 租賃或代管設備依合約返還供應商前之清點、資料清除、設定重置、證明取得與交接活動。
資料清除 使資料無法以合理方式復原、讀取或重建之技術或管理措施。
加密抹除 透過銷毀或撤銷加密金鑰，使加密資料在合理條件下不可解密之清除方式。
實體銷毀 透過粉碎、穿孔、熔毀、消磁或其他核准方式破壞媒體或設備，使資料不可復原。
資產除帳 將設備於資產、財務、維運、授權、保固、租賃與清冊中更新為退役、報廢、轉移或移除狀態。
可信再部署 設備經核准映像、修補、安全基準、EDR/MDM、加密、帳號與監控設定後重新投入使用。
銷毀證明 證明設備、媒體或資料已依核准方法完成清除或銷毀之文件化證據。

Internal Auditor 抽查汰除、清除、再使用、供應商證明、清冊更新與例外管理。 稽核底稿與發現。

6. 設備汰除與再使用作業流程

階段 作業要求 責任角色 輸出證據
1. 需求提出 提出汰除、報廢、退租、移轉、再使用、維修、轉售或捐贈需求，說明原因與影響。 Asset Owner / Requester 申請單。
2. 資產盤點 確認資產編號、序號、Owner、位置、使用者、附件、儲存媒體、授權、租約與保固。 Asset Manager / IT 資產盤點紀錄。
3. 資料與保存確認 確認資料分類、Data Owner、備份需求、Legal Hold、事件保全、合約與法規保存限制。 Data Owner / DPO / Legal 保存確認紀錄。
4. 風險分級 依資料敏感度、設備類型、外部移交、供應商、可復原性與業務重要性判定風險等級。 Security Owner / Asset Owner 風險評估。
5. 備份或資料移轉 必要資料依核准方式備份、移轉或封存，並驗證可用性。 System Owner / IT 備份/移轉紀錄。
6. 存取撤銷 撤銷帳號、Token、憑證、MDM綁定、VPN、API Key、遠端管理與供應商存取。 IT / IAM Owner 撤權紀錄。
7. 資料清除或銷毀 依媒體與資料分類執行安全清除、加密抹除、設定重置或實體銷毀。 IT / Supplier 清除/銷毀證明。
8. 實體交接 暫存、搬運、出場、物流、退租或銷毀需清點、簽收、雙人或可追蹤控制。 Facility / Asset Manager 交接紀錄。
9. 再使用重建 再使用設備需以核准映像或標準程序重建，套用安全基準、修補與監控。 IT Operations 再部署紀錄。
10. 驗證與驗收 確認資料不可復原、設定已清除、設備狀態正確、再使用環境安全。 Security / Asset Owner 驗證與驗收紀錄。
11. 清冊與財務更新 更新資產、財務、授權、保固、租約、Owner、位置與文件證據索引。 Asset Manager / Finance 清冊更新紀錄。
12. 結案與改善 保存證據，關閉工單，追蹤例外、缺失、供應商補件與改善措施。 ISMS代表 / CAPA Owner 結案紀錄。

12. 例外管理

例外情境 最低要求 核准層級 期限與重評
媒體故障無法清除 需實體銷毀或提出替代控制，保留序號與見證紀錄。 CISO / Asset Owner 單次處理。
設備返修無法移除媒體 需Data Owner與CISO核准，使用加密、封條、供應商合約與追蹤。 CISO / Legal / Supplier Owner 維修完成即重評。
供應商未提供完整證明 不得結案，需補證明、替代證據或正式風險接受。 Supplier Owner / CISO 最長30日。
Legal Hold暫停汰除 設備需封存於受控區域並限制存取。 Legal / Compliance 依案件狀態重評。
租約限制無法銷毀媒體 需依合約協商、加密抹除、供應商證明或風險接受。 Legal / Procurement / CISO 退租前完成。
再使用前無法完成完整重建 需隔離、限制用途、補償控制與改善計畫。 IT Owner / CISO 最長30日。
雲端Snapshot無法即時刪除 需記錄限制、保留期限、加密狀態與到期刪除計畫。 Cloud Owner / DPO / CISO 每季重評。

13. 高風險事件與通報

情境 立即處置 升級對象 後續要求
設備遺失或未授權出場 立即通知SOC、Physical Security與Asset Owner，保全紀錄並遠端鎖定/抹除。 CISO / Incident Manager / DPO視資料分類 啟動事件調查與資料外洩評估。
再使用後發現殘留資料 立即隔離設備、保存證據、停止使用、重新清除。 CISO / Data Owner / DPO 評估資料外洩並完成RCA/CAPA。
供應商遺失設備或媒體 要求供應商立即通報、保全、調查與提供事件報告。 Supplier Owner / Legal / CISO 依合約追究並評估通報義務。
清除證明造假或不可信 暫停供應商、重新驗證或重新銷毀設備。 CISO / Procurement / Legal 供應商風險重評。
高機密設備未清除即移轉 立即追回或隔離設備並啟動重大事件處理。 CISO / Management 完成事件檢討與管理審查。
