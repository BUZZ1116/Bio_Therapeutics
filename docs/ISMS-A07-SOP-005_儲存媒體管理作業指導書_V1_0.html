1. 作業目的

本作業指導書用於規範組織儲存媒體之申請、採購、配置、標示、使用、保管、攜出、傳輸、備份、盤點、維護、汰換、抹除、銷毀、事件通報與稽核要求，確保儲存媒體於完整生命週期中維持資訊之機密性、完整性、可用性、可追溯性與合規性。

本文件同時支援 ISO/IEC 27001:2022 Annex A.7.10「Storage media」之落地執行，並與資訊分類、資產管理、存取控制、資料外洩防護、備份、事件管理、數位證據保存、供應商管理、隱私保護與營運持續管理整合，以形成可稽核、可驗證、可追蹤之企業級媒體管理控制。

2. 作業原則

  • 所有儲存媒體應納入資產管理、分類標示、責任歸屬、授權使用、保存保護、盤點與處置控制。
  • 儲存機密、高機密、PII、客戶資料、AI模型資料、Prompt、金鑰、原始碼、事件證據、備份資料或合約限制資料之媒體，應採加密、存取限制、實體保護及完整紀錄。
  • 可攜式媒體原則上不得作為常態資料傳輸或保存工具；必要使用時，應事前核准、加密、標示、登錄、限定目的與期限。
  • 媒體離開受控區域、交付第三方、送修、報廢或銷毀前，應完成資料抹除、加密狀態確認或保全交接，並保留證據。
  • 媒體遺失、遭竊、未授權存取、誤用、未按規定抹除、未按規定銷毀或疑似外洩時，應依資訊安全事件管理程序立即通報。

3. 名詞與定義

名詞 定義
儲存媒體 可保存或承載數位資訊之實體或邏輯媒介，包括固定式、可攜式、可移除式、虛擬化、雲端與備份媒體。
可攜式媒體 可由人員攜帶、移動或交接之儲存媒體，例如 USB、外接硬碟、記憶卡、磁帶、光碟或加密行動硬碟。
受控媒體 已完成登錄、分類、Owner指定、存取授權、保護措施、使用目的與保存/處置要求之媒體。
媒體Owner 對媒體使用目的、資料分類、授權、風險、保存期限與處置決策負責之角色。
媒體Custodian 負責媒體實際保管、操作、盤點、搬運、交接、維護或執行處置之角色。
清除（Clear） 透過邏輯方式移除資料，使一般軟體工具無法復原資料，適用低風險或重複使用情境。
淨化（Purge） 使用密碼抹除、覆寫、消磁、加密金鑰銷毀或其他強化方法，使資料無法以實驗室方法合理復原。
銷毀（Destroy） 以物理破壞、粉碎、熔毀、切割、穿孔或經核准第三方處置方式，使媒體不再可用且資料不可復原。
Chain of Custody 媒體或證據於保存、移交、分析、送修、銷毀或交付第三方過程中之完整保管鏈紀錄。
加密金鑰銷毀 透過銷毀或失效加密金鑰使受加密保護之資料無法解密之處置方式。

4. 角色與責任

角色 主要責任
最高管理階層 核准重大媒體風險接受、重大資料外洩處理、重大供應商處置與資源配置。
CISO / 資訊安全負責人 制定媒體安全控制要求，核准高風險例外、媒體遺失處理與高機密媒體處置。
ISMS管理代表 維護本文件，追蹤稽核、KPI/KRI、風險登錄、矯正措施與管理審查輸入。
IT Asset Owner 建立媒體資產清冊，管制媒體採購、發放、盤點、回收、汰換與報廢。
Data Owner 判定媒體內資料分類、使用目的、授權、保存期限、抹除或銷毀要求。
Media Custodian 負責媒體日常保管、交接、標示、物理保護、盤點與使用紀錄維護。
IT Operations / Endpoint 管理 執行加密、DLP、裝置控制、惡意軟體掃描、媒體掛載限制與技術紀錄保存。
Backup Owner 管理備份媒體、備份磁帶、離線備份、異地保存、加密與復原測試。
實體安全負責人 管理媒體保存場所、保險櫃、機房、倉庫、門禁、監控、環境與訪客控制。
SOC / 資安監控 監控可攜式媒體使用、DLP告警、端點異常、資料外洩與違規事件。
DPO / PIMS負責人 審查含PII媒體之保存、傳輸、遺失、銷毀、跨境與資料主體權利影響。
供應商管理 / 法務 確保送修、回收、銷毀、雲端或外包媒體處理具合約、保密、證明與稽核權。
使用者 依授權使用媒體、妥善保護、禁止未核准媒體、不得私自複製或攜出資料，並通報異常。

8. 標示、保管與實體保護要求

控制項目 作業要求 注意事項 證據
媒體標示 媒體外部應標示資產編號、分類代碼、Owner或保管單位；不得標示可暴露敏感內容之細節。 高機密媒體可使用代碼化標示，避免顯示客戶名稱或案件名稱。 資產標籤、清冊。
安全保存 未使用媒體應存放於上鎖櫃、保險箱、機房、受控倉庫或其他經核准場所。 機密以上媒體不得留置於桌面、車輛、公共場所或未受控區域。 場所檢查紀錄。
環境保護 備份磁帶、硬碟與長期封存媒體應考量溫濕度、防火、防水、防塵、防磁與防震。 必要時採異地保存或防火資料櫃。 環境監測紀錄。
存取限制 媒體保存區應限制授權人員進入，保存進出紀錄或監控紀錄。 訪客或供應商接觸媒體需陪同與登錄。 門禁紀錄、訪客紀錄。
攜出保護 媒體攜出受控區域需核准、加密、封裝、簽收與目的地確認。 不得以無人看管方式寄放或交付。 攜出申請、交接紀錄。
長期封存 封存媒體應標示保存期限、解封條件、Owner、版本與銷毀到期日。 應定期檢查可讀性與保存條件。 封存清冊、檢查紀錄。

9. 加密、金鑰與存取控制

控制領域 最低要求 適用情境 證據
全碟加密 筆電、可攜式硬碟、USB及含機密以上資料之媒體應啟用全碟或等效加密。 端點、可攜式媒體、外接媒體。 加密狀態報告。
檔案/容器加密 需跨系統或外部交付時，可使用受控加密容器、PGP或壓縮檔加密，密碼分離傳送。 外部交付、供應商傳輸。 傳輸與密碼交付紀錄。
金鑰管理 加密金鑰應由核准工具管理，避免與媒體同置；金鑰應有Owner、備援與撤銷機制。 備份媒體、伺服器、雲端儲存。 KMS/Vault紀錄。
端點裝置控制 未核准USB與外接媒體應由端點控管阻擋或唯讀；例外需核准。 員工端點與伺服器。 EDR/DLP/MDM政策。
最小權限 媒體存取應限授權人員、必要期間與必要資料；不得共用帳號或密碼。 機密媒體、備份媒體、證據媒體。 授權紀錄。
金鑰銷毀 採加密刪除時，應確認金鑰不可復原，並保存銷毀授權與執行紀錄。 雲端媒體、虛擬磁碟、大量加密媒體。 金鑰銷毀紀錄。

10. 可攜式媒體使用限制

情境 允許條件 禁止事項 核准要求
一般內部文件暫存 僅限核准媒體、內部資料、短期使用、完成後刪除。 不得長期保存、轉借或使用個人媒體。 部門主管或Owner核准。
機密資料搬移 需加密、登錄、簽收、資料最小化、使用期限與回收確認。 不得未加密、不得交由未授權人員攜帶。 Data Owner與資安核准。
高機密/PII資料 原則上避免使用；必要時需使用公司核准加密媒體並採雙人覆核。 不得使用一般USB、個人硬碟或未受控媒體。 CISO / DPO核准。
供應商資料交換 需合約、保密、交接、完整性檢查與回收/銷毀證明。 不得未簽收、未加密或未確認收件方。 供應商管理與法務核准。
緊急營運持續用途 需BCMS/DRP授權，使用後補登錄、補審查與補強控制。 不得以緊急為由規避通報與事後追蹤。 BCMS/IT主管核准。
數位證據保存 需使用唯讀、封存、Hash與Chain of Custody控制。 不得在證據媒體上直接分析或修改原始內容。 事件指揮官/資安核准。

作業項目 作業要求 責任角色 證據

封裝與標示 使用防拆封裝、封條、外部代碼化標示與收件資訊；避免暴露敏感內容。 Custodian 封裝照片或交接紀錄。
交接簽收 交付、接收、轉交、退回均需記錄人員、時間、地點、媒體狀態與封條狀態。 交付人 / 接收人 交接簽收紀錄。
運送方式 依分類選擇專人、掛號、受信任快遞、保全運送或雙人交接。 Owner / 實體安全 運送追蹤紀錄。
完整性確認 接收後確認封條、序號、Hash、檔案數、磁帶標籤或備份校驗結果。 接收人 / IT 接收確認紀錄。
回收關閉 目的完成後回收媒體，確認資料處置、清冊更新與使用案件關閉。 IT Asset Owner 回收與關閉紀錄。

12. 備份媒體管理要求

控制項目 作業要求 頻率 / 時機 證據
備份媒體登錄 記錄媒體編號、系統、資料分類、備份日期、保存期限、地點、Owner與加密狀態。 每次備份產生或媒體更換時。 備份媒體清冊。
加密與保護 備份媒體應加密，金鑰與媒體分離保存，並限制復原權限。 持續。 備份設定、KMS紀錄。
異地保存 關鍵系統備份媒體應依BCMS要求異地保存，並考量RTO/RPO與災害風險。 依備份策略。 異地交接紀錄。
復原測試 定期驗證備份媒體可讀性、完整性與復原程序有效性。 至少每年或依系統關鍵性。 復原測試報告。
保留與到期 依法規、合約、業務與資料分類設定保存期限，到期後安全銷毀。 定期審查。 保存期限清冊、銷毀紀錄。
磁帶輪替 磁帶應依週期輪替，淘汰老化或錯誤率異常媒體。 依備份政策。 磁帶輪替紀錄。

13. 雲端、虛擬媒體與快照管理

媒體型態 控制要求 風險考量 證據
雲端物件儲存 啟用加密、IAM最小權限、公開存取阻擋、版本控管、生命週期與存取日誌。 公開暴露、跨區複製、誤刪、未授權下載。 雲端設定截圖、日誌。
虛擬磁碟 登錄系統與Owner，限制掛載、快照、複製、匯出與刪除權限。 快照殘留資料、複製失控、權限過大。 雲端資產清冊、IAM紀錄。
資料庫快照 記錄來源、時間、資料分類、用途與保存期限；含PII需遮罩或限制存取。 生產資料外洩、測試環境濫用。 快照清冊、核准紀錄。
容器與映像 不得將Secrets、憑證、PII或敏感設定寫入映像；映像需掃描與簽章。 秘密資訊外洩、供應鏈污染。 映像掃描報告。
AI資料與模型媒體 模型、訓練資料、向量資料庫、Prompt資料應納入清冊、版本與存取控制。 模型外洩、資料重識別、Prompt洩漏。 AI資產清冊、版本紀錄。
雲端刪除 確認刪除保護、保留政策、金鑰銷毀、備份與跨區副本處理。 殘留副本、法規保存衝突。 刪除與金鑰銷毀紀錄。

14. 送修、退貨與供應商處理

情境 處理要求 禁止事項 證據
端點送修 送修前移除資料、完成備份、抹除或確認全碟加密；高風險案件採硬碟留置。 不得將未加密含敏感資料媒體直接送外。 送修檢核、加密證據。
伺服器硬碟故障 若硬碟含機密以上資料，應優先留置並內部銷毀；供應商需支援保留故障硬碟條款。 不得未審查即退回原廠。 硬碟留置紀錄。
供應商資料處理 要求NDA、DPA、資料處理限制、事件通報、再委外揭露與銷毀證明。 不得交付未簽約或未評估供應商。 合約、供應商評估。
第三方銷毀 需核准銷毀方法、見證方式、序號清單、銷毀證明與抽樣驗證。 不得只以一般廢棄物處理。 銷毀證明、見證紀錄。
租賃設備返還 返還前完成資料清除/淨化、帳號移除、金鑰撤銷與設定重置。 不得返還仍可存取組織環境之設備。 返還檢核表。
跨境送修 涉及跨境或PII時需法務/DPO審查，必要時禁止或改採硬碟留置。 不得未確認法規與合約要求即跨境送修。 法務/DPO審查紀錄。

15. 媒體清除、淨化與銷毀標準

資料分類 / 情境 最低處置方式 適用媒體 核准與證據
公開資料媒體重用 清除、格式化或重新部署前標準初始化。 低風險端點、測試媒體。 IT作業紀錄。
內部資料媒體重用 受控清除或加密重置，確認無業務資料殘留。 端點、外接硬碟、虛擬磁碟。 抹除工具報告。
機密資料媒體重用 淨化或加密金鑰銷毀，必要時覆寫驗證。 硬碟、SSD、備份媒體。 淨化報告、Owner確認。
高機密 / PII / 合約限制 原則採淨化後銷毀或直接物理銷毀；需保留序號與見證紀錄。 可攜式媒體、伺服器硬碟、磁帶。 CISO/DPO核准、銷毀證明。
SSD與快閃媒體 優先使用廠商安全抹除、加密金鑰銷毀或物理銷毀。 SSD、USB、記憶卡。 工具報告、銷毀證明。
磁帶與光碟 依分類採消磁、粉碎、切割或物理銷毀。 磁帶、光碟。 銷毀批號、照片或證書。
雲端媒體 刪除資源、刪除快照、處理備份、撤銷金鑰，確認保留政策與法規保存。 雲端儲存、虛擬磁碟、快照。 刪除紀錄、KMS紀錄。

16. 媒體盤點與差異處理

盤點項目 盤點要求 頻率 異常處理
資產存在性 確認媒體實體存在、序號一致、保管人與位置正確。 至少每年；高機密與備份媒體至少每半年。 立即查明，疑似遺失依事件通報。
分類與標示 確認標籤、分類、Owner、保存期限與用途仍正確。 每年或用途變更時。 更新清冊並補正標示。
加密狀態 確認加密啟用、金鑰有效、密碼未共用或失控。 每半年或例外審查時。 立即補強或停止使用。
使用必要性 確認媒體仍有業務必要，過期或無必要者回收處置。 每年或專案結束時。 回收、清除、銷毀或展延核准。
供應商持有媒體 確認第三方媒體清冊、保存地、用途、銷毀或返還狀態。 依合約或至少每年。 啟動供應商矯正要求。
備份媒體 確認備份媒體可讀性、輪替、保存期限、異地狀態與復原測試。 依BCMS與備份政策。 更換媒體或更新復原策略。

17. 媒體遺失、竊盜與異常事件處理

事件情境 立即處置 後續處置 必要通報 / 證據
媒體遺失或遭竊 立即通報SOC、主管、Data Owner與CISO，確認媒體內容、加密狀態與最後位置。 啟動事件分級、風險評估、法規通報判定與矯正措施。 事件通報紀錄、調查報告。
未授權媒體接入 隔離端點、收集日誌、掃描惡意程式、保留媒體。 分析資料是否外流，檢討端點裝置控制。 EDR/DLP紀錄。
媒體未加密 停止使用並補加密或回收，確認是否已存放敏感資料。 評估外洩風險與使用者訓練需求。 補救紀錄、教育紀錄。
送修或銷毀失控 暫停供應商作業，要求說明、追蹤媒體位置與保全證據。 供應商事件審查、合約追責與矯正措施。 供應商事件紀錄。
資料疑似殘留 停止媒體重用或交付，重新淨化或銷毀。 檢討抹除流程、工具與抽樣驗證。 重新處置紀錄。
備份媒體讀取失敗 標記異常，確認是否影響RTO/RPO與復原能力。 更換媒體、重建備份、更新BCP/DRP風險。 復原測試與改善紀錄。
