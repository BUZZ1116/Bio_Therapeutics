1. 作業目的

本作業指導書規範軟體安裝、軟體白名單、封鎖清單、授權合規、軟體資產清冊、安裝申請、風險評估、測試驗證、部署、維護、移除、例外與稽核要求，以防止未授權軟體、惡意軟體、破解軟體、盜版軟體、風險工具、未核准AI工具、未受控遠端管理工具、弱點軟體及供應鏈高風險元件進入組織環境。

本文件旨在建立軟體生命週期管理與應用程式控制機制，確保軟體之來源、用途、授權、版本、弱點、資料存取、網路連線、特權需求、AI與隱私風險均經適當審查，並與端點防護、MDM、EDR、IAM、DLP、弱點管理、採購、法務、供應商管理及內部稽核流程整合。

2. 作業原則

  • 組織設備與系統原則上僅得安裝、執行或使用經核准之軟體；非核准軟體應阻擋、移除或依例外流程處理。
  • 軟體安裝應遵循最小權限、集中部署、版本控管、來源驗證、授權合規、弱點檢查及安全測試原則。
  • 使用者不得自行下載、安裝、執行或攜入未核准軟體、破解工具、序號產生器、可繞過監控之工具、未核准遠端管理工具、未核准AI工具或高風險瀏覽器外掛。
  • 白名單規則應以軟體名稱、版本、發行者、簽章、Hash、路徑、來源、使用者群組、設備群組及業務用途為依據，避免過度寬鬆。
  • 軟體例外應具備業務必要性、風險評估、補償控制、核准、期限與重評，不得以永久例外替代正式核准與治理。
  • 軟體移除、退場或授權到期時，應同步處理設定檔、暫存資料、服務帳號、網路規則、瀏覽器外掛、資料留存與供應商存取。

3. 名詞與定義

名詞 定義
軟體白名單 經核准可安裝、執行、更新或使用之軟體清單、規則或控制政策。
應用程式控制 透過端點、作業系統、MDM、EDR、App Control或其他工具限制可執行程式之技術控制。
封鎖清單 已知不允許安裝或執行之軟體、工具、Hash、發行者、路徑、套件、外掛或服務清單。
未授權軟體 未經組織核准、未登錄、未授權、未符合安全要求或不具業務必要性之軟體。
影子IT軟體 未經IT、安全、採購或法務核准而由使用者自行導入或使用之軟體或SaaS。
特權安裝 需本機管理員、Root、sudo、MDM特權、系統服務權限或安全例外方可安裝之軟體安裝活動。
開源軟體 以開源授權發布之軟體、套件、Library、工具、框架、模型或容器映像。
瀏覽器外掛 安裝於瀏覽器內之Extension、Plugin或Add-on，可能存取網頁內容、剪貼簿、憑證或資料。
AI工具 生成式AI、程式碼輔助、資料分析、模型工具、Prompt工具、RAG工具或AI SaaS應用。
軟體資產清冊 記錄軟體名稱、版本、Owner、授權、設備、用途、風險、弱點、到期與狀態之清冊。
軟體供應鏈風險 由軟體來源、開源套件、供應商、更新機制、簽章、建置流程或依賴元件所導致之安全風險。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
CISO / 資訊安全負責人 核准軟體安裝與白名單政策、高風險軟體、例外、風險接受與重大事件處置。 核准紀錄、風險接受、事件決策。
Software Asset Management Owner 維護軟體資產清冊、授權狀態、使用範圍、到期與退場追蹤。 軟體清冊、授權紀錄。
Endpoint Security Owner 設計與維護應用程式控制、白名單、封鎖清單、EDR/MDM政策與端點執行限制。 EDR/MDM設定、白名單紀錄。
IT Operations / IT Helpdesk 受理安裝申請、部署核准軟體、移除未授權軟體、支援使用者與維護標準軟體包。 服務單、部署紀錄。
Procurement / Legal 審查軟體採購、授權條款、開源授權、資料處理、供應商合約與使用限制。 採購紀錄、合約與授權審查。
System / Business Owner 提出業務需求、確認用途、資料分類、使用者範圍、成本與風險接受。 需求與核准紀錄。
Application Security / DevSecOps 審查開發工具、開源套件、容器、CI/CD工具、程式碼輔助與供應鏈風險。 安全審查與掃描報告。
Data Owner / DPO 審查軟體是否處理PII、客戶資料、跨境、資料上傳、同步或隱私影響。 資料與隱私審查紀錄。
AI Governance Owner 審查AI工具、模型工具、AI程式碼輔助、資料不訓練、Prompt保存與AI風險。 AI工具核准紀錄。
SOC / Incident Response 監控未授權軟體、惡意軟體、封鎖事件、可疑安裝、資料外洩與事件調查。 告警、事件紀錄。
Internal Auditor 抽查軟體清冊、白名單規則、授權、例外、未授權軟體與控制有效性。 稽核底稿、稽核發現。

5. 軟體分類與預設處置

軟體分類 範例 預設處置 核准要求
標準辦公軟體 辦公套件、PDF工具、瀏覽器、會議軟體。 集中部署或核准清單允許。 IT Owner核准，授權合規。
業務專用軟體 ERP客戶端、財務工具、設計軟體、專業分析工具。 依業務Owner與授權核准。 Business Owner、IT、Procurement核准。
開發工具 IDE、SDK、Compiler、套件管理器、DB工具、API測試工具。 依開發角色與環境允許。 DevSecOps/AppSec審查。
系統工具 壓縮、遠端管理、磁碟、網路掃描、管理工具。 限制或需特權核准。 IT/Security核准。
安全工具 掃描、封包分析、惡意樣本分析、滲透測試工具。 限資安人員與隔離環境使用。 CISO/SOC核准。
AI工具 生成式AI、程式碼輔助、AI資料分析、模型工具。 未核准預設阻擋或限制。 AI Governance、CISO、Data Owner視情況核准。
瀏覽器外掛 密碼管理、翻譯、截圖、AI外掛、資料擷取外掛。 白名單管理，未核准禁止。 Endpoint Security與Data Owner視風險核准。
雲端同步/分享工具 個人雲端、P2P同步、檔案分享。 未核准禁止。 Data Owner、CISO核准。
遠端控制工具 遠端桌面、RMM、VPN、Tunnel、Proxy工具。 未核准禁止。 IT、CISO核准。
破解/盜版/繞控工具 Keygen、Crack、盜版軟體、規避監控工具。 禁止。 無例外，必要時事件處理。
高風險未知軟體 來源不明、未簽章、低信譽、過期或含已知重大弱點。 阻擋或隔離。 CISO核准例外。

6. 軟體安裝與白名單管理流程

階段 作業要求 責任角色 輸出證據
1. 安裝需求提出 申請人說明軟體名稱、版本、來源、用途、使用者、設備、資料類型、期限與授權需求。 申請人 / Business Owner 軟體安裝申請單。
2. 初步審查 確認是否已有核准替代軟體、是否屬標準軟體、是否需採購與授權。 IT Helpdesk / SAM Owner 初審紀錄。
3. 安全風險評估 評估來源、簽章、Hash、弱點、權限、網路連線、資料存取、AI/雲端/供應鏈風險。 Endpoint Security / AppSec / CISO 安全評估紀錄。
4. 法務與授權審查 確認授權條款、開源授權、使用範圍、商用限制、資料處理與合約義務。 Procurement / Legal 授權審查紀錄。
5. 隱私與AI審查 涉及PII、客戶資料、雲端同步、AI、Prompt或資料上傳時審查。 DPO / Data Owner / AI Governance 資料與AI審查紀錄。
6. 測試與封裝 於受控環境測試安裝、相容性、弱點、EDR告警、網路行為與移除程序。 IT / Endpoint Security 測試與封裝紀錄。
7. 核准與白名單設定 依風險取得核准，設定白名單條件與適用對象。 CISO / IT / Endpoint Security 核准與白名單紀錄。
8. 部署與使用 透過MDM、軟體中心、套件管理或受控方式部署，不鼓勵手動安裝。 IT Operations 部署紀錄。
9. 監控與維護 監控版本、弱點、授權、使用、異常行為與更新。 SAM / SOC / IT 監控與修補紀錄。
10. 退場與移除 軟體不再需要、授權到期或風險不可接受時移除並更新清冊。 IT / SAM Owner 移除與退場紀錄。

8. 軟體安全評估項目

評估領域 評估問題 處置要求
來源可信度 是否來自官方網站、核准套件倉庫、企業市集或可信供應商？ 來源不明者不得安裝。
數位簽章 安裝檔是否具有效簽章、可信發行者與未遭竄改？ 未簽章或簽章異常需加強審查。
Hash與完整性 是否可驗證Hash或Checksum？ 高風險軟體需保存Hash。
弱點狀態 是否存在Critical/High CVE或已知被利用弱點？ 未修復重大弱點原則不得核准。
授權合規 授權是否允許商用、內部使用、修改、散布或雲端部署？ Legal/Procurement審查。
資料存取 是否可存取檔案、剪貼簿、Email、瀏覽器資料、PII或客戶資料？ 需Data Owner/DPO審查。
網路行為 是否需連接外部API、雲端、遙測、更新伺服器或未知網域？ 需網路與DLP控制。
權限需求 是否需要本機管理員、Root、Kernel Extension、Driver或系統服務？ 需特權安裝與安全審查。
供應鏈風險 是否使用第三方套件、Auto-update、插件、腳本或模型下載？ 需供應鏈評估。
AI風險 是否含生成式AI、模型訓練、Prompt保存、資料上傳或資料不訓練條款？ 需AI Governance審查。
移除能力 是否可完整移除軟體、Agent、驅動、外掛、設定與資料？ 需退場程序。

9. 白名單規則設計要求

規則項目 最低要求 避免事項
軟體名稱與版本 白名單應指定核准名稱與版本範圍。 避免允許所有版本或未知版本。
發行者簽章 優先依可信發行者與簽章控管。 不得將不可信或過寬發行者完全信任。
Hash控制 對高風險、固定版本、特定工具應使用Hash白名單。 避免使用路徑白名單取代Hash。
安裝路徑 限制標準安裝路徑與不可寫入路徑。 避免允許使用者可寫目錄執行。
使用者群組 依角色、部門、設備群組、專案或環境限制。 避免全公司開放不必要軟體。
設備範圍 依受管理設備、伺服器、開發工作站或隔離環境限制。 避免BYOD或未知裝置使用高風險軟體。
網路目的地 需外連之軟體應限定目的地、協定、埠號與Proxy。 避免任意Egress。
到期日 臨時白名單應設定到期日與自動重評。 避免永久例外。
審計日誌 白名單命中、阻擋、例外與規則變更需記錄。 避免無法追溯。

10. 封鎖清單與禁止軟體管理

禁止 / 限制類型 處置要求 補充說明
破解、盜版與Keygen 立即阻擋、移除並依違規或事件程序處理。 涉及法律與惡意程式風險。
未核准遠端控制工具 阻擋或移除；若業務需要需正式核准與日誌。 避免未授權遠端存取。
匿名代理與繞控工具 阻擋或移除。 避免規避網頁過濾、DLP與監控。
未核准AI工具 阻擋、限制或要求改用核准工具。 避免資料、Prompt、Secrets外洩。
個人雲端同步工具 未核准者阻擋或限制同步。 避免資料外傳。
高風險瀏覽器外掛 阻擋或移除可讀取全部網站、剪貼簿、密碼或資料之外掛。 需外掛白名單。
已知惡意或低信譽軟體 阻擋、隔離、移除並檢查IOC。 需SOC調查。
過期與不支援軟體 限制使用、升級或退場。 若無法退場需風險接受。
未授權套件管理器或腳本 限制可使用之套件來源、Registry與執行政策。 防止供應鏈攻擊。
