1. 作業目的

本作業指導書規範組織資料外洩防護（Data Loss Prevention, DLP）之資料分類、偵測規則、端點/網路/雲端/Email/SaaS/AI資料流控制、告警分級、事件調查、例外管理、隱私保護、監控、稽核與持續改善要求，避免機密資料、高機密資料、個人資料、客戶資料、原始碼、Secrets、憑證、財務、人資、法務、AI模型、Prompt、RAG資料及其他受管制資訊遭未授權外洩、誤送、誤分享、過度下載、未核准上傳或輸入至外部AI/SaaS平台。

DLP控制應與資料分類分級、存取控制、加密、端點安全、網頁過濾、CASB、SASE/SSE、Email安全、雲端安全、日誌監控、事件管理、隱私治理、AI工具與資料使用政策整合，形成以資料為中心之防護能力，並支援法規、合約、客戶承諾及ISO/IEC 27001:2022 Annex A控制要求。

2. 作業原則

  • DLP規則應依資料分類、資料Owner、業務必要性、資料流、法規合約、威脅情境與使用者角色設計，不得僅依單一關鍵字或單一工具判斷。
  • DLP控制應採分階段導入，包括盤點、監控、微調、告警、使用者提醒、限制、阻擋與事件回應，以兼顧安全、隱私與營運效率。
  • 涉及PII、客戶資料、員工資料、醫療/金融/法務資料、Secrets、AI資料或高機密資料之外傳，應採更嚴格之阻擋、核准、加密、遮罩或DPO/Data Owner審查。
  • DLP告警與調查資料本身可能含敏感資訊，應限制存取、加密保存、最小化展示並保留稽核軌跡。
  • 使用者不得為規避DLP而改名、壓縮、加密、分割、截圖、拍照、轉貼、輸入AI工具或使用個人帳號/個人雲端傳輸受管制資料。
  • 所有DLP例外、白名單、規則停用或大範圍放行應經風險評估、核准、期限設定、補償控制與定期重評。

3. 名詞與定義

名詞 定義
DLP Data Loss Prevention，資料外洩防護，用於偵測、監控、告警、限制或阻擋敏感資料未授權使用、傳輸、分享、列印或外洩之控制措施。
資料外洩 資料未經授權或違反政策被取得、揭露、傳輸、上傳、下載、列印、分享、輸入外部工具或暴露於不適當對象。
敏感資料 依資訊分類分級表定義之機密、高機密、PII、客戶資料、Secrets、財務、人資、法務、原始碼、AI資料、GHG/ESG資料等。
Endpoint DLP 在端點裝置上監控或控制檔案複製、USB、列印、剪貼簿、截圖、應用程式、瀏覽器與資料傳輸之DLP能力。
Network DLP 在網路、Proxy、SWG、Email Gateway、API Gateway或邊界上監控資料傳輸之DLP能力。
Cloud DLP / CASB 在SaaS、雲端儲存、協作平台與雲端應用中偵測與控制敏感資料之能力。
Content Inspection 依檔案內容、格式、關鍵字、正則表示式、指紋、標籤、機器學習或資料分類標籤檢測敏感資料。
Exact Data Match（EDM） 以受保護資料集指紋比對精準偵測特定敏感資料，例如客戶名單或員工資料。
Document Fingerprinting 以文件指紋偵測特定受保護文件或文件片段之傳輸或分享。
資料標籤 用於標示資料分類、Owner、保存期限、使用限制或保護要求之Metadata或標記。
AI Prompt DLP 針對輸入生成式AI、模型API、AI Agent或RAG服務之Prompt、檔案與上下文進行敏感資料檢測與限制。

5. DLP保護資料類型與最低處置

資料類型 偵測方式 預設處置 補充要求
PII / 個人資料 正則、EDM、資料標籤、文件指紋、欄位分類。 告警、限制或阻擋，依情境升級DPO。 需最小化調查資料與保護告警內容。
客戶資料 EDM、文件指紋、資料庫欄位、檔案標籤。 未核准外傳阻擋或需Data Owner核准。 合約客戶資料需依客戶要求處理。
高機密文件 文件指紋、分類標籤、關鍵字、Metadata。 禁止外部分享與未核准上傳。 需加密、權限與例外核准。
Secrets / 憑證 Regex、Entropy、Secrets掃描、Token格式、Key Pattern。 立即阻擋、告警與撤銷輪替。 需啟動Secrets事件處理。
原始碼 / 架構文件 Repo偵測、文件指紋、關鍵字、路徑與檔案類型。 限制個人雲端、外部Email、AI工具上傳。 DevSecOps與AppSec審查。
財務 / 法務 / 人資資料 文件指紋、關鍵字、標籤、資料Owner清單。 限制外部分享與未核准下載。 需Legal/HR/Data Owner核准例外。
AI模型 / Prompt / RAG資料 模型檔副檔名、Prompt標籤、向量資料、RAG來源指紋。 限制外部AI、個人雲端與未核准SaaS。 需AI Governance核准。
GHG/ESG與碳資料 資料標籤、文件指紋、報告格式、供應商資料。 依機密或合約等級控制。 需保護資料完整性與來源可信度。
大量資料匯出 筆數、檔案大小、下載頻率、異常行為。 告警、限制或阻擋。 需行為分析與Data Owner確認。

6. DLP導入與規則生命週期流程

階段 作業要求 責任角色 輸出證據
1. 資料盤點與分類 識別資料類型、Owner、位置、資料流、保存期限、外部分享需求與保護等級。 Data Owner / DLP Owner 資料盤點與分類紀錄。
2. 風險評估 評估外洩可能性、影響、使用者、通道、供應商、AI/SaaS與法規合約要求。 CISO / Risk Owner 風險評估紀錄。
3. 規則設計 定義偵測條件、處置、告警分級、例外、測試資料與調查流程。 DLP Owner / SOC / Data Owner DLP規則設計。
4. 隱私與法務審查 涉及員工監控、PII、跨境日誌或內容檢查時完成DPO/Legal審查。 DPO / Legal / HR 隱私審查紀錄。
5. 測試與調校 以受控樣本測試誤判、漏判、性能、營運影響與告警品質。 DLP Owner / SOC 測試與調校紀錄。
6. 試行監控 先以Monitor或Alert模式收集基準，必要時使用者提醒。 SOC / DLP Owner 試行報告。
7. 正式啟用 依風險啟用阻擋、隔離、加密、核准流程或強制標籤。 CISO / Data Owner 啟用核准紀錄。
8. 監控與事件處理 監控告警、分級、調查、關閉、升級與事件管理。 SOC / Incident Response DLP事件紀錄。
9. 定期審查 定期審查規則命中、誤判、例外、事件趨勢與控制有效性。 DLP Owner / ISMS代表 規則審查紀錄。
10. 改善與退場 依資料變更、系統退場、法規變更或事件檢討更新或移除規則。 DLP Owner / Data Owner 變更與退場紀錄。

7. DLP通道與控制要求

通道 控制要求 證據
Email 偵測附件、本文、收件人、外部網域、加密狀態與敏感資料，必要時阻擋或加密。 Email DLP政策與告警。
Web / Browser上傳 透過SWG、Proxy、SASE或端點DLP檢查檔案上傳、表單輸入與AI Prompt。 Web DLP報告。
SaaS / Cloud Storage 檢查外部分享、公開連結、個人帳號、同步資料與下載異常。 CASB / Cloud DLP報告。
Endpoint 控制USB、外接硬碟、列印、剪貼簿、截圖、本機複製、藍牙與應用程式外傳。 Endpoint DLP設定。
Network / API 監控未加密傳輸、資料外傳、API大量匯出、異常目的地與非標準協定。 Network DLP / NDR紀錄。
Source Code / Repo 偵測Secrets、PII、客戶資料、受限程式碼與未核准公開Repo。 Repo掃描報告。
CI/CD / Artifact 檢查Build Log、Artifact、Container Image、SBOM與部署輸出是否含敏感資訊。 Pipeline掃描紀錄。
Database / Data Warehouse 監控大量查詢、匯出、Dump、外部共享與未核准資料集建立。 DB Audit / DLP紀錄。
AI / LLM / RAG 檢查Prompt、檔案上傳、模型API請求、RAG檢索結果與Agent工具輸出。 AI DLP告警與審計日誌。
Print / Screenshot 高敏感資料列印、截圖或拍照風險需限制或記錄。 端點DLP/MDM紀錄。

8. DLP規則設計要求

規則項目 最低要求 避免事項
資料定義 規則應明確說明資料類型、Owner、分類、偵測條件與適用通道。 避免使用過度籠統關鍵字造成大量誤判。
偵測精準度 優先使用資料標籤、EDM、文件指紋、格式驗證、上下文與閾值。 避免單一Regex未驗證即阻擋正式流程。
處置動作 需定義Monitor、Alert、User Justification、Encrypt、Quarantine、Block或Escalate。 避免所有事件一律阻擋造成營運中斷。
告警分級 依資料類型、數量、外部目的地、使用者角色、通道與歷史行為分級。 避免無分級導致SOC無法優先處理。
例外條件 應定義可允許之業務目的、收件人、網域、SaaS、使用者群組與期限。 避免永久白名單或全公司例外。
測試樣本 測試樣本不得使用真實高敏感資料，必要時使用遮罩或合成資料。 避免測試資料造成外洩。
隱私最小化 告警展示內容應遮罩敏感資料，僅授權調查者可查看必要內容。 避免告警平台暴露完整PII或Secrets。
版本控管 規則新增、修改、停用與刪除需有版本、核准、測試與回復紀錄。 避免未記錄的臨時變更。

9. DLP告警分級與處置SLA

等級 判定條件 初步處置 處理時限
Critical 大量高機密/PII/客戶資料外傳、Secrets外洩、外部AI輸入、公開分享、惡意帳號或特權使用者異常外傳。 立即阻擋或隔離，升級Incident Response、CISO、Data Owner與DPO。 立即至4小時內初判。
High 機密資料外部Email、未核准雲端上傳、DB大量匯出、原始碼外傳、重要文件公開連結。 阻擋或隔離，通知Owner並調查。 1個工作日內初判。
Medium 內部敏感資料不當分享、低量PII、疑似誤送、使用者正當性待確認。 告警、使用者確認、必要時限制。 3個工作日內初判。
Low 低敏感度資料、測試命中、可解釋業務行為、誤判疑似。 記錄、調校或教育提醒。 依SOC流程處理。
False Positive 經確認非敏感資料或合法業務且規則誤判。 關閉告警並調整規則或白名單。 納入定期調校。
Policy Exception 經核准例外之DLP命中。 確認仍在期限與範圍內，記錄使用。 依例外條件監控。

10. DLP事件調查流程

步驟 作業要求 責任角色 輸出證據
1. 告警接收 接收DLP告警，確認時間、使用者、裝置、資料類型、通道、目的地與處置結果。 SOC 告警紀錄。
2. 分級初判 依資料敏感度、數量、目的地、使用者角色、外部對象與歷史行為分級。 SOC / DLP Owner 分級紀錄。
3. 證據保存 保存告警、日誌、檔案指紋、截圖、Metadata、網路紀錄與相關工單。 SOC / Forensics 證據紀錄。
4. 事實確認 確認是否為誤判、合法業務、核准例外、使用者誤操作或惡意行為。 SOC / Data Owner 調查紀錄。
5. 影響評估 評估資料範圍、資料主體、客戶、法規、合約、AI供應商、外部收件者與可回收性。 Data Owner / DPO / Legal 影響評估。
6. 控制處置 執行阻擋、撤回、刪除、權限撤銷、帳號停用、Secrets輪替、外部通知或隔離端點。 Incident Response / IT 處置紀錄。
7. 通報升級 依事件等級通報CISO、DPO、Legal、管理層、客戶或主管機關。 Incident Manager 通報紀錄。
8. 根因分析 分析規則缺口、流程問題、使用者教育、權限過大、系統設定或惡意行為。 Incident Response / DLP Owner RCA。
9. 改善結案 更新規則、權限、流程、訓練、技術控制與風險登錄後結案。 DLP Owner / ISMS代表 CAPA與結案紀錄。

場景 DLP控制要求 證據

AI供應商 需確認資料不訓練、Prompt保存、區域、刪除、子處理者與事件通報條款。 供應商評估與合約。

12. DLP例外管理

例外情境 最低要求 核准層級 期限與重評
合法業務外部傳輸 需業務目的、資料分類、收件方、加密方式、保存期限與Data Owner核准。 Data Owner / CISO視風險 最長90日或專案期限。
大量資料匯出 需查詢目的、欄位範圍、資料最小化、保存位置、刪除日期與審計日誌。 Data Owner / DPO / CISO 單次或短期。
向AI工具輸入資料 需AI工具核准、資料不訓練、Prompt保存條款、資料遮罩與AI Governance核准。 AI Governance / Data Owner / CISO 最長90日。
供應商資料分享 需合約、DPA、NDA、傳輸加密、使用目的、刪除證明與供應商風險評估。 Supplier Owner / Legal / DPO 合約期間內定期重評。
DLP規則暫停 需說明營運影響、替代控制、停用範圍、期間、監控與回復時間。 CISO / DLP Owner 最長30日。
誤判白名單 需限定使用者、收件者、資料類型、系統與期限。 DLP Owner / Data Owner 每季重評。
安全測試例外 DLP測試或紅隊演練需測試授權、範圍、時間與SOC註記。 CISO / SOC Owner 單次測試。
