1. 作業目的

本作業指導書用於規範組織雲端服務之申請、評估、採購、導入、組態、存取、資料保護、監控、變更、事件應變、供應商監督、營運持續、退場與持續改善作業，確保雲端服務使用符合資訊安全、隱私、法規、合約、營運持續、AI治理與資料治理要求。

本文件特別支援ISO/IEC 27001:2022 Annex A.5.23「Information security for use of cloud services」之落實，並整合A.5.19至A.5.22供應商治理、A.5.12至A.5.14資訊分類與傳輸、A.8系列技術控制與A.5.30 ICT營運持續要求。

2. 作業原則

  • 所有雲端服務不論免費、試用、部門自購、個人註冊、正式採購或由供應商提供，均應納入雲端服務與AI服務清冊並完成必要審查。
  • 雲端服務應採風險導向管理，依服務模式、資料分類、業務重要性、供應商風險、跨境、PII、AI、BCMS與合約要求決定控制強度。
  • 雲端服務應清楚界定共享責任，避免因責任不明導致控制缺口。
  • 未核准雲端服務、個人雲端、公開分享連結或未完成DPA/合約審查之雲端服務不得用於處理內部以上資訊。
  • 所有高風險雲端服務應具備可稽核證據，包括設定、權限、日誌、加密、監控、事件、備份、變更、SLA與供應商審查紀錄。

3. 名詞與定義

名詞 定義
雲端服務 透過網路提供之運算、儲存、應用、平台、資料、AI、網路或安全能力，包括SaaS、PaaS、IaaS、CaaS與Serverless。
共享責任模型 雲端供應商與組織依服務模式分擔實體安全、基礎設施、平台、應用、資料、身份、組態與監控責任之模型。
CSPM Cloud Security Posture Management，用於監控雲端組態、基準、風險與不符合之工具或流程。
CWPP Cloud Workload Protection Platform，用於保護雲端工作負載、容器、VM與Serverless之安全能力。
CASB Cloud Access Security Broker，用於雲端使用可視性、DLP、存取管控與影子IT偵測之工具或流程。
SSPM SaaS Security Posture Management，用於SaaS設定、權限與安全狀態管理之工具或流程。
雲端租戶 組織在雲端服務供應商環境中建立之帳號、訂閱、專案、組織、Tenant或Landing Zone。
Landing Zone 雲端環境初始架構與治理基準，通常包含帳號、網路、身份、日誌、安全、政策與組織結構。
影子IT / 影子雲端 未經組織核准、登錄或監督而使用之雲端服務。
雲端退場 終止雲端服務、移轉資料、撤銷帳號、刪除資料、銷毀金鑰、回收資源與保存證據之活動。

服務Owner / System Owner 負責雲端服務之用途、上線、維運、風險、SLA、供應商與退場。
Data Owner 確認雲端服務處理資料之分類、授權、保留、刪除、跨境與資料保護要求。

供應商管理 / 採購 / 法務 審查雲端供應商、合約、SLA、DPA、NDA、安全條款、稽核權與退場條款。
BCMS / DRP負責人 確認關鍵雲端服務之RTO/RPO、備援、備份、復原與演練。
雲端使用者 遵守雲端服務使用、資料分類、共享、AI輸入、存取與事件通報要求。

5. 雲端服務分類與管理層級

雲端類型 範例 主要風險 最低管理要求
SaaS Email、CRM、ERP、HR、ITSM、文件協作、DMS。 資料外洩、權限過度、外部分享、DPA不足、供應商事件。 SaaS審查、DPA/合約、SSO/MFA、DLP、外部分享控管、SSPM/CASB。
PaaS 資料庫、Kubernetes服務、MLOps、API平台、應用平台。 組態錯誤、權限過高、資料庫暴露、日誌不足、開發安全缺口。 Landing Zone、安全基準、IAM、加密、日誌、CSPM、DevSecOps。
IaaS VM、VPC/VNet、儲存、負載平衡、防火牆、KMS。 網路暴露、未修補工作負載、金鑰管理、儲存桶公開、備份不足。 雲端架構審查、CSPM、CWPP、網路隔離、KMS、備份與監控。
Serverless/CaaS Functions、Containers、Kubernetes、容器登錄。 相依元件弱點、Secrets外洩、權限過度、映像污染、日誌不足。 容器掃描、IaC掃描、最小權限、Secrets管理、映像簽章。
雲端AI/資料平台 AI API、LLM、資料湖、BI、資料倉儲、向量資料庫。 資料訓練誤用、PII外洩、跨境、模型變更、未覆核AI輸出。 AI治理審查、資料限制、DPA、存取控管、輸出覆核、日誌。

8. 雲端服務禁用與限制條件

個人雲端帳號 不得用於儲存、傳輸或共享內部以上資訊。 原則不核准。
公開分享連結 不得用於內部以上資訊，除非經核准且具期限與下載限制。 需Data Owner核准與留痕。
未簽DPA之PII雲端處理 不得上傳或處理PII。 需DPO/法務核准與補救條款。
未核准AI雲端服務 不得輸入內部以上資訊、PII、源碼、金鑰或客戶資料。 需AI治理與CISO核准。
資料地區不可確認 不得處理高機密、PII或受客戶/法規限制資料。 需法務/DPO風險接受。
弱控制免費服務 不得處理機密以上資訊或營運關鍵資料。 需正式採購與安全審查。

11. 雲端身份與存取控制

控制項目 作業要求 證據

13. 雲端資料保護

控制項目 作業要求 證據
資料分類 雲端資料集、儲存桶、資料庫與檔案需標示資料分類與Owner。 資料清冊、標籤報表。

傳輸加密 雲端服務間、用戶端至雲端、API與跨區傳輸需使用TLS或等效加密。 TLS設定、傳輸設計。
金鑰管理 KMS/HSM、客戶自管金鑰、金鑰輪替、存取審查與撤銷需依風險實施。 KMS設定與輪替紀錄。
資料最小化 僅上傳或處理必要資料，避免將高機密或PII放入非必要雲端。 資料流審查。
DLP與外洩防護 SaaS、雲端儲存、郵件與資料平台應視風險啟用DLP/CASB。 DLP/CASB政策與告警。
資料刪除 資料到期、服務終止或目的消失時需安全刪除並保存證據。 刪除紀錄。

映像管理 映像需來源可信、掃描、簽章、版本控制與定期更新。 映像掃描報告。
容器安全 容器需限制特權、掃描弱點、管理Secrets、限制網路與資源。 容器安全報告。
Serverless安全 Serverless需最小權限、輸入驗證、Secrets管理、日誌與逾時限制。 Function設定與日誌。

16. 雲端應用、API與DevSecOps安全

控制項目 作業要求 證據
Secure SDLC 雲端應用開發需納入安全需求、威脅建模、SAST、DAST、SCA與安全測試。 DevSecOps紀錄。
API安全 API需身份驗證、授權、Rate Limit、輸入驗證、日誌與錯誤處理。 API Gateway設定。
CI/CD安全 Pipeline需權限控管、審批、Secrets管理、掃描、簽章與部署日誌。 Pipeline報表。
IaC安全 Terraform、CloudFormation、Bicep或Kubernetes Manifest需掃描與審查。 IaC掃描報告。
Secrets管理 禁止Secrets硬編碼或提交Repo，應使用Vault/KMS/Secret Manager。 Secret Scan報告。
環境隔離 Dev/Test/Prod資料、權限與網路應隔離，測試不得使用未遮罩PII。 環境隔離證據。

17. 雲端日誌、監控與SIEM整合

成本與資源異常 異常建立資源、大量運算、大量資料傳輸或加密貨幣挖礦跡象。 FinOps/SOC聯合監控。
