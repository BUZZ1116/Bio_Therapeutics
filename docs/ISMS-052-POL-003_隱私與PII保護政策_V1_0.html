1. 目的

本政策旨在建立組織對個人可識別資訊（Personally Identifiable Information, PII）與隱私保護之治理原則、責任分工、風險管理、控制要求與稽核證據鏈，以確保組織在蒐集、使用、保存、揭露、委外、跨境傳輸、AI處理、雲端處理與刪除PII時，符合適用法規、合約、資料主體期待、ISO/IEC 27701隱私資訊管理系統要求，以及ISMS對機密性、完整性、可用性與持續改善之要求。

本政策亦作為組織建立PIMS或將PIMS整合至ISMS之政策層文件，用以支持PII controller與PII processor角色判定、PII處理活動管理、資料主體權利保障、委外處理監督、隱私風險評估、個資外洩事件通報、內部稽核與管理審查。

2. 適用範圍

  • 組織全部門、員工、約聘人員、外包人員、供應商、合作夥伴與代表組織處理PII之第三方。
  • 客戶、使用者、員工、應徵者、供應商聯絡人、學員、網站訪客、活動參與者、合作夥伴、資料主體及其他自然人之PII。
  • 紙本、電子、口頭、影像、錄音、影片、日誌、備份、資料庫、雲端平台、SaaS、API、AI工具、資料湖、資料倉儲、測試環境與行動裝置中之PII。
  • 組織作為PII controller、PII processor、joint controller、sub-processor或AI服務角色時之PII處理活動。
  • 涉及AI系統、生成式AI、RAG、資料分析、自動化決策、個人化推薦、客戶服務、HR、CRM、Moodle、教育訓練、稽核、驗證、顧問服務與雲端服務之PII處理。

4. 名詞與定義

名詞 定義
PII Personally Identifiable Information，個人可識別資訊，指可直接或間接識別特定自然人之任何資訊。
資料主體 PII所關聯、可被識別或可識別之自然人。
PII controller 決定PII處理目的與方法之組織或單位。
PII processor 依PII controller指示代表其處理PII之組織或單位。
Joint controller 共同決定PII處理目的與方法之多個組織或單位。
Sub-processor 受PII processor委託而進一步處理PII之第三方。
PII處理 對PII進行蒐集、記錄、組織、結構化、儲存、調整、查詢、使用、揭露、傳輸、共享、合併、限制、刪除或銷毀之任何活動。
敏感PII 依法律、合約或組織分類認定需較高保護之PII，例如身分證明、健康、財務、兒少、精準位置、生物特徵、帳號憑證或特殊類別資料。
隱私風險 PII處理活動對資料主體權利、自由、合理期待、組織合規、聲譽或營運造成不利影響之不確定性。
去識別化 降低資料識別特定自然人可能性之處理方式，但仍可能在特定條件下重新識別。
匿名化 使資料無法合理識別資料主體，且不可逆或重新識別風險極低之處理方式。
資料最小化 僅蒐集與處理達成特定、明確且合法目的所必要之PII。
個資外洩 PII發生未授權揭露、存取、取得、使用、變更、遺失、刪除、破壞或其他違反安全要求之事件。
跨境傳輸 將PII傳輸、遠端存取、託管或提供至其他司法管轄區之行為。
自動化決策 以AI、演算法或自動化處理對資料主體產生法律效果或重大影響之決策或決策輔助活動。
DPIA / PIA 資料保護或隱私影響評估，用於評估PII處理活動對資料主體權利與組織合規造成之風險與控制需求。

5. 政策聲明

最高管理階層承諾，組織應以合法、公平、透明、目的限制、資料最小化、正確性、保存限制、完整性與保密性、責任可證明性及風險導向為核心原則保護PII。組織不得以便利、效率、業務需求、AI工具可用性或供應商標準條款為由，降低對PII之保護要求。

任何PII處理活動均應具有明確目的、適當權責、合法基礎、資料分類、風險評估、必要控制、保存期限、刪除或匿名化安排，以及可供稽核與管理審查之紀錄。

6. 隱私保護原則

隱私原則 政策要求 主要證據
合法、公平與透明 PII處理應具有合法、明確且正當之目的，並向資料主體提供清楚、易懂且可取得之隱私告知。 合法基礎判定、隱私告知、同意紀錄。
目的限制 PII不得以不相容目的進行後續處理，目的變更應重新評估合法性、告知與同意需求。 PII處理活動清冊、目的變更評估。
資料最小化 PII蒐集與處理應限於達成目的所必要之範圍，避免過度蒐集、過度保存或過度共享。 資料項目審查、最小化評估、資料共享核准。
正確性 PII應維持正確性與完整性，並提供合理更正機制。 更正紀錄、資料品質檢查。
保存限制 PII保存期限應依法律、合約、業務與風險要求定義，屆期應刪除、銷毀、匿名化或封存。 保存期限清冊、刪除/銷毀/匿名化紀錄。
完整性與保密性 PII應依資訊分類、存取控制、加密、日誌、備份、傳輸保護、端點安全與實體安全要求保護。 分類分級、權限紀錄、加密、日誌、備份證據。
委外與跨境可控 PII之委外處理、雲端託管、AI處理與跨境傳輸應事前審查並建立合約與監督機制。 供應商評估、DPA、跨境評估、持續監督。
高風險先評估 涉及高風險處理、敏感PII、大規模處理、自動化決策、AI分析、兒少資料或跨境傳輸者，應執行隱私風險評估。 隱私風險評估表、風險處理計畫。
責任可證明性 組織應保存足以證明遵循本政策及PIMS要求之紀錄。 紀錄保存、稽核證據、管理審查輸入。

角色 主要責任
最高管理階層 核准隱私與PII保護政策、重大隱私風險接受、重大個資外洩事件處理、資源配置與管理審查決議。
ISMS管理代表 確保PII保護要求納入ISMS範圍、風險管理、SoA、控制措施、稽核與管理審查。
隱私保護負責人 / DPO 維護PIMS要求、監督PII處理活動、隱私風險評估、資料主體權利、委外與跨境、個資外洩通報及隱私教育訓練。
PII controller負責人 決定PII處理目的與方法，確認合法基礎、告知、權利保障、風險評估、委外監督與資料刪除。
PII processor負責人 依controller指示處理PII，落實合約要求、安全控制、事件通報、子處理者管理與處理紀錄。
資料擁有人 核准PII使用目的、資料分類、存取權限、保存期限、共享與刪除要求。
系統擁有人 確保處理PII之系統具備存取控制、日誌、加密、備份、弱點管理、變更管理與事件回應能力。
AI系統擁有人 確認AI使用PII之目的、資料最小化、輸出風險、人工覆核、資料主體權利支援與AI供應商管理。
採購 / 供應商管理單位 確保委外處理、雲端服務及AI服務供應商完成隱私與資安審查並簽署必要合約條款。
全體員工與外包人員 依核准目的與權限處理PII，不得未授權揭露、下載、複製、傳輸、輸入AI工具或保存PII，並應通報疑似事件。
內部稽核員 依稽核方案查核PIMS、PII處理活動、隱私風險、資料主體權利、委外處理與個資外洩處理證據。

10. 合法性、告知與同意管理

  • PII處理應確認合法基礎，並於清冊或相關紀錄中保存判定結果。
  • 隱私告知應以清楚、易懂、可取得之方式提供，內容至少包括處理目的、資料類型、使用方式、共享對象、保存期間、資料主體權利、聯絡窗口及其他法規要求事項。
  • 如PII處理依賴同意，應確保同意為可證明、可撤回、具體、知情且自由作成；撤回同意後應停止相關處理，除非另有合法基礎。
  • 如處理目的、資料類型、共享對象、跨境傳輸或AI使用方式有重大變更，應重新評估是否需更新告知或取得同意。
  • 不得以預設勾選、模糊條款、捆綁同意或不當壓力取得資料主體同意。

11. 資料主體權利管理

組織應建立資料主體權利請求處理機制，確保資料主體可依適用法規與合約要求行使權利。

權利類型 處理要求 證據要求
查詢與存取 確認請求人身分與權利範圍，於規定期限內提供可允許揭露之PII或處理資訊。 請求紀錄、身分確認、回覆紀錄。
更正 資料主體提出錯誤或不完整PII時，應依合理程序更正並通知必要接收者。 更正紀錄、通知紀錄。
刪除 符合法規、合約或目的達成條件時，應刪除或匿名化PII；若依法需保存，應限制處理。 刪除紀錄、限制處理紀錄。
限制處理 在爭議、合法性待釐清或資料主體要求情況下，應限制特定PII處理。 限制設定、處理紀錄。
反對處理 資料主體反對特定目的處理時，應評估合法性與是否停止處理。 評估紀錄、回覆紀錄。
資料可攜 適用時應以結構化、常用且機器可讀格式提供資料。 匯出紀錄、交付紀錄。
自動化決策申訴 涉及自動化決策或AI高影響處理時，應提供人工覆核、說明與申訴管道。 覆核紀錄、申訴處理紀錄。

12. PII分類、存取控制與保護措施

PII應納入資訊分類分級與資產管理，並依敏感度、處理規模、法規要求與風險等級採取適當控制措施。

控制主題 最低要求 證據要求
分類與標示 PII應依公開、內部、機密、高度機密、敏感PII或特殊類別資料進行分類與標示。 分類分級表、資料標示紀錄。
存取控制 僅授權人員可基於業務必要存取PII，並應定期審查權限。 權限申請、存取審查紀錄。
加密 PII於傳輸、儲存、備份及可攜媒體中應依風險採用適當加密。 加密設定、金鑰管理紀錄。
遮罩與去識別化 測試、訓練、分析、AI使用及共享前應優先使用遮罩、去識別化、匿名化或合成資料。 遮罩紀錄、匿名化方法紀錄。
日誌與監控 PII系統應記錄存取、下載、匯出、管理者活動與異常行為。 日誌設定、監控告警紀錄。
資料外洩防護 應依資料敏感度導入DLP、匯出限制、郵件與雲端共享管制。 DLP政策、阻擋或告警紀錄。
備份與復原 PII備份應受保護，並在刪除、保存期限與資料主體權利管理中納入考量。 備份設定、復原測試紀錄。
實體與媒體安全 紙本、媒體、設備與可攜儲存裝置中之PII應安全保存、傳遞、銷毀。 媒體清冊、銷毀紀錄。

13. 委外處理、供應商與跨境傳輸

凡第三方代表組織處理PII，或組織代表客戶處理PII，應明確約定角色、責任、處理目的、處理指示、安全措施、子處理者、事件通報、資料返還、刪除、稽核權與跨境要求。

主題 政策要求 證據要求
供應商審查 委外處理PII前應評估供應商資安、隱私、合規、資料位置、子處理者與事件通報能力。 供應商評估表、審查紀錄。
資料處理協議 應簽署DPA或具同等效力之資料處理條款，載明處理目的、指示、安全措施、保密與刪除要求。 DPA、合約條款檢核表。
子處理者 供應商使用子處理者應事前告知或取得核准，並確保同等保護義務。 子處理者清單、核准紀錄。
跨境傳輸 跨境傳輸應確認目的地、法規要求、保障措施、資料主體告知與風險評估。 跨境評估、保障條款。
服務終止 合約終止或目的完成後，供應商應依要求返還、刪除或銷毀PII並提供證明。 刪除證明、返還紀錄。
持續監督 重大PII供應商應定期重新審查安全控制、稽核報告、事件紀錄與合約遵循。 年度審查紀錄、改善追蹤。

14. AI系統與自動化處理之隱私要求

  • 使用PII進行AI訓練、微調、RAG、分析、分類、推薦、摘要或自動化決策前，應確認合法基礎、目的相容性與資料最小化。
  • 不得將PII輸入未核准之外部生成式AI、聊天機器人、翻譯工具、摘要工具或AI API。
  • AI輸出若可能揭露PII、推論敏感屬性、造成不公平影響或作成重大決策，應建立人工覆核與申訴機制。
  • AI系統使用PII之Prompt、RAG知識庫、向量資料庫、日誌與模型輸出應依PII分類與保存期限管理。
  • AI模型不得在未授權情況下以客戶PII或資料主體PII進行再訓練或供應商模型改善。
  • 涉及自動化決策、個人化推薦、信用、聘僱、教育評估、保險、醫療或其他高影響情境，應執行DPIA/PIA並取得適當核准。

15. 測試資料、開發環境與資料分析

  • 開發、測試、教育訓練、展示、模型驗證或資料分析應優先使用合成資料、匿名化資料或遮罩資料。
  • 使用正式PII作為測試資料須具明確業務必要性、風險評估、資料擁有人核准、存取限制、保存期限與刪除紀錄。
  • 開發、測試與正式環境應區隔，測試環境不得使用與正式環境相同之高權限帳號或未受保護之PII。
  • 測試資料不得複製至個人裝置、未核准雲端、外部AI工具或未受控儲存位置。
  • 測試完成後應依核准期限刪除測試PII並保存刪除紀錄。

16. 個資外洩與隱私事件管理

任何疑似或確認之PII未授權存取、揭露、遺失、破壞、竄改、誤寄、誤上傳、未授權AI輸入、供應商事件、雲端設定錯誤或資料主體權利處理失誤，均應依日誌、監控與事件偵測作業指導書及不符合與矯正措施管理程序處理。

事件階段 要求 輸出 / 證據
發現與通報 員工、供應商或系統偵測疑似PII事件時，應立即通報指定窗口。 事件通報紀錄。
初步分類 判定是否涉及PII、資料主體數量、資料類型、敏感度、外洩範圍與是否需升級。 事件分類紀錄。
遏止與保存證據 立即限制外洩來源、撤銷存取、隔離系統、保全日誌與證據。 處置紀錄、日誌與證據。
風險評估 評估對資料主體權利、財務、身分盜用、歧視、聲譽、合規與客戶合約之影響。 外洩風險評估。
通報與通知 依法律、合約與客戶要求判定是否通知主管機關、客戶、資料主體或其他關注方。 通報決策、通知紀錄。
復原與改善 完成資料復原、權限修正、供應商改善、控制補強與必要CAPA。 復原紀錄、CAPA。

17. 教育訓練與認知

  • PII定義、資料分類、敏感PII及常見個資外洩情境。
  • 合法蒐集、目的限制、資料最小化、告知、同意與保存期限。
  • 資料主體權利請求處理流程。
  • PII不得輸入未核准AI工具或未受控雲端服務之要求。
  • PII傳輸、共享、委外、跨境與供應商管理要求。
  • 個資外洩通報時限、通報窗口與初步處置要求。
  • 開發、測試、資料分析與AI系統使用PII之特殊限制。

19. 違反政策之處理

違反本政策之行為，包括未經授權蒐集或使用PII、超出目的處理、未授權揭露、未依程序委外、未經核准跨境傳輸、將PII輸入未核准AI工具、逾期保存、未通報個資外洩或不當處理資料主體權利請求者，應依日誌、監控與事件偵測作業指導書、不符合與矯正措施管理程序、持續改善管理程序、合約條款及適用法規處理。

22. 政策流程圖

  1. 識別PII處理需求、業務流程、系統或AI應用。
  2. 判定PII角色、資料主體、PII類型、處理目的與合法基礎。
  3. 登錄PII處理活動清冊並確認PIMS範圍。
  4. 建立或更新隱私告知、同意機制及資料主體權利處理管道。
  5. 依風險判定是否執行DPIA/PIA或隱私風險評估。
  6. 選擇並實施存取控制、分類標示、加密、日誌、遮罩、保存期限與刪除控制。
  7. 若涉及委外、雲端、AI服務或跨境傳輸，執行供應商與跨境審查並簽署必要合約。
  8. 正式處理PII並執行監控、權限審查、事件通報與資料主體權利回應。
  9. 定期檢視PII處理活動、風險、供應商、保存期限與控制有效性。
  10. 將隱私績效、事件、稽核發現、重大風險與改善需求納入管理審查。
  11. 依稽核、事件、權利請求、法規變更與管理審查結果執行CAPA與持續改善。
