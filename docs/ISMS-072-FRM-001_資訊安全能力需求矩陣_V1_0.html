1. 表單目的

本矩陣用於系統性定義、盤點、評估與追蹤ISMS相關角色所需之資訊安全能力，確保在組織控制下工作之人員具備其職務、權限、風險、控制責任、法規合約義務、隱私、AI、備份、備援、復原、GHG/CO2資料治理、雲端供應鏈及稽核活動所需能力。

本矩陣支援ISO/IEC 27001:2022 Clause 7.2 Competence與Clause 7.3 Awareness之符合性證據，並可作為年度教育訓練計畫、角色別訓練、能力缺口分析、資源管理、CAPA及管理審查輸入之依據。

2. 適用時機

  • 年度ISMS能力盤點、年度訓練計畫建立及管理審查前。
  • 新進、轉任、升遷、離職交接、重大職責調整或新增關鍵角色時。
  • 重大變更、AI系統導入、PII處理變更、雲端服務導入、備份/備援/復原調整、GHG/CO2資料治理要求改變或供應商模式改變時。
  • 事件、違規、稽核不符合、客戶稽核缺失、CAPA或PIR發現能力不足時。
  • 法規、標準、客戶合約、主管機關要求或驗證機構要求改變時。

3. 名詞與定義

名詞 定義
能力需求矩陣 用於記錄角色、所需能力、現有能力、缺口、訓練需求、證據與有效性評估之表單。
能力等級 對人員在特定能力領域之熟練程度判定，可分為L0未具備、L1了解、L2可執行、L3可獨立負責、L4可指導/審查。
關鍵角色 對ISMS、風險、控制、事件應變、隱私、AI、復原、供應商或稽核具有重大影響之角色。
能力缺口 現有能力與職務所需能力之差距，可能導致控制失效、風險升高或不符合。
能力證據 可證明能力之訓練紀錄、測驗、證照、經驗、演練、實作、稽核見習、績效或主管確認。
補強措施 為縮小能力缺口而採取之訓練、指導、外部課程、證照、工作坊、實作演練、代理或外部支援。
有效性確認 確認能力補強後是否能實際改善工作表現、控制執行、風險處理或稽核結果之活動。

4. 能力等級定義

等級 名稱 定義 可接受證據 適用情境
L0 未具備 尚未具備該能力，無法獨立執行相關工作。 尚無訓練或實作證據。 新進、轉任或未接觸角色。
L1 了解 理解基本概念、政策、流程與通報要求，但需他人指導。 完成認知訓練、測驗通過。 一般員工、初階角色。
L2 可執行 能依既定程序執行工作，必要時需主管或專家確認。 操作紀錄、作業紀錄、測驗、主管確認。 一般控制執行者。
L3 可獨立負責 能獨立規劃、執行、判斷與保存證據，並能處理例外。 實務經驗、專案/稽核/事件紀錄、有效性證據。 Owner、主管、關鍵角色。
L4 可指導/審查 能設計制度、審查他人成果、指導他人並改善管理系統。 證照、稽核經驗、授課、審查紀錄、管理審查輸入。 CISO、ISMS代表、稽核主管、專家角色。
