1. 作業目的

本作業指導書用於規範組織資訊於內部、外部、雲端、供應商、AI服務、系統介接、資料交換、備份復原、遠距工作與跨境情境下之安全傳輸要求，確保資訊在傳輸過程中維持機密性、完整性、可用性、可追溯性與合法合規性。

本文件同時提供各種傳輸通道之允許使用情境、加密要求、核准要求、日誌與監控要求、傳輸前檢核、傳輸中防護、傳輸後確認、事件通報與證據保存要求，以支援ISO/IEC 27001:2022 Annex A.5.14「Information transfer」及相關控制。

2. 作業原則

  • 所有資訊傳輸應基於授權、業務必要、最小揭露、最小資料量、最短必要期間及可追溯性原則。
  • 機密、高機密、PII、客戶資料、AI輸入輸出、金鑰、源碼、事件證據、稽核證據及GHG/CO2查證資料之傳輸應使用核准安全通道。
  • 跨組織、跨供應商、跨雲端、跨境、跨系統或跨安全域傳輸應事前確認資料分類、收件方、傳輸目的、保護措施與責任歸屬。
  • 不得使用個人信箱、個人雲端、未核准即時通訊、未加密可攜式媒體、公開分享連結或未核准AI服務傳輸內部以上資訊。
  • 傳輸異常、誤傳、未授權接收、外洩疑慮或安全控制失效時，應立即通報SOC、主管、Data Owner與相關專項Owner。

3. 名詞與定義

名詞 定義
資訊傳輸 資訊於人員、系統、組織、平台、地區、設備或媒介間之傳送、共享、複製、同步、匯出、匯入或交換。
受控傳輸 使用核准通道、身份驗證、授權、加密、完整性檢查、日誌與監控之資訊傳輸。
外部傳輸 資訊傳送至組織外部收件人、供應商、客戶、雲端服務、AI服務、主管機關或第三方。
跨境傳輸 資訊由一個司法管轄區傳送、存取或儲存至另一司法管轄區。
MFT Managed File Transfer，受控檔案傳輸平台，支援加密、身份驗證、傳輸紀錄、到期與稽核。
SFTP Secure File Transfer Protocol，使用SSH保護之檔案傳輸協定。
API資料交換 系統間透過API進行資料傳輸、查詢、同步或事件推送。
DLP Data Loss Prevention，資料外洩防護技術或流程，用於偵測、阻擋、告警或稽核敏感資料傳輸。
完整性檢查 透過雜湊、簽章、校驗碼、交易筆數、檔案大小、批次總額或對帳確認資料未被未授權變更。
傳輸Owner 對特定傳輸活動之目的、資料範圍、收件人、控制措施與風險承擔負責之角色。

8. 傳輸中安全控制

控制類型 控制要求 適用情境
身份驗證 收件人、系統、API、服務帳號或供應商需完成身份驗證。 所有機密以上或系統介接傳輸。
傳輸加密 使用TLS 1.2以上、SFTP、MFT、VPN、mTLS、PGP或等效安全通道。 機密以上、PII、跨境與外部傳輸。
完整性保護 使用雜湊、簽章、檔案大小、筆數、批次總額或對帳機制。 批次資料、財務資料、GHG資料、系統同步。

傳輸限制 限制下載、轉寄、複製、公開分享、到期日與地區存取。 雲端分享、DMS、受控文件。

錯誤處理 傳輸失敗、部分成功或異常回應需記錄、告警與補救。 API、批次、MFT、資料同步。

10. 電子郵件傳輸安全作業

情境 作業要求 禁止事項
內部郵件 依分類標示主旨或附件，避免不必要轉寄與大量附件。 不得濫寄、轉寄無必要資料。
外部郵件 確認收件人、目的、附件、分類與核准，必要時使用加密或受控連結。 不得使用個人信箱或未確認收件人。
機密附件 附件加密或改用受控分享；密碼需分離通道傳送。 不得以同一封郵件寄送密碼與附件。
高機密資料 原則上不用郵件附件，應使用MFT/DMS並由CISO核准。 不得以一般附件寄送。
PII資料 確認DPO/流程要求、合法目的、最小化與加密。 不得寄送完整PII清冊給未授權對象。
郵件群組 使用群組寄送前需確認成員與外部人員。 不得將機密資料寄至未維護群組。

PII資訊 僅可分享最小必要且已遮罩資料。 不得傳送敏感PII或大量PII。
AI輸出 需標示AI Output與Human Review狀態。 不得傳播未覆核AI輸出作為正式結論。
群組管理 定期審查群組成員，專案結束後封存或移除。 不得保留無必要外部成員。

28. 誤傳、外洩與異常處理

異常情境 立即處置 通報對象 後續要求
寄錯收件人 停止後續傳輸，要求收件方刪除，不得隱匿。 SOC、Data Owner、主管；PII時DPO 事件判定、影響評估、CAPA。
公開分享連結 立即撤銷連結、檢查存取紀錄。 SOC、Data Owner 確認下載者與資料範圍。
未授權外部下載 暫停權限、保留日誌、啟動事件調查。 SOC、CISO 根因分析與補救。
傳輸中斷或失敗 停止重送前確認原因，避免重複或不完整資料。 System Owner、IT 重傳與對帳。
API異常大量輸出 限制Token、阻斷來源、分析日誌。 SOC、System Owner 事件調查、金鑰輪替。
AI服務疑似外洩 停止使用服務，保全紀錄，要求供應商刪除或隔離。 AI治理、SOC、DPO（如涉及PII） 風險評估與供應商追蹤。
可攜式媒體遺失 立即通報，確認加密與資料內容。 SOC、CISO、Data Owner 事件判定、通知與CAPA。
