1. 程序目的

本程序用於建立、實施、維持與持續改善組織資訊安全認知管理機制，使所有在組織控制下工作之人員能理解資訊安全政策、資訊安全目標、個人責任、資料保護要求、事件通報義務、社交工程防護、隱私保護、AI安全使用、備份/備援/復原、供應鏈安全、GHG/CO2資料治理與不符合後果。

本程序作為ISO/IEC 27001:2022 Clause 7.3 Awareness與Annex A.6.3之核心符合性證據，並支援Clause 7.2能力、7.4溝通、7.5文件化資訊、9.1績效評估、9.2內部稽核、9.3管理審查及10.2矯正措施。

3. 名詞與定義

名詞 定義
資訊安全認知 人員對資訊安全政策、目標、責任、風險、控制要求、通報義務與不符合後果之理解、重視與實際行為表現。
認知管理 規劃、執行、監督、評估與改善資訊安全認知活動之系統化管理過程。
認知活動 包含公告、短課程、微學習、海報、電子報、案例分享、演練、社交工程測試、測驗、問卷與工作坊等活動。
社交工程演練 透過模擬釣魚郵件、惡意連結、假登入頁、QR碼、語音詐騙或深偽情境，評估人員辨識與通報能力之活動。
認知有效性 認知活動是否實際改善人員行為、降低風險、增加通報、減少違規或改善KPI/KRI之程度。
高風險族群 因職務、權限、資料處理、系統存取、AI工具使用或外部接觸而具有較高資訊安全風險暴露之人員群組。
事件後認知補強 事件、違規、稽核發現或演練失敗後，針對特定人員或群組進行之認知再教育。

4. 認知管理原則

原則 說明 管理要求
全員參與 資訊安全是所有人員共同責任，不限於IT或資安部門。 全體人員需定期接受資訊安全認知宣導與確認。
風險導向 認知活動應優先處理高風險行為、高風險角色與近期威脅。 活動主題需連結風險登錄、事件、稽核與KPI/KRI。
角色導向 不同角色需接受符合其職務、權限與責任之認知內容。 管理員、PII處理者、AI使用者、供應商需有角色化內容。
行為導向 認知管理不僅追求完成率，更需促成安全行為。 透過社交工程演練、情境測驗、通報率與事件趨勢評估成效。
持續改善 認知主題與方法應隨威脅、法規、技術與事件變化更新。 每年至少檢討一次，重大事件或變更後即時更新。
可稽核性 認知活動需保留計畫、教材、對象、完成、測驗、演練與改善證據。 紀錄需可追溯至活動、群組、結果與後續處置。
