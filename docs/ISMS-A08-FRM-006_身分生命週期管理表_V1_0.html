1. 填寫說明與管理原則

本表單用於完整記錄身分從申請、建立、啟用、異動、停用、撤權、歸檔到刪除之生命週期。填寫時應確認身分來源、聘僱或合約狀態、業務角色、系統Owner、資料分類、權限基準、MFA/PAM要求、到期日與撤權責任。任何未具有效Owner、未經核准、無業務必要性、無期限、未納管或無法追溯之身分，均不得建立或持續保留。

  • 人員身分應以HR或授權人員主資料為來源；供應商身分應以合約、工單、採購或供應商Owner確認為來源。
  • 帳號與權限應依最小權限、Need-to-know、職務分離、資料分類與系統風險設定。
  • 臨時帳號、供應商帳號、特權帳號、Break-glass帳號、服務帳號與API Token必須設定Owner、用途、期限、監控與撤銷條件。
  • 離職、異動、合約終止、專案結束或供應商退場時，應即時撤銷不再需要之帳號、Token、憑證、群組、角色、裝置與實體存取。
  • 所有建立、異動、撤權、刪除與例外均應留下工單、核准、系統紀錄或其他可稽核證據。
