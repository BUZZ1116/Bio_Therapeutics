1. 作業目的

本作業指導書規範組織網頁過濾之政策、分類、設定、監控、例外、事件處理、日誌保存、隱私保護、遠端工作、供應商、SaaS與AI服務存取管制要求，確保員工、承包商及系統於使用企業網路或受管理端點進行網頁存取時，能有效降低惡意網站、釣魚網站、惡意下載、命令與控制連線、資料外洩、違規雲端服務、未核准AI工具、成人/賭博/非法內容、濫用頻寬及法規/合約違反之風險。

本文件旨在將網頁過濾作為深度防禦的一部分，與端點安全、DNS安全、Firewall、Proxy、SASE/SSE、CASB、DLP、日誌監控、事件回應、AI工具與資料使用政策及使用者教育訓練整合，建立可管理、可稽核、可例外核准且可持續改善之網頁存取控制機制。

2. 作業原則

  • 網頁過濾應依業務必要性、資料風險、使用者角色、裝置狀態、網路位置、威脅情報、網站分類及法規合約要求採風險導向管理。
  • 惡意、釣魚、命令與控制、惡意軟體、非法內容、已知資料外洩、匿名代理、未核准檔案分享、未核准AI工具及高風險未知分類網站應預設阻擋或受限制。
  • 網頁過濾例外應具備申請、風險評估、Owner、期限、補償控制、核准與定期重評，不得以永久白名單取代安全審查。
  • 網頁存取日誌應以安全、合規與事件調查為目的，依最小必要原則保存及使用，避免不必要侵犯個人隱私。
  • 遠端工作、BYOD或供應商存取情境應透過受管理端點、VPN/ZTNA、SASE/SSE、DNS安全或等效方式維持網頁過濾控制。
  • 涉及AI服務、SaaS、雲端儲存、開發者工具、程式碼分享與資料上傳之網站，應與DLP、CASB及AI資料使用政策連動。

3. 名詞與定義

名詞 定義
網頁過濾 依URL、網域、IP、網站分類、內容、信譽、檔案類型、使用者、裝置或風險條件，允許、阻擋、警示、隔離或記錄網頁存取之控制措施。
Secure Web Gateway（SWG） 安全網頁閘道，用於檢查、過濾、記錄與控制HTTP/HTTPS網頁流量。
DNS Security 透過DNS解析層阻擋惡意網域、釣魚、C2、DGA或高風險查詢之控制措施。
CASB Cloud Access Security Broker，雲端存取安全代理，用於管控SaaS、雲端服務及資料上傳下載風險。
SASE / SSE Secure Access Service Edge / Security Service Edge，整合網路與安全存取能力之架構或服務。
Browser Isolation 瀏覽器隔離，將高風險網站於隔離環境中開啟，降低惡意內容對端點之影響。
URL分類 依網站內容、用途、風險、信譽及業務需求對URL或網域進行分類。
例外清單 經核准允許、暫時允許或特定條件允許存取之URL、網域、分類或使用者清單。
封鎖清單 因惡意、違規、高風險或不符合政策而禁止存取之URL、網域、IP或分類清單。
未知分類網站 尚未被威脅情報或URL分類服務判定類別之網站，通常需採限制、警示或隔離策略。
SSL/TLS檢查 在符合法規、隱私與技術可行性前提下，對加密網頁流量進行安全檢查之機制。
AI服務存取控制 針對生成式AI、模型API、AI寫作、程式碼生成、影像生成、RAG或AI SaaS工具之網頁存取與資料上傳管控。

4. 角色與責任

角色 主要責任 主要輸出 / 證據
CISO / 資訊安全負責人 核准網頁過濾策略、高風險例外、重大封鎖/開放決策與管理審查輸入。 政策核准、風險接受、管理審查紀錄。
Network Security Owner 設計、維護Proxy、SWG、DNS Security、Firewall、SASE/SSE與網路層過濾規則。 規則設定、網路圖、變更紀錄。
Endpoint Security Owner 確保端點、瀏覽器、行動裝置與遠端工作環境套用網頁過濾與防護。 端點設定、MDM/EDR紀錄。
SOC / Monitoring Owner 監控網頁存取異常、惡意連線、封鎖事件、資料外傳、AI服務濫用與告警。 SIEM告警、調查紀錄。
IT Helpdesk 受理使用者網頁存取問題、例外申請初步資訊收集與教育提醒。 服務單、使用者回覆紀錄。
Data Owner / DPO 審查涉及PII、客戶資料、日誌監控、SSL檢查、DLP與跨境資料傳輸之隱私與資料保護風險。 DPIA、隱私審查。
AI Governance Owner 審查AI工具、模型服務、Prompt平台、AI API與AI SaaS之存取與資料上傳要求。 AI工具核准清單、風險評估。
HR / Compliance Owner 協助使用者可接受使用、違規處理、教育訓練與勞動/合規要求。 教育訓練、違規處理紀錄。
System / Business Owner 提出業務所需網站、SaaS或AI服務例外，承擔業務風險與使用控管責任。 例外申請與核准。
Supplier Management 確保供應商與承包商使用組織網路或資料時遵守網頁過濾與資料保護要求。 合約條款、供應商紀錄。
Internal Auditor 抽查網頁過濾策略、例外、日誌、事件、使用者訓練與控制有效性。 稽核底稿、稽核發現。

5. 網頁過濾政策分類與建議處置

網站 / 流量分類 預設處置 處置說明 例外要求
惡意軟體、C2、釣魚、詐騙、憑證竊取 阻擋 立即封鎖並產生安全告警。 原則不得例外；若為誤判需SOC與CISO核准。
已知惡意下載、惡意廣告、Drive-by Download 阻擋 阻擋下載與存取，必要時隔離端點。 需威脅情報確認後處理。
匿名代理、Tor、規避工具、未核准VPN 阻擋 避免繞過監控、DLP與地理限制。 高風險例外需CISO核准。
非法內容、賭博、成人、仇恨、暴力極端內容 阻擋 依法律、合規與公司政策阻擋。 原則不得例外。
未核准雲端儲存與檔案分享 阻擋或限制 避免資料外洩與未授權分享。 需Data Owner與Security核准。
未核准AI工具與生成式AI平台 阻擋或限制 避免Prompt、原始碼、PII、客戶資料或Secrets外洩。 需AI Governance與CISO核准。
社群媒體、影音串流、遊戲、娛樂 依角色限制或警示 依業務與頻寬需求控制。 業務用途需Owner核准。
開發者工具、程式碼平台、套件倉庫 允許但監控 允許核准工具，監控Secrets與惡意套件風險。 高風險下載或上傳需DLP/CASB。
金融、政府、教育、醫療與客戶網站 允許 依業務需求允許，仍需威脅檢查。 特殊限制依風險設定。
未知分類、新註冊網域、高風險地區網站 警示、隔離或阻擋 依威脅情報、使用者角色與裝置健康決定。 需短期例外與重評。
個人Email與個人雲端 阻擋或限制上傳 降低資料外傳與憑證釣魚風險。 業務需要需核准。
AI模型API與開發測試端點 限制或允許核准清單 需檢查資料不訓練、API Key、用量與DLP。 需AI與Data Owner核准。

6. 網頁過濾作業流程

階段 作業要求 責任角色 輸出證據
1. 需求與風險識別 識別網頁過濾需求、使用者群組、業務例外、資料外傳、AI/SaaS與遠端工作情境。 Network Security / Business Owner 需求與風險紀錄。
2. 策略設計 定義網站分類、允許/封鎖規則、SSL檢查、檔案下載、上傳管控與告警條件。 Network Security / SOC / CISO 策略設計文件。
3. 隱私與合規審查 涉及SSL檢查、使用者行為監控、PII日誌與跨境傳輸時需審查。 DPO / Legal / HR 隱私與合規審查。
4. 設定與部署 於Proxy、SWG、DNS Security、CASB、SASE/SSE、Firewall與端點套用策略。 Network Security / Endpoint Security 設定與變更紀錄。
5. 測試與驗證 測試封鎖、允許、警示、隔離、日誌、DLP、例外與遠端情境。 SOC / QA / IT 測試報告。
6. 使用者溝通 公告可接受使用規範、阻擋頁面說明、例外申請流程與AI工具限制。 HR / IT / Security 公告與教育紀錄。
7. 監控與事件處理 監控惡意連線、封鎖事件、資料外傳、異常瀏覽與規避嘗試。 SOC / Incident Response 告警與事件紀錄。
8. 例外管理 評估、核准、設定、到期、重評與關閉例外。 CISO / Network Security 例外紀錄。
9. 定期審查 審查策略有效性、分類誤判、例外清單、日誌保存與KPI/KRI。 CISO / ISMS代表 審查紀錄。

7. 技術架構與控制要求

控制領域 最低要求 證據
Secure Web Gateway 應對HTTP/HTTPS流量進行URL分類、惡意內容檢查、檔案下載控制與日誌記錄。 SWG設定與報告。
DNS Security 應阻擋惡意網域、C2、DGA、釣魚、新註冊高風險網域與未知惡意查詢。 DNS安全報告。
Proxy / SASE / SSE 使用者無論在辦公室或遠端均應套用一致策略或等效補償控制。 Proxy/SASE設定。
Firewall / Egress控制 重要網段、伺服器與正式環境出站網頁流量應限制目的地與必要服務。 Firewall規則。
CASB / SaaS控制 對雲端儲存、SaaS、AI服務與個人帳號使用應識別、限制與監控。 CASB報告。
DLP整合 檔案上傳、表單提交、Prompt輸入與雲端分享應依資料分類套用DLP。 DLP事件報告。
Browser Isolation 對高風險但業務必要之網站可採隔離瀏覽、唯讀、禁止剪貼或下載。 隔離策略設定。
SSL/TLS檢查 在合法、透明、最小必要與隱私審查通過之前提下，對高風險流量進行檢查。 審查紀錄與組態。
端點代理 受管理端點應安裝網頁過濾代理或使用等效流量導向控制。 EDR/MDM報告。
日誌集中化 關鍵網頁存取、封鎖、例外、DLP與惡意事件應接入SIEM或集中平台。 SIEM接入證據。

8. 使用者、角色與情境化政策

使用者 / 情境 政策要求 補充控制
一般員工 套用標準URL分類、惡意網站阻擋、未核准雲端與AI工具限制。 教育訓練與阻擋頁面說明。
特權使用者 加強惡意網站阻擋、未知網站限制、下載掃描與日誌監控。 PAM、EDR、MFA與行為分析。
開發人員 允許核准開發者網站、套件倉庫與技術文件，監控Secrets與惡意套件。 SCA、Secrets掃描、DLP。
SOC / 資安研究人員 可申請受控存取高風險網站或惡意樣本研究環境。 隔離沙箱、專用帳號、無正式資料。
遠端工作者 透過VPN/ZTNA/SASE/端點代理套用等效網頁過濾。 端點健康檢查與DLP。
供應商 / 承包商 僅允許業務必要網站與核准SaaS，限制資料上傳與個人雲端。 合約、NDA、Session Recording視風險。
高敏感資料處理人員 限制個人Email、檔案分享、AI工具與外部雲端上傳。 DLP、CASB、分層授權。
AI / MLOps人員 僅允許核准AI平台、模型API、資料集來源與雲端服務。 AI工具清單、Prompt與資料監控。
訪客與公共Wi-Fi 訪客網路應與內部網路分離並套用基本惡意網站與非法內容阻擋。 Captive Portal與頻寬限制。

9. AI、SaaS與雲端服務網頁存取管制

服務類型 管制要求 例外核准
生成式AI工具 未核准AI工具預設阻擋或限制；核准工具需資料不訓練、DLP與使用紀錄。 AI Governance / CISO / Data Owner。
AI程式碼輔助工具 需確認不得上傳Secrets、未授權原始碼、客戶資料或高機密資訊。 DevSecOps / AppSec / AI Governance。
雲端儲存 個人雲端預設阻擋或限制上傳；企業核准雲端需CASB與DLP。 Data Owner / CISO。
SaaS應用 依核准清單、資料分類、使用目的與合約審查開放。 SaaS Owner / Supplier Management。
檔案轉換與線上工具 涉及文件上傳、PDF轉換、翻譯、OCR、截圖、壓縮或程式碼格式化之工具需限制。 Data Owner / Security。
外部開發平台 程式碼平台、套件Registry、CI/CD SaaS需與供應鏈安全控制連動。 DevSecOps / AppSec。
社群與協作平台 需限制敏感資料、客戶資料與Secrets發布或上傳。 Business Owner / DLP。
模型API與資料集網站 需確認來源可信、授權、資料分類、惡意模型風險與網域信譽。 AI Governance / Legal。

10. 檔案下載、上傳與內容檢查要求

項目 控制要求 證據
可執行檔下載 對EXE、MSI、Script、Macro、容器映像、套件與壓縮檔下載應掃描或限制。 下載策略與告警。
文件下載 Office、PDF、壓縮檔、影像與未知格式需進行惡意內容與信譽檢查。 SWG掃描報告。
檔案上傳 上傳至雲端、AI、個人Email、社群或檔案分享網站應依資料分類套用DLP。 DLP事件。

加密壓縮檔 無法掃描之加密壓縮檔應限制或隔離。 SWG策略。
未知檔案 未知或低信譽檔案應阻擋、沙箱分析或隔離下載。 Sandbox報告。
AI輸入內容 Prompt、文件上傳與模型API請求應檢查是否含PII、Secrets或高機密資料。 AI/DLP監控紀錄。

11. 例外申請與核准流程

階段 作業要求 責任角色 輸出證據
1. 例外提出 申請人說明URL/網域、分類、用途、使用者、期間、資料類型與業務必要性。 申請人 / Business Owner 例外申請單。
2. 初步檢查 檢查網站信譽、分類、惡意紀錄、資料外傳、供應商與AI風險。 IT Helpdesk / SOC 初步風險檢查。
3. 風險評估 依資料分類、使用者角色、裝置狀態、上傳下載、隱私與合規風險評估。 Network Security / Data Owner / DPO 風險評估紀錄。
4. 補償控制 設定唯讀、禁止上傳、Browser Isolation、DLP、短期開放、特定使用者或監控告警。 Network Security / SOC 補償控制設定。
5. 核准 依風險由Business Owner、CISO、Data Owner、DPO、AI Governance或Legal核准。 核准角色 核准紀錄。
6. 設定與通知 依核准範圍設定例外，通知申請人可用範圍、限制與到期日。 Network Security / IT 變更紀錄。
7. 到期重評 例外到期前重新確認是否仍有必要，未核准續用者自動移除。 Exception Owner 重評紀錄。

13. 日誌、監控與隱私保護要求

控制項目 最低要求 隱私與合規注意
日誌內容 記錄使用者、裝置、來源IP、URL/網域、分類、處置、時間、檔案雜湊、告警ID。 避免記錄不必要內容或完整敏感資料。
日誌保存 依紀錄保存期限清冊保存，支援事件調查與稽核。 保存期限需合理且可說明。
存取限制 網頁存取日誌僅限SOC、Security、稽核或授權調查人員存取。 需角色權限與存取審計。
使用者透明 應透過政策或公告告知網頁存取可能受監控與過濾。 依當地法規與HR政策。
SSL檢查排除 金融、醫療、個人隱私高度敏感網站可依政策排除SSL解密。 需平衡安全與隱私。
告警監控 惡意連線、規避、未知網站、大量下載/上傳、AI工具濫用需告警。 告警不得過度收集個人內容。
調查使用 日誌用於資安、合規、事件、稽核或違規調查，不得任意監控私人行為。 需授權與紀錄。
跨境日誌 若日誌傳輸至境外SaaS或安全平台，需DPO/Legal審查。 DPA與資料地區要求。

14. 網頁過濾事件處理

事件類型 判定條件 處置要求
惡意網站存取 使用者或系統嘗試連線惡意、C2、釣魚或惡意下載網站。 SOC調查端點、封鎖網域、檢查EDR與身份風險。
釣魚連結點擊 使用者點擊釣魚URL或提交憑證跡象。 重設密碼、檢查MFA、通報事件、使用者教育。
資料外傳風險 大量上傳、敏感資料上傳至未核准雲端/AI/Email。 啟動DLP調查、通知Data Owner與DPO。
規避控制 使用匿名代理、Tor、未核准VPN或私人熱點規避網頁過濾。 依違規程序處理並加強端點控制。
惡意下載 下載惡意檔案、低信譽檔案或含惡意Macro文件。 隔離端點、刪除檔案、分析IOC。
AI工具誤用 將Secrets、PII、客戶資料或高機密資料輸入未核准AI服務。 依AI政策與事件程序處理。
誤判封鎖 合法業務網站遭錯誤封鎖。 驗證信譽、暫時例外、回報分類供應商。
供應商濫用 供應商使用組織存取上傳資料或瀏覽未授權網站。 暫停存取、通知Supplier Management與Legal。
