1. 填寫說明與檢核原則

本表單為企業級設備安置安全檢核文件化資訊。設備安置前應確認位置、電力、網路、纜線、門禁、CCTV、消防、空調、維護空間、資產標籤、資料分類、安全組態、供應商進場與支援設施容量。設備安置後應完成驗收、清冊更新、監控接入與缺失改善。Critical/High設備或位於機房、弱電間、資料中心、客戶場址、供應商場址或高敏感區域之設備，應由Facility、IT、Security與相關Owner共同確認。

  • 設備不得放置於未核准、未受控、易受水、火、熱、撞擊、偷竊、旁觀、未授權接觸或環境威脅影響之位置。
  • 設備安置不得阻礙逃生通道、消防設施、空調氣流、機櫃門、維護通道、門禁設備、CCTV視線或電力安全。
  • 設備安置應符合最小暴露原則，避免將敏感設備置於公共區、訪客可接觸區、開放辦公區或不可監控位置。
  • 設備安置若涉及網路連線、電力、支援設施、機櫃、弱電間或供應商施工，應依變更、纜線安全、支援設施與訪客管理要求執行。
  • 所有檢核結果應填寫「符合、不符合、不適用」，不得以空白取代結論；不符合項應建立改善措施、Owner、期限與驗證方式。

無法即時更新圖資 需臨時紀錄、標示與補圖期限。 Network / Facility Owner 最長10個工作日。
供應商設備需長期放置 需合約、NDA、Owner、期限、存取限制、盤點與退場計畫。 Supplier Owner / CISO 至少每季重評。
臨時設備超過期限 需重新核准、風險評估、標示與移除計畫。 Asset Owner / Security 最長30日重評。
